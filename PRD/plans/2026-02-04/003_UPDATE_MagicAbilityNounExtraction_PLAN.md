# PLAN: 마법 권역 어빌리티 명사 추출 및 분류
> **Date:** 2026-02-04
> **Task ID:** 003_UPDATE_MagicAbilityNounExtraction
> **Language:** Korean (Required)

## 1. Objective
이전에 분석한 어절 빈도 리포트(`report/마법권역_어빌리티_어절_빈도_분석.md`)를 기반으로 핵심 '명사'만을 정제하여 추출합니다. 추출된 명사를 통해 실질적인 어빌리티 태그로서의 효용성을 검증합니다.

## 2. Context Analysis
- **Target Files:** `report/마법권역_어빌리티_어절_빈도_분석.md` (이미 생성된 데이터 활용)
- **Current Issue:** 어절 빈도 분석 결과는 조사('~을', '~를', '~으로')가 포함되어 있어 데이터베이스 태그로 즉시 활용하기에는 후처리가 필요함. 명사만 분리해내면 태그화가 용이해짐.

## 3. Strategy
1. **데이터 로드**: `report/마법권역_어빌리티_어절_빈도_분석.md`에서 어절 목록을 읽어옵니다.
2. **명사 추출 로직**: 파이썬의 간단한 정규식 패턴 매칭을 통해 조사(은/는/이/가/을/를/의/로/에/에게/와/과 등)를 제거하고 명사형을 복원합니다.
    - *Note:* 전문 형태소 분석기(Mecab, Kiwi 등)를 사용할 수 없는 환경이므로, 패턴 매칭 방식을 정교하게 사용하여 근사치를 추출합니다.
3. **불용어 처리**: '것', '수', '등'과 같은 의존 명사나 의미가 약한 명사는 필터링합니다.
4. **리포트 생성**: 빈도순으로 정렬된 명사 목록을 생성합니다.

## 4. Impact Analysis
- **Affected Files:** 
    - `report/마법권역_어빌리티_명사_분석.md` (신규 생성)
- **Side Effects:** 패턴 매칭의 한계로 일부 복합 명사나 어미 처리가 완벽하지 않을 수 있으나, 1차 필터링으로는 충분함.
