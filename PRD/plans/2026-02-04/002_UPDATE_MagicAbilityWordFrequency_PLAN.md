# PLAN: 마법 권역 어빌리티 어절 빈도 전수 분석

> **Language:** Korean (Required)

## 1. Objective
마법 권역 어빌리티 설명문을 공백 단위로 분절(Tokenizing)하여 모든 어절의 사용 빈도를 측정합니다. 이를 통해 빈번하게 사용되는 마법적 표현, 상태 변화, 수식어 등을 빠짐없이 파악하여 태그 프로토콜의 완성도를 높입니다.

## 2. Context Analysis
- **Target Files:** `report/마법권역_어빌리티_설명_목록.md`
- **Current Issue:** 이전 분석은 특정 키워드 매칭 위주였으나, 마스터의 제안대로 공백 기준 전수 조사를 실시하여 데이터의 노이즈를 포함한 전체 패턴을 파악할 필요가 있음.

## 3. Strategy
1. **데이터 로드**: 이미 생성된 `report/마법권역_어빌리티_설명_목록.md`에서 모든 설명 텍스트를 가져옵니다.
2. **어절 분리**: 각 설명문을 공백(' ') 단위로 스플릿합니다. (특수문자 제거는 최소화하여 문장 내 실제 사용 형태를 보존합니다.)
3. **빈도 계산**: 모든 어절의 출현 횟수를 카운트합니다.
4. **결과 생성**: 빈도순으로 정렬된 전체 어절 목록 리포트를 생성합니다.

## 4. Impact Analysis
