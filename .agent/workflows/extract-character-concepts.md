---
description: 외부 매체 캐릭터 컨셉 추출
---

1. 사용자에게 분석할 대상(캐릭터, 사물, 아티팩트 등)의 이름과 출처 작품(예: "워크래프트의 아서스 메네실" 또는 "페이트의 성배")을 요청합니다.
2. 웹 검색을 통해 대상의 상세 정보를 수집합니다. 성격/기능, 내력, 능력, 주요 사건에 집중하십시오.
   - 쿼리: `[대상 이름] [출처] 분석 나무위키 특성 능력`
3. 다음의 지침 파일들을 모두 읽고 각 규칙을 숙지합니다:
   - `prompt/02_refinement/extract_concepts_from_character.md` (추출 및 생성 규칙)
   - `prompt/01_creation/create_passive_skill.md` (지속 능력 필수 필드 확인: 계통, 대상, 상태 이상 등)
   - `prompt/01_creation/create_active_skill.md` (발동 능력 필수 필드 확인: 계통, 대상, 피해 유형 등)
4. 검색 결과와 지침을 바탕으로 다음 내용을 포함하는 분석 토큰을 생성합니다:
   - **핵심 컨셉 키워드:** 3~5개 식별.
   - **데이터 생성:** 각 키워드 별로 아래 수량을 엄격히 준수하십시오.
     - **[직접 추출 (Extraction)]**: 원작 반영, **최소 3개 이상**.
     - **[브레인스토밍 (Expansion)]**: 파생 아이디어, **최소 5개 이상**.
   - **속성 필수 기재:** 모든 능력(Skill)은 `계통`, `대상`, `피해 유형`, `상태 이상 유형` 필드를 반드시 포함해야 합니다.
5. 최종 응답 생성 전, 스스로 다음 사항을 검증합니다 (Self-Correction):
   - **[메타데이터]**: 리포트 상단에 `분석 대상`, `출처`, `작성일`, `수정일`, `상태`가 포함된 메타데이터 블록이 있는가?
   - 각 키워드마다 '직접 추출'이 3개 이상인가?
   - 각 키워드마다 '브레인스토밍'이 5개 이상인가?
   - 모든 발동/지속 능력에 `계통`, `대상` 등의 필수 필드가 빠짐없이 기재되었는가?
   - 누락이 있다면 보완하여 최종 응답을 출력하십시오.
   - 모든 출력은 반드시 한글로 작성하십시오.
