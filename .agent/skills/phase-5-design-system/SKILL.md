# phase-5-design-system Skill (bkit Standard)

## Instructions

이 스킬은 프로젝트의 시각적 일관성과 재사용성을 위한 디자인 시스템 구축 지침입니다.

### 🛠️ 수행 단계

1. **디자인 토큰 수립**: 컬러, 간격, 폰트 등 기초 스타일 변수를 정의합니다.
2. **아토믹 컴포넌트 설계**: 버튼, 입력창 등 기본 단위 컴포넌트의 사양을 정의합니다.
3. **산출물 저장**:
    - **경로**: `docs/02-design/`
    - **파일명**: `{YYYY-MM-DD}-design-system-DESIGN.md`

### 📌 규칙
- bkit PDCA의 `Do` 단계(또는 상세 Design) 활동으로 취급됩니다.
- 완료 후 `Recommended` 섹션을 통해 `/phase-6-ui-integration`을 안내합니다.
