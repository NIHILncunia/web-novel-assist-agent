# 기능: 플롯 생성 (`create_plot`)

이 스킬은 시놉시스(Step 4)를 바탕으로, 실제 집필 가능한 단위인 **'아크(Arc)'**와 **'에피소드(Episode)'**를 설계하는 **[Step 6] 플롯 아웃라인** 단계의 작업 지침입니다.

## 1. 개요 및 저장 위치

- **저장 위치:** `01_planning/06_plot_outline.md`
- **템플릿:** `templates/06_story_arc_sheet.md`

## 2. 작업 프로세스

### Phase 1. 총 분량 및 속도 설정
- **총 화수:** 완결 목표 화수 결정 (예: 200화, 300화)
- **전개 속도:** 초반/중반/후반 호흡(Pacing) 전략 수립

### Phase 2. 아크 할당 (Arc Allocation)
- 전체 화수를 덩어리(Arc)로 분할.
- 시놉시스의 기-승-전-결 흐름 매핑.
- 후반부 아크는 '확보된 화수(Slot)'와 '핵심 목표'라도 기재.

### Phase 3. 에피소드 매핑 (Episode Mapping)
- 각 아크별 상세 에피소드 리스트 작성.
- 에피소드는 **'핵심 사건 한 줄 요약'** 형태.
- 아크 마지막에 클라이맥스 배치.

### Phase 4. 페이스 점검
- 강약 조절(고구마/사이다 배분) 점검.

## 3. 인터뷰 지침

| 순서 | 단계 | 질문 예시 |
|:---:|:---|:---|
| 1 | **분량 설정** | "이 작품의 완결 목표 화수는 몇 화로 생각하고 계십니까? (웹소설 표준: 200화 내외)" |
| 2 | **아크 설계** | "시놉시스의 흐름을 고려할 때, 이야기를 크게 몇 개의 챕터(아크)로 나누는 것이 좋을까요? (예: 튜토리얼 15화 -> 아카데미 35화...)" |
| 3 | **세부 매핑** | "[Arc 1]의 구체적인 에피소드를 채워보겠습니다. 주인공이 위기를 겪고 각성하는 과정을 5화 단위로 끊어서 구상해볼까요?" |

## 4. 데이터 저장 지침

1. **템플릿 사용:** `templates/06_story_arc_sheet.md`
2. **저장:** `01_planning/06_plot_outline.md` (프로젝트 폴더 내)
