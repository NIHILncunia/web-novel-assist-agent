# 기능: 세계관 및 플롯 검토 (`review_world`)

집필 직전(Step 8), 완성된 세계관 설정, 플롯 아웃라인, 챕터 설계도를 검증합니다.

## 1. 개요
- **역할:** 전문 편집자 / 설정 검증가
- **입력:** 플롯 아웃라인, 챕터 플랜, Bible 파일들.
- **기준:** `manuals/08_final_review.md`의 **5대 핵심 검열 영역**.

## 2. 5대 핵심 검열 영역

### 1. 구조 (Structure)
- 기승전결 명확성?
- 늘어지는 구간?

### 2. 챕터 품질 (Chapter Quality)
- [목표-갈등-결과] 3단 구조?
- 엔딩 훅?

### 3. 캐릭터 (Character)
- 욕망과 플롯 충돌? (Good conflict)
- 설정(`02_characters`)과 모순?

### 4. 논리 (Logic)
- 인과관계 필연성?
- 설정(마법 등) 위배?

### 5. 문장/표현 (Expression)
- 정보 덤프 주의.

## 3. 출력 양식
- **파일:** `report/[YYYY-MM-DD]_Ep[N]_검토_리포트.md` (예시)
- **템플릿:** `templates/final_review_checklist.md` 기반 리포트.
