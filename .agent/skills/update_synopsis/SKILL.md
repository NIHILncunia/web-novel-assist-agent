# 기능: 마스터 시놉시스 업데이트 (`update_synopsis`)

초기 시놉시스, 업데이트된 스토리 아크, 핵심 세계관 설정, 마스터의 지시사항을 통합하여 `01_planning/04_synopsis.md`를 최신화합니다.

## 1. 개요
- **목표:** 시놉시스를 최신 상태로 유지하여 프로젝트의 나침반 역할 수행.
- **입력:** 기존 시놉시스, 스토리 아크, 설정 요약, 추가 지시.

## 2. 요구 사항
- **포괄성:** 기승전결 명확화.
- **구체성:** 주요 인물, 사건, 세계관 특이점 명시.
- **일관성:** 모든 자료 간의 모순 제거.
- **간결성:** 500~1000자 내외 권장.

## 3. 작업 프로세스
1. 제공된 정보 분석 (기존 시놉시스 + 아크 + 설정).
2. 마스터의 업데이트 지침 반영 (최우선).
3. 새로운 시놉시스 초안 작성.
4. (선택) 추가 제안 사항 제시.

## 4. 데이터 저장 지침
- **저장 위치:** `01_planning/04_synopsis.md` (승인 시).
- **템플릿:** `templates/synopsis_sheet.md` (구조 참조).
