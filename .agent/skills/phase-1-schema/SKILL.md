# phase-1-schema Skill (bkit Standard)

## Instructions

이 스킬은 프로젝트의 근간이 되는 용어와 데이터 구조를 bkit 표준에 맞게 정의하기 위한 지침입니다.

### 🛠️ 수행 단계

1. **용어집(Glossary) 작성**:
    - 도메인 전반에서 사용되는 명칭을 한글/영문 매핑과 함께 정의합니다.
2. **데이터 모델링**:
    - 핵심 엔티티와 관계(ERD), 속성 타입을 정의합니다.
3. **산출물 저장**:
    - **경로**: `docs/01-plan/`
    - **파일명**: `{YYYY-MM-DD}-schema-PLAN.md`

### 📌 규칙
- bkit PDCA의 `Plan` 단계 산출물로 취급됩니다.
- 작성 완료 후 `Recommended` 섹션을 통해 `/development-pipeline next` 또는 `/phase-2-convention`을 수행하도록 안내합니다.
