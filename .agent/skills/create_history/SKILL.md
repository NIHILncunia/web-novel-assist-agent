# 기능: 역사적 사건 생성 (`create_history`)

이 스킬은 세계관의 **역사적 사건, 전쟁, 재난, 쿠데타** 등 과거의 중요 사건을 설계하는 지침입니다. 사건의 원인과 결과를 명확히 하고, 현재 서사에 미치는 영향을 정의합니다.

## 1. 개요 및 저장 위치

- **저장 위치:** `00_bible/07_history/`
- **파일명:** `사건_[이름].md` 또는 `전쟁_[이름].md`
- **템플릿:** `templates/07_history_template.md`

## 2. 인터뷰 프로세스 (6 Axes)

에이전트는 다음 6가지 축(Axis)을 기반으로 인터뷰를 진행합니다.

### Axis 1. 유형 (Type)
- **질문:** "이 사건은 어떤 종류입니까?"
- **옵션:** 전쟁 / 쿠데타 / 혁명 / 재난 / 조약 / 발견 / 암살 / 기타

### Axis 2. 규모 및 시기 (Scale & Time)
- **질문:** "언제, 얼마나 큰 규모로 일어났습니까?"
- **시기:** (예: 100년 전, 제국력 500년, 주인공 출생 직전)
- **규모:** 국지적 / 국가적 / 대륙적 / 세계적

### Axis 3. 원인 (Cause)
- **질문:** "이 사건은 왜 일어났습니까? (필연적 이유)"
- **표면적 이유:** (대중에게 알려진 이유)
- **실제 이유:** (정치적, 개인적, 숨겨진 진실)

### Axis 4. 전개 (Flow)
- **질문:** "사건은 어떻게 진행되었습니까?"
- **발단:** 사건의 시작점 (트리거)
- **전개:** 주요 전투, 갈등의 심화
- **절정:** 승패가 갈린 결정적 순간 (터닝 포인트)
- **결말:** 사건의 종결 방식

### Axis 5. 결과 및 영향 (Result & Impact)
- **질문:** "이 사건은 세계를 어떻게 바꾸어 놓았습니까?"
- **직접적 피해:** 사상자, 지형 변화, 멸망 등
- **사회적 변화:** 제도 변경, 계급 이동, 기술 발전
- **현재와의 연결:** 주인공에게 미치는 영향, 남겨진 유산/후유증

### Axis 6. 왜곡 (Distortion)
- **질문:** "우리가 아는 역사와 진실은 어떻게 다릅니까?"
- **승자의 기록:** 공식적으로 알려진 역사
- **숨겨진 진실:** 실제 일어난 일 (음모, 배신 등)

## 3. 데이터 저장 지침

1. **템플릿 적용:** `templates/07_history_template.md` 사용.
2. **저장:**
   - `00_bible/07_history/` 폴더에 저장.
   - 필요 시 `data/word_list/history.md` (연표)에 요약 추가.
