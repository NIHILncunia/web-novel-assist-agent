# phase-3-mockup Skill (bkit Standard)

## Instructions

이 스킬은 사용자 경험(UX)을 구체화하고 화면 구조를 설계하기 위한 지침입니다.

### 🛠️ 수행 단계

1. **와이어프레임 설계**: 주요 화면의 레이아웃과 컴포넌트 배치를 정의합니다.
2. **사용자 흐름(User Flow)**: 사용자의 행동 시나리오를 단계별로 기술합니다.
3. **산출물 저장**:
    - **경로**: `docs/02-design/`
    - **파일명**: `{YYYY-MM-DD}-mockup-DESIGN.md`

### 📌 규칙
- bkit PDCA의 `Design` 단계 산출물로 취급됩니다.
- 완료 후 `Recommended` 섹션을 통해 `/phase-4-api` 또는 다음 단계로 유도합니다.
