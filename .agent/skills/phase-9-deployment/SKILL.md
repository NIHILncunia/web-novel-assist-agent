# phase-9-deployment Skill (bkit Standard)

## Instructions

이 스킬은 개발이 완료된 기능을 실제 환경에 배포하고 프로젝트 사이클을 최종 마무리하기 위한 지침입니다.

### 🛠️ 수행 단계

1. **배포 실행**: CI/CD 파이프라인을 통해 프로덕션 배포를 수행합니다.
2. **Act (완료 보고)**: 전체 PDCA 사이클을 회고하고 성과 및 개선점을 기록합니다.
3. **산출물 저장**:
    - **경로**: `docs/04-report/`
    - **파일명**: `{YYYY-MM-DD}-deployment-REPORT.md`

### 📌 규칙
- bkit PDCA의 `Act` 단계 산출물로 취급됩니다.
- 완료 후 마스터에게 최종 보고 리포트를 출력하며 신규 프로젝트/태스크 제안을 `Recommended` 섹션에 포함합니다.
