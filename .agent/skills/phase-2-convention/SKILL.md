# phase-2-convention Skill (bkit Standard)

## Instructions

이 스킬은 프로젝트의 코드 품질과 일관성을 유지하기 위한 규칙을 정의하는 지침입니다.

### 🛠️ 수행 단계

1. **명명 규약(Naming)**: 파일, 폴더, 상수, 변수 등에 대한 엄격한 규칙을 수립합니다.
2. **프로젝트 구조**: 레이어별 폴더 구성과 의존성 규칙을 정의합니다.
3. **산출물 저장**:
    - **경로**: `docs/01-plan/`
    - **파일명**: `{YYYY-MM-DD}-convention-PLAN.md`

### 📌 규칙
- bkit PDCA의 `Plan` 단계 산출물로 취급됩니다.
- `PRD/Coding-Rules.md`가 있을 경우 이를 최우선으로 참고하되, 구체적인 기술 스펙은 본 실습에서 보완합니다.
