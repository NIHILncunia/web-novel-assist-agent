# 기능: 국가 생성 (Nation Creation)

> **작성일:** 2026-01-04
> **수정일:** 2026-01-04

## 1. 개요
이 문서는 판타지 세계관 설계를 위한 **국가 데이터 관리자**의 작업 지침입니다. 국가 생성은 총 8개의 축(Axis)에 포함된 **세부 항목(Sub-Axis)**을 인터뷰 형식으로 채워나가는 과정입니다.

---

## 2. 저장 위치 (Storage Location)

국가 설정 파일은 각 소설 작품 폴더 내 `00_bible/05_nations/` 디렉토리에 저장됩니다.

- **저장 경로:** `[프로젝트폴더]/00_bible/05_nations/[Nation_Name].md`
- **예시:** `projects/제국의_검/00_bible/05_nations/국가_카이만제국.md`

**참고:** 
- 작품명이 확정되지 않은 경우 `incubator/[가제_컨셉명]/00_bible/05_nations/` 폴더에 저장
- 작품명 확정 후 `projects/[작품명]/00_bible/05_nations/` 폴더로 이동

---

## 3. 작업 모드 (Operation Modes)

각 **세부 항목(Sub-Axis)**마다 사용자는 다음 두 가지 중 하나를 선택합니다.

1. **지정 (Select):** 사용자가 구체적인 내용이나 키워드를 직접 제시.
2. **위임 (Delegate):** "랜덤", "알아서", "추천해줘" 등. 에이전트가 맥락에 맞춰 제안.

---

## 4. 인터뷰 지침 (Interview Process)

에이전트는 다음 8가지 축을 순차적으로 확인합니다. 사용자의 피로도를 고려하여 관련 있는 항목은 묶어서 질문하십시오.

### Axis 1. 개요 (Overview)
국가의 정체성을 정의하는 첫 단계입니다.

| 세부 항목 | 에이전트 질문 메시지 (Prompt) |
|:---|---|
| **국가 정체성** | 이 국가를 한 문장으로 요약한다면 무엇입니까? (예: "대륙 북부를 지배하는 철혈의 군사 강국") |
| **위치** | 세계관 내에서 이 국가의 지리적 위치는 어디입니까? |
| **인구 규모** | 대략적인 인구 수는 얼마나 됩니까? (소국, 중견국, 대국 등) |
| **핵심 테마** | 이 국가를 대표하는 핵심 가치나 이념은 무엇입니까? (`data/word_list/character/성향가치관.md`를 참조하여 '국가의 기질'을 정의해보세요.) |

### Axis 2. 통치 구조 (Governance Structure)
국가의 정치 체제를 정의합니다.

| 세부 항목 | 에이전트 질문 메시지 (Prompt) |
|:---|---|
| **정치 체제** | 군주제(왕국/제국), 공화제, 신정 정치 등 어떤 형태입니까? |
| **통치자** | 현재 국가를 다스리는 최고 통치자는 누구입니까? (왕, 황제, 대통령 등) 명목상 통치자와 실질 권력자가 다를 수 있습니다. |
| **행정 체계** | 국가의 행정은 어떻게 이루어집니까? (원로원, 의회, 내각 등) 중앙/지방 행정 조직과 관료 체계는 무엇입니까? |
| **법률 체계** | 어떤 법률을 따르며, 법 집행은 어떻게 이루어집니까? 사법 기관과 형벌 제도는 무엇입니까? |

### Axis 3. 국교/이념/정책 (Religion, Ideology & Policies)
국가의 이념과 정책을 정의합니다.

| 세부 항목 | 에이전트 질문 메시지 (Prompt) |
|:---|---|
| **국교/종교** | 국가의 공식 종교나 지배적인 신앙은 무엇입니까? 종교 정책과 종교의 자유도는 어떻습니까? |
| **국가 이념** | 이 국가가 추구하는 핵심 가치나 사상은 무엇입니까? 건국 이념과 통치 철학은 무엇입니까? |
| **주요 정책** | 현재 국가가 중점적으로 추진하는 정책은 무엇입니까? 핵심 법률, 제도, 사회 정책은 무엇입니까? |
| **금기/금지 사항** | 국가적으로 금지되거나 터부시되는 것이 있습니까? 탄압 대상이나 이단 취급을 받는 것은 무엇입니까? |

### Axis 4. 대외 관계 (Foreign Relations)
다른 국가와의 관계를 정의합니다.

| 세부 항목 | 에이전트 질문 메시지 (Prompt) |
|:---|---|
| **외교 정책** | `data/traits/12_외교.md`를 참조하여 국가의 외교적 성향(예: 패권주의, 고립주의)을 정의하십시오. 기본 외교 방침과 원칙은 무엇입니까? |
| **동맹국** | 긴밀한 협력 관계에 있는 국가가 있습니까? 동맹 내용과 협력 분야는 무엇입니까? |
| **적대국** | 대립하거나 전쟁 중인 국가가 있습니까? 갈등 원인과 전쟁/분쟁 이력은 무엇입니까? |
| **중립국/무역 파트너** | 중립을 유지하거나 주요 무역 대상국은 어디입니까? 경제 교류는 어떻게 이루어집니까? |

### Axis 5. 내부 갈등 (Internal Conflicts)
국가 내부의 갈등을 정의합니다.

| 세부 항목 | 에이전트 질문 메시지 (Prompt) |
|:---|---|
| **계급 갈등** | 사회 계층 간의 갈등이 있습니까? 신분/계급 간 갈등과 사회 불평등은 무엇입니까? |
| **종교 갈등** | 다른 종교나 이단과의 갈등이 있습니까? 교파 분열이나 이단 문제는 무엇입니까? |
| **지역 갈등** | 특정 지역 간의 대립이나 불만이 있습니까? 지방 분리주의나 중앙-지방 갈등은 무엇입니까? |
| **권력 다툼** | 통치 계층 내부의 권력 다툼이 있습니까? 후계자 문제나 쿠데타 가능성은 무엇입니까? |

### Axis 6. 경제/문화/사회 (Economy, Culture & Society)
국가의 경제, 문화, 사회를 정의합니다.

| 세부 항목 | 에이전트 질문 메시지 (Prompt) |
|:---|---|
| **경제** | 주요 산업, 화폐 체계, 무역 구조, 경제력 수준은 무엇입니까? |
| **문화** | 문화적 특색, 음식/의상, 축제/의식, 예술/문학 등 문화적 특징은 무엇입니까? |
| **사회** | `data/traits/` 폴더를 참조하여 국민들의 보편적 기질(예: 전투 민족, 예술가적 기질)을 정의하십시오. 사회 구조, 계급 체계, 교육 제도, 사회 복지는 무엇입니까? |
| **군사력** | 병력 규모, 주력 병종, 군사 기술 수준은 무엇입니까? 방어 체계는 어떻게 구성되어 있습니까? |

### Axis 7. 역사적 사건 (Historical Events)
국가와 관련된 역사적 맥락을 정의합니다.

| 세부 항목 | 에이전트 질문 메시지 (Prompt) |
|:---|---|
| **과거 사건** | 국가의 건국이나 주요 전환점과 관련된 역사적 사건이 있습니까? 전쟁, 정변, 관련 인물은 무엇입니까? |
| **연관 사건** | 관련된 다른 사건이 있습니까? 그 사건이 이 국가에 어떤 영향을 미쳤습니까? |
| **현재 상태** | 과거 사건으로 인해 현재 이 국가의 모습이 어떻게 변화했습니까? |

### Axis 8. 비고 (Notes)
추가 설정을 정의합니다.

| 세부 항목 | 에이전트 질문 메시지 (Prompt) |
|:---|---|
| **전설** | 국가와 관련된 유명한 전설이나 예언이 있습니까? |
| **서사적 떡밥** | 나중에 밝혀질 예정인 설정이나 떡밥이 있습니까? |
| **연관 문서** | 이 국가와 관련된 다른 설정 문서(인물, 지역, 단체 등)가 있습니까? |

## 6. 데이터 저장 지침

### 6-1. 저장 위치

국가 설정 파일은 각 소설 작품 폴더 내 `00_bible/05_nations/` 디렉토리에 저장됩니다.

- **저장 경로:** `[프로젝트폴더]/00_bible/05_nations/[Nation_Name].md`
- 작품명이 확정되지 않은 경우 `incubator/[가제_컨셉명]/00_bible/05_nations/` 폴더에 저장
- 작품명 확정 후 `projects/[작품명]/00_bible/05_nations/` 폴더로 이동

### 6-2. 저장 규칙

1. **중복 확인:** 동일한 이름의 국가가 이미 존재하는지 확인합니다.
2. **연관 문서:** 관련된 다른 설정 문서(지역, 조직, 인물 등)가 있으면 연관문서 필드에 링크합니다.
3. **영토 범위:** 국가의 영토 범위를 명확히 하여 지도상 배치가 가능하도록 합니다.

## 7. 작업 프로세스 요약

1. **국가 타입 결정:** 새로운 국가 생성 또는 기존 국가 수정

3. **템플릿 적용:** 완성된 내용을 템플릿 형식에 맞춰 작성
4. **저장:** 지정된 저장 경로에 파일 생성
5. **가이드 확인:** `manuals/05-05_nations_guide.md`의 체크리스트로 최종 검토
