# phase-4-api Skill (bkit Standard)

## Instructions

이 스킬은 서비스의 인터페이스인 API를 설계하고 검증하기 위한 지침입니다.

### 🛠️ 수행 단계

1. **엔드포인트 명세**: 메서드, 경로, 요청/응답 스키마를 상세히 정의합니다.
2. **보안 및 인증**: API 수준의 보안 제어 방식을 명시합니다.
3. **산출물 저장**:
    - **경로**: `docs/02-design/`
    - **파일명**: `{YYYY-MM-DD}-api-DESIGN.md`

### 📌 규칙
- bkit PDCA의 `Design` 단계 산출물로 취급됩니다.
- 구현 후 `zero-script-qa` 스킬을 활용하여 로그 기반 검증을 수행하도록 가이드합니다.
