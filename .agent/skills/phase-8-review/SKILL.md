# phase-8-review Skill (bkit Standard)

## Instructions

이 스킬은 구현된 결과물의 품질을 bkit 아키텍처 및 컨벤션 표준에 따라 검증하기 위한 지침입니다.

### 🛠️ 수행 단계

1. **품질 검사(Check)**: 코드 분석기를 활용하여 복잡도와 정적 분석을 수행합니다.
2. **Gap 분석**: 최초 설계(Plan/Design)와 실제 구현(Do) 사이의 일치율을 계산합니다.
3. **산출물 저장**:
    - **경로**: `docs/03-analysis/`
    - **파일명**: `{YYYY-MM-DD}-review-ANALYSIS.md`

### 📌 규칙
- bkit PDCA의 `Check` 단계 산출물로 취급됩니다.
- 일치도 점수가 90% 이상일 경우에만 `Act` 단계로 진입 가능함을 마스터에게 보고합니다.
