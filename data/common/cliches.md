# 장르 클리셰 & 트로프 라이브러리 (Genre Clichés & Tropes)

> **설명:** 웹소설 각 장르에서 빈번하게 사용되는 전형적인 설정, 전개, 장치들을 정리한 라이브러리입니다. 이를 활용하여 익숙한 재미와 신선한 비틀기를 동시에 설계할 수 있습니다.

---

## 1. 판타지 (Fantasy)

| 클리셰/트로프 | 설명 | 비틀기 아이디어 (Twist) |
| :--- | :--- | :--- |
| **선택받은 용사** | 신이나 운명에 의해 세상을 구할 존재로 점지됨. | 용사가 사실은 마왕이 보낸 간첩이거나, 운명이 조작된 경우. |
| **아카데미물** | 재능 있는 주인공이 학교에 입학하여 성장하고 인맥을 쌓음. | 교수가 주인공보다 무능하거나, 학교 자체가 거대한 감옥인 경우. |
| **회빙환 (회환빙)** | 회귀, 빙의, 환생을 통해 정보를 선점하고 성장함. | 미래를 알고 있지만, 본인이 개입할수록 미래가 절망적으로 변함. |
| **드래곤** | 세계관 최강자이자 지혜로운 조력자 혹은 적. | 드래곤이 사실은 매우 게으르거나, 인간에게 아첨하며 사는 경우. |

## 2. 무협 (Murim)

| 클리셰/트로프 | 설명 | 비틀기 아이디어 (Twist) |
| :--- | :--- | :--- |
| **기연 (Lucky Encounter)** | 비급이나 영물을 얻어 단숨에 고수가 됨. | 기연을 얻었으나 그 부작용으로 인간성을 상실하거나 몸이 변형됨. |
| **정사대전** | 정파와 사파의 거대한 전쟁. | 정파가 사파보다 더 사악하고, 사파의 수장이 알고 보니 대협인 경우. |
| **폐관수련** | 외부와 단절한 채 무공을 연마함. | 수련하고 나왔더니 세상이 멸망해 있거나, 수련에 실패해 주화입마에 빠짐. |
| **정체 은닉** | 고수가 정체를 숨기고 점소이나 노비로 은거함. | 끝까지 정체를 숨기려다 무공이 녹슬어버린 경우. |

---

## 3. 현대판타지 (Modern Fantasy)

| 클리셰/트로프 | 설명 | 비틀기 아이디어 (Twist) |
| :--- | :--- | :--- |
| **상태창/시스템** | 현대인에게 게임 시스템이 부여됨. | 시스템이 주인공을 속이고 있거나, 시스템 명령이 점차 악의적으로 변함. |
| **던전/게이트** | 도심 한복판에 괴물이 쏟아지는 통로가 생김. | 던전이 사실은 외계 문명의 관광 상품이거나 쇼핑몰인 경우. |
| **헌터/성좌** | 선택받은 자들이 초월적인 존재의 후원을 받음. | 성좌들이 서로 간식 내기하듯 인간을 소모품으로 다루는 비극. |
| **재벌가 서자** | 멸시받던 서자가 재능이나 회귀로 가문을 장악함. | 가문을 장악했더니 가문 자체가 파산 직전인 경우. |

---

## 4. 주인공 시작 유형 (Starter Archetypes)

- **[먼치킨형]**: 압도적인 실력으로 모든 장애물을 부수는 통쾌함 중점.
- **[성장형]**: 처절한 패배와 수련을 거쳐 점진적으로 강해지는 서사 중점.
- **[지능형/책략가]**: 힘보다는 두뇌와 정보, 심리전을 이용해 상황을 조절함.
- **[착취형/악당형]**: 도덕적 관념보다는 개인의 이득과 목적을 위해 수단을 가리지 않음.
