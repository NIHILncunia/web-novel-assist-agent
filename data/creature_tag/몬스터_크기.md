# 몬스터 생물 크기 (Creature Size)

> **작성일:** 2026-01-04
> **수정일:** 2026-01-04

## 설명
"이 존재는 공간을 얼마나 차지하는가?"

전투 맵에서의 점유 공간, 은신 용이성, 물리적 압박감 등 크기와 관련된 메커니즘을 정의합니다.

## 키워드 목록

| 특성 이름 | 특성 설명 |
|:---:|---|
| 생물크기/초소형(Tiny) | 2.5ft (약 75cm) 이하의 아주 작은 크기. (예: 고양이, 까마귀, 임프, 요정) |
| 생물크기/소형(Small) | 2.5~5ft (75cm ~ 1.5m) 정도의 작은 크기. (예: 고블린, 하프링, 코볼트) |
| 생물크기/중형(Medium) | 5ft (1.5m ~ 2m) 내외의 인간과 유사한 크기. (예: 인간, 오크, 드워프, 엘프) |
| 생물크기/대형(Large) | 10ft (3m) 내외의 큰 크기, 2x2 칸 차지. (예: 오거, 말, 트롤, 사자) |
| 생물크기/거대(Huge) | 15ft (4.5m) 내외의 매우 큰 크기, 3x3 칸 차지. (예: 힐 자이언트, 트리앤트, 성체 드래곤) |
| 생물크기/초대형(Gargantuan) | 20ft (6m) 이상의 압도적인 크기, 4x4 칸 이상. (예: 크라켄, 에이션트 드래곤, 타라스크) |
