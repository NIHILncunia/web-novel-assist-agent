# 몬스터 감각 특성 (Creature Senses Traits)

> **작성일:** 2026-01-04
> **수정일:** 2026-01-04

## 설명
"이 존재는 어떤 방식으로 주변을 인지하는가?"

스탯 블록의 Senses를 명시적으로 분류합니다. 감각 능력은 탐지, 추적, 전투에서 중요한 역할을 합니다.

## 키워드 목록

| 특성 이름 | 특성 설명 |
|:---:|---|
| 어둠 시야 | 이 생물은 어둠 속에서도 볼 수 있습니다 |
| 초감각 | 이 생물은 초자연적인 감각을 가집니다 |
| 진동 감지 | 이 생물은 땅의 진동을 감지합니다 |
| 진실 시야 | 이 생물은 환영을 뚫고 진실을 봅니다 |
| 예리한 후각 | 이 생물은 매우 예리한 후각을 가집니다 |
| 예리한 청각 | 이 생물은 매우 예리한 청각을 가집니다 |
| 예리한 시야 | 이 생물은 매우 예리한 시야를 가집니다 |
| 마법 감지 | 이 생물은 마법을 감지할 수 있습니다 |
