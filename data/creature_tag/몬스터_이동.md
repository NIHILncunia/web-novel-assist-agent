# 몬스터 이동 특성 (Creature Mobility Traits)

> **작성일:** 2026-01-04
> **수정일:** 2026-01-04

## 설명
"이 존재는 어떤 방식으로 이동하는가?"

스탯 블록의 Speed와 이동 방식(비행, 수영, 굴착 등)을 명시적으로 분류합니다. 이동 능력은 전투 스타일과 서사적 묘사에 중요한 요소입니다.

## 키워드 목록

| 특성 이름 | 특성 설명 |
|:---:|---|
| 지상 이동 | 이 생물은 지상에서 이동합니다 |
| 비행 | 이 생물은 날아서 이동합니다 |
| 수영 | 이 생물은 물속에서 이동합니다 |
| 굴착 | 이 생물은 땅을 파고 이동합니다 |
| 등반 | 이 생물은 벽이나 나무를 타고 이동합니다 |
| 텔레포트 | 이 생물은 순간이동으로 이동합니다 |
| 차원 이동 | 이 생물은 차원을 넘나들며 이동합니다 |
