# D&D 용어 번역 및 표기 가이드

> **작성일:** 2026-01-04
> **수정일:** 2026-01-04

이 문서는 D&D 룰북의 용어를 소설 집필에 적합한 자연스러운 한국어로 변환하기 위한 기준을 제시합니다.
**기계적인 직역보다는 장르 소설의 통용어나 문맥에 맞는 의역을 우선합니다.**

## 1. 차원 및 장소 (Planes & Places)

## 3. 어빌리티 및 트레잇 (Abilities & Traits)

| 원문 (English) | 직역/기존 번역 | **권장 번역 (Novel Style)** | 비고 |
| :--- | :--- | :--- | :--- |
| **Armor Class (AC)** | 방어 등급 | **방어력, 껍질의 단단함** | 수치보다는 '단단한 비늘', '민첩한 회피' 등으로 묘사. |
| **Hit Points (HP)** | 생명력 | **생명력, 맷집** | - |
| **Saving Throw** | 내성 굴림 | **저항, 내성** | '굴림'이라는 게임 용어 삭제. (예: 독 내성굴림 -> 독 저항력) |
| **Check** | 판정, 체크 | **어빌리티, 감각** | (예: 지혜(인식) 체크 -> 예리한 감각) |
| **Advantage** | 유리함 | **탁월함, 능숙함** | (예: 은신 체크에 유리함 -> 은신에 매우 능숙함) |
| **Disadvantage** | 불리함 | **취약함, 서툼** | - |
| **Resistance** | 저항 | **내성, 강함** | 반감(전투룰)보다는 '잘 견딤'으로 묘사. |
| **Immunity** | 면역 | **면역, 통하지 않음** | - |
| **Vulnerability** | 취약성 | **약점, 치명적임** | - |
| **Legendary Action** | 전설적 행동 | **초월적 반응, 전설적인 위용** | 턴 제약 없이 행동하는 것을 '반응 속도가 빠르다' 등으로 묘사. |
| **Lair Action** | 둥지 행동 | **둥지의 이점, 지형 활용** | - |

## 4. 번역 원칙

1.  **게임 용어의 서사화:** `Action`, `Bonus Action`, `Reaction` 등의 턴 기반 용어는 "순식간에", "동시에", "반격하여" 등의 서사적 표현으로 풀어씁니다.
2.  **수치 제거:** 거리(ft), 시간(round/minute), 무게(lb) 등의 구체적 수치는 "가까운 거리", "잠시 동안", "육중한" 등으로 상대적이고 묘사적인 표현으로 대체합니다. (단, 소설적 설정상 구체적 수치가 중요한 경우 제외)
3.  **고유 명사:** 몬스터 이름이나 지명은 한글 표기를 원칙으로 하되, 괄호 안에 영문을 병기하여 레퍼런스의 정확성을 유지합니다.
## 5. 명명 규칙 (Naming Conventions)

### 5-1. 드래곤 (Dragons)

| 원문 구조 (English) | 표기 원칙 (Korean) | 예시 (Example) | 비고 |
| :--- | :--- | :--- | :--- |
| **Color/Metal + Dragon** | **[색상/재질] 드래곤** (음차) | Red Dragon -> **레드 드래곤** | '붉은 용' (X) |
| **Age + Dragon** | **[드래곤 종] [연령]** | Adult Red Dragon -> **레드 드래곤 성체** | 연령은 뒤로 보냄. |
| **Ancient + Dragon** | **에인션트 [드래곤 종]** | Ancient Red Dragon -> **에인션트 레드 드래곤** | 고룡급은 수식어를 앞으로. |
