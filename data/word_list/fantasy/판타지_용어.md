# 판타지 용어 (Fantasy)

> **작성일:** 2026-01-06
> **수정일:** 2026-01-07

| 분류 | 키워드 | 설명 | 예문 |
|:---:|:---:|---|---|
| 에너지 | **마나 (Mana)** | 자연계에 존재하는 마법의 근원 에너지를 지칭하는 보편적 용어. 대기 중에 흐르거나 생명체 내부에 축적된다. | "대기 중의 마나가 요동치기 시작했다." |
| 에너지 | **오러 (Aura)** | 육체의 생명 에너지를 정제하여 외부로 표출하는 힘. 주로 기사나 전사 계열이 사용하며, 마나와 대비되는 개념으로 쓰인다. | "검 끝에 푸른 오러 블레이드가 맺혔다." |
| 에너지 | **신성력 (Divine Power)** | 신에게서 빌려오거나 신앙심을 통해 발현되는 성스러운 힘. 치유와 정화, 언데드 퇴치에 특화되어 있다. | "사제의 손에서 따스한 신성력이 흘러나왔다." |
| 에너지 | **마기 (Demonic Energy)** | 마족이나 마수가 사용하는 탁하고 파괴적인 에너지. 일반적인 생명체에게는 맹독과 같다. | "짙은 마기가 숲을 뒤덮어 식물들이 말라죽었다." |
| 기술/체계 | **마법 (Magic)** | 마나를 특정 공식(수식, 주문)을 통해 물리적 현상으로 구현하는 기술. | "그는 3서클 파이어볼 마법을 시전했다." |
| 기술/체계 | **서클 (Circle)** | 마법사의 경지를 나타내는 척도. 심장 근처에 형성된 마나 고리의 개수로 등급을 나눈다. (보통 1~9서클) | "7서클 대마법사의 위엄은 압도적이었다." |
| 기술/체계 | **연공법 (Cultivation Method)** | 마나나 오러를 체내에 받아들이고 정제하여 쌓는 수련법. 호흡법이나 명상을 포함한다. | "가문 대대로 내려오는 연공법을 익혀야 한다." |
| 기술/체계 | **마법진 (Magic Circle)** | 마법을 발동하거나 특정 공간을 제어하기 위해 바닥이나 허공에 그리는 복잡한 도형. | "바닥에 그려진 거대한 은빛 마법진이 빛을 발하기 시작했다." |
| 기술/체계 | **영창/주문 (Chant/Incantation)** | 마법의 힘을 이끌어내거나 제어하기 위해 외우는 특별한 구절이나 단어. | "긴 영창 끝에, 하늘에서 거대한 운석이 떨어졌다." |
| 기술/체계 | **소환마법 (Summoning Magic)** | 정령, 악마, 혹은 다른 차원의 존재를 현실 세계로 불러내는 마법 체계. | "그는 고위 악마를 소환하기 위한 위험한 의식을 거행했다." |
| 기술/체계 | **강령술 (Necromancy)** | 죽은 자의 시체를 되살려 조종하거나 영혼과 소통하는 흑마법의 한 갈래. | "강령술사는 해골 병사들을 일으켜 전방으로 내보냈다." |
| 기술/체계 | **연금술 (Alchemy)** | 물질의 본질을 연구하고 변환하여 새로운 물질이나 비약을 만들어내는 고대의 기술. | "연금술의 궁극적인 목표는 납을 황금으로 바꾸는 것이었다." |
| 기술/체계 | **마법부여 (Enchantment)** | 무기, 방어구, 장신구 등의 아이템에 영구적인 마법 효과를 부여하는 기술. | "성검은 '언데드 추가 대미지' 마법부여가 되어 있었다." |
| 기술/체계 | **룬 문자 (Runes)** | 각각의 문자가 고유한 힘을 지닌 고대의 문자. 조합하여 마법진을 그리거나 마법을 발동한다. | "고대 유적의 석판에는 해독할 수 없는 룬 문자가 새겨져 있었다." |
| 현상 | **폭주 (Rampage/Overload)** | 통제할 수 없는 마나나 감정으로 인해 힘이 멋대로 분출되어 파괴적인 상태가 되는 것. | "마나 폭주로 인해 그의 혈관이 터져나갔다." |
| 현상 | **침식 (Erosion)** | 마기나 저주, 혹은 이계의 기운이 서서히 대상의 정신이나 육체를 오염시키는 현상. | "마검을 쥔 팔부터 검은색으로 침식되기 시작했다." |
| 현상 | **공명 (Resonance)** | 영혼, 마나, 혹은 아티팩트가 서로 반응하여 증폭되거나 특별한 현상을 일으키는 것. | "두 자루의 검이 서로 공명하며 웅웅거리는 소리를 냈다." |
| 신체기관 | **단전 (Dantian)** | 기(氣)나 마나를 저장하는 신체 내부의 가상의 공간. 배꼽 아래(하단전)나 심장(중단전), 머리(상단전)에 위치한다. | "단전에 뜨거운 기운이 뭉치기 시작했다." |
| 신체기관 | **마나 홀/코어** | 마나를 저장하는 기관. 단전과 유사한 개념이나, 서양 판타지나 헌터물에서 '코어'라는 용어로 자주 쓰인다. | "마나 코어가 파괴되면 마법사로서의 생명은 끝이다." |
| 아이템 | **아티팩트 (Artifact)** | 마법적 처리가 되어 특별한 능력을 가진 도구. 고대 유물이나 던전에서 발견되는 경우가 많다. | "이 반지는 은신 마법이 걸려 있는 희귀 아티팩트다." |
| 아이템 | **마석 (Magic Stone)** | 마수가 죽은 뒤 남기는 결정체 혹은 마나가 응축된 광석. 에너지원이나 화폐로 쓰인다. | "오우거를 잡고 획득한 마석은 꽤 비싼 값에 팔린다." |
| 아이템 | **인벤토리 (Inventory)** | 물건을 아공간에 저장할 수 있는 능력이나 시스템. 짐을 들고 다니지 않아도 되어 편리하다. | "그는 인벤토리에서 거대한 대검을 꺼내 들었다." |
| 아이템 | **스킬북 (Skill Book)** | 사용하면 특정 스킬을 배울 수 있는 마법적인 책. 던전 보상으로 주로 나온다. | "경매에서 희귀 스킬북 '메테오'가 천문학적인 가격에 낙찰되었다." |
| 아이템 | **성물 (Holy Relic)** | 신의 힘이 깃들어 있거나 성녀/성자가 사용하던 신성한 물건. | "교황청은 잃어버린 성물을 되찾기 위해 원정대를 파견했다." |
| 아이템 | **마도구 (Magic Tool)** | 생활 편의나 통신, 이동 등을 위해 마법을 공학적으로 적용하여 만든 도구. 문명 수준을 보여준다. | "통신 마도구를 이용해 수도에 긴급 연락을 취했다." |
| 아이템 | **촉매 (Catalyst)** | 마법의 위력을 강화하거나 연금술 반응을 일으키기 위해 필요한 보조 재료. | "드래곤의 심장은 그 자체로 최고의 마법 촉매다." |
| 시스템 | **상태창 (Status Window)** | 게임 UI처럼 자신의 능력치(스탯), 스킬 등을 눈으로 확인할 수 있는 반투명한 창. | "눈앞에 파란색 상태창이 떠올랐다." |
| 시스템 | **스킬 (Skill)** | 특정 행동이나 능력이 시스템에 의해 정형화된 것. 숙련도에 따라 등급이 오르기도 한다. | "[검술 Lv.3] 스킬을 획득했습니다." |
| 시스템 | **클래스 (Class)** | 개인의 직업이나 역할군. 전직을 통해 상위 클래스로 성장한다. | "네크로맨서 클래스로 전직하시겠습니까?" |
| 시스템 | **던전 (Dungeon)** | 몬스터가 출몰하고 보상이 숨겨져 있는 위험한 구역. 게이트를 통해 연결되기도 한다. | "서울 한복판에 S급 던전이 발생했다." |
| 시스템 | **게이트 (Gate)** | 현대 사회에 몬스터나 던전을 연결하는 차원의 문. 주로 현대 판타지(헌터물)의 핵심 설정. | "강남역 상공에 나타난 거대한 보라색 게이트에서 마수들이 쏟아져 나오기 시작했다." |
| 시스템 | **각성자 (Awakened)** | 평범한 인간이었으나 특별한 계기로 마나, 스킬 등 초능력을 각성한 존재. | "생사의 위기에서 그는 S급 각성자로 눈을 떴다." |
| 시스템 | **헌터 (Hunter)** | 각성자 중 게이트나 던전에 들어가 마수를 사냥하고 마석을 채취하는 것을 직업으로 삼는 사람. | "그는 세계 랭킹 1위 헌터이자 '국가권력급' 전략 병기였다." |
| 시스템 | **랭크 (Rank)** | 헌터나 던전, 몬스터의 강함을 나타내는 등급. S, A, B, C, D, E, F 등으로 나뉜다. | "고작 C급 게이트에서 A급 보스 몬스터가 나타날 줄은 아무도 몰랐다." |
| 존재 | **정령 (Spirit)** | 자연의 구성 요소(불, 물, 바람, 땅 등)가 의인화된 존재. 정령사와 계약하여 힘을 빌려준다. | "바람의 정령이 내 귓가에 속삭였다." |
| 존재 | **마수/몬스터** | 마나나 마기의 영향으로 변이되거나, 이계에서 넘어온 괴물. | "마수들이 성벽을 향해 돌진해왔다." |
| 존재 | **마왕 (Demon King)** | 마족의 왕이자 악의 정점. 단순한 우두머리를 넘어 재앙을 불러오는 절대적인 상징. | "마왕의 부활이 임박했다." |
| 존재 | **용사 (Hero)** | 마왕을 물리칠 운명을 타고난 영웅. 단순한 직업이 아닌, 시대를 구원할 상징적 존재. | "용사만이 마왕을 죽일 수 있다." |
| 조직 | **길드 (Guild)** | 모험가, 헌터, 용병들이 모여 만든 이익 집단. 의뢰를 중개하고 세력을 형성한다. | "그는 국내 최대 길드인 '제우스'의 스카우트 제의를 받았다." |
| 조직 | **헌터 협회** | 각성자와 헌터를 관리하고 지원하며, 게이트를 통제하는 공공기관 또는 국제기구. | "헌터 협회는 이번 사건의 위험 등급을 최고 수준으로 격상했다." |
| 조직 | **마탑 (Mage Tower)** | 마법사들의 연구소이자 거주지, 도서관 역할을 하는 거대한 탑. 강력한 마법사들이 탑주로 있다. | "대륙의 모든 마법사는 마탑에 소속되는 것을 꿈꾼다." |
| 조직 | **기사단 (Knightly Order)** | 국왕이나 특정 신, 혹은 신념을 위해 헌신하는 무장 조직. | "성기사단 '빛의 방패'는 제국의 가장 강력한 무력이었다." |
| 조직 | **암살 길드 (Assassin's Guild)** | 돈을 받고 암살을 청부받아 처리하는 비밀스러운 범죄 조직. '그림자 길드' 등으로 불린다. | "왕의 갑작스러운 죽음 뒤에는 암살 길드의 소행이라는 소문이 돌았다." |
| 장소 | **결계 (Barrier/Ward)** | 외부의 간섭을 차단하거나 특정 존재의 출입을 막기 위해 설치한 마법적인 장벽. | "마탑 주변에는 강력한 결계가 쳐져 있어 개미 새끼 한 마리도 들어갈 수 없다." |
| 장소 | **성소 (Sanctuary)** | 신성한 기운이 가득 차 있어 사악한 존재가 접근할 수 없는 보호받는 구역. | "상처 입은 용사는 성소로 피신해 안식을 취했다." |
| 장소 | **심연 (Abyss)** | 세상의 밑바닥, 끝을 알 수 없는 깊은 어둠이나 그런 공간. 보통 강력한 마물이나 고대의 악이 잠들어 있다. | "심연을 들여다보면 심연 또한 너를 들여다볼 것이다." |
| 장소 | **마경 (Demonic Realm)** | 마기가 너무 짙어 동식물이 기괴하게 변이하고 인간이 생존하기 힘든 위험 지역. | "북부 마경에는 아직 밝혀지지 않은 몬스터들이 득실거린다." |
| 장소 | **유적 (Ruins)** | 고대 문명의 흔적이 남아 있는 폐허. 보물이나 잃어버린 마법(로스트 테크놀로지)이 숨겨져 있다. | "사막 한가운데서 고대 왕국의 유적이 발견되었다." |
| 장소 | **아공간 (Dimension/Subspace)** | 현실 공간과 겹쳐져 있지만 분리된, 물리 법칙이 다르게 적용될 수 있는 특수한 공간. | "대마법사는 아공간을 열어 자신의 서재를 숨겨두었다." |
| 개념 | **이계 (Another World)** | 현실과는 다른 차원이나 세상. 차원문을 통해 이동하거나 몬스터가 넘어오는 곳. | "이계의 침략자들을 막아내야 한다." |
| 개념 | **마계 (Demon World)** | 마족들이 거주하는 차원. 마기가 가득 차 있으며, 가혹한 환경인 경우가 많다. | "마계의 문이 열렸다." |
| 개념 | **정령계 (Spirit World)** | 정령들이 태어나고 살아가는 차원. 자연의 순수한 힘으로 이루어져 있다. | "정령왕이 사는 정령계로 소환되었다." |
| 개념 | **원소계 (Elemental Plane)** | 불, 물, 바람, 땅 등 특정 원소만이 존재하는 극단적인 차원. | "화염의 원소계에서는 숨쉬기조차 힘들다." |
| 개념 | **회귀 (Regression)** | 죽음이나 특정 사건 후 과거의 시점으로 돌아가는 현상. 미래의 기억을 가지고 있다. | "눈을 떠보니 10년 전, 훈련소 입소 날이었다." |
| 개념 | **빙의 (Possession)** | 다른 사람(주로 소설이나 게임 속 등장인물)의 몸에 영혼이 들어가는 현상. | "내가 쓴 소설 속 악역 조연에 빙의했다." |
| 개념 | **환생 (Reincarnation)** | 죽은 후 다른 존재로 다시 태어나는 것. | "전생의 기억을 가진 채 제국의 황자로 환생했다." |
| 개념 | **마나 역류 현상** | 게이트가 불안정해지거나 던전 브레이크 시 발생하는 현상. 마나가 현실 세계로 넘쳐흐르며 주변을 오염시키고 변이시킨다. | "마나 역류 현상으로 인해 서울 전역의 통신이 마비되었다." |
| 개념 | **세계수 (World Tree)** | 여러 차원이나 세계를 연결하는 중심축 역할을 하는 신성한 나무. | "엘프들은 세계수의 가지 위에 도시를 짓고 살아간다." |
| 개념 | **고대 문명 (Ancient Civilization)** | 지금은 사라졌지만, 현대보다 월등히 발전된 마법이나 기술을 가졌던 초고대 문명. | "유적 깊은 곳에서 고대 문명의 유산인 '아티팩트'가 발견되었다." |
| 개념 | **예언 (Prophecy)** | 미래에 일어날 중대한 사건에 대한 신탁이나 계시. 종종 모호한 내용으로 되어 있다. | "'별이 떨어지는 날, 마왕이 부활하리라'는 예언이 전해져 내려왔다." |
| 개념 | **계약 (Contract)** | 인간이 정령, 마족, 신 등 초월적인 존재와 힘을 빌리기 위해 맺는 구속력 있는 약속. | "그는 악마와 계약하여 강력한 힘을 얻었지만, 대가로 영혼을 바쳤다." |
| 개념 | **저주 (Curse)** | 대상에게 고통이나 불행을 가져오는 악의적인 마법. 풀기 매우 어렵다. | "가보로 내려오던 목걸이에는 탐욕스러운 자를 파멸시키는 저주가 걸려있었다." |
| 개념 | **인과율 (Causality)** | 원인과 결과의 법칙. 마법이나 시간 여행 등에서 거스르기 힘든 세계의 절대적인 이치로 묘사된다. | "죽은 자를 되살리는 것은 인과율을 거스르는 금기다." |
| 개념 | **진명 (True Name)** | 존재의 본질을 담고 있는 진짜 이름. 진명을 알면 대상에게 절대적인 명령을 내릴 수 있다. | "악마의 진명을 부르자 그가 고통스러워하며 무릎을 꿇었다." |
| 개념 | **금기 (Taboo)** | 신이나 마법의 법칙에 의해 절대 해서는 안 되는 행위. 어길 시 끔찍한 대가가 따른다. | "그는 힘을 얻기 위해 금기를 어기고 영혼을 팔았다." |
| 개념 | **위계 (Hierarchy)** | 마족이나 몬스터, 혹은 귀족 사회에서 힘이나 신분에 따라 절대적으로 나누어지는 서열. | "상위 마족의 위계에 눌려 하급 마족들은 꼼짝도 할 수 없었다." |
| 개념 | **속성 (Attribute/Element)** | 불, 물, 바람, 땅, 빛, 어둠 등 마법이나 몬스터가 가진 고유한 에너지의 성질. | "화염 속성 몬스터에게는 얼음 마법이 효과적이다." |
| 개념 | **상성 (Compatibility)** | 속성 간의 우열 관계(물은 불에 강함 등). 전투의 유불리를 결정한다. | "상성에서 밀리면 실력이 좋아도 고전할 수밖에 없다." |
| 장르 | **정통 판타지 (High Fantasy)** | 완전히 가상의 세계를 배경으로 하며, 마법과 이종족이 존재하는 장르. 반지의 제왕이 대표적. | "엘프와 드워프가 공존하는 중간계." |
| 장르 | **퓨전 판타지 (Fusion Fantasy)** | 판타지와 무협, 혹은 현대물 등 서로 다른 장르가 결합된 형태. | "무림 고수가 판타지 세계로 넘어갔다." |
| 장르 | **헌터물 (Hunter/Raid)** | 현대 사회에 던전과 몬스터가 등장하고, 각성자(헌터)들이 이를 사냥하는 장르. | "S급 헌터로 각성하여 세상을 구한다." |
| 장르 | **어반 판타지 (Urban Fantasy)** | 현대 도시를 배경으로 뱀파이어, 마법사 등 초자연적 존재가 암약하는 장르. | "서울의 밤거리를 배회하는 뱀파이어 헌터." |
| 장르 | **다크 판타지 (Dark Fantasy)** | 꿈도 희망도 없는 어둡고 절망적인 분위기의 판타지. 주인공이 굴러야 제맛. | "이 세계에서 선의는 약점일 뿐이다." |
| 장르 | **게임 판타지 (Game Fantasy)** | 가상현실 게임 속에서 벌어지는 모험을 다루는 장르. 상태창과 시스템이 필수 요소. | "로그아웃이 불가능한 데스 게임이 시작되었다." |
| 장르 | **로맨스 판타지 (Romance Fantasy)** | 판타지 세계관(주로 서양 귀족 사회)을 배경으로 한 로맨스물. 빙의나 회귀가 자주 쓰인다. | "폭군 황제의 유일한 이해자가 되었다." |
| 장르 | **스팀펑크 (Steampunk)** | 증기기관 문명과 마법 혹은 오버 테크놀로지가 결합된 레트로한 미래상. | "증기 로봇과 비공정이 하늘을 뒤덮었다." |
