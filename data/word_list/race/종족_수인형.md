# 수인형

| 분류 | 키워드명 | 설명 | 예문 |
|:---:|:---:|---|---|
| 종족 | 수인 | 동물의 특징을 지닌 인간형 종족 (통칭) | "수인족은 종류에 따라 다양한 신체 특성을 지닌다" |
| 종족 | 비스트맨 | 짐승의 특성이 강한 야만적인 수인 | "비스트맨은 도구보다는 날카로운 발톱을 믿는다" |
| 종족 | 묘인족 (캐트시) | 고양이의 특성(귀, 꼬리)을 지닌 수인 | "묘인족은 높은 곳에서 떨어져도 소리 없이 착지한다" |
| 종족 | 낭인족 (울프람) | 늑대의 특성을 지닌 수인, 부족 단위 생활 | "낭인족 전사들은 무리지어 사냥할 때 가장 강력하다" |
| 종족 | 호인족 (타이가) | 호랑이 특성을 지닌 수인, 강력한 무력 | "호인족은 산군(山君)이라 불리며 숲을 지배한다" |
| 종족 | 웅인족 (베어킨) | 곰의 특성을 지닌 수인, 우직하고 강력함 | "웅인족의 앞발 후려치기는 바위도 부순다" |
| 종족 | 묘족 (토끼) | 토끼 특성을 지닌 수인, 청력이 좋고 빠름 | "묘족은 겁이 많지만 위험을 감지하는 능력이 탁월하다" |
| 종족 | 여우족 | 여우의 특성을 지닌 수인, 구미호 등 | "여우족은 환술에 능하고 꼬리 개수로 마력을 가늠한다" |
| 종족 | 조인족 (아라크로아) | 새의 날개나 머리를 가진 종족 | "조인족은 높은 절벽에 둥지를 틀고 살아간다" |
| 종족 | 켄타우로스 | 상반신은 인간, 하반신은 말 | "켄타우로스 기병대는 그 자체로 완벽한 기동력을 자랑한다" |
| 종족 | 미노타우로스 | 황소 머리와 인간 몸을 가진 종족 | "미노타우로스는 한번 길을 막으면 절대 비키지 않는다" |
| 종족 | 리자드맨 | 도마뱀 특성을 가진 파충류형 수인 | "리자드맨은 늪지대 전투에서 타의 추종을 불허한다" |
| 종족 | 코볼트 | 개 또는 용의 형상을 한 소형 수인 | "코볼트들은 광산 깊은 곳에서 희귀한 광물을 캔다" |
| 종족 | 놀 (Gnoll) | 하이에나 형상의 수인 | "놀의 기괴한 웃음소리가 전장을 가득 메웠다" |
| 종족 | 라미아 | 상반신은 인간, 하반신은 뱀 | "라미아는 사막의 열기 속에서 사냥감을 조인다" |
| 종족 | 나가 | 여러 개의 팔이나 뱀의 하반신을 가진 종족 | "네 개의 팔에 검을 든 나가가 춤추듯 공격해왔다" |
| 종족 | 하피 | 새의 날개와 발톱을 가진 여성형 종족 | "하피의 날카로운 비명이 고막을 찢을 듯 울려 퍼졌다" |
| 종족 | 아라크네 | 상반신은 인간, 하반신은 거미 | "아라크네는 끈적한 거미줄로 침입자를 포박했다" |
| 종족 | 스킬라 | 하반신이 여러 마리의 괴수나 촉수로 된 종족 | "스킬라의 촉수들이 배를 감아 부서뜨렸다" |
| 종족 | 늑대인간 (웨어울프) | 보름달 밤이나 의지에 따라 늑대로 변신하는 인간 | "그는 평범한 인간처럼 보였으나, 달이 뜨자 야수로 돌변했다" |
| 종족 | 곰인간 (웨어베어) | 곰으로 변신하는 인간, 치유력이 뛰어남 | "상처 입은 웨어베어는 곰으로 변해 빠르게 회복했다" |
| 종족 | 쥐인간 (웨어랫) | 쥐로 변신하는 인간, 은신과 잠입에 능함 | "웨어랫은 하수구를 통해 도시 어디든 갈 수 있다" |
| 종족 | 시프터 | 동물적 특징을 일부 발현하거나 변신하는 종족 | "시프터는 순간적으로 피부를 경화시키거나 손톱을 길게 뽑아낸다" |
| 종족 | 스킨워커 | 동물 가죽을 뒤집어써 그 동물로 변신하는 주술사 | "스킨워커는 죽은 늑대의 가죽을 쓰고 어둠 속으로 사라졌다" |
| 종족 | 라이칸스로프 | 수인성 바이러스/저주에 걸린 변신 종족의 학명 | "라이칸스로프에게 물리면 저주가 전염된다" |
