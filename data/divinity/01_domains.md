# 신격 도메인 (Deity Domains)

> **설명:** 신이 관장하는 권능의 영역(Domain) 목록입니다.
> **정렬:** **[우주/근원]**에서 시작하여 **[자연]**, **[생명]**, **[정신]**, **[문명]**, **[추상 개념]** 순으로 신격의 탄생 순서에 따라 정렬되었습니다.

---

## 1단계. 태초: 우주와 법칙 (The Primordial)
> 존재하기 이전의 상태, 세계를 구성하는 절대적인 법칙.

| 이름 (영문) | 분류 | 관장하는 것 | 설명 |
| :--- | :--- | :--- | :--- |
| **공허/망각 (Oblivion)** | 우주 | 무(Emptiness), 소멸, 잊혀짐, 끝 | 모든 존재와 기억이 사라진 절대적인 허무. |
| **혼돈 (Chaos)** | 개념 | 무질서, 변덕, 변화, 가능성 | 정해진 규칙 없이 끊임없이 변화하는 예측 불가의 상태. |
| **질서 (Order)** | 개념 | 규율, 체계, 조직, 법칙 | 혼란을 잠재우고 규칙과 안정을 세우는 힘. |
| **엔트로피 (Entropy)** | 우주 | 무질서, 붕괴, 열역학, 종말 | 질서가 무너지고 무작위성이 증가하는 우주의 경향. |
| **시간 (Time)** | 우주 | 세월, 노화, 영원, 순간, 흐름 | 멈추지 않고 흐르며 만물을 변화시키는 우주의 법칙. |
| **우주/천체 (Cosmos)** | 우주 | 별, 행성, 공허, 달, 천문 | 대기권 밖의 광활한 공간과 그 안의 별들. |
| **균형 (Balance)** | 개념 | 중용, 조화, 대칭, 중립 | 어느 한쪽으로 치우치지 않는 평형 상태를 유지함. |
| **예언/운명 (Fate)** | 우주 | 점술, 숙명, 미래, 인과율 | 정해진 미래를 미리 보거나 그 흐름을 읽는 힘. |

## 2단계. 창세: 원소와 자연 (The Elements)
> 세계의 물질적 기반이 되는 원소와 자연 현상.

| 이름 (영문) | 분류 | 관장하는 것 | 설명 |
| :--- | :--- | :--- | :--- |
| **어둠 (Darkness)** | 자연 | 밤, 그림자, 은신, 공포 | 빛이 없는 상태이자 미지의 것을 감추는 장막. |
| **빛 (Light)** | 자연 | 광휘, 태양, 낮, 시야 | 어둠을 몰아내고 세상을 비추는 에너지. |
| **공기/바람 (Air/Wind)** | 자연 | 하늘, 비행, 구름, 산소 | 자유롭게 흐르는 대기와 하늘을 지배하는 힘. |
| **금속/대지 (Earth/Metal)** | 자연 | 땅, 바위, 동굴, 보석, 광물 | 단단한 지반과 그 속에 묻힌 광물질의 견고함. |
| **물/바다 (Water/Ocean)** | 자연 | 해양, 파도, 비, 강, 흐름 | 모든 생명의 근원이자 파괴적인 힘을 가진 유체. |
| **불/화염 (Fire)** | 자연 | 열기, 소각, 마그마, 화산 | 문명을 태동시키기도 하고 모든 것을 태워버리기도 하는 에너지. |
| **폭풍 (Storm)** | 자연 | 천둥, 번개, 태풍, 기상 | 강력한 바람과 번개를 동반하여 세상을 휩쓰는 힘. |
| **겨울/냉기 (Winter/Cold)** | 자연 | 눈, 서리, 얼음, 혹한 | 생명 활동을 멈추게 하는 차가움과 계절의 혹독함. |
| **광야/자연 (Nature/Wild)** | 자연 | 숲, 식물, 야생, 초목, 동물 | 문명의 손이 닿지 않은 원초적인 생태계 그 자체. |
| **재난 (Cataclysm)** | 자연 | 대재앙, 파멸, 멸망, 지진 | 인간의 힘으로 막을 수 없는 거대한 파괴의 파동. |

## 3단계. 태동: 생명과 죽음 (Life & Death)
> 물질 위에서 꿈틀거리는 생명력과 그 필연적인 끝.

| 이름 (영문) | 분류 | 관장하는 것 | 설명 |
| :--- | :--- | :--- | :--- |
| **생명 (Life)** | 자연 | 치유, 성장, 부활, 활력 | 태어나고 자라며 살아숨쉬는 모든 에너지. |
| **죽음 (Death)** | 자연 | 사신, 종말, 끝, 수명 | 모든 생명체의 필연적인 끝이자 순환의 고리. |
| **피 (Blood)** | 자연 | 혈통, 생명력, 희생, 폭력 | 생명을 유지하는 붉은 액체이자 핏줄로 이어지는 유대. |
| **부패/쇠락 (Decay)** | 자연 | 타락, 썩음, 몰락, 오염 | 생명과 물질이 무너져 흙으로 돌아가는 과정. |
| **점액 (Slime)** | 자연 | 슬라임, 산성, 젤리, 부식 | 형태가 없고 끈적이며 무엇이든 녹이는 물질. |
| **역병 (Plague)** | 자연 | 질병, 전염병, 바이러스, 세균 | 생명을 갉아먹고 퍼져나가는 미시적인 재앙. |
| **용 (Dragon)** | 초자연| 드래곤, 파충류, 위엄, 힘 | 강력한 힘과 지혜를 가진 신화적인 파충류 종족. |
| **영혼 (Soul)** | 초자연| 정령, 유령, 에테르, 본질 | 육체와 분리되어 존재하는 생명의 근원적 에너지. |
| **신비/마법 (Magic)** | 개념 | 비전, 룬, 의식, 마력, 초자연 | 물리 법칙을 초월하여 현상을 조작하는 지식. |

## 4단계. 발현: 정신과 감정 (Mind & Emotion)
> 생명체가 지성을 갖추며 생겨난 내면의 세계.

| 이름 (영문) | 분류 | 관장하는 것 | 설명 |
| :--- | :--- | :--- | :--- |
| **각성 (Awakening)** | 정신 | 깨달음, 자각, 개안, 통찰 | 무지를 깨우치고 진실이나 잠재력을 자각하는 순간. |
| **의지 (Will)** | 정신 | 인내, 끈기, 저항, 생존본능 | 고난에도 굴하지 않고 자신을 지키는 정신력. |
| **공포 (Fear/Nightmare)** | 정신 | 악몽, 전율, 트라우마, 위협 | 생명체가 본능적으로 느끼는 두려움과 심연의 공포. |
| **고문/고통 (Torture/Pain)** | 행위 | 가학, 피학, 징벌, 신체적 고통 | 육체적, 정신적 고통을 주거나 견디는 잔혹한 영역. |
| **광기 (Madness)** | 정신 | 정신착란, 혼란, 이성 상실 | 논리와 이성이 무너진 카오스 상태의 정신. |
| **꿈 (Dream)** | 정신 | 환상, 잠, 무의식, 예지 | 수면 중에 펼쳐지는 환상 세계와 무의식의 영역. |
| **기억 (Memory)** | 정신 | 회상, 기록, 역사, 보존 | 지나간 시간의 흔적을 보존하고 되새기는 능력. |
| **통찰 (Insight)** | 정신 | 꿰뚫어봄, 직감, 심안 | 겉모습 너머의 본질이나 숨겨진 의도를 간파함. |
| **분노 (Rage/Anger)** | 감정 | 격노, 화, 증오, 파괴 충동 | 이성을 마비시키는 폭발적인 감정의 에너지. |
| **사랑/매혹 (Love/Charm)** | 감정 | 아름다움, 유혹, 연애, 정욕 | 타인을 끌어당기고 마음을 뺏는 강렬한 감정. |
| **절망 (Despair)** | 감정 | 좌절, 포기, 슬픔, 무력감 | 희망이 사라져 더 이상 나아갈 힘을 잃은 상태. |
| **희망 (Hope)** | 감정 | 기대, 염원, 빛, 기도 | 절망적인 상황에서도 나아질 것이라는 믿음. |
| **용기 (Courage)** | 감정 | 담력, 대담함, 의지 | 두려움에 맞서 나아가는 강인한 마음. |
| **감정 (Empathy/Passion)** | 정신 | 공감, 열정, 애정, 욕망 | 타인의 마음에 공명하거나 강렬한 마음의 동요를 일으킴. |

## 5단계. 구축: 문명과 사회 (Civilization & Society)
> 인간(지성체)이 모여 사회를 이루며 만들어낸 개념들.

| 이름 (영문) | 분류 | 관장하는 것 | 설명 |
| :--- | :--- | :--- | :--- |
| **공동체 (Community)** | 문명 | 사회, 협력, 단결, 마을 | 개인이 모여 이룬 집단의 조화와 결속. |
| **가정/화로 (Hearth)** | 문명 | 난로, 가족, 집, 안식처 | 가족의 안녕과 집안의 불씨를 지키는 따뜻한 보호의 영역. |
| **지식 (Knowledge)** | 문명 | 지혜, 사고, 진리, 도서관, 연구| 세상을 이해하고 정보를 축적하여 활용하는 힘. |
| **가공/제작 (Artifice/Forge)** | 문명 | 기술, 대장간, 장치, 산업, 노동 | 무에서 유를 창조하고 도구를 만드는 기술과 노동의 영역. |
| **건설/계획 (Planning)** | 문명 | 전략, 설계, 건축, 구조 | 체계적으로 미래를 설계하고 물리적 구조물을 세우는 지혜. |
| **기계 (Clockwork)** | 문명 | 시계, 톱니바퀴, 공학, 자동화 | 정밀하게 맞물려 돌아가는 장치와 규칙적인 작동. |
| **교역/부 (Wealth/Trade)** | 문명 | 번영, 탐욕, 재물, 상업, 화폐 | 재화의 흐름과 축적, 경제적 이득을 관장함. |
| **연금술 (Alchemy)** | 문명 | 변환, 포션, 물질 연구, 등가교환| 물질의 성질을 이해하고 변화시키는 탐구의 영역. |
| **음악/예술 (Art/Music)** | 문명 | 소리, 노래, 시, 창작, 미학 | 감정을 표현하고 아름다움을 창조하는 행위. |
| **전쟁 (War)** | 문명 | 전투, 전술, 무력, 군대 | 집단 간의 무력 충돌과 승리를 위한 전략. |
| **정치/지배 (Dominion)** | 문명 | 귀족, 통치, 권력, 리더십 | 타인을 이끌고 다스리며 권위를 행사하는 힘. |
| **사냥 (Hunt)** | 행위 | 추적, 포식, 야성, 생존 | 먹이 사슬의 정점에서 대상을 쫓고 잡는 행위. |
| **살인 (Murder)** | 행위 | 암살, 도살, 피, 죽음 | 타인의 생명을 의도적으로 끊는 폭력적인 행위. |
| **사후/무덤 (Grave)** | 개념 | 안식, 장례, 영혼전령, 매장 | 죽음 이후의 안식과 시신을 처리하는 예법. |

## 6단계. 성찰: 관념과 가치 (Concepts & Ideals)
> 문명이 고도화되며 정의된 추상적인 가치와 이념.

| 이름 (영문) | 분류 | 관장하는 것 | 설명 |
| :--- | :--- | :--- | :--- |
| **심판/정의 (Justice)** | 개념 | 법, 판결, 공정, 처벌 | 옳고 그름을 가리고 죄를 묻는 사회적 기준. |
| **평화 (Peace)** | 개념 | 안녕, 중재, 비폭력, 고요 | 갈등과 전쟁이 없는 평온하고 안전한 상태. |
| **미덕/선 (Good/Virtue)** | 개념 | 선행, 도덕, 자비, 이타심 | 올바르고 도덕적인 행동과 선한 의지. |
| **악 (Evil/Vice)** | 개념 | 악덕, 죄악, 비열함, 타락 | 도덕적 타락과 남을 해하려는 악한 의지. |
| **해방/자유 (Freedom)** | 개념 | 혁명, 탈출, 독립, 방랑 | 억압과 구속에서 벗어나 스스로의 의지대로 행동함. |
| **영광/명예 (Glory)** | 개념 | 영웅, 승리, 자부심, 평판 | 위업을 달성하여 얻는 찬사와 드높은 이름. |
| **충성 (Loyalty)** | 개념 | 맹세, 서약, 신의, 복종 | 주군이나 신념을 배신하지 않고 끝까지 따르는 마음. |
| **철학/사상 (Philosophy)** | 문명 | 이념, 신념, 종교, 가치관 | 세상을 바라보는 관점과 정신적인 믿음의 체계. |
| **수호/보호 (Protection)** | 행위 | 방어, 피난처, 요새, 안전 | 위협으로부터 대상을 지키고 감싸는 힘. |
| **결속/우정 (Friendship)** | 개념 | 유대, 동료애, 신의 | 개인과 개인을 이어주는 끈끈한 관계와 믿음. |
| **경쟁 (Rivalry)** | 개념 | 대립, 승부, 도전, 라이벌 | 서로를 뛰어넘으려 하는 투쟁심과 발전적인 대립. |
| **비밀 (Secrets)** | 개념 | 은밀, 첩보, 숨겨진 진실, 음모 | 드러나지 않은 정보와 감춰진 지식. |
| **거짓/속임수 (Trickery)** | 개념 | 환영, 착시, 사기, 도둑, 비밀 | 진실을 가리고 남을 현혹하거나 은밀하게 행동하는 재주. |
| **불화 (Discord)** | 개념 | 갈등, 불협화음, 이간질, 혼란 | 조화를 깨뜨리고 분쟁을 일으키는 균열. |
| **가난 (Poverty)** | 개념 | 빈곤, 결핍, 부족 | 물질적 곤궁함과 그로 인한 고통 혹은 청빈함. |
| **축제 (Revelry)** | 문명 | 연회, 쾌락, 술, 유흥 | 삶의 고단함을 잊고 즐거움과 쾌락을 탐닉함. |
| **여행/방랑 (Travel)** | 행위 | 길, 탐험, 문, 자유 | 정처 없이 떠돌거나 목적지를 향해 나아가는 과정. |
| **순수/정화 (Purity)** | 개념 | 청정, 신성, 소독, 무결 | 더러움이나 사악함을 씻어내고 본질을 회복함. |
| **제물/희생 (Sacrifice)** | 행위 | 공물, 헌신, 대가, 성스러움 | 더 큰 가치를 위해 소중한 것을 바치는 행위. |
| **복수 (Vengeance)** | 행위 | 응징, 보복, 심판, 원한 | 받은 만큼 되돌려주는 인과응보와 집요한 추적. |
| **운/행운 (Luck)** | 개념 | 도박, 우연, 기회, 확률 | 예측할 수 없는 결과가 자신에게 유리하게 작용함. |

## 7단계. 이계: 초자연적 존재 (The Supernatural)
> 세계의 변두리 혹은 뒤편에 존재하는 신화적 존재들.

| 이름 (영문) | 분류 | 관장하는 것 | 설명 |
