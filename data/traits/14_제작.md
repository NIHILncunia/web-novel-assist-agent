# 14. 제작 (Production)

> **설명:** 무기, 도구, 건축물 등을 **제작(Crafting)**하거나, 이를 뒷받침하는 **학문적 지식(Academics)** 및 **생산 기술(Technology)**과 관련된 트레잇입니다.
> 직업(Role)이나 재능(Passive)이 아닌, **'습득하여 구사하는 기술 및 지식'**을 의미합니다.

---

### 제작 및 학문 목록

| 키워드 | 분류 | 설명 |
| :--- | :---: | :--- |
| **채집술 (Gathering)** | 자원 | 숲이나 들판에서 유용한 약초, 버섯, 열매 등을 식별하고 손상 없이 채취하는 기술. |
| **채광술 (Mining)** | 자원 | 광맥을 찾아내고 곡괭이 등 도구를 이용해 광석, 보석, 마석을 채굴하는 기술. |
| **벌목술 (Logging)** | 자원 | 나무의 결을 읽어 효율적으로 벌목하고, 목재로 쓰기 좋은 상태로 다듬는 기술. |
| **무두질 (Tanning)** | 자원 | 동물의 가죽을 벗겨내고 약품 처리하여 가죽 제품의 재료로 만드는 가공 기술. |
| **도축술 (Butchery)** | 자원 | 사냥한 동물이나 몬스터를 해체하여 고기, 뼈, 가죽 등 부위별로 나누는 기술. |
| **낚시술 (Fishing)** | 자원 | 물고기의 습성을 이해하고 낚싯대나 그물을 이용해 수산물을 획득하는 기술. |
| **야금술 (Metallurgy)** | 학문/기술 | 광석에서 순수한 금속을 추출하고 합금을 만드는 비율과 온도 조절에 관한 지식 및 기술. |
| **제련술 (Smelting)** | 기술 | 금속을 녹여 불순물을 제거하고 원하는 형태의 주괴(Ingot)로 만드는 기술. |
| **직조술 (Weaving)** | 기술 | 실을 뽑아내고 베틀 등을 이용해 천이나 마법 원단을 짜는 기술. |
| **염색술 (Dyeing)** | 기술 | 천연 재료나 마법 염료를 사용하여 천, 가죽 등에 색을 입히는 기술. |
| **석공술 (Masonry)** | 기술 | 돌을 정교하게 깎고 다듬어 건축 자재나 조각상으로 만드는 기술. |
| **목공술 (Carpentry)** | 기술 | 나무를 자르고 끼워 맞추어 가구, 건물, 도구 등을 만드는 기술. |
| **대장 기술 (Blacksmithing)** | 기술 | 망치와 모루를 이용해 금속을 단조하여 무기나 갑옷을 제작하거나, 파손된 장비를 수리하는 기술. |
| **세공술 (Jewelry Crafting)** | 기술 | 보석을 커팅하고 귀금속을 섬세하게 가공하여 장신구나 마법 매개체를 만드는 기술. |
| **마도구 제작 (Magic Item Crafting)** | 기술 | 물건에 마력을 불어넣거나 마법진을 새겨 마법 도구(아티팩트)를 제작하는 기술. |
| **유리 공예 (Glassblowing)** | 기술 | 유리를 녹여 병, 렌즈, 연금술 실험 도구 등을 만드는 기술. |
| **도예술 (Pottery)** | 기술 | 흙을 빚어 그릇이나 도자기를 만들고 구워내는 기술. |
| **가죽 공예 (Leatherworking)** | 기술 | 가죽을 재단하고 바느질하여 경갑, 가방, 신발 등을 만드는 기술. |
| **마물 조리술 (Monster Cooking)** | 기술 | 독이나 저주가 깃든 마물 식재료를 안전하게 손질하고 맛있는 요리로 승화시키는 특수 조리법. |
| **고급 조리술 (Haute Cuisine)** | 기술 | 최상급 식재료를 사용해 맛뿐만 아니라 섭취 시 버프 효과를 주는 요리를 만드는 기술. |
| **양조술 (Brewing)** | 기술 | 곡물이나 과일을 발효시켜 술을 빚거나, 특수한 효능이 있는 음료를 만드는 기술. |
| **마도 공학 (Magic Engineering)** | 학문 | 마법과 기계 공학을 결합하여 골렘, 마동력 기관 등을 설계하고 제작하는 학문. |
| **기계 공학 (Mechanical Engineering)** | 학문 | 톱니바퀴, 증기 기관, 레버 등 물리적 장치의 구조를 이해하고 설계하는 학문. |
| **연금술 (Alchemy)** | 학문 | 물질의 구성 원리를 이해하고 변환하거나, 포션 및 현자의 돌을 연구하는 학문. |
| **약초학 (Herbalism)** | 학문 | 식물의 약효와 독성을 연구하여 치료제나 독극물을 조제하는 지식. |
| **마물학 (Monsterology)** | 학문 | 몬스터의 생태, 습성, 약점, 부산물의 가치를 연구하는 학문. |
| **해부학 (Anatomy)** | 학문 | 생체 구조, 근육, 뼈, 장기의 위치를 이해하여 의료나 전투(치명타)에 응용하는 지식. |
| **독물학 (Toxicology)** | 학문 | 자연계 및 인공 독의 성분을 분석하고 해독제나 치명적인 독을 제조하는 지식. |
| **무기 공학 (Weapon Engineering)** | 학문 | 무기의 타격 메커니즘, 밸런스, 재질 역학을 연구하여 무기를 개량하거나 설계하는 학문. |
| **건축 공학 (Architecture)** | 학문 | 하중, 구조, 미학을 고려하여 튼튼하고 기능적인 건물을 설계하는 학문. |
| **마석학 (Manastone Science)** | 학문 | 마력의 원천인 마석의 파장과 효율, 가공법을 연구하는 학문. |
| **고문학 (Paleography)** | 학문 | 고대 문자, 비석, 문서 등을 해석하여 잊혀진 역사나 기술을 복원하는 학문. |
| **도면 해독 (Blueprint Reading)** | 기술 | 복잡한 설계도나 지도를 정확하게 이해하고 입체적으로 시각화하는 기술. |
| **지도 제작술 (Cartography)** | 기술 | 탐험한 지형의 거리, 고저차, 랜드마크를 측량하여 정확한 지도를 그려내는 기술. |
| **원예술 (Gardening)** | 기술 | 식물의 생장 조건을 조절하여 희귀 약초나 관상용 식물을 최상급으로 길러내는 기술. |
| **함정 설치 (Trap Crafting)** | 기술 | 주변 재료를 이용해 포획용, 살상용 함정을 설계하고 설치하는 기술. |
| **위조술 (Forgery)** | 기술 | 문서, 신분증, 화폐 등을 원본과 구별할 수 없을 정도로 정교하게 복제하는 기술. |
| **암호학 (Cryptography)** | 학문 | 정보를 숨기기 위해 암호를 만들거나, 복잡한 암호 체계를 논리적으로 해독하는 지식. |
| **자물쇠 기술 (Locksmithing)** | 기술 | 복잡한 잠금 장치를 설계하거나 해제하고, 보안 시설을 구축하는 기술. |
| **시계 공학 (Clockwork Engineering)** | 학문/기술 | 태엽과 톱니바퀴를 이용해 시계, 오르골, 자동 인형을 만드는 초정밀 기술. |
| **재봉술 (Tailoring)** | 기술 | 직조된 천을 재단하여 의복, 로브, 가방 등을 제작하는 기술. |
| **제화술 (Cobbling)** | 기술 | 발의 형태에 맞춰 신발과 부츠를 제작하거나 수리하여 이동 효율을 높이는 기술. |
| **식품 보존 (Preservation)** | 기술 | 염장, 훈제, 건조 등을 통해 식량의 부패를 막고 휴대용 식량(Ration)을 만드는 기술. |
| **제빵술 (Baking)** | 기술 | 오븐과 발효 기술을 이용해 빵, 과자, 건빵 등을 대량 생산하는 기술. |
| **선박 건조 (Shipwrighting)** | 기술 | 목공과 방수 기술을 종합하여 배를 설계하고 건조하는 거대 산업 기술. |
| **공성 공학 (Siege Engineering)** | 학문/기술 | 투석기, 발리스타, 공성추 등 거대 전쟁 병기를 설계하고 제작하는 학문. |
| **폭파 공학 (Demolitions)** | 기술 | 화약과 폭발물을 배합하여 구조물을 파괴하거나 광산을 개척하는 위험한 기술. |
| **총기 제작 (Gunsmithing)** | 기술 | 정밀 금속 가공과 화약 배합을 통해 총기와 탄약을 제작하고 정비하는 기술. |
| **필사 (Scribing)** | 기술 | 마법 주문을 스크롤에 옮겨 적거나, 중요 문서를 보존 처리하여 사본을 만드는 기술. |
| **마법 문신 (Magic Tattooing)** | 기술 | 마력이 담긴 잉크로 피부에 문양을 새겨 영구적인 버프나 능력을 부여하는 시술. |
| **룬 조각 (Runecrafting)** | 기술 | 돌이나 금속에 고대 룬 문자를 새겨 장비에 영구적인 마법 효과를 고정하는 기술. |
| **골공예 (Bone Carving)** | 기술 | 몬스터나 용의 뼈를 깎아 금속만큼 단단한 무기나 갑옷, 장신구를 만드는 기술. |
| **영혼 결속 (Soul Binding)** | 학문/기술 | 영혼을 사물에 가두어 지성 아이템을 만들거나 골렘의 동력원으로 삼는 금기 기술. |
| **연단술 (Pill Refining)** | 학문/기술 | 약초와 기(Qi)를 응축하여 영구적 능력 상승을 주는 단약(Elixir)을 정제하는 기술. |
| **부적 제작 (Talisman Crafting)** | 기술 | 특수한 종이와 먹으로 주문을 봉인하여 일회용 마법 도구나 결계를 만드는 기술. |
| **진법 (Formation)** | 학문/기술 | 지형지물이나 영석을 배치하여 특정 구역에 지속적인 마법 효과(방어, 환각)를 부여하는 기술. |
| **악기 제작 (Luthier)** | 기술 | 나무, 현, 가죽 등을 다루어 연주용 악기를 정교하게 제작하는 예술적 기술. |
| **고고학 (Archaeology)** | 학문 | 유적을 발굴하고 유물의 연대와 가치를 감정하며 잃어버린 문명을 연구하는 학문. |
| **문장학 (Heraldry)** | 학문 | 가문이나 국가의 문장을 식별하고 도안을 제작하여 신분을 증명하는 학문. |
| **도구 수리 (Tool Repair)** | 기술 | 전투 중이나 휴식 시 장비의 내구도를 간단하게 응급 처치하여 유지함. |
| **고문 기술자 (Torturer)** | 제작 | 대상에게 영원한 고통을 주거나 육체를 기괴하게 변형시키는 고문의 기술에 통달함. |
| **모듈식 설계** | 제작 | 건물이나 장비에 호환 가능한 부속품을 달아 기능을 확장하거나 변경할 수 있는 설계 사상. |
| **대량 생산** | 제작 | 단일 개체를 정성들여 키우는 것이 아니라, 한 번에 수십, 수백 마리의 유체를 동시에 부화시킨다. |
