# 15. 속성 (Attributes)

> **설명:** 어빌리티나 공격이 갖는 **근원적 성질(Element)**이나 **피해 유형(Damage Type)**을 정의하는 트레잇입니다.
> `create_ability` 스킬의 피해 유형 목록을 기준으로 합니다.

---

## 속성 목록

| 키워드 | 분류 | 유발 상태 이상 (Induced Status Effects) | 설명 |
| :--- | :---: | :--- | :--- |
| **물리 (Physical)** | 물리 | 넉백, 넘어짐, 골절 | 순수한 질량과 운동 에너지에 기반한 기본 속성. |
| **참격 (Slashing)** | 물리 | 출혈, 심층 창상, 신체 훼손 | 날카로운 날로 베거나 가르는 속성. 출혈을 유발하기 쉬움. |
| **관통 (Piercing)** | 물리 | 출혈, 방어구 관통 | 뾰족한 것으로 뚫거나 찌르는 속성. 갑옷을 뚫는 데 유리함. |
| **타격 (Bludgeoning)** | 물리 | 기절, 골절, 넉백 | 둔탁한 힘으로 내리치거나 부수는 속성. 뼈를 부수거나 경직을 줌. |
| **화염 (Fire)** | 원소 | 화상 | 고열로 태우는 불의 속성. 지속적인 화상 피해를 입힘. |
| **냉기 (Ice/Cold)** | 원소 | 동상, 동결, 둔화 | 열을 앗아가고 얼리는 얼음 속성. 이동 속도 저하나 동결을 유발. |
| **전기 (Lightning)** | 원소 | 감전, 마비, 기절 | 전류를 흘려 감전시키는 번개 속성. 마비나 기절을 유발. |
| **폭풍 (Storm)** | 원소 | 넉백, 넘어짐 | 강력한 바람과 기압을 다루는 바람 속성. 넉백이나 절단을 동반. |
| **수류 (Water)** | 원소 | 젖음, 질식, 둔화, 넘어짐 | 물의 흐름이나 수압을 다루는 물 속성. 질식이나 충격을 줌. |
| **산성 (Acid)** | 원소 | 부식, 신체 훼손 | 물질을 녹이는 부식성 액체나 가스 속성. 방어구를 손상시킴. |
| **독 (Poison)** | 원소 | 중독, 허약, 마비 | 생체에 해로운 독소 속성. 중독 상태를 유발하여 서서히 체력을 깎음. |
| **광휘 (Radiance)** | 신비 | 실명, 화상 | 신성한 빛이나 정화의 힘. 언데드나 어둠 속성에 치명적. |
| **어둠 (Darkness)** | 신비 | 실명, 공포 | 빛을 삼키는 순수한 어둠. 시야를 차단하거나 공포를 유발. |
| **사령 (Necrotic)** | 신비 | 부패, 허약, 오염 | 죽음과 부패를 관장하는 속성. 생명력을 직접적으로 앗아감. |
| **저주 (Curse)** | 신비 | 허약, 혼란, 속박, 변이 | 불행이나 약화를 초래하는 부정적인 마력. 각종 디버프를 동반. |
| **정신 (Psychic)** | 신비 | 혼란, 수면, 광분, 기절 | 물리적 실체 없이 마음에 직접 타격을 주는 정신 에너지. |
| **폭발 (Explosive)** | 신비 | 화상, 넉백, 넘어짐 | 순간적인 팽창과 충격파를 일으키는 속성. 광범위한 파괴력. |
| **플라즈마 (Plasma)** | 초상 | 화상, 소멸 | 초고온의 이온화된 기체 에너지. 물질을 증발시키는 파괴력. |
| **방사능 (Radiation)** | 초상 | 오염, 변이, 허약 | 치명적인 방사선을 방출하는 속성. 유전자 변형이나 지속 피폭 피해. |
| **역장 (Force Field)** | 초상 | 넉백, 속박 | 순수한 마력이나 물리력을 고체화한 에너지 장막. 방어 무시 타격. |
| **공허 (Void)** | 초상 | 소멸, 침묵 | 존재 자체를 지우거나 무(無)로 되돌리는 소멸의 속성. |
