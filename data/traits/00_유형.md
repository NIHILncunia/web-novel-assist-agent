# 00. 유형 (Type)

> **설명:** 존재의 생물학적 기원, 종족, 혹은 본질적인 분류를 나타내는 특성입니다.

## 키워드 목록

| 특성 이름 | 분류 | 특성 설명 |
| :--- | :---: | :--- |
| 이형체(Aberration) | 이형 | 상식적인 생태계에 속하지 않는 이질적인 존재. (예: 비홀더, 마인드 플레이어, 아볼레스) |
| 야수(Beast) | 자연 | 자연 생태계에 속하는 일반적인 동물이나 거대 동물. (예: 늑대, 곰, 독수리, 공룡) |
| 천사(Celestial) | 신비 | 상위 차원(천계)에서 유래한 신성한 존재. (예: 페가수스, 유니콘, 솔라, 데바) |
| 구조물(Construct) | 인공 | 인위적으로 만들어진 기계나 마법적 생명체. (예: 골렘, 오토마톤, 애니메이티드 아머) |
| 드래곤(Dragon) | 초월 | 강력한 힘과 마법을 지닌 고대 파충류형 종족. (예: 레드 드래곤, 골드 드래곤, 와이번) |
| 정령(Elemental) | 신비 | 4대 원소(불, 물, 흙, 공기)로 이루어진 존재. (예: 파이어 엘리멘탈, 정령왕, 가고일) |
| 요정(Fey) | 신비 | 자연의 마력과 밀접하게 연관된 신비로운 존재. (예: 픽시, 드라이어드, 사티로스, 해그) |
| 악마(Fiend) | 신비 | 하위 차원(지옥, 심연)에서 유래한 사악한 존재. (예: 임프, 서큐버스, 발로, 핏 핀드) |
| 거인(Giant) | 초월 | 인간과 비슷하지만 압도적으로 거대한 종족. (예: 오거, 트롤, 힐 자이언트) |
| 인간형(Humanoid) | 일반 | 언어와 문화를 가진 인간과 유사한 종족. (예: 인간, 오크, 고블린, 엘프) |
| 괴물(Monstrosity) | 이형 | 마법적 실험이나 저주로 변질된 부자연스러운 괴물. (예: 키메라, 미노타우로스, 아울베어, 도플갱어) |
| 슬라임(Ooze) | 이형 | 부정형의 젤리나 점액질로 이루어진 생물. (예: 젤라티너스 큐브, 블랙 푸딩) |
| 식물(Plant) | 자연 | 이동하거나 지능을 가진 식물형 몬스터. (예: 트리앤트, 섐블링 마운드) |
| 언데드(Undead) | 불사 | 죽음에서 되살아난 시체나 영혼. (예: 좀비, 스켈레톤, 뱀파이어, 리치) |
| 알 수 없음(Unknown) | 기타 | 데이터가 부족하거나 정의할 수 없는 존재. (예: 미확인 생명체, 이형의 존재) |
