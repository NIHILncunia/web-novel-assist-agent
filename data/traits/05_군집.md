# 05. 군집 (Social)

> **설명:** 존재의 사회적 구조, 무리 생활 방식, 다른 존재와의 관계, 그리고 기본적인 가치관(Alignment)을 나타내는 특성입니다.

---

### 사회성 및 관계

| 키워드 | 설명 |
| :--- | :--- |
| **단독 생활** | 무리를 짓지 않고 홀로 영역을 지키거나 떠돔 |
| **무리 사냥** | 우두머리를 중심으로 조직적인 협동 사냥을 함 |
| **계급 사회** | 여왕, 병정, 일꾼 등 철저한 역할 분담이 되어 있음 |
| **기생 관계** | 다른 생물의 몸에 붙거나 조종하여 생존함 |
| **공생 관계** | 다른 종족과 협력하여 서로 이득을 취함 |
| **유목 생활** | 한곳에 정착하지 않고 자원을 찾아 계속 이동함 |
| **영역 집착** | 자신의 영역에 침범하는 것을 극도로 싫어함 |
| **약육강식** | 동족 간에도 강한 자만이 살아남는 문화를 가짐 |
| **배타적** | 외부인에게 적대적이며 소통을 거부함 |
| **헌신적** | 자신이 섬기는 대상이나 가족을 위해 희생함 |
| **은둔형** | 세상과 단절된 깊은 곳에 숨어 지냄 |
| **지배자** | 주변의 약한 종족들을 노예로 부림 |
| **유아독존** | 세상의 중심이 자신이라고 믿으며, 동료나 협력자조차 자신의 소유물로 간주하는 태도 |
| **군대식 대형** | 군대처럼 조직화된 대형을 이루어 전투나 생활을 함 |
| **여왕 호위** | 개미나 벌처럼, 집단의 중심인 여왕을 호위하는 역할을 맡음 |
| **드래곤 라이더** | 드래곤과 교감하여 그들을 타고 다니는 특별한 관계 |
| **짝짓기 비행** | 특정 시기가 되면 하늘에서 짝짓기를 위한 군무를 펼침 |
| **가족 단위 수렵** | 늑대처럼 혈연으로 맺어진 가족 단위로 사냥하고 생활함 |
| **둥지 수호** | 자신의 둥지나 서식지를 목숨 걸고 지킴 |
