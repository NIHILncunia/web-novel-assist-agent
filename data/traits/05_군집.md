# 05. 군집 (Social)

> **설명:** 존재의 사회적 구조, 무리 생활 방식, 다른 존재와의 관계, 그리고 기본적인 가치관(Alignment)을 나타내는 트레잇입니다.

---

### 사회성 및 관계

| 키워드 | 분류 | 설명 |
| :--- | :---: | :--- |
| **비사회적 독립 생태** | 사회성 | 무리를 짓지 않고 홀로 영역을 지키거나 떠돌며 독자적인 생태를 유지함 |
| **전술적 집단 사냥** | 사회성 | 우두머리를 중심으로 고도의 전술을 구사하여 조직적으로 사냥함 |
| **절대적 신분 위계** | 사회성 | 여왕, 병정, 일꾼 등 역할에 따라 절대복종하는 엄격한 신분 사회 |
| **숙주 의존형 사회** | 사회성 | 타 생물이나 집단에 기생하거나 그들을 조종하여 사회를 유지함 |
| **상호 공존 동맹** | 사회성 | 타 종족과 적극적인 동맹을 맺고 공존하며 서로의 번영을 도모함 |
| **순환형 유목 문명** | 사회성 | 한곳에 머물지 않고 자원의 흐름을 따라 이동하며 문명을 유지함 |
| **절대적 영역권** | 사회성 | 자신의 영역에 침범하는 것을 극도로 싫어하며 절대적인 권리를 주장함 |
| **무력 서열제** | 사회성 | 동족 간에도 오직 강한 자만이 살아남고 지배하는 힘의 논리를 따름 |
| **폐쇄적 고립주의** | 사회성 | 외부인에게 적대적이며 소통을 거부하고 자신들만의 사회를 고수함 |
| **무한한 충성심** | 사회성 | 자신이 섬기는 대상이나 집단을 위해서라면 목숨도 아깝지 않게 희생함 |
| **은둔형 사회** | 사회성 | 세상과 단절된 깊은 곳에 숨어 지내며 외부와의 접촉을 피함 |
| **노예제 운영** | 사회성 | 주변의 약한 종족들을 정복하여 노예로 부리는 사회 구조를 가짐 |
| **선민사상** | 사회성 | 세상의 중심이 자신들이라고 믿으며, 타 종족을 하등하게 여김 |
| **군대식 대형** | 사회성 | 군대처럼 조직화된 대형을 이루어 전투나 생활을 함 |
| **여왕 수호대** | 사회성 | 집단의 중심인 여왕이나 지도자를 목숨 걸고 호위하는 정예 친위대 |
| **드래곤 라이더** | 사회성 | 드래곤과 교감하여 그들을 타고 다니는 특별한 관계 |
| **짝짓기 비행** | 사회성 | 특정 시기가 되면 하늘에서 짝짓기를 위한 군무를 펼침 |
| **가족 단위 수렵** | 사회성 | 늑대처럼 혈연으로 맺어진 가족 단위로 사냥하고 생활함 |
| **둥지 수호** | 사회성 | 자신의 둥지나 서식지를 목숨 걸고 지킴 |
| **계약 공동체** | 사회성 | 혈연이나 감정이 아닌, 절대적인 마법적 계약과 조항에 의해 유지되는 사회 |
| **지식의 도서관** | 사회성 | 개체 간 경험이 공유되며, 사망 시 모든 지식이 중앙 집단 지성(아카이브)으로 전송됨 |
| **기생 숙주 사회** | 사회성 | 거대한 생물(숙주)의 몸 안이나 등 위에서 그 부산물을 먹으며 형성된 사회 |
| **무정부 혼돈** | 사회성 | 지도자나 규칙이 전혀 없으며 서로 죽이고 뺏는 혼란 속에서 기이한 균형을 유지함 |
| **그림자 정부** | 사회성 | 표면적으로는 평범한 사회 속에 숨어 실권을 쥐고 조종하는 비밀 결사 형태 |
| **유아독존** | 사회성 | 자신만이 세상의 유일한 기준이며, 타인은 오직 자신의 신하이거나 도구일 뿐이라는 극단적 사고 |
| **단독 행동** | 사회성 | 계약자나 조직의 마력 공급 없이도 독자적으로 현계하고 활동할 수 있는 독립성 |
| **어빌리티주의** | 사회성 | 혈통이나 나이에 상관없이 오직 어빌리티와 성과로만 계급이 결정되는 사회 |
| **정신적 민주주의** | 사회성 | 모든 구성원이 텔레파시로 연결되어 다수결로 의사 결정을 내리는 집단 지성 체제 |
| **약탈 경제** | 사회성 | 생산 활동 없이 오직 다른 집단을 약탈하여 자원을 수급하는 야만적 경제 구조 |
| **검투사 사회** | 사회성 | 모든 갈등과 법적 분쟁을 결투로 해결하며, 강자가 정의가 되는 사회 |
| **침묵의 맹약** | 사회성 | 구성원 전체가 특정 비밀을 지키기 위해 혀를 자르거나 침묵 서약을 맺은 집단 |
| **조상 숭배** | 사회성 | 죽은 조상의 영혼을 신처럼 모시며, 그들의 조언을 듣고 따르는 영적인 사회 |
| **유랑 선단** | 사회성 | 거대한 배나 비행선, 이동 요새를 타고 평생을 떠돌아다니는 유목 집단 |
| **비밀 결사** | 사회성 | 겉으로는 평범한 시민으로 위장하고 있으나, 암호와 의식을 통해 연결된 지하 조직 |
| **거짓 유토피아** | 사회성 | 겉보기엔 완벽하고 평화롭지만, 그 이면에 끔찍한 희생이나 세뇌가 숨겨진 디스토피아 |
| **기계적 공산주의** | 사회성 | 모든 자원을 공평하게 분배하고 개성을 말살하여 효율만을 추구하는 기계적인 사회 |
| **피의 맹약** | 사회성 | 타인과 계약을 맺어 힘을 공유하지만, 계약자가 사망하면 자신도 치명적인 피해를 입거나 함께 사망하는 운명 공동체 |
| **맹세의 구속력** | 사회성 | 자신과 맺은 약속이나 맹세를 어길 경우, 배신자에게 물리적인 고통이 따르거나 저주가 발동됨 |
| **신정 일치 (Theocracy)** | 사회성 | 종교 지도자가 국가 원수를 겸하며, 교리가 곧 법이 되는 종교 국가. (역사적 모티브: 바티칸, 고대 이집트) |
| **입헌 군주제** | 사회성 | 왕은 상징적인 존재로 남고, 헌법과 의회가 실질적인 통치를 담당함. (역사적 모티브: 영국, 현대 일본) |
| **군사 정권 (Stratocracy)** | 사회성 | 군대가 국가의 중심이며, 군 계급이 곧 사회 신분과 정치 권력이 됨. (역사적 모티브: 스파르타, 군사 독재) |
| **직접 민주정** | 사회성 | 시민들이 대표를 거치지 않고 직접 정책을 투표하고 결정하는 체제. (역사적 모티브: 고대 아테네) |
| **상인 공화정** | 사회성 | 왕이나 귀족이 아닌, 거대 상인 가문이나 길드가 의회를 구성해 통치함. (역사적 모티브: 베네치아 공화국) |
| **유목 제국** | 사회성 | 정해진 수도 없이 이동하는 거대한 텐트 도시를 중심으로 정복 전쟁을 수행함. (역사적 모티브: 몽골 제국) |
| **해양 제국 (Thalassocracy)** | 사회성 | 육지 영토보다는 주요 항구와 무역로를 장악하여 바다를 지배하는 국가. (역사적 모티브: 페니키아, 대영제국) |
| **도시 국가 연맹** | 사회성 | 독립적인 자치권을 가진 도시들이 군사/경제적 필요에 의해 뭉친 연합체. (역사적 모티브: 델로스 동맹, 한자 동맹) |
| **관료제 (Bureaucracy)** | 사회성 | 혈통보다는 시험으로 선발된 관리들이 복잡한 행정 시스템을 통해 통치함. (역사적 모티브: 과거제 - 중국/조선) |
| **과두정 (Oligarchy)** | 사회성 | 소수의 특권층(귀족, 재벌, 마법사 등)이 권력을 독점하는 체제. (역사적 모티브: 로마 공화정 말기) |
| **봉건제 (Feudalism)** | 사회성 | 중앙의 힘이 약하고, 지방 영주들이 토지와 백성을 사유화하여 다스림. (역사적 모티브: 중세 유럽, 전국시대) |
| **용병단 (Mercenary)** | 사회성 | 돈을 받고 전쟁에 참여하는 무력 집단. 의뢰인의 이익보다 생존과 보수를 우선함. |
| **병영 국가 (Garrison State)** | 사회성 | 국민 전체가 예비군이며, 모든 생산 활동이 군사력 유지에 맞춰진 국가. |
| **비밀 결사 (Cult)** | 사회성 | 금지된 지식을 숭배하며 암호와 의식으로 연결된 폐쇄적인 집단. |
| **부족 사회** | 사회성 | 혈연 중심의 작은 공동체. 배타적이며 전통과 주술을 중시함. |
| **공범 의식 (Accomplice)** | 사회성 | 같은 범죄를 저지른 동료들과는 끈끈한 유대감을 가지며 비밀을 공유함 |
| **조직의 규율 (Omerta)** | 사회성 | 국가의 법은 무시하지만, 조직 내부의 규율이나 배신에 대한 처벌은 절대시함 |
| **민폐 혐오** | 사회성 | 타인에게 불쾌감이나 번거로움을 주는 것을 극도로 경계하며, 자신의 영역을 침범당하는 것도 거부함 |
| **이중 표출** | 사회성 | 사회적 조화를 위해 겉으로 드러내는 표정과 내면의 진짜 감정을 철저히 분리함 |
| **집단적 배제** | 사회성 | 공동체의 질서를 어긴 구성원에게 필수 요소를 제외한 모든 사회적 교류를 끊어버림 |
| **화합의 결계** | 사회성 | 구성원 간의 유대는 끈끈하지만, 울타리 밖의 존재에게는 보이지 않는 차가운 벽을 세움 |
| **만물 정령** | 사회성 | 세상 모든 자연물과 현상에 신성함이 깃들어 있다고 믿으며 공존을 중시함 |
| **은둔형 외톨이** | 사회성 | 사회적 압박을 피해 절대적인 안전지대로 도피하여 자발적 유폐 생활을 함 |
| **직언 권리** | 사회성 | 신분에 상관없이 지도자의 결정에 공식적으로 이의를 제기할 수 있는 권리 |
| **예법 논쟁** | 사회성 | 형식, 의전, 절차의 적합성을 두고 치열하게 토론하고 검증하는 문화 |
| **접속 전쟁** | 사회성 | 한정된 자원이나 기회를 차지하기 위해 반응 속도와 네트워크를 겨루는 초단기 경쟁 |
| **단판 승부** | 사회성 | 특정 시기에 치러지는 단 한 번의 시험을 위해 젊음과 자원을 쏟아부으며 경쟁함 |
| **등급제** | 사회성 | 구성원의 가치를 수치화된 점수나 소속 집단의 등급으로 매겨 줄 세움 |
| **열성적 후원** | 사회성 | 후계자의 성장을 위해 가문의 모든 자원을 쏟아부으며 과도하게 개입함 |
| **병영 문화** | 사회성 | 수직적인 위계질서와 절대복종을 강조하는 경직된 조직 문화 |
| **집단 제창** | 사회성 | 거대한 하나의 목소리가 되어 공연자와 일체감을 형성하고 에너지를 증폭시킴 |
| **동기화된 군무** | 사회성 | 수많은 개체가 마치 하나의 몸처럼 오차 없이 움직이는 완벽한 통제와 호흡 |
| **소환물 유지 (Summon Maintenance)** | 마법 | 소환물을 현세에 유지하기 위해 지속 마력 공급. |
| **꼭두각시의 실 (Puppet String)** | 마법 | 종속된 대상과 연결되어 감각 공유 및 조종. |
