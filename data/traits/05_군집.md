# 05. 군집 (Social)

> **설명:** 존재의 사회적 구조, 무리 생활 방식, 다른 존재와의 관계, 그리고 기본적인 가치관(Alignment)을 나타내는 특성입니다.

---

### 사회성 및 관계

| 키워드 | 설명 |
| :--- | :--- |
| **비사회적 독립 생태** | 무리를 짓지 않고 홀로 영역을 지키거나 떠돌며 독자적인 생태를 유지함 |
| **전술적 집단 사냥** | 우두머리를 중심으로 고도의 전술을 구사하여 조직적으로 사냥함 |
| **절대적 신분 위계** | 여왕, 병정, 일꾼 등 역할에 따라 절대복종하는 엄격한 신분 사회 |
| **숙주 의존형 사회** | 타 생물이나 집단에 기생하거나 그들을 조종하여 사회를 유지함 |
| **상호 공존 동맹** | 타 종족과 적극적인 동맹을 맺고 공존하며 서로의 번영을 도모함 |
| **순환형 유목 문명** | 한곳에 머물지 않고 자원의 흐름을 따라 이동하며 문명을 유지함 |
| **절대적 영역권** | 자신의 영역에 침범하는 것을 극도로 싫어하며 절대적인 권리를 주장함 |
| **무력 서열제** | 동족 간에도 오직 강한 자만이 살아남고 지배하는 힘의 논리를 따름 |
| **폐쇄적 고립주의** | 외부인에게 적대적이며 소통을 거부하고 자신들만의 사회를 고수함 |
| **무한한 충성심** | 자신이 섬기는 대상이나 집단을 위해서라면 목숨도 아깝지 않게 희생함 |
| **은둔형 사회** | 세상과 단절된 깊은 곳에 숨어 지내며 외부와의 접촉을 피함 |
| **노예제 운영** | 주변의 약한 종족들을 정복하여 노예로 부리는 사회 구조를 가짐 |
| **선민사상** | 세상의 중심이 자신들이라고 믿으며, 타 종족을 하등하게 여김 |
| **군대식 대형** | 군대처럼 조직화된 대형을 이루어 전투나 생활을 함 |
| **여왕 수호대** | 집단의 중심인 여왕이나 지도자를 목숨 걸고 호위하는 정예 친위대 |
| **드래곤 라이더** | 드래곤과 교감하여 그들을 타고 다니는 특별한 관계 |
| **짝짓기 비행** | 특정 시기가 되면 하늘에서 짝짓기를 위한 군무를 펼침 |
| **가족 단위 수렵** | 늑대처럼 혈연으로 맺어진 가족 단위로 사냥하고 생활함 |
| **둥지 수호** | 자신의 둥지나 서식지를 목숨 걸고 지킴 |
| **계약 공동체** | 혈연이나 감정이 아닌, 절대적인 마법적 계약과 조항에 의해 유지되는 사회 |
| **지식의 도서관** | 개체 간 경험이 공유되며, 사망 시 모든 지식이 중앙 집단 지성(아카이브)으로 전송됨 |
| **기생 숙주 사회** | 거대한 생물(숙주)의 몸 안이나 등 위에서 그 부산물을 먹으며 형성된 사회 |
| **무정부 혼돈** | 지도자나 규칙이 전혀 없으며 서로 죽이고 뺏는 혼란 속에서 기이한 균형을 유지함 |
| **그림자 정부** | 표면적으로는 평범한 사회 속에 숨어 실권을 쥐고 조종하는 비밀 결사 형태 |
| **유아독존** | 자신만이 세상의 유일한 기준이며, 타인은 오직 자신의 신하이거나 도구일 뿐이라는 극단적 사고 |
| **단독 행동** | 계약자나 조직의 마력 공급 없이도 독자적으로 현계하고 활동할 수 있는 독립성 |
| **능력주의** | 혈통이나 나이에 상관없이 오직 능력과 성과로만 계급이 결정되는 사회 |
| **정신적 민주주의** | 모든 구성원이 텔레파시로 연결되어 다수결로 의사 결정을 내리는 집단 지성 체제 |
| **약탈 경제** | 생산 활동 없이 오직 다른 집단을 약탈하여 자원을 수급하는 야만적 경제 구조 |
| **검투사 사회** | 모든 갈등과 법적 분쟁을 결투로 해결하며, 강자가 정의가 되는 사회 |
| **침묵의 맹약** | 구성원 전체가 특정 비밀을 지키기 위해 혀를 자르거나 침묵 서약을 맺은 집단 |
| **조상 숭배** | 죽은 조상의 영혼을 신처럼 모시며, 그들의 조언을 듣고 따르는 영적인 사회 |
| **유랑 선단** | 거대한 배나 비행선, 이동 요새를 타고 평생을 떠돌아다니는 유목 집단 |
| **비밀 결사** | 겉으로는 평범한 시민으로 위장하고 있으나, 암호와 의식을 통해 연결된 지하 조직 |
| **거짓 유토피아** | 겉보기엔 완벽하고 평화롭지만, 그 이면에 끔찍한 희생이나 세뇌가 숨겨진 디스토피아 |
| **기계적 공산주의** | 모든 자원을 공평하게 분배하고 개성을 말살하여 효율만을 추구하는 기계적인 사회 |
| **피의 맹약** | 타인과 계약을 맺어 힘을 공유하지만, 계약자가 사망하면 자신도 치명적인 피해를 입거나 함께 사망하는 운명 공동체 |
