# 11. 지역 및 환경 특성 (Regional Characteristics)

> **💡 설명:** 지역이나 장소가 가지는 환경적 비법, 마법적 이상 현상, 혹은 지형적 이점을 정의합니다. `03_regions_template.md`의 **[지역 특성]** 항목에서 참조하여 사용합니다.

| **간헐천 지대** | 위험 | 지하의 뜨거운 물과 증기가 주기적으로 솟구쳐 오르는 지열 지대. | 화상 위험 |

| **사구 (Sand Dune)** | 자연 | 바람에 의해 계속해서 모양과 위치가 변하는 거대한 모래 언덕. | 길 잃음 |
| **고대 결계** | 인공 | 허가받지 않은 자의 접근을 거부하고 튕겨내는 불가시의 장벽 | 마법으로 해제 불가 |
| **오염된 대지** | 재해 | 땅 자체가 병들어 있어 머무르는 생명체의 활력을 앗아가고 변이시킴 | 정화 의식 필요 |
| **성역 (Sanctuary)** | 신비 | 적의가 무력화되며 누구도 무기를 들 수 없는 평화의 공간 | 언데드/악마 진입 시 소멸 |
| **차원의 균열** | 신비 | 공간이 불안정하게 찢겨져 있어 이계의 존재가 넘어오거나 빨려 들어감 | 공간 마법 불안정 |
| **중력 왜곡 지대** | 위험 | 중력이 제멋대로 바뀌어 바위가 떠다니거나 짓눌리는 현상 발생. | 비행 불가 |
| **수정 동굴** | 자연 | 모든 벽이 마력을 반사하는 거대한 수정으로 이루어진 지하 공간. | 마법 폭주 위험 |
| **용암 호수** | 위험 | 끓어오르는 마그마가 강처럼 흐르는 지대. | 화염 저항 필수 |
| **침묵의 숲** | 저주 | 소리가 물리적으로 차단된 숲. 마법 영창과 대화가 불가능함. | 암살/기습 |
| **마력 폭풍우** | 재해 | 비 대신 순수한 마력 덩어리가 번개처럼 쏟아지는 기상 이변. | 마나 과잉 |
| **석화의 황무지** | 위험 | 이곳의 바람을 맞으면 피부가 서서히 돌처럼 굳어짐. | 바실리스크 서식 |
| **별빛의 호수** | 신비 | 밤이 되면 호수가 자체적으로 빛을 내며, 치유 효과가 있는 성수(Holy Water). | 정령 서식지 |
| **천공의 섬** | 신비 | 반중력 광석으로 인해 구름 위에 떠 있는 부유 대륙. | 비행 수단 필수 |
| **심연의 입구** | 신비 | 지하 세계나 이계로 연결되는 바닥을 알 수 없는 거대한 구멍. | 고위 마족 출몰 |
| **살아있는 숲** | 자연 | 나무와 덩굴이 스스로 움직이며 침입자를 공격하거나 길을 만듦. | 식물형 몬스터 |
| **대도서관 (Grand Library)** | 시설 | 고대부터의 지식이 축적된 곳. 마도서 열람 시 지능/지식 습득 속도 대폭 상승. | 침묵 필수 |
| **마탑 (Magic Tower)** | 시설 | 고농도의 마나와 연구 설비를 갖춘 마법사의 거점. 외부의 간섭을 차단하는 강력한 결계가 있음. | 마법 연구 |
| **콜로세움 (Colosseum)** | 시설 | 합법적인 살육과 전투가 허용되는 투기장. 승리 시 명성과 보상을 얻지만 패배는 죽음. | 전투 버프 |
| **환락가 (Red Light District)** | 구역 | 술, 도박, 이성 등 쾌락을 파는 거리. 정보 수집에 유리하지만 소매치기와 시비를 조심해야 함. | 정보/유혹 |
| **암시장 (Black Market)** | 구역 | 불법 물건(장물, 독, 노예)이 거래되는 은밀한 시장. 신분증 없이도 거래 가능. | 희귀템 |
| **대장간 지구** | 구역 | 24시간 풀무질 소리가 끊이지 않는 장인들의 거리. 무기 수리 및 제작 효율 상승. | 화염/소음 |
| **국제 무역항** | 도시 | 온갖 종족과 문물이 오가는 거대한 항구. 다양한 언어와 문화가 섞여 있음. | 전염병 주의 |
| **요새 도시** | 도시 | 도시 전체가 성벽과 방어 시설로 요새화되어 있음. 치안이 엄격하고 외부인 출입이 까다로움. | 방어력 상승 |
| **귀족 거리** | 구역 | 고위층만 거주하는 호화로운 구역. 사설 경비병이 순찰하며, 허가 없는 평민은 체포됨. | 신분 차별 |
| **지하 도시** | 도시 | 지표면 아래 거대한 동굴에 건설된 도시. 햇빛이 없고 습하며, 범죄자나 추방자들의 은신처. | 어둠 시야 |
| **위성 도시** | 도시 | 거대 도시 주변을 둘러싼 배후 도시. 물가가 싸고 노동자가 많지만 치안은 불안정함. | 인구 밀집 |
| **국경 검문소** | 시설 | 국가 간의 경계를 나누는 관문. 삼엄한 경비와 수색이 이루어짐. | 통행증 필요 |
| **왕궁 정원** | 시설 | 희귀한 식물과 마수가 사육되는 왕실 전용 정원. 미로처럼 꾸며져 있음. | 은신/침투 |
| **강제 수용소** | 시설 | 포로, 정치범 등을 가두고 강제 노동을 시키는 가혹한 시설. 탈출이 불가능에 가까움. | 억압/기아 |
| **치료소 (Sanatorium)** | 시설 | 병자나 부상자를 치료하는 시설. 신성력이나 약품 냄새가 진동하며, 전염병 환자가 격리되기도 함. | 회복/감염 |
| **대협곡 (Grand Canyon)** | 자연 | 비행 없이는 건널 수 없는 깊고 거대한 계곡. 다리가 끊어지면 고립됨. | 낙사 주의 |
| **열대 우림 (Jungle)** | 자연 | 빽빽한 수풀로 시야가 좁고 이동이 어려움. 맹수와 독충, 습기로 인한 질병이 가득함. | 질병/기습 |

| **유빙 지대** | 위험 | 바다 위에 떠다니는 거대한 얼음 조각들. 밟으면 깨지거나 뒤집힐 수 있음. | 냉기/익사 |

| **유황 온천** | 자연 | 지독한 유황 냄새가 나는 끓는 물 웅덩이. 독성 가스가 피어오르지만 피부병 치료 효과가 있음. | 독/화상 |
| **수정 광산** | 시설 | 마력을 머금은 광석이 자라는 동굴. 채굴 시 마력 폭발의 위험이 있음. | 마석 획득 |
| **거대 버섯 숲** | 자연 | 나무 대신 집채만한 버섯들이 자라는 숲. 포자가 날려 환각을 보거나 호흡기를 마비시킴. | 환각/중독 |

| **잊혀진 도서관** | 유적 | 역사에서 지워진 금서들이 보관된 폐허. 책을 읽으면 정신이 오염될 수 있음. | 금기 지식 |
