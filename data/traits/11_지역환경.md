# 11. 지역 및 환경 트레잇 (Regional Characteristics)

> **💡 설명:** 지역이나 장소가 가지는 환경적 비법, 마법적 이상 현상, 혹은 지형적 이점을 정의합니다. `03_regions_template.md`의 **[지역 트레잇]** 항목에서 참조하여 사용합니다.

## 통합 목록

| 트레잇명 | 분류 | 효과/설명 |
| :--- | :---: | :--- |
| **마나 과잉 지대** | 자연 | 대기 중 마나 농도가 짙어 마법의 위력이 폭주하거나 제어가 어려움 |
| **죽음의 늪** | 위험 | 발이 빠지는 끈적한 진흙과 호흡 곤란을 유발하는 독기가 가득함 |
| **칼바람 협곡** | 자연 | 몸을 가누기 힘들 정도의 강풍이 불어 날아가는 것조차 불가능함 |
| **치유의 온천** | 자연 | 피로와 상처를 빠르게 아물게 하는 신비한 성분이 함유된 온천 |
| **영구 동토** | 자연 | 뼛속까지 얼어붙게 만드는 초자연적인 냉기가 휘몰아치는 땅 |
| **카르스트 지형** | 자연 | 석회암이 침식되어 만들어진 날카로운 바위 숲과 수많은 동굴이 존재하는 지대. |

| **델타 (삼각주)** | 자연 | 강 하류에 퇴적물이 쌓여 만들어진 비옥하고 평평한 습지. 수로가 미로처럼 얽혀 있음. |
| **툰드라 (동토)** | 기후 | 일 년 내내 땅이 얼어있는 황무지. 나무가 자라지 못하고 이끼류만 서식함. |
| **몬순 우림** | 기후 | 우기와 건기가 극명하게 나뉘는 열대 우림. 우기에는 숲 전체가 물에 잠김. |
| **사바나** | 기후 | 끝없이 펼쳐진 초원과 드문드문 서 있는 나무. 건기에는 대형 산불이 자주 발생함. |
| **테이블 마운틴** | 자연 | 정상 부분이 칼로 자른 듯 평평한 거대한 산. 고립된 생태계가 존재함. |
| **간헐천 지대** | 위험 | 지하의 뜨거운 물과 증기가 주기적으로 솟구쳐 오르는 지열 지대. |
| **맹그로브 숲** | 자연 | 바닷물과 민물이 만나는 곳에 뿌리를 내린 숲. 복잡한 뿌리가 천연 방파제 역할. |
| **사구 (Sand Dune)** | 자연 | 바람에 의해 계속해서 모양과 위치가 변하는 거대한 모래 언덕. |
| **고대 결계** | 인공 | 허가받지 않은 자의 접근을 거부하고 튕겨내는 불가시의 장벽 |
| **오염된 대지** | 재해 | 땅 자체가 병들어 있어 머무르는 생명체의 활력을 앗아가고 변이시킴 |
| **성역 (Sanctuary)** | 신비 | 적의가 무력화되며 누구도 무기를 들 수 없는 평화의 공간 |
| **차원의 균열** | 신비 | 공간이 불안정하게 찢겨져 있어 이계의 존재가 넘어오거나 빨려 들어감 |
| **중력 왜곡 지대** | 위험 | 중력이 제멋대로 바뀌어 바위가 떠다니거나 짓눌리는 현상 발생. |
| **수정 동굴** | 자연 | 모든 벽이 마력을 반사하는 거대한 수정으로 이루어진 지하 공간. |
| **용암 호수** | 위험 | 끓어오르는 마그마가 강처럼 흐르는 지대. |
| **침묵의 숲** | 저주 | 소리가 물리적으로 차단된 숲. 마법 영창과 대화가 불가능함. |
| **마력 폭풍우** | 재해 | 비 대신 순수한 마력 덩어리가 번개처럼 쏟아지는 기상 이변. |
| **석화의 황무지** | 위험 | 이곳의 바람을 맞으면 피부가 서서히 돌처럼 굳어짐. |
| **별빛의 호수** | 신비 | 밤이 되면 호수가 자체적으로 빛을 내며, 치유 효과가 있는 성수(Holy Water). |
| **천공의 섬** | 신비 | 반중력 광석으로 인해 구름 위에 떠 있는 부유 대륙. |
| **심연의 입구** | 신비 | 지하 세계나 이계로 연결되는 바닥을 알 수 없는 거대한 구멍. |
| **살아있는 숲** | 자연 | 나무와 덩굴이 스스로 움직이며 침입자를 공격하거나 길을 만듦. |
| **대도서관 (Grand Library)** | 시설 | 고대부터의 지식이 축적된 곳. 마도서 열람 시 지능/지식 습득 속도 대폭 상승. |
| **마탑 (Magic Tower)** | 시설 | 고농도의 마나와 연구 설비를 갖춘 마법사의 거점. 외부의 간섭을 차단하는 강력한 결계가 있음. |
| **콜로세움 (Colosseum)** | 시설 | 합법적인 살육과 전투가 허용되는 투기장. 승리 시 명성과 보상을 얻지만 패배는 죽음. |
| **환락가 (Red Light District)** | 구역 | 술, 도박, 이성 등 쾌락을 파는 거리. 정보 수집에 유리하지만 소매치기와 시비를 조심해야 함. |
| **암시장 (Black Market)** | 구역 | 불법 물건(장물, 독, 노예)이 거래되는 은밀한 시장. 신분증 없이도 거래 가능. |
| **대장간 지구** | 구역 | 24시간 풀무질 소리가 끊이지 않는 장인들의 거리. 무기 수리 및 제작 효율 상승. |
| **국제 무역항** | 도시 | 온갖 종족과 문물이 오가는 거대한 항구. 다양한 언어와 문화가 섞여 있음. |
| **요새 도시** | 도시 | 도시 전체가 성벽과 방어 시설로 요새화되어 있음. 치안이 엄격하고 외부인 출입이 까다로움. |
| **귀족 거리** | 구역 | 고위층만 거주하는 호화로운 구역. 사설 경비병이 순찰하며, 허가 없는 평민은 체포됨. |
| **지하 도시** | 도시 | 지표면 아래 거대한 동굴에 건설된 도시. 햇빛이 없고 습하며, 범죄자나 추방자들의 은신처. |
| **위성 도시** | 도시 | 거대 도시 주변을 둘러싼 배후 도시. 물가가 싸고 노동자가 많지만 치안은 불안정함. |
| **국경 검문소** | 시설 | 국가 간의 경계를 나누는 관문. 삼엄한 경비와 수색이 이루어짐. |
| **왕궁 정원** | 시설 | 희귀한 식물과 마수가 사육되는 왕실 전용 정원. 미로처럼 꾸며져 있음. |
| **강제 수용소** | 시설 | 포로, 정치범 등을 가두고 강제 노동을 시키는 가혹한 시설. 탈출이 불가능에 가까움. |
| **치료소 (Sanatorium)** | 시설 | 병자나 부상자를 치료하는 시설. 신성력이나 약품 냄새가 진동하며, 전염병 환자가 격리되기도 함. |
| **대협곡 (Grand Canyon)** | 자연 | 비행 없이는 건널 수 없는 깊고 거대한 계곡. 다리가 끊어지면 고립됨. |
| **열대 우림 (Jungle)** | 자연 | 빽빽한 수풀로 시야가 좁고 이동이 어려움. 맹수와 독충, 습기로 인한 질병이 가득함. |
| **소금 사막 (Salt Flat)** | 자연 | 끝없이 펼쳐진 하얀 소금 결정의 대지. 낮에는 눈이 멀 듯한 반사광, 밤에는 혹한이 찾아옴. |
| **대나무 숲** | 자연 | 강철처럼 단단한 대나무들이 빽빽한 숲. 바람이 불면 기괴한 공명음이 들림. |
| **바위 산 (Rocky Mt.)** | 자연 | 흙이나 나무 없이 날카로운 바위로만 이루어진 산. 낙석이 잦고 숨을 곳이 적음. |
| **유빙 지대** | 위험 | 바다 위에 떠다니는 거대한 얼음 조각들. 밟으면 깨지거나 뒤집힐 수 있음. |
| **안개 낀 호수** | 자연 | 한 치 앞도 보이지 않는 짙은 물안개가 낀 호수. 방향 감각을 상실하게 만듦. |
| **유황 온천** | 자연 | 지독한 유황 냄새가 나는 끓는 물 웅덩이. 독성 가스가 피어오르지만 피부병 치료 효과가 있음. |
| **수정 광산** | 시설 | 마력을 머금은 광석이 자라는 동굴. 채굴 시 마력 폭발의 위험이 있음. |
| **거대 버섯 숲** | 자연 | 나무 대신 집채만한 버섯들이 자라는 숲. 포자가 날려 환각을 보거나 호흡기를 마비시킴. |
| **가시 덤불** | 자연 | 갑옷도 뚫는 날카로운 가시 식물이 뒤덮인 지대. 이동 속도가 급감하고 지속적인 출혈 피해를 입음. |
| **돌풍의 평원** | 기후 | 몸을 가누기 힘든 강풍이 항상 불어오는 평원. 원거리 무기(활)의 명중률이 바닥으로 떨어짐. |
| **암흑림 (Dark Forest)** | 저주 | 대낮에도 밤처럼 어두운 숲. 나무들이 빛을 흡수하며, 어둠 속성 몬스터가 강화됨. |
| **갈대밭** | 자연 | 사람 키보다 높은 갈대가 빽빽한 들판. 적의 움직임을 소리로만 감지해야 함. |
| **용의 무덤** | 신비 | 고대 드래곤들의 유해가 묻힌 곳. 뼈에 남은 마력이 주변 생물을 변이시키거나 용의 영혼이 출몰함. |
| **고대 전장** | 유적 | 수많은 병사가 죽은 전쟁터. 녹슨 무기가 널려 있고, 원한을 품은 언데드가 배회함. |
| **봉인된 문** | 신비 | 무엇을 가두었는지 알 수 없는 거대한 문. 강력한 마법으로 잠겨 있으며, 열면 재앙이 닥침. |
| **차원의 미로** | 신비 | 물리적 거리와 상관없이 공간이 뒤틀려 연결된 미로. 지도가 무용지물임. |
| **하늘 정원** | 신비 | 고대 문명이 하늘에 띄워 올린 아름다운 정원. 멸종된 식물들이 자생함. |
| **해저 신전** | 유적 | 바다 깊은 곳에 가라앉은 신전. 수중 호흡 마법 없이는 접근 불가. |
| **거울의 방** | 신비 | 사방이 마법 거울로 된 방. 자신의 도플갱어가 튀어나오거나 다른 장소를 비춤. |
| **잊혀진 도서관** | 유적 | 역사에서 지워진 금서들이 보관된 폐허. 책을 읽으면 정신이 오염될 수 있음. |
| **유령선** | 위험 | 선원 없이 바다를 떠도는 저주받은 배. 올라타면 목적지에 닿을 때까지 내릴 수 없음. |
| **별자리 제단** | 신비 | 특정 별자리가 뜰 때 마력이 증폭되거나 신의 계시를 받을 수 있는 높은 제단. |
| **산성비 지대** | 재해 | 금속을 부식시키고 피부를 녹이는 비가 내리는 지역. 내구도가 깎이고 지속 피해를 입음. |
| **자기장 폭풍** | 재해 | 나침반과 기계 장치를 먹통으로 만들고, 금속 장비에 벼락을 유도하는 폭풍. |
| **역병 지대** | 재해 | 치사율 높은 전염병이 창궐하여 격리된 땅. 공기만 마셔도 감염될 수 있음. |
| **몬스터 둥지** | 위험 | 특정 몬스터가 대량으로 서식하며 번식하는 본거지. 끊임없이 증원군이 몰려옴. |
| **마나 공백지 (Null Zone)** | 재해 | 마나가 전혀 존재하지 않는 공간. 마법 사용이 불가능하며, 마법 생명체는 힘을 잃고 소멸함. |
| **뼈의 탑** | 신비 | 희생자들의 뼈를 쌓아 만든 탑. 주변에 강한 저주와 공포 오라를 방출함. |
| **피의 연못** | 위험 | 물 대신 피가 고여 있는 연못. 들어가면 체력을 흡수당하거나 흡혈귀가 됨. |
| **수정 탑** | 시설 | 주변 지역의 마나를 빨아들여 저장하거나 방어막을 펼치는 거대한 구조물. |
| **그림자 회랑** | 신비 | 빛이 닿지 않는 어둠 속의 복도. 그림자 몬스터가 무한히 생성됨. |
| **사건의 지평선** | 우주 | 시간과 공간이 멈추거나 왜곡되어 탈출이 불가능한 경계 구역. |
| **엔트로피의 바다** | 우주 | 모든 질서와 형태가 무너지고 에너지로 환원되는 혼돈의 차원. |
| **비유클리드 미로** | 우주 | 기하학적으로 불가능한 구조(끊임없이 이어지는 계단 등)로 이루어진 공간. |
| **공허의 균열** | 우주 | 현실 세계에 난 구멍. 주변의 빛과 소리를 빨아들이며 존재를 지움. |
| **죽은 별의 무덤** | 우주 | 수명을 다한 별들의 잔해가 떠다니는 우주 공간. 고밀도 중력이 작용함. |
| **참호선 (Trench Line)** | 인공 | 적의 포격을 피하기 위해 길게 파놓은 방어선. 진흙탕과 시체가 뒤엉켜 있음. |
| **벙커 (Bunker)** | 인공 | 지하 깊은 곳이나 두꺼운 콘크리트로 지어진 견고한 방공호. |
| **지뢰밭** | 위험 | 밟으면 폭발하는 함정이 매설된 지역. 공병 없이는 통과가 불가능함. |
| **보급로** | 시설 | 식량과 탄약을 나르는 생명선. 이곳이 끊기면 군대는 굶어 죽음. |
