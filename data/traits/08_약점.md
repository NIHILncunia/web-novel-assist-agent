# 08. 약점 (Weakness)

> **설명:** 존재를 무력화하거나 파괴할 수 있는 치명적인 결함이나 취약점을 나타내는 특성입니다.

## 키워드 목록

| 키워드 | 설명 |
| :--- | :--- |
| **화염 취약** | 불에 닿으면 일반적인 경우보다 훨씬 큰 피해를 입음 |
| **냉기 취약** | 추위나 냉기 공격에 일반적인 경우보다 훨씬 큰 피해를 입음 |
| **신성 취약** | 성수나 신성력에 닿으면 타들어가거나 소멸함 (언데드/악마) |
| **은 취약** | 은으로 된 무기에 닿으면 재생이 억제되거나 치명상을 입음 |
| **태양광 취약** | 햇빛을 받으면 돌이 되거나 재가 되어 소멸함 |
| **핵심 파괴** | 몸 어딘가에 있는 코어(심장/마석)가 파괴되면 즉사함 |
| **머리 절단** | 재생 능력이 있어도 목을 자르면 죽음 (혹은 두 개 다 잘라야 함) |
| **물 공포증** | 물을 극도로 싫어하거나 몸이 녹아내림 |
| **소리 민감** | 특정 주파수나 큰 소음에 극심한 고통을 느낌 |
| **마법 저항 불가** | 물리 공격에는 강하지만 마법 공격에는 무방비함 |
| **느린 이동** | 공격력이나 방어력은 강하지만 이동 속도가 매우 느림 (카이팅 가능) |
| **꼬리 절단** | 꼬리가 잘리면 균형을 잃거나 특정 능력을 상실함 |
| **진명(True Name)** | 본명이 불리면 힘을 잃거나 강제로 복종하게 됨 |
| **거울 공포** | 자신의 모습을 거울로 보면 공포에 질리거나 석화됨 |
| **성직자 기피** | 신앙심 깊은 자의 기도나 성물에 접근하지 못함 |
| **역린** | 건드리면 폭주하거나 그 부위만 방어력이 0임 |
| **성수 공포** | 성스러운 물건이나 액체에 공포를 느끼고 기피함 |
| **핵 노출** | 외부의 충격으로 신체 내부의 핵(코어)이 노출되면 급격히 약해짐 |
| **오만함으로 인한 약점** | 지나친 오만함 때문에 상대를 얕보거나 명백한 함정에 빠짐 |
| **날개 손상** | 비행 능력의 핵심인 날개가 손상되면 무력화됨 |
| **특정 보석에 대한 약점** | 특정 종류의 보석 앞에서 힘을 잃거나 해로운 효과를 받음 |
| **성스러운 무기에 대한 약점** | 신성력이 깃든 무기에 특히 큰 피해를 입음 |
| **특정 음악에 대한 약점** | 특정 음악을 들으면 잠에 빠지거나 특정 행동을 제어하지 못함 |
