# 08. 약점 (Weakness)

> **설명:** 존재를 무력화하거나 파괴할 수 있는 치명적인 결함이나 취약점을 나타내는 특성입니다. 단순한 피해 증가를 넘어, 몬스터의 행동 양식과 서사에 영향을 주는 요소들입니다.

## 키워드 목록

| 키워드 | 설명 |
| :--- | :--- |
| **발화성 표피 (Flammable)** | 피부가 기름을 머금은 듯 불에 닿으면 격렬하게 타오르며 재생이 멈춥니다. |
| **냉기 경직 (Freeze Vulnerability)** | 극저온에 노출되면 신체 기능이 급격히 저하되거나, 세포 조직이 파괴되어 바스러집니다. |
| **광과민증 (Photosensitivity)** | 직사광선이나 강한 빛에 노출되면 피부가 화상을 입거나, 시력을 잃고 행동 불능이 됩니다. |
| **건조 취약 (Dehydration)** | 수분이 부족하면 급격히 약해지거나, 소금/건조한 바람에 닿으면 몸이 갈라집니다. (슬라임/수생 생물) |
| **전도체 (Conductor)** | 전기에 특히 민감하여, 감전 시 신경계가 마비되거나 내부 장기가 타버립니다. |
| **산성 부식 (Acid Vulnerability)** | 산성 물질에 닿으면 일반적인 생물보다 훨씬 빠르게 녹아내리며 고통스러워합니다. |
| **청각 과민 (Sonic Sensitivity)** | 특정 주파수나 폭음(종소리 등)에 노출되면 신경계가 붕괴되듯 고통스러워하며 균형을 잃습니다. |
| **노출된 핵 (Exposed Core)** | 생명력의 원천인 코어(심장/마석)가 외부 충격에 쉽게 노출되어 있어, 파괴 시 즉사합니다. |
| **역린 (Vital Spot)** | 전신이 단단하지만 특정 부위(비늘 하나, 눈 등)만 방어력이 전무하며, 피격 시 폭주하거나 사망합니다. |
| **재생 불가 부위 (Irreversible Spot)** | 다른 부위는 재생되지만, 특정 부위(머리, 심장 등)가 절단되면 재생되지 않고 사망합니다. |
| **관절 취약 (Joint Weakness)** | 갑옷 틈새나 관절 부위가 헐거워, 정밀한 타격에 의해 자세가 무너지거나 절단되기 쉽습니다. |
| **비행 기관 손상 (Wing Fragility)** | 날개나 부유 기관이 손상되면 단순히 날지 못하는 것을 넘어 전신 무력화 상태에 빠집니다. |
| **시야 사각 (Blind Spot)** | 신체 구조상 특정 각도(등 뒤, 머리 위 등)를 전혀 볼 수 없어 기습에 취약합니다. |
| **무게 중심 불안 (Top-Heavy)** | 머리가 크거나 상체가 비대하여, 다리를 공격받으면 쉽게 넘어져 일어나지 못합니다. |
| **은 취약 (Silver Aversion)** | 은이나 도금된 무기에 닿으면 상처가 썩어들어가고 재생이 억제됩니다. (늑대인간/변신수) |
| **철 취약 (Iron Burn)** | 차가운 무쇠(Cold Iron)에 닿으면 화상을 입으며 마법적인 능력이 봉인됩니다. (요정/정령) |
| **신성 기피 (Unholy)** | 성수, 성직자의 기도, 신성한 빛에 닿으면 검은 연기를 내며 타들어갑니다. (언데드/악마) |
| **소금 취약 (Salt Vulnerability)** | 소금이 닿으면 삼투압으로 수분을 뺏기거나 정화되어 소멸합니다. |
| **거울 공포 (Mirror phobia)** | 자신의 추한 모습을 거울로 보면 공포에 질리거나 석화되어 움직이지 못합니다. |
| **특정 식물 기피 (Herb Aversion)** | 마늘, 투구꽃, 월계수 등 특정 식물의 향이나 즙을 극도로 혐오하여 접근하지 못합니다. |
| **진명 구속 (True Name)** | 본명이 불리면 저항할 수 없는 강한 고통을 느끼거나 절대적인 명령에 복종해야 합니다. |
| **초대 제약 (Invitation Rule)** | 거주인의 허락 없이는 가택이나 성역에 들어갈 수 없습니다. (뱀파이어/악령) |
| **강박증 (Compulsion)** | 흩어진 쌀알을 보면 세어야 하거나, 매듭을 보면 풀어야 하는 등 특정 행동을 무시하지 못합니다. |
| **오만함 (Hubris)** | 자신보다 약해 보이는 대상을 무시하거나 가지고 놀다가 빈틈을 자주 보입니다. |
| **분노 조절 장애 (Berserk Trigger)** | 특정 도발이나 상황(동족의 죽음 등)에 이성을 잃고 돌진하여 함정에 쉽게 빠집니다. |
| **주인 의존 (Master Dependency)** | 자신을 창조했거나 계약한 상위 존재(소환사, 군주)가 죽으면 즉시 소멸하거나 마비됩니다. |
| **공포증 (Phobia)** | 불, 물, 십자가, 고양이 등 특정 대상에 대해 비이성적인 공포를 느껴 도망칩니다. |
| **존재의 망각 (Cognitive Dependence)** | 타인이 자신을 인식하거나 바라보지 않으면 존재가 희미해지거나 소멸함. (관측 의존) |
| **논리적 모순 (Logical Paradox)** | 절대적인 규칙을 따르므로, 논리적 모순이나 딜레마를 제시하면 사고 회로가 정지하거나 자괴함. |
| **형체 붕괴 (Cohesion Loss)** | 액체나 기체 형태를 유지하는 힘이 불안정하여, 충격이나 마력 고갈 시 흩어져버림. |
| **환경 의존 (Environmental Dependency)** | 특정 장소(물속, 어둠, 둥지)를 벗어나면 급격히 약화되거나 숨을 쉬지 못함. |
| **핵심 파괴 (Core Destruction)** | 육체는 불사지만 어딘가 숨겨진 본체(성물함, 필락터리)가 파괴되면 즉시 사망함. |
| **과부하 (Overload)** | 자신의 능력을 제어할 수 없어, 힘을 과도하게 사용하면 자멸하거나 폭주함. |
| **연료 의존 (Fuel Dependency)** | 혈액, 마나, 영혼 등 특정 자원을 주기적으로 섭취하지 않으면 굳거나 기능이 정지함. |
| **극심한 연비** | 출력은 강력하지만, 그만큼 유지에 필요한 자원(마력, 식량, 돈 등)이 비정상적으로 많이 소모됨 |
| **속성 피격** | 특정 속성(예: 용 살해, 신성, 특정 가문 등)을 가진 공격에 대해 방어력이 전무하거나 치명상을 입음 |
| **불운** | 실력과 무관하게 결정적인 순간마다 상황이 꼬이거나 운이 따르지 않아 실패를 겪음 |
| **강제 명령 취약** | 절대적인 권한(노예 계약, 영혼의 서약 등)을 가진 자의 명령에 대해 자신의 의지로 저항할 수 없음 |
| **치명적인 방심** | 압도적인 힘 때문에 상대를 과하게 얕보며, 전력을 다해야 할 결정적인 타이밍을 놓쳐 패배함 |
| **상성 공략** | 정면 승부로는 무적에 가까우나, 자신의 능력을 완벽하게 카운터 치는 천적이나 환경을 만나면 급격히 무력해짐 |
| **진명 저당** | 진짜 이름이 타인에게 알려지면 생사여탈권이 넘어가거나 영혼이 종속됨 |
| **시간 제한** | 강력한 힘을 낼 수 있지만 유지 시간이 극도로 짧음 (예: 3분) |
| **불살의 맹세** | 어떤 상황에서도 생명을 해치지 않겠다는 맹세 때문에 결정적인 순간에 공격하지 못함 |
| **햇빛 소멸** | 햇빛을 받으면 재가 되어 사라지거나 돌로 변함 (흡혈귀, 트롤) |
| **물에 녹음** | 물에 닿으면 신체가 녹아내리거나 힘을 잃음 (악마의 열매 능력자 등) |
| **소음 알러지** | 특정 데시벨 이상의 소음에 노출되면 신경 발작을 일으키며 무력화됨 |
| **공생 의존** | 파트너나 기생 식물이 없으면 생명 유지가 불가능함 |
| **수면 의존** | 하루의 대부분(20시간 이상)을 잠으로 보내야 힘을 비축할 수 있음 |
| **기억 누수** | 기록해두지 않으면 기억이 주기적으로 사라지거나 리셋됨 |
| **금기어 (Taboo)** | 특정 단어를 말하거나 들으면 저주가 발동하여 고통받음 |
