# 04. 지성 (Intellect)

> **설명:** 존재의 지능 수준, 논리적 사고력, 지식의 습득 및 처리 방식, 소통 능력 등 **순수한 인지적 능력(CPU)**과 관련된 특성입니다.

## 키워드 목록

| 키워드 | 분류 | 설명 |
| :--- | :---: | :--- |
| **교활한 책략** | 일반 | 함정을 파거나 상대를 속이는 등 전술적이고 지능적인 전투를 구사함 |
| **야수적 본능** | 본능 | 논리적인 이성은 낮으나, 생존과 사냥에 특화된 직관적인 판단력을 가짐 |
| **고지능** | 천재 | 인간을 초월한 연산 능력과 이해력을 보유함 (마법 공식 해석, 고차원적 설계) |
| **보물 탐지** | 일반 | 물건의 가치나 마력이 담긴 아티팩트를 감별해내는 전문적인 식견 |
| **독립된 영격** | 일반 | 소환된 개체 하나하나가 단순한 꼭두각시가 아니라, 자아와 고유한 판단 능력을 지닌다. |
| **공유된 기억** | 집단 | 군집 내의 한 개체가 습득한 정보나 전술을 다른 개체들도 직관적으로 공유받는다. |
| **지도 제작** | 일반 | 한 번 지나간 지형이나 전장을 기억하고 지도 형태로 머릿속에 시각화할 수 있다. |
| **늙은 현자** | 일반 | 오랜 세월 축적된 경험을 통해 삶의 지혜와 깊은 통찰력을 가짐 |
| **마법적 지식** | 일반 | 마법의 원리, 역사, 주문 체계에 대해 학자 수준의 지식을 보유함 |
| **무지성(짐승)** | 본능 | 고등 사고 능력이 거의 없어 순수한 본능과 반사 신경에 의존함 |
| **무정한 저울** | 일반 | 생명의 가치를 수치로 환산하여 철저히 공리주의적이고 논리적인 판단을 내림 |
| **텔레파시** | 일반 | 언어 중추를 거치지 않고 정신파로 직접 의사를 소통하거나 이미지를 전송함 |
| **정신 연결** | 일반 | 특정 대상과 신경망이 연결된 것처럼 실시간으로 감각과 정보를 공유함 |
| **동물 언어** | 일반 | 모든 종류의 동물과 울음소리나 몸짓으로 의사소통할 수 있음 |
| **발화 불가** | 일반 | 지능 문제나 신체 구조상 말을 할 수 없어 괴성이나 몸짓으로 소통함 |
| **기계적 중립** | 일반 | 선악이나 감정의 치우침 없이 입력된 규칙과 논리 알고리즘만 따름 |
| **예언자** | 일반 | 인과율을 계산하거나 미래의 가능성을 연산하여 현재가 아닌 미래를 위해 행동함 |
| **직관적 천재** | 천재 | 체계적으로 배우지 않아도 본능적으로 사물의 이치나 마법의 원리를 깨우침 |
| **살아있는 도서관** | 일반 | 창의적인 응용력은 부족하나, 방대한 양의 지식과 역사를 토씨 하나 틀리지 않고 기억함 |
| **모방 학습** | 지성 | 한 번 본 기술이나 무술, 행동을 즉석에서 완벽하게 따라 할 수 있음 (카피캣) |
| **단순 명쾌** | 일반 | 복잡한 계산이나 꼼수를 쓰지 않고, 문제의 본질을 단순하고 명확하게 꿰뚫어 봄 |
| **병렬 사고** | 일반 | 동시에 여러 개의 마법을 연산하거나, 여러 개의 자아를 동시에 운용하여 다중 작업을 수행함 |
| **미래 직관** | 본능 | 논리적 계산이 아닌 본능으로 찰나의 미래나 적의 공격 궤적을 예지 수준으로 읽어냄 |
| **천리안** | 일반 | 단순한 시력을 넘어, 먼 곳에서 일어나는 일이나 평행 세계, 혹은 미래의 진실을 꿰뚫어 보는 눈 |
| **진리 통찰** | 일반 | 사물의 본질, 가치, 진위를 단번에 파악하며 상대의 속임수나 환영을 무력화하는 지혜 |
| **집단 기억** | 집단 | 개체 간에 기억이 실시간으로 동기화되어, 한 명이 겪은 일을 모두가 기억함 |
| **몽상가** | 일반 | 현실과 꿈의 경계를 넘나들며, 꿈속의 논리를 현실에 적용하거나 자각몽을 꿀 수 있음 |
| **전술 컴퓨터** | 일반 | 감정을 배제하고 수천 가지의 전술 시나리오를 시뮬레이션하여 최적의 수를 도출함 |
| **혼돈의 계산** | 일반 | 무질서하고 불규칙한 패턴(카오스) 속에서 숨겨진 질서를 찾아내는 비선형적 사고방식 |
| **수수께끼 달인** | 천재 | 은유, 비유, 암호 해독에 천재적인 재능을 보이며 언어유희를 즐김 |
| **언어 해독** | 일반 | 처음 듣는 언어나 고대의 룬 문자라도 문법적 구조를 파악해 즉시 이해함 |
| **패턴 인식** | 일반 | 사소한 단서들의 공통점을 찾아내어 사건의 재구성을 하거나 약점을 찾아냄 (탐정형) |
| **확률 조작** | 일반 | 단순한 운이 아니라, 가능성이 낮은 사건의 변수를 계산하고 조작하여 필연으로 만듦 |
| **다중 연산** | 일반 | 뇌를 파티션 나누듯 구획하여 동시에 서로 다른 복잡한 사고(마법+검술)를 수행함 |
| **감정의 논리화** | 일반 | 타인의 감정을 수치나 화학 반응식처럼 논리적으로 분석하여 예측하고 대응함 |
| **속독 학습** | 지성 | 일반적인 서적이나 문서를 초고속으로 스캔하여 단시간에 방대한 정보를 습득하고 기억함 |
| **설계도 직관** | 일반 | 복잡한 기계나 건축물을 한 번 보는 것만으로도 내부 구조와 원리, 약점을 파악하는 공학적 직관 |
| **편집증적 설계** | 일반 | 아군을 포함한 모든 존재의 배신이나 최악의 수를 가정하고, 그에 대한 대항 수단을 미리 준비함 |
| **사건 재구성** | 일반 | 현장에 남은 미세한 단서만으로 과거에 일어난 사건을 홀로그램처럼 머릿속에 시뮬레이션함 |
| **기억의 궁전** | 일반 | 한 번 보거나 들은 정보는 절대 잊지 않으며, 머릿속의 라이브러리에서 언제든 꺼내볼 수 있음 |
| **미치광이의 논리** | 일반 | 일반적인 논리가 통하지 않는 광인이나 이형의 존재들의 사고방식을 이해하고 예측함 |
| **기계치** | 천재 | 마법이나 특정 분야엔 천재적이나 현대 문물(기계)을 다루는 데는 잼병이라 만지면 고장 냄 |
| **봉인 전문가 (Sealing Specialist)** | 일반 | 다양한 종류의 봉인술과 해제 방법에 대해 깊은 지식을 가지고 있다. 복잡한 봉인도 빠르게 이해하고 해제할 수 있다. |
| **조숙한 마술사** | 일반 | 어린 나이에도 복잡한 이론과 실전을 성인 수준으로 소화한다. 조기 교육과 선천적 재능이 결합된 결과다. |
| **전술적 연산** | 일반 | 전장의 지형과 병력 수, 무장 상태를 보고 승률을 순식간에 계산하는 군사적 지능. |
| **해부학적 식견** | 일반 | 지성체의 급소, 관절, 동맥 위치를 정확히 꿰뚫고 있는 의학적/살육적 지식. |
| **기계 장치 직관** | 본능 | 처음 보는 자물쇠나 트랩도 그 메커니즘을 본능적으로 이해하고 파훼함. |
| **언령의 이해** | 일반 | 상대의 말 속에 숨겨진 의도나 거짓을 파악하고, 말로써 상대를 조종하는 지능. |
| **야생 지리학** | 일반 | 풀 한 포기, 돌 모양만 보고도 현재 위치와 날씨 변화를 읽어내는 자연 지능. |
| **암호 해독** | 일반 | 고대 문자나 적군의 암호 체계를 분석하여 숨겨진 메시지를 찾아내는 지능. |
| **독물학 지식** | 일반 | 자연계의 독초와 광물 독을 조합하여 치명적인 독이나 해독제를 만드는 지식. |
| **마물 생태학** | 일반 | 몬스터의 습성, 약점, 서식지를 연구하여 사냥에 최적화된 지식. |
| **전투 병법** | 일반 | 고전적인 병법서를 통달하여 대규모 부대의 진형과 작전을 설계하는 전략적 사고. |
| **무기 공학** | 일반 | 무기의 구조와 재질을 이해하여, 급할 때 수리하거나 개조하는 기술적 지식. |
| **도구적 지성 (Instrumental Intellect)** | 일반 | 전투와 명령 수행에 필요한 전술적 판단력은 갖추었으나, 창의성이나 감정, 도덕적 판단 능력은 거세되어 있음. |
