# 04. 지성 (Intellect)

> **설명:** 존재의 지능 수준, 논리적 사고력, 지식의 습득 및 처리 방식, 소통 능력 등 **순수한 인지적 능력(CPU)**과 관련된 특성입니다.

## 키워드 목록

| 키워드 | 설명 |
| :--- | :--- |
| **교활한 책략** | 함정을 파거나 상대를 속이는 등 전술적이고 지능적인 전투를 구사함 |
| **야수적 본능** | 논리적인 이성은 낮으나, 생존과 사냥에 특화된 직관적인 판단력을 가짐 |
| **고지능** | 인간을 초월한 연산 능력과 이해력을 보유함 (마법 공식 해석, 고차원적 설계) |
| **보물 탐지** | 물건의 가치나 마력이 담긴 아티팩트를 감별해내는 전문적인 식견 |
| **이중인격** | 상반된 두 가지 이상의 인격이 공존하며, 상황에 따라 주도권을 바꿈 |
| **독립된 영격** | 소환된 개체 하나하나가 단순한 꼭두각시가 아니라, 자아와 고유한 판단 능력을 지닌다. |
| **공유된 기억** | 군집 내의 한 개체가 습득한 정보나 전술을 다른 개체들도 직관적으로 공유받는다. |
| **지도 제작** | 한 번 지나간 지형이나 전장을 기억하고 지도 형태로 머릿속에 시각화할 수 있다. |
| **늙은 현자** | 오랜 세월 축적된 경험을 통해 삶의 지혜와 깊은 통찰력을 가짐 |
| **마법적 지식** | 마법의 원리, 역사, 주문 체계에 대해 학자 수준의 지식을 보유함 |
| **무지성(짐승)** | 고등 사고 능력이 거의 없어 순수한 본능과 반사 신경에 의존함 |
| **무정한 저울** | 생명의 가치를 수치로 환산하여 철저히 공리주의적이고 논리적인 판단을 내림 |
| **텔레파시** | 언어 중추를 거치지 않고 정신파로 직접 의사를 소통하거나 이미지를 전송함 |
| **정신 연결** | 특정 대상과 신경망이 연결된 것처럼 실시간으로 감각과 정보를 공유함 |
| **동물 언어** | 모든 종류의 동물과 울음소리나 몸짓으로 의사소통할 수 있음 |
| **발화 불가** | 지능 문제나 신체 구조상 말을 할 수 없어 괴성이나 몸짓으로 소통함 |
| **기계적 중립** | 선악이나 감정의 치우침 없이 입력된 규칙과 논리 알고리즘만 따름 |
| **예언자** | 인과율을 계산하거나 미래의 가능성을 연산하여 현재가 아닌 미래를 위해 행동함 |
| **직관적 천재** | 체계적으로 배우지 않아도 본능적으로 사물의 이치나 마법의 원리를 깨우침 |
| **살아있는 도서관** | 창의적인 응용력은 부족하나, 방대한 양의 지식과 역사를 토씨 하나 틀리지 않고 기억함 |
| **모방 학습** | 한 번 본 기술이나 무술, 행동을 즉석에서 완벽하게 따라 할 수 있음 (카피캣) |
| **단순 명쾌** | 복잡한 계산이나 꼼수를 쓰지 않고, 문제의 본질을 단순하고 명확하게 꿰뚫어 봄 |
| **병렬 사고** | 동시에 여러 개의 마법을 연산하거나, 여러 개의 자아를 동시에 운용하여 다중 작업을 수행함 |
| **미래 직관** | 논리적 계산이 아닌 본능으로 찰나의 미래나 적의 공격 궤적을 예지 수준으로 읽어냄 |
| **천리안** | 단순한 시력을 넘어, 먼 곳에서 일어나는 일이나 평행 세계, 혹은 미래의 진실을 꿰뚫어 보는 눈 |
| **진리 통찰** | 사물의 본질, 가치, 진위를 단번에 파악하며 상대의 속임수나 환영을 무력화하는 지혜 |
| **집단 기억** | 개체 간에 기억이 실시간으로 동기화되어, 한 명이 겪은 일을 모두가 기억함 |
| **몽상가** | 현실과 꿈의 경계를 넘나들며, 꿈속의 논리를 현실에 적용하거나 자각몽을 꿀 수 있음 |
| **전술 컴퓨터** | 감정을 배제하고 수천 가지의 전술 시나리오를 시뮬레이션하여 최적의 수를 도출함 |
| **혼돈의 계산** | 무질서하고 불규칙한 패턴(카오스) 속에서 숨겨진 질서를 찾아내는 비선형적 사고방식 |
| **수수께끼 달인** | 은유, 비유, 암호 해독에 천재적인 재능을 보이며 언어유희를 즐김 |
| **언어 해독** | 처음 듣는 언어나 고대의 룬 문자라도 문법적 구조를 파악해 즉시 이해함 |
| **패턴 인식** | 사소한 단서들의 공통점을 찾아내어 사건의 재구성을 하거나 약점을 찾아냄 (탐정형) |
| **확률 조작** | 단순한 운이 아니라, 가능성이 낮은 사건의 변수를 계산하고 조작하여 필연으로 만듦 |
| **다중 연산** | 뇌를 파티션 나누듯 구획하여 동시에 서로 다른 복잡한 사고(마법+검술)를 수행함 |
| **감정의 논리화** | 타인의 감정을 수치나 화학 반응식처럼 논리적으로 분석하여 예측하고 대응함 |
