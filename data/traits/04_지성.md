# 04. 지성 (Intellect)

> **설명:** 존재의 지능 수준, 사고방식, 성격, 정신력, 소통 방식 등 지적 능력 및 성격과 관련된 모든 특성입니다.

---

### 지능 및 사고방식

| 키워드 | 설명 |
| :--- | :--- |
| **하이브 마인드** | 개체의 의식 없이 여왕이나 상위 존재의 명령에 절대 복종함 |
| **광적인 신앙** | 특정 신이나 이념을 맹목적으로 따르며 죽음도 불사함 |
| **교활한 책략** | 함정을 파거나 상대를 속이는 등 지능적인 전투를 함 |
| **야수적 본능** | 이성은 없지만 생존과 사냥에 특화된 직감을 가짐 |
| **고지능** | 인간을 초월한 지적 능력을 보유함 (마법 이해, 언어 구사) |
| **피에 굶주림** | 살육 자체에 쾌락을 느끼며 멈추지 않고 공격함 |
| **오만함** | 자신을 과신하여 상대를 얕보거나 방심하는 경향 |
| **집착** | 특정 물건(보물)이나 대상에게 병적인 집착을 보임 |
| **이중인격** | 두 가지 이상의 자아가 공존하며 성격이 급변함 |
| **복수심** | 자신이나 동족의 원수를 갚기 위해 끝까지 추적함 |
| **탐욕** | 재물이나 마력, 식욕 등 끝없는 갈망을 가짐 |
| **명예 중시** | 적이라도 정정당당한 승부를 원하며 약속을 지킴 |
| **사이코패스** | 타인의 고통에 공감하지 못하고 도구처럼 이용함 |
| **왕의 자존심** | 타인에게 고개를 숙이거나 명령받는 것을 죽기보다 싫어하며, 모욕을 당하면 반드시 응징하는 성향 |
| **보물 탐지** | 가치 있는 물건이나 마력이 담긴 아티팩트를 본능적으로 감별하고 위치를 찾아내는 감각 |
| **신성 거부** | 신이나 신성한 존재에 대한 본능적인 반발심을 가지며, 그들의 권능에 굴복하지 않는 강인한 정신력 |
| **편집증적 광기** | 사소한 일에도 심각한 위협을 느끼며 편집증적으로 광기에 사로잡혀 있음 |
| **늙은 현자** | 오랜 세월을 살아오며 깊은 지혜와 통찰력을 가짐 |
| **마법적 지식** | 마법의 원리와 역사에 대해 해박한 지식을 보유함 |
| **광적인 수집벽** | 특정 물건이나 지식을 광적으로 수집하고 집착함 |
| **무지성(짐승)** | 지능이 거의 없어 순수한 본능에 따라서만 행동함 |
| **파괴적 본능** | 눈앞의 모든 것을 파괴하려는 충동을 느낌 |

---

### 언어 및 소통

| 키워드 | 설명 |
| :--- | :--- |
| **텔레파시** | 언어 대신 정신파로 의사를 소통함 |
| **공용어** | 대륙이나 세계에서 널리 쓰이는 공통 언어를 구사함 |
| **용어** | 고대 용족의 언어를 구사하며, 마법적인 힘을 담을 수 있음 |
| **엘프어** | 고대 엘프의 언어를 구사함 |
| **정신 연결** | 특정 대상과 정신적으로 연결되어 감정이나 생각을 공유함 |
| **동물 언어** | 모든 종류의 동물과 의사소통할 수 있음 |
| **원소어** | 불, 물, 바람, 흙의 정령들과 소통하는 언어 |
| **악마어** | 하위 차원의 악마들이 사용하는 타락한 언어 |
| **천사어** | 상위 차원의 천사들이 사용하는 신성한 언어 |
| **언어 무능** | 지능이 낮거나 신체 구조상 언어를 구사할 수 없음 |
