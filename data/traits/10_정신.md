# 10. 정신 (Mind & Spirit)

> **설명:** 존재의 자아, 의지력, 감정 상태, 신념, 트라우마 등 **내면의 정신세계(OS)**를 포괄하는 트레잇입니다. 관계성 관련 트레잇은 `17_관계.md`로 이동되었습니다.

## 트레잇 목록

| 키워드 | 분류 | 설명 |
| :--- | :---: | :--- |
| **광적인 신앙** | 정신 | 특정 신이나 이념을 맹목적으로 따르며, 이를 위해 죽음도 불사하는 흔들리지 않는 믿음 |
| **피에 굶주림** | 정신 | 이성적인 판단보다 살육과 파괴 행위 자체에서 오는 쾌락을 우선시함 |
| **집착** | 정신 | 특정 물건, 인물, 목표에 병적으로 매달리며 그것을 잃으면 이성을 잃음 |
| **이중인격** | 정신 | 상반된 두 가지 이상의 인격이 공존하며, 상황에 따라 주도권을 바꿈 |
| **복수심** | 정신 | 자신이나 동족이 입은 피해를 잊지 않고, 대를 이어서라도 갚으려는 끈질긴 원념 |
| **탐욕** | 정신 | 재물, 마력, 권력 등에 대해 만족을 모르고 끝없이 갈망함 |
| **명예 중시** | 정신 | 승리보다 과정을 중시하며, 적이라도 정정당당한 승부를 원하고 약속을 생명처럼 여김 |
| **사이코패스** | 정신 | 타인의 고통이나 감정에 전혀 공감하지 못하고, 그들을 자신의 목적을 위한 도구로만 여김 |
| **왕의 자존심** | 정신 | 타인에게 고개를 숙이거나 지배당하는 것을 죽기보다 싫어하며, 모욕을 당하면 반드시 응징함 |
| **신성 거부** | 정신 | 신이나 성스러운 존재에 대해 본능적인 혐오감과 반발심을 가짐 |
| **편집증적 광기** | 정신 | 주변의 모든 것을 의심하고, 사소한 징조에도 심각한 위협을 느껴 선제공격을 가함 |
| **광적인 수집벽** | 정신 | 쓰레기나 특정 물건(뼈, 돌 등)을 병적으로 모으고, 건드리면 격분함 |
| **파괴적 본능** | 정신 | 눈앞에 존재하는 질서나 형체를 무너뜨리고 부수려는 원초적인 충동 |
| **마술 혐오** | 정신 | 마법이나 초자연적인 힘을 부정한 것으로 여기며 극도로 불신함 |
| **마모된 감정** | 정신 | 너무 오랜 세월을 살거나 비극을 겪어, 기쁨도 슬픔도 느끼지 못하는 건조한 상태 |
| **생존자의 죄책감** | 정신 | 동료나 가족 중 홀로 살아남았다는 죄책감에 시달리며, 자신의 행복을 거부함 |
| **왜곡된 이타심** | 정신 | 남을 돕는다는 명분으로 상대의 의사를 무시하거나, 자신의 희생을 강요함 |
| **강철의 마음** | 정신 | 육체가 부서지는 고통이나 절망적인 상황 앞에서도 결코 꺾이지 않는 불굴의 의지 |
| **감정 동조** | 정신 | 자신의 주관이 희미해, 주변 존재들의 강렬한 감정(분노, 공포)에 쉽게 전염됨 |
| **광기의 전염** | 정신 | 존재 자체가 비상식적이라, 대화를 나누거나 정신이 연결된 상대를 미치게 만듦 |
| **현실 조작** | 정신 | 자신의 강력한 망상이나 믿음이 물리적인 현실에 영향을 미쳐 세계를 왜곡함 |
| **기억 포식** | 정신 | 타인의 기억을 먹어야 자아를 유지할 수 있으며, 먹은 기억의 인격을 연기하기도 함 |
| **하이브 마인드** | 정신 | 개별적인 자아가 없이 여왕이나 집단 지성의 명령을 자신의 의지처럼 수행함 |
| **유리 멘탈** | 정신 | 평소에는 강해 보이지만, 예상치 못한 실패나 모욕을 당하면 급격히 무너져 내림 |
| **공허한 영혼** | 정신 | 감정과 욕구가 거세된 텅 빈 상태. 허무주의에 빠져 있으며 외부 자극에 둔감함 |
| **고결한 기사도** | 정신 | 약자를 보호하고 정의를 수호하려는 도덕적 신념을 목숨보다 소중히 여김 |
| **타락한 신념** | 정신 | 한때는 숭고했으나, 과정이 왜곡되어 악행을 정의라 믿고 행하는 뒤틀린 신념 |
| **예술적 광기** | 정신 | 완벽한 아름다움이나 예술적 성취를 위해서라면 살인이나 파괴도 서슴지 않음 |
| **자기 파괴적 충동** | 정신 | 극심한 스트레스를 받거나 흥분하면 자신의 몸을 해치는 방식으로 감정을 표출함 |
| **멸사봉공** | 정신 | 사사로운 이익이나 개인의 행복을 철저히 배제하고 집단이나 큰 대의를 위해서만 헌신함 |
| **회귀 본능** | 정신 | 자신의 과거나 운명을 부정하고, 그것을 되돌리거나 수정하려는 강렬한 집착과 미련 |
| **이상주의** | 정신 | 현실의 제약이나 타협을 거부하고, 도덕적으로 완벽한 세계나 목표를 쫓는 고결하지만 위험한 정신 |
| **충절의 강박** | 정신 | 과거의 배신이나 실패에 대한 트라우마로 인해 주군에게 병적으로 집착하며 충성을 증명하려 함 |
| **유열 추구** | 정신 | 타인의 번민, 갈등, 혹은 파멸하는 모습에서 비틀린 즐거움과 살아있음을 느낌 |
| **인간 찬가** | 정신 | 인간의 나약함과 추악함조차 그들의 가능성으로 인정하며, 그들의 발버둥을 사랑하고 지켜보는 초월적 시선 |
| **허무주의** | 정신 | 삶의 의미나 가치를 부정하며, 세상의 파멸이나 무질서를 담담하게 받아들이거나 조장함 |
| **쾌락적 구도자** | 정신 | 도덕이나 법보다는 자신의 쾌락과 호기심을 충족시키는 것을 인생의 유일한 목표로 삼음 |
| **순교자 콤플렉스** | 정신 | 자신이 희생함으로써 구원받거나 인정받을 수 있다고 믿으며, 고통을 자처함 |
| **비겁함** | 정신 | 생존을 위해서라면 동료를 배신하거나 비굴하게 구는 것을 부끄러워하지 않음 |
| **완벽주의** | 정신 | 티끌만 한 오점도 용납하지 못하며, 완벽하지 않은 것은 가치가 없다고 여겨 파기함 |
| **열등감** | 정신 | 타인과 자신을 끊임없이 비교하며, 자신의 부족함에 대해 분노하거나 좌절함 |
| **메시아 콤플렉스** | 정신 | 자신만이 세상을 구원할 수 있다고 믿으며, 타인의 구원을 자신의 사명으로 여김 |
| **사디즘 (가학증)** | 정신 | 타인에게 고통을 주거나 지배함으로써 성적, 정신적 만족감을 느낌 |
| **마조히즘 (피학증)** | 정신 | 타인에게 학대받거나 고통받는 상황에서 오히려 안도감이나 쾌락을 느낌 |
| **금욕주의** | 정신 | 욕망을 억제하고 고행을 통해 정신적 완성을 추구하며, 물질적 풍요를 거부함 |
| **비틀린 인과** | 정신 | 타인의 소망이나 기도를 들어주려 하지만, 그 과정과 결과를 가장 파괴적이고 비극적인 형태로 왜곡하여 실현하는 본능 |
| **혐오스러운 오라** | 정신 | 별다른 행동을 하지 않아도 주변 존재들에게 본능적인 혐오감과 공포심을 심어주어, 사회적 상호작용을 불가능하게 만듦 |
| **마나 중독** | 정신 | 마력이 풍부한 환경에서는 강력해지지만, 마력이 희박한 곳에서는 극심한 금단 증상(불안, 초조)을 겪음 |
| **순수한 영혼** | 정신 | 마나 친화력이 극도로 높고 선한 성향을 지니지만, 타인의 악의나 거짓말을 의심하지 못해 쉽게 이용당함 |
| **끝없는 탐구심** | 정신 | 미지의 영역이나 새로운 지식에 대해 두려움 없이 접근하며, 이를 빠르게 습득하고 자신의 것으로 만든다. |
| **시련의 즐거움** | 정신 | 위기 상황이나 강적을 조우할수록 정신 고양감이 높아져 공포를 느끼지 않게 된다. |
| **냉철한 계산** | 정신 | 감정에 휘둘리지 않고 피해와 이득을 정확히 계산하여, 필요하다면 아군의 희생도 전술의 일부로 삼는다. |
| **대인배** | 정신 | 사소한 모욕이나 피해에 연연하지 않으며, 적이라도 훌륭한 점은 칭찬하고 인정하는 넓은 도량을 가진다. |
| **무방비의 방어** | 정신 | 전혀 방어 태세를 취하지 않음으로서 오히려 적이 함정이 아닐까 의심하게 만들어 섣불리 공격하지 못하게 한다. |
| **영겁의 권태** | 정신 | 불멸의 삶을 살아가며 느끼는 지독한 권태감 때문에, 사소한 자극이나 유희를 쫓음 |
| **정신 간섭 면역** | 정신 | 강인한 정신력이나 이중 자아 덕분에, 정신 지배나 텔레파시 공격을 튕겨냄 |
| **희망의 상징** | 정신 | 존재 자체만으로 사람들에게 희망을 주고, 절망적인 상황에서도 포기하지 않게 만듦 |
| **침략자의 본능** | 정신 | 세계를 정복하거나 파괴하도록 프로그래밍된 본능이 이성을 뚫고 나오려 함 |
| **동족 혐오** | 정신 | 자신과 같은 종족을 혐오하며, 그들을 멸종시키는 것을 사명으로 여김 |
| **이중인격의 괴리** | 정신 | 영웅으로서의 자아와 소시민으로서의 자아가 끊임없이 충돌하며 정체성의 혼란을 겪음 |
| **관심 종자** | 정신 | 타인의 관심과 사랑을 받지 못하면 힘을 잃거나 존재가 희미해지는 강박적 성향 |
| **사랑의 사도** | 정신 | 증오나 분노에 잠식되지 않는 순수한 정신을 가지며, 타인을 돕고 사랑하는 행위에서 힘을 얻음 |
| **무력에 의한 평화** | 정신 | "진정한 평화는 압도적인 힘 아래서만 유지된다"는 신념을 가지고, 평화를 위해 무력을 행사함 |
| **도시전설** | 정신 | 존재 자체가 불확실한 소문으로 퍼져 있어, 조우하는 적들에게 공포와 혼란을 줌 |
| **생존자 증후군** | 정신 | 재난에서 홀로 살아남았다는 부채감으로 인해, 자신의 행복을 죄악시하고 희생을 당연시함 |
| **이타적 기계** | 정신 | 공감이나 인간적인 감정이 결여된 채, 입력된 프로그램처럼 타인을 돕는 행위를 기계적으로 수행함 |
| **차용된 이상** | 정신 | 스스로의 욕망이 아닌, 타인이 남긴 이상이나 꿈을 맹목적으로 동경하고 모방하며 살아감 |
| **파탄 난 가치관** | 정신 | 가치 판단의 기준이 왜곡되어, 자신을 가장 소모적인 도구로 취급하며 자기 파괴적인 선택을 함 |
| **냉소적 실용주의** | 정신 | 대의를 위해서라면 감정을 배제하고 가장 효율적이고 비정한 수단을 선택함 |
| **자기 혐오** | 정신 | 자신의 과거 모습이나, 자신이 혐오하는 과거의 신념을 가진 자를 보면 참을 수 없는 혐오감을 느낀다 |
| **타락의 산파** | 정신 | 닿는 대상(생명체, 영령)을 오염시켜 자신의 수족으로 만들며, 순수한 존재일수록 더 빨리 타락시킴 |
| **이중 자아** | 정신 | 평소의 착한 인격과 억눌린 욕망이 표출된 잔혹한 인격이 공존하며, 충격 시 주도권이 바뀜 |
| **고통 내성** | 정신 | 극심한 육체적 고통에 익숙해져, 일반인이라면 기절할 수준의 고통에도 의식을 유지함 |
| **억눌린 분노** | 정신 | 평소에는 온화해 보이지만, 내면에는 세상을 향한 증오와 분노가 마그마처럼 끓고 있음 |
| **결정적 실수** | 정신 | 평소에는 완벽하지만, 중요한 승부처나 결정적인 순간에 반드시 치명적인 실수를 저지름 (징크스) |
| **명문가의 긍지** | 정신 | 언제나 우아하고 여유로운 태도를 유지하려 하며, 타인에게 약한 모습을 보이는 것을 극도로 싫어함 |
| **책임감** | 정신 | 자신의 관리 구역이나 맡은 임무에 대해 끝까지 책임을 지려 하며, 손해를 보더라도 해결하려 함 |
| **왕의 위엄** | 정신 | 군단을 지휘하는 타고난 왕의 기질. 아군의 사기를 고취시키고, 적에게는 범접할 수 없는 위압감을 준다 |
| **무거운 왕관** | 정신 | 리더라는 자리의 무게감 때문에 개인의 행복을 포기하고 공적인 임무에만 몰두하며, 정신적 피로가 항상 누적되어 있다 |
| **기사의 맹세** | 정신 | 명예와 신의를 목숨보다 중시한다. 약자를 보호하고 악에 맞서며, 비겁한 수단(인질, 독 등)을 혐오하고 거부한다 |
| **정면 승부** | 정신 | 적이라 해도 경의를 표할 만한 상대라면 1:1 정면 승부를 고집한다. 기습이나 함정을 사용하는 것을 수치스럽게 여긴다 |
| **완벽주의자의 고뇌** | 정신 | 타인에게도 자신과 같은 완벽함을 요구하거나, 자신의 기준에 미치지 못하는 현실에 고뇌한다. 고립을 자초하기 쉽다 |
| **이종족의 고독** | 정신 | 인간과 다른 존재가 되어버렸다는 소외감을 느끼며, 인간 사회에 완전히 섞이지 못하고 겉돈다 |
| **전투 경험자** | 정신 | 무수한 전투를 경험하여, 어떤 상황에서도 침착함을 유지하고 최적의 판단을 내린다. 공포나 압박에 쉽게 흔들리지 않는다 |
| **수호자의 고뇌** | 정신 | 대의를 위해 무수한 생명을 제거해야 했던 과거로 인해 깊은 고뇌에 빠져 있다. 자신의 선택이 정당했는지 끊임없이 의심하며, 정신적 피로가 누적되어 있다 |
| **자기 부정** | 정신 | 자신의 과거나 미래의 모습을 부정하고, 그런 존재가 되지 않으려고 노력한다. 하지만 이미 그 길을 걸었기 때문에 절망감이 깊다 |
| **냉소적 현실주의** | 정신 | 이상주의를 버리고 현실을 냉정하게 바라본다. 감정에 휘둘리지 않고 효율적인 선택을 하지만, 그 과정에서 인간성을 잃어가는 것에 대한 두려움을 느낀다 |
| **영웅이 되지 못한 자** | 정신 | 영웅이 되려 했지만 실패하여 무명의 존재가 되었다. 영웅들의 이름을 빌려 복제품으로 싸워야 하는 역설적 상황에 처해 있으며, 자신의 정체성에 대한 혼란이 깊다 |
| **복제품의 자존심** | 정신 | 원본이 아닌 복제품으로 싸워야 하는 것에 대한 자존심 상처를 가지고 있다. 원본의 주인과 맞서는 것을 두려워하지만, 동시에 복제품으로도 승리할 수 있다는 것을 증명하려 한다 |
| **인간성 상실 (Humanity Loss)** | 정신 | 마물로 변해가면서 인간적인 감정이나 도덕관이 점차 사라진다. 냉혹하고 효율적인 사고만 남게 된다. |
| **조기 교육의 흔적** | 정신 | 어린 시절부터 엄격하고 체계적인 교육을 받아 형성된, 어른스러운 사고 방식과 책임감을 가진다. |
| **가문의 사명** | 정신 | 가문의 목적을 달성하는 것이 자신의 존재 이유가 되었다. 목표를 위해 감정과 개인적 행복을 뒤로 미루기 쉽다. |
| **가문의 기대** | 정신 | 후계자로서 모든 기대를 짊어지는 압박을 느낀다. 실패에 대한 두려움이 판단과 행동에 영향을 줄 수 있다. |
| **냉정한 판단** | 정신 | 감정에 휘둘리지 않고 이성과 논리로 상황을 분석해 최적의 선택을 내린다. |
| **감정 억제** | 정신 | 목적 달성을 위해 감정을 억누르고 이성을 우선시한다. 감정적 동요가 판단에 영향을 주지 않게 만든다. |
| **감정 마비** | 정신 | 과도한 억제나 충격으로 감정을 느끼는 어빌리티 자체가 둔화되거나 마비된 상태다. |
| **냉정함의 가면** | 정신 | 겉으로는 냉정해 보이지만 내면에는 감정이 존재한다. 냉정함은 자신을 보호하기 위한 방어 기제일 수 있다. |
| **마술사의 자존심** | 정신 | 자신의 어빌리티와 지위에 강한 자부심을 가진다. 인정받고자 하며, 타인을 경시하는 태도로 갈등을 만들 수 있다. |
| **패배 불수용** | 정신 | 패배나 실패를 인정하지 못하고 스스로의 우위를 고집하려는 경향이 있다. |
| **자존심 회복** | 정신 | 자존심이 상처받았을 때 이를 회복하기 위해 과격한 행동이나 증명 욕구에 집착한다. |
| **자존심의 가면** | 정신 | 외형상 강한 자존심 뒤에 불안감이나 열등감이 숨겨져 있다. 자존심이 방어 기제로 작동한다. |
| **이성 상실 (Loss of Reason)** | 정신 | 광화 상태에서는 이성적인 판단이나 복잡한 전술을 사용할 수 없다. 본능과 감각에만 의존하여 행동한다. |
| **마모된 영혼** | 정신 | 지나치게 긴 삶이나 잘못된 불사법의 부작용으로 영혼 자체가 낡고 병들어 있다. 기억이 흐릿해지거나 성격이 기괴하게 비틀리며, 끝없는 허기나 갈증에 시달린다. |
| **흑막** | 정신 | 직접 나서기보다 대리인이나 장기말을 내세워 상황을 조종하는 것을 선호한다. 정보를 통제하고 함정을 파는 데 능숙하며, 자신의 정체는 최후까지 숨긴다. |
| **인간 혐오** | 정신 | 인간이라는 종족 자체를 혐오하거나 하등하게 여긴다. 그들의 감정이나 생명을 벌레보다 못하게 취급하며, 학살이나 실험 재료로 쓰는 것에 아무런 죄책감을 느끼지 않는다. |
| **망각된 초심** | 정신 | 너무 오랜 시간을 살아오며 최초의 동기나 목적을 잊어버렸다. 수단 자체가 목적이 되어, 멈추지 못하고 맹목적으로 폭주하는 기관차와 같다. |
| **비틀린 사랑** | 정신 | 대상을 사랑하거나 아낀다고 생각하지만, 그 표현 방식이 학대, 구속, 개조 등 파괴적인 형태로 나타난다. 상대가 고통스러워하는 것을 애정의 증거로 받아들인다. |
| **비틀린 긍지** | 정신 | 자존심이 기형적으로 비대해져, 자신의 결점을 인정하는 것을 죽기보다 싫어하며 타인을 깎아내려 우월감을 느낀다. |
| **과거의 망령** | 정신 | 이미 사라진 과거의 규칙이나 위상에 집착하여, 변화한 현실에 적응하지 못하고 도태된다. |
| **불굴의 투사** | 정신 | 압도적인 열세나 패배가 확정된 상황에서도 결코 항복하거나 절망하지 않는다. 최후의 순간까지 역전의 기회를 노리며 비웃음을 날리는 강철 멘탈의 소유자. |
| **비극의 영웅** | 정신 | 영웅적인 업적을 세울수록 개인적인 불행이 닥쳐오는 저주받은 운명을 타고났다. 사랑하는 사람을 잃거나, 지키려던 것을 자신의 손으로 파괴하는 상황에 자주 처한다. |
| **제약과 서약** | 정신 | 스스로에게 강력한 제약(금기)을 거는 대신 힘을 얻는다. 금기를 어기면 힘을 잃거나 죽음에 이르는 저주를 받지만, 지키는 동안에는 행운과 가호를 받는다. |
| **교단의 율법** | 정신 | 세상의 법보다 자신이 속한 조직의 규율을 우선시한다. 조직의 비밀을 지키기 위해서라면 혀를 깨물고 자결하는 것도 주저하지 않는다. |
| **장인의 고집** | 정신 | 사소해 보이는 목표라도 자신이 납득할 때까지 끝없이 파고든다. 비효율적이라도 자신의 방식을 고수하며, 그 끝에서 남들은 이해 못 할 경지에 도달한다. |
| **수호자의 맹세** | 정신 | 자신이 지키기로 한 문이나 통로를 절대 벗어나지 않는다. 목숨을 걸고 자리를 사수하며, 그 어떤 적도 자신의 허가 없이는 통과시키지 않는다. |
| **허무의 삶** | 정신 | 삶의 목적이나 욕망이 희박하다. 세속적인 가치에 관심이 없으며, 오직 자신의 기술을 완성하는 것에서만 삶의 의미를 찾는다. |
| **구도자** | 정신 | 세상의 이치나 깨달음을 얻기 위해 끊임없이 수련한다. 전투조차도 수련의 연장으로 여기며, 강한 상대와 싸우며 성장하는 것을 즐거움으로 삼는다. |
| **풍류가** | 정신 | 세상사를 한 발짝 뗴어서 관조하는 여유를 가진다. 아름다운 것을 즐길 줄 알며, 긴박한 상황에서도 농담을 던질 수 있는 대범함이 있다. |
| **낭만주의자** | 정신 | 효율보다 멋과 낭만을 중시한다. 비겁한 승리보다는 화려한 패배를 선호하며, 드라마틱한 상황을 연출하려 든다. |
| **무구한 살의** | 정신 | 살인 행위에 감정이나 죄책감을 싣지 않아, 상대가 살기를 감지하기 어렵거나 위화감을 느낀다. |
| **도구적 이성** | 정신 | 인간적인 연민이나 도덕률보다 임무의 완수와 효율성을 최우선 가치로 판단한다. |
| **사심 없음** | 정신 | 행위에 사적인 욕심이 섞이지 않아, 유혹이나 타락, 매수 등의 교섭이 통하지 않는다. |
| **배신의 낙인** | 정신 | 타인을 뼛속까지 불신하며, 언제든 배신당할 수 있다는 전제하에 행동한다. 역설적으로 자신이 먼저 배신하는 것을 합리화하며, 누군가에게 진심을 주는 것을 극도로 두려워한다. |
| **비련의 악녀** | 정신 | 사랑하는 사람을 위해서라면 가족도 국가도 팔아넘길 수 있는 맹목적인 애정을 품고 있다. 그 사랑이 배신당했을 때 세상에서 가장 잔혹한 악녀로 돌변한다. |
| **헌신과 집착** | 정신 | 한 번 마음을 연 상대에게는 자신의 모든 어빌리티와 자원을 바쳐 헌신한다. 그러나 그 헌신은 도를 지나쳐 상대방을 통제하려 하거나, 상대에게 접근하는 이들을 배제하려는 집착으로 변질되기도 한다. |
| **시스템 파괴자** | 정신 | 고착화된 시스템이나 질서를 혐오하며, 이를 내부에서부터 붕괴시키는 데 희열을 느낀다. 조직의 허점을 찾아내거나 불합리한 규칙을 깨부수는 데 천재적인 재능이 있다. |
| **수집가** | 정신 | 희귀한 재료나 아름다운 물건, 혹은 특이한 생명체를 수집하는 것에 병적인 집착을 보인다. 수집품 채워 넣는 것을 낙으로 삼으며, 컬렉션을 건드리면 불같이 화를 낸다. |
| **오만** | 정신 | 자신을 제외한 대다수를 하등한 존재(잡종)로 여기며, 타인의 의견을 무시한다. 자신의 기준에 부합하지 않는 자와는 대화조차 섞으려 하지 않는다. |
| **수집광** | 정신 | 세상의 진귀한 물건은 모두 자신의 소유라고 생각한다. 보물을 훔친 자는 끝까지 추적해 응징하며, 자신의 창고가 채워지는 것에 희열을 느낀다. |
| **진실을 아는 자** | 정신 | 우주의 진리와 세계의 구조를 이해하고 있다. 혼돈이나 정신 공격에 영향을 받지 않으며, 세계의 멸망 앞에서도 의연함을 유지한다. |
| **파괴의 화신** | 정신 | 필요하다면 문명을 리셋하고 다시 시작할 냉혹함을 지닌다. 파괴를 단순한 폭력이 아닌, 새로운 창조를 위한 정화 과정으로 여긴다. |
| **재력 과시** | 정신 | 자신의 부를 과시하지 않고는 못 배긴다. 적을 죽일 때조차 값비싼 보석을 던지거나 황금 탄환을 쓰는 등, 비효율적인 사치를 부린다. |
| **관측자** | 정신 | 역사의 시작부터 끝까지 지켜보는 초월적인 시점을 가진다. 당장의 승패보다 인류 전체의 흐름이나 역사의 분기점을 관측하는 것에 흥미를 느낀다. |
| **스포일러** | 정신 | 세상 모든 일의 결말을 알고 있기에 삶에 권태를 느낀다. 예상 밖의 변수나 자신의 예측을 뛰어넘는 '바보 같은' 행동에만 흥미를 보인다. |
| **사냥꾼의 집요함** | 정신 | 한번 표적으로 지정한 대상은 세상 끝까지라도 쫓아가는 집요함을 가진다. 도주 경로를 예측하고 은신처를 찾아내는 추적 어빌리티가 탁월하며, 임무 완수 전까지는 쉬지 않는다. |
| **고지식한 융통성** | 정신 | 원칙주의자처럼 보이지만, 예상치 못한 호의나 비논리적인 상황에 약하다. 규칙과 현실 사이에서 갈등하거나, 겉으로만 엄격한 척하는 허당 기질이 있다. |
| **문신 중독** | 정신 | 자신의 몸에 의미 있는 문자나 그림을 새기는 것에 집착한다. 피부에 빈 곳이 있으면 불안해하며, 새로운 힘을 얻을 때마다 기념으로 문신을 추가하려 한다. |
| **보복주의자** | 정신 | 은혜든 원한이든 자신이 받은 것은 반드시 동일하거나 더 큰 크기로 되돌려줘야 직성이 풀린다. 당하고는 못 사는 성격이다. |
| **전투광** | 정신 | 평소의 무뚝뚝한 모습과 달리, 강한 적과 싸울 때 희열을 느끼고 미소를 짓는다. 피를 볼수록 투쟁심이 고조된다. |
| **가문의 굴레** | 정신 | 태어날 때부터 정해진 가문의 의무와 기대에 짓눌려 있다. 개인의 행복보다 가문의 명예나 사명을 우선시하도록 세뇌에 가깝게 교육받았다. |

| **프론티어 정신** | 정신 | 미지의 세계에 대한 호기심과 모험심, 그리고 위험을 무릅쓰고 나아가는 도전 정신. |
| **사이오닉 네트워크 (Psionic Network)** | 정신 | 개체 간의 정신적 연결이 구축되어 있어, 언어나 신호 없이도 동료의 상태와 위치를 실시간으로 파악한다. |
| **절대 복종 (Absolute Obedience)** | 정신 | 상위 개체의 명령에 대해 의심이나 거부감을 갖지 않으며, 죽음을 불사하고 임무를 수행한다. |
| **자아 부재 (No Self)** | 정신 | 개별적인 자아가 희미하거나 없으며, 오직 군단의 일부로서만 기능한다. 공포나 고통에 의한 도주가 발생하지 않는다. |
| **빛 혐오** | 정신 | 순수하고 밝은 빛을 극대로 혐오하며, 강한 빛 아래에서는 능력치가 감소하거나 고통을 느낌. |
| **강철의 폭군 (Iron Tyrant)** | 정신 | 자신을 따르지 않는 자는 철저히 짓밟으며, 공포와 힘으로 지배할 때 가장 큰 희열과 안정을 느낌. |
| **영혼의 가면** | 정신 | 자신의 사악한 본성과 오라를 완벽하게 숨겨, 성스러운 존재나 탐지 마법조차 그를 선한 존재로 착각하게 만듦. |
