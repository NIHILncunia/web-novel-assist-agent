# 10. 정신 (Mind & Spirit)

> **설명:** 존재의 자아, 의지력, 감정 상태, 신념, 트라우마 등 **내면의 정신세계(OS)**와 관련된 특성입니다.

## 키워드 목록

| 키워드 | 설명 |
| :--- | :--- |
| **광적인 신앙** | 특정 신이나 이념을 맹목적으로 따르며, 이를 위해 죽음도 불사하는 흔들리지 않는 믿음 |
| **피에 굶주림** | 이성적인 판단보다 살육과 파괴 행위 자체에서 오는 쾌락을 우선시함 |
| **집착** | 특정 물건, 인물, 목표에 병적으로 매달리며 그것을 잃으면 이성을 잃음 |
| **이중인격** | 상반된 두 가지 이상의 인격이 공존하며, 상황에 따라 주도권을 바꿈 |
| **복수심** | 자신이나 동족이 입은 피해를 잊지 않고, 대를 이어서라도 갚으려는 끈질긴 원념 |
| **탐욕** | 재물, 마력, 권력 등에 대해 만족을 모르고 끝없이 갈망함 |
| **명예 중시** | 승리보다 과정을 중시하며, 적이라도 정정당당한 승부를 원하고 약속을 생명처럼 여김 |
| **사이코패스** | 타인의 고통이나 감정에 전혀 공감하지 못하고, 그들을 자신의 목적을 위한 도구로만 여김 |
| **왕의 자존심** | 타인에게 고개를 숙이거나 지배당하는 것을 죽기보다 싫어하며, 모욕을 당하면 반드시 응징함 |
| **신성 거부** | 신이나 성스러운 존재에 대해 본능적인 혐오감과 반발심을 가짐 |
| **편집증적 광기** | 주변의 모든 것을 의심하고, 사소한 징조에도 심각한 위협을 느껴 선제공격을 가함 |
| **광적인 수집벽** | 쓰레기나 특정 물건(뼈, 돌 등)을 병적으로 모으고, 건드리면 격분함 |
| **파괴적 본능** | 눈앞에 존재하는 질서나 형체를 무너뜨리고 부수려는 원초적인 충동 |
| **마술 혐오** | 마법이나 초자연적인 힘을 부정한 것으로 여기며 극도로 불신함 |
| **마모된 감정** | 너무 오랜 세월을 살거나 비극을 겪어, 기쁨도 슬픔도 느끼지 못하는 건조한 상태 |
| **생존자의 죄책감** | 동료나 가족 중 홀로 살아남았다는 죄책감에 시달리며, 자신의 행복을 거부함 |
| **왜곡된 이타심** | 남을 돕는다는 명분으로 상대의 의사를 무시하거나, 자신의 희생을 강요함 |
| **강철의 마음** | 육체가 부서지는 고통이나 절망적인 상황 앞에서도 결코 꺾이지 않는 불굴의 의지 |
| **감정 동조** | 자신의 주관이 희미해, 주변 존재들의 강렬한 감정(분노, 공포)에 쉽게 전염됨 |
| **광기의 전염** | 존재 자체가 비상식적이라, 대화를 나누거나 정신이 연결된 상대를 미치게 만듦 |
| **현실 조작** | 자신의 강력한 망상이나 믿음이 물리적인 현실에 영향을 미쳐 세계를 왜곡함 |
| **기억 포식** | 타인의 기억을 먹어야 자아를 유지할 수 있으며, 먹은 기억의 인격을 연기하기도 함 |
| **하이브 마인드** | 개별적인 자아가 없이 여왕이나 집단 지성의 명령을 자신의 의지처럼 수행함 |
| **유리 멘탈** | 평소에는 강해 보이지만, 예상치 못한 실패나 모욕을 당하면 급격히 무너져 내림 |
| **공허한 영혼** | 감정과 욕구가 거세된 텅 빈 상태. 허무주의에 빠져 있으며 외부 자극에 둔감함 |
| **고결한 기사도** | 약자를 보호하고 정의를 수호하려는 도덕적 신념을 목숨보다 소중히 여김 |
| **타락한 신념** | 한때는 숭고했으나, 과정이 왜곡되어 악행을 정의라 믿고 행하는 뒤틀린 신념 |
| **예술적 광기** | 완벽한 아름다움이나 예술적 성취를 위해서라면 살인이나 파괴도 서슴지 않음 |
| **자기 파괴적 충동** | 극심한 스트레스를 받거나 흥분하면 자신의 몸을 해치는 방식으로 감정을 표출함 |
| **멸사봉공** | 사사로운 이익이나 개인의 행복을 철저히 배제하고 집단이나 큰 대의를 위해서만 헌신함 |
| **회귀 본능** | 자신의 과거나 운명을 부정하고, 그것을 되돌리거나 수정하려는 강렬한 집착과 미련 |
| **이상주의** | 현실의 제약이나 타협을 거부하고, 도덕적으로 완벽한 세계나 목표를 쫓는 고결하지만 위험한 정신 |
| **충절의 강박** | 과거의 배신이나 실패에 대한 트라우마로 인해 주군에게 병적으로 집착하며 충성을 증명하려 함 |
| **유열 추구** | 타인의 번민, 갈등, 혹은 파멸하는 모습에서 비틀린 즐거움과 살아있음을 느낌 |
| **인간 찬가** | 인간의 나약함과 추악함조차 그들의 가능성으로 인정하며, 그들의 발버둥을 사랑하고 지켜보는 초월적 시선 |
| **허무주의** | 삶의 의미나 가치를 부정하며, 세상의 파멸이나 무질서를 담담하게 받아들이거나 조장함 |
| **쾌락적 구도자** | 도덕이나 법보다는 자신의 쾌락과 호기심을 충족시키는 것을 인생의 유일한 목표로 삼음 |
| **순교자 콤플렉스** | 자신이 희생함으로써 구원받거나 인정받을 수 있다고 믿으며, 고통을 자처함 |
| **비겁함** | 생존을 위해서라면 동료를 배신하거나 비굴하게 구는 것을 부끄러워하지 않음 |
| **완벽주의** | 티끌만 한 오점도 용납하지 못하며, 완벽하지 않은 것은 가치가 없다고 여겨 파기함 |
| **열등감** | 타인과 자신을 끊임없이 비교하며, 자신의 부족함에 대해 분노하거나 좌절함 |
| **메시아 콤플렉스** | 자신만이 세상을 구원할 수 있다고 믿으며, 타인의 구원을 자신의 사명으로 여김 |
| **사디즘 (가학증)** | 타인에게 고통을 주거나 지배함으로써 성적, 정신적 만족감을 느낌 |
| **마조히즘 (피학증)** | 타인에게 학대받거나 고통받는 상황에서 오히려 안도감이나 쾌락을 느낌 |
| **금욕주의** | 욕망을 억제하고 고행을 통해 정신적 완성을 추구하며, 물질적 풍요를 거부함 |
| **비틀린 인과** | 타인의 소망이나 기도를 들어주려 하지만, 그 과정과 결과를 가장 파괴적이고 비극적인 형태로 왜곡하여 실현하는 본능 |
| **혐오스러운 오라** | 별다른 행동을 하지 않아도 주변 존재들에게 본능적인 혐오감과 공포심을 심어주어, 사회적 상호작용을 불가능하게 만듦 |
| **마나 중독** | 마력이 풍부한 환경에서는 강력해지지만, 마력이 희박한 곳에서는 극심한 금단 증상(불안, 초조)을 겪음 |
| **순수한 영혼** | 마나 친화력이 극도로 높고 선한 성향을 지니지만, 타인의 악의나 거짓말을 의심하지 못해 쉽게 이용당함 |
| **끝없는 탐구심** | 미지의 영역이나 새로운 지식에 대해 두려움 없이 접근하며, 이를 빠르게 습득하고 자신의 것으로 만든다. |
| **시련의 즐거움** | 위기 상황이나 강적을 조우할수록 정신 고양감이 높아져 공포를 느끼지 않게 된다. |
| **냉철한 계산** | 감정에 휘둘리지 않고 피해와 이득을 정확히 계산하여, 필요하다면 아군의 희생도 전술의 일부로 삼는다. |
| **대인배** | 사소한 모욕이나 피해에 연연하지 않으며, 적이라도 훌륭한 점은 칭찬하고 인정하는 넓은 도량을 가진다. |
| **무방비의 방어** | 전혀 방어 태세를 취하지 않음으로서 오히려 적이 함정이 아닐까 의심하게 만들어 섣불리 공격하지 못하게 한다. |
| **영겁의 권태** | 불멸의 삶을 살아가며 느끼는 지독한 권태감 때문에, 사소한 자극이나 유희를 쫓음 |
| **정신 간섭 면역** | 강인한 정신력이나 이중 자아 덕분에, 정신 지배나 텔레파시 공격을 튕겨냄 |
| **희망의 상징** | 존재 자체만으로 사람들에게 희망을 주고, 절망적인 상황에서도 포기하지 않게 만듦 |
| **침략자의 본능** | 세계를 정복하거나 파괴하도록 프로그래밍된 본능이 이성을 뚫고 나오려 함 |
| **동족 혐오** | 자신과 같은 종족을 혐오하며, 그들을 멸종시키는 것을 사명으로 여김 |
| **이중인격의 괴리** | 영웅으로서의 자아와 소시민으로서의 자아가 끊임없이 충돌하며 정체성의 혼란을 겪음 |
| **관심 종자** | 타인의 관심과 사랑을 받지 못하면 힘을 잃거나 존재가 희미해지는 강박적 성향 |
| **사랑의 사도** | 증오나 분노에 잠식되지 않는 순수한 정신을 가지며, 타인을 돕고 사랑하는 행위에서 힘을 얻음 |
| **무력에 의한 평화** | "진정한 평화는 압도적인 힘 아래서만 유지된다"는 신념을 가지고, 평화를 위해 무력을 행사함 |
| **도시전설** | 존재 자체가 불확실한 소문으로 퍼져 있어, 조우하는 적들에게 공포와 혼란을 줌 |
| **생존자 증후군** | 재난에서 홀로 살아남았다는 부채감으로 인해, 자신의 행복을 죄악시하고 희생을 당연시함 |
| **이타적 기계** | 공감이나 인간적인 감정이 결여된 채, 입력된 프로그램처럼 타인을 돕는 행위를 기계적으로 수행함 |
| **차용된 이상** | 스스로의 욕망이 아닌, 타인이 남긴 이상이나 꿈을 맹목적으로 동경하고 모방하며 살아감 |
| **파탄 난 가치관** | 가치 판단의 기준이 왜곡되어, 자신을 가장 소모적인 도구로 취급하며 자기 파괴적인 선택을 함 |
| **냉소적 실용주의** | 대의를 위해서라면 감정을 배제하고 가장 효율적이고 비정한 수단을 선택함 |
| **자기 혐오** | 자신의 과거 모습이나, 자신이 혐오하는 과거의 신념을 가진 자를 보면 참을 수 없는 혐오감을 느낀다 |
| **타락의 산파** | 닿는 대상(생명체, 영령)을 오염시켜 자신의 수족으로 만들며, 순수한 존재일수록 더 빨리 타락시킴 |
| **이중 자아** | 평소의 착한 인격과 억눌린 욕망이 표출된 잔혹한 인격이 공존하며, 충격 시 주도권이 바뀜 |
| **고통 내성** | 극심한 육체적 고통에 익숙해져, 일반인이라면 기절할 수준의 고통에도 의식을 유지함 |
| **억눌린 분노** | 평소에는 온화해 보이지만, 내면에는 세상을 향한 증오와 분노가 마그마처럼 끓고 있음 |
| **결정적 실수** | 평소에는 완벽하지만, 중요한 승부처나 결정적인 순간에 반드시 치명적인 실수를 저지름 (징크스) |
| **명문가의 긍지** | 언제나 우아하고 여유로운 태도를 유지하려 하며, 타인에게 약한 모습을 보이는 것을 극도로 싫어함 |
| **책임감** | 자신의 관리 구역이나 맡은 임무에 대해 끝까지 책임을 지려 하며, 손해를 보더라도 해결하려 함 |
| **왕의 위엄** | 군단을 지휘하는 타고난 왕의 기질. 아군의 사기를 고취시키고, 적에게는 범접할 수 없는 위압감을 준다 |
| **무거운 왕관** | 리더라는 자리의 무게감 때문에 개인의 행복을 포기하고 공적인 임무에만 몰두하며, 정신적 피로가 항상 누적되어 있다 |
| **기사의 맹세** | 명예와 신의를 목숨보다 중시한다. 약자를 보호하고 악에 맞서며, 비겁한 수단(인질, 독 등)을 혐오하고 거부한다 |
| **정면 승부** | 적이라 해도 경의를 표할 만한 상대라면 1:1 정면 승부를 고집한다. 기습이나 함정을 사용하는 것을 수치스럽게 여긴다 |
| **완벽주의자의 고뇌** | 타인에게도 자신과 같은 완벽함을 요구하거나, 자신의 기준에 미치지 못하는 현실에 고뇌한다. 고립을 자초하기 쉽다 |
| **이종족의 고독** | 인간과 다른 존재가 되어버렸다는 소외감을 느끼며, 인간 사회에 완전히 섞이지 못하고 겉돈다 |
| **전투 경험자** | 무수한 전투를 경험하여, 어떤 상황에서도 침착함을 유지하고 최적의 판단을 내린다. 공포나 압박에 쉽게 흔들리지 않는다 |
| **수호자의 고뇌** | 대의를 위해 무수한 생명을 제거해야 했던 과거로 인해 깊은 고뇌에 빠져 있다. 자신의 선택이 정당했는지 끊임없이 의심하며, 정신적 피로가 누적되어 있다 |
| **자기 부정** | 자신의 과거나 미래의 모습을 부정하고, 그런 존재가 되지 않으려고 노력한다. 하지만 이미 그 길을 걸었기 때문에 절망감이 깊다 |
| **냉소적 현실주의** | 이상주의를 버리고 현실을 냉정하게 바라본다. 감정에 휘둘리지 않고 효율적인 선택을 하지만, 그 과정에서 인간성을 잃어가는 것에 대한 두려움을 느낀다 |
| **영웅이 되지 못한 자** | 영웅이 되려 했지만 실패하여 무명의 존재가 되었다. 영웅들의 이름을 빌려 복제품으로 싸워야 하는 역설적 상황에 처해 있으며, 자신의 정체성에 대한 혼란이 깊다 |
| **복제품의 자존심** | 원본이 아닌 복제품으로 싸워야 하는 것에 대한 자존심 상처를 가지고 있다. 원본의 주인과 맞서는 것을 두려워하지만, 동시에 복제품으로도 승리할 수 있다는 것을 증명하려 한다 |
| **인간성 상실 (Humanity Loss)** | 마물로 변해가면서 인간적인 감정이나 도덕관이 점차 사라진다. 냉혹하고 효율적인 사고만 남게 된다. |
| **조기 교육의 흔적** | 어린 시절부터 엄격하고 체계적인 교육을 받아 형성된, 어른스러운 사고 방식과 책임감을 가진다. |
| **가문의 사명** | 가문의 목적을 달성하는 것이 자신의 존재 이유가 되었다. 목표를 위해 감정과 개인적 행복을 뒤로 미루기 쉽다. |
| **가문의 기대** | 후계자로서 모든 기대를 짊어지는 압박을 느낀다. 실패에 대한 두려움이 판단과 행동에 영향을 줄 수 있다. |
| **냉정한 판단** | 감정에 휘둘리지 않고 이성과 논리로 상황을 분석해 최적의 선택을 내린다. |
| **감정 억제** | 목적 달성을 위해 감정을 억누르고 이성을 우선시한다. 감정적 동요가 판단에 영향을 주지 않게 만든다. |
| **감정 마비** | 과도한 억제나 충격으로 감정을 느끼는 능력 자체가 둔화되거나 마비된 상태다. |
| **냉정함의 가면** | 겉으로는 냉정해 보이지만 내면에는 감정이 존재한다. 냉정함은 자신을 보호하기 위한 방어 기제일 수 있다. |
| **마술사의 자존심** | 자신의 능력과 지위에 강한 자부심을 가진다. 인정받고자 하며, 타인을 경시하는 태도로 갈등을 만들 수 있다. |
| **패배 불수용** | 패배나 실패를 인정하지 못하고 스스로의 우위를 고집하려는 경향이 있다. |
| **자존심 회복** | 자존심이 상처받았을 때 이를 회복하기 위해 과격한 행동이나 증명 욕구에 집착한다. |
| **자존심의 가면** | 외형상 강한 자존심 뒤에 불안감이나 열등감이 숨겨져 있다. 자존심이 방어 기제로 작동한다. |
| **이성 상실 (Loss of Reason)** | 광화 상태에서는 이성적인 판단이나 복잡한 전술을 사용할 수 없다. 본능과 감각에만 의존하여 행동한다. |
