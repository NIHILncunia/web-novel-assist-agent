# 09. 생활 (Daily Life)

> **설명:** 전투나 모험 외에 일상생활, 가사, 직업 활동, 혹은 무리 내에서의 역할과 관련된 특성입니다. NPC의 직업이나 몬스터의 생태적 지위를 나타내기도 합니다.

---

### 생활 기술 및 역할

| 키워드 | 설명 |
| :--- | :--- |
| **살림꾼** | 요리, 청소, 도구 수리 등 가사 전반에 뛰어난 재능을 보이며, 타인을 돌보는 것에서 만족을 느낌 |
| **장인** | 무기, 도구, 예술품 등을 만들거나 수리하는 손재주가 뛰어남 (대장장이, 세공사) |
| **추적자** | 사냥감의 흔적, 발자국, 냄새를 분석하여 끈질기게 뒤를 쫓음 |
| **기록자** | 역사, 지식, 마법 등을 기록하고 보존하려는 학구적인 본능 |
| **약탈자** | 남의 것을 효율적으로 훔치거나 빼앗는 기술과 생존 방식 |
| **중재자** | 무리 간의 분쟁을 조율하거나, 타 종족과의 거래/협상을 담당함 |
| **예술가** | 뼈, 돌, 나무 등으로 기이한 조형물을 만들거나 춤/노래로 감정을 표현함 |
| **채집가** | 약초, 광물, 식재료 등 유용한 자원을 식별하고 수집하는 능력 |
| **지도자** | 무리를 통솔하고 지휘하며, 구성원의 사기를 높이는 카리스마 |
| **교육자** | 어린 개체나 후임자에게 생존 기술과 지식을 전수함 |
| **수호자** | 특정 대상이나 지역을 목숨 걸고 지키는 역할을 수행함 |
| **신수 조련** | 일반적인 방법으로는 길들일 수 없는 환수나 마수급 생명체를 자유자재로 부릴 수 있다. |
| **대식가** | 신체 활동에 필요한 에너지를 보충하기 위해 일반적인 양을 훨씬 초과하는 식사를 함 |
| **위장 신분** | 성별, 신분, 직업 등을 철저히 숨기거나 가짜 신분을 내세워 사회 활동을 함 |
| **문지기** | 차원의 문이나 던전 입구를 지키며 자격을 시험하거나 통행료를 징수함 |
| **장의사** | 시체를 처리하고 영혼을 달래주거나, 시체에서 유용한 부위를 적출하는 전문가 |
| **암시장 상인** | 금지된 물건이나 정보를 은밀하게 거래하는 뒷세계의 상인 |
| **이중 간첩** | 적대적인 두 세력 사이를 오가며 정보를 팔고 이득을 취함 |
| **외교관** | 서로 말이 통하지 않는 이종족 간의 대화를 통역하고 조율함 |
| **마물 요리사** | 독이 있거나 기괴한 몬스터를 조리하여 안전하고 맛있는(혹은 효과 있는) 음식으로 만듦 |
| **고물상 (Scavenger)** | 전장이나 폐허를 뒤져 쓸만한 부품이나 유물을 수집하고 재활용함 |
| **지도 제작자** | 미지의 영역을 탐험하며 지형과 위험 요소를 기록하여 지도로 만듦 |
| **간수** | 탈출이 불가능한 감옥이나 봉인된 괴물을 감시하고 관리함 |
| **영혼 치유사** | 육체의 상처가 아닌, 트라우마나 저주받은 영혼을 치유하고 상담함 |
| **소시민의 연기** | 정체를 숨기기 위해, 일부러 어리숙하거나 평범하고 존재감 없는 소시민을 완벽하게 연기함 |
| **자비로운 중재자** | 분쟁 중인 세력 사이에 개입하여 대화와 협상으로 평화를 이끌어내는 탁월한 외교적 능력 |
| **신조 병기** | 필멸자의 기술로는 절대 파괴하거나 녹일 수 없는 '파괴 불가' 속성의 장비를 사용함 |
| **귀족의 의무** | 상류층 사교계에서의 명성과 인맥을 활용하여 고급 정보를 수집하거나 정치적 영향력을 행사함 |
| **몰락한 귀족** | 과거엔 엄청난 부자였으나 현재는 파산하여, 낡은 장비와 과거의 영광(허세)만 남은 상태 |
| **암시장 큰손** | 합법적인 부자가 아니라, 뒷세계의 경제를 쥐락펴락하는 어둠의 자본가로서 불법 무기를 조달함 |
| **만능 수리공** | 고장 난 기계나 도구의 원인을 즉시 찾아내고 손쉽게 수리함 |
| **세계의 청소부** | 거대한 질서의 존속을 위해 위험 요소를 배제하는 임무를 띠고 활동함 (자유 의지 억압) |
| **재물 소모** | 강력한 힘을 발휘하기 위해 값비싼 매개체(보석 등)를 소모해야 함 (전투 시 재산 피해 막심) |
| **근접 마법사** | 마법사임에도 불구하고 거리 벌리기보다는 적극적으로 접근하여 육탄전을 벌이는 것을 선호함 |
| **고결한 굶주림** | 평소에는 엄격하고 금욕적이지만, 맛있는 음식 앞에서는 무장 해제된다. 엄청난 대식가이며 식사에 진심이다 |
| **복제 마법사** | 마법사임에도 불구하고 창조보다는 복제에 특화되어 있어, 원본을 분석하고 재현하는 데 뛰어난 재능을 보인다 |
| **무기 수집가** | 강력하거나 희귀한 무기를 보면 복제하여 수집하려는 본능적인 욕구를 가진다. 무기 컬렉션이 많을수록 전투력이 향상된다 |
| **환상종 조련사 (Phantasmal Beast Tamer)** | 전설의 환상종이나 마수를 조련하고 부릴 수 있는 특별한 재능을 가진다. 일반적인 방법으로는 길들일 수 없는 존재도 제어할 수 있다. |
| **소환 계약자** | 소환술에 특화되어 존재를 소환하고 계약·지배·유지하는 일을 전문적으로 수행한다. |
| **거짓된 주인** | 실질적인 능력이나 자격은 없으나, 특수한 계약이나 도구를 통해 명목상의 지배권을 행사하는 상태. |
| **권력 기생** | 독자적인 생존력은 낮으나, 강력한 숙주(조직, 후원자)에 속해 있을 때 자원 획득량이나 사회적 영향력이 증폭된다. |
| **도구 취급** | 타인에 의해 자신의 의지와 상관없이 소모품이나 매개체로 이용당하기 쉬운 운명적 특성. |
| **충직한 번견** | 자신이 모시기로 맹세한 주인을 위해서라면 지옥 불 속이라도 뛰어든다. 배신을 가장 혐오하며, 주인의 명령(신뢰 관계 전제)이라면 목숨을 건 임무도 묵묵히 수행한다. |
| **저주받은 무기** | 소유자가 다루는 무기에는 항상 씻을 수 없는 저주가 깃들어 있다. 이 무기에 상처 입은 자는 회복 마법이 듣지 않으며, 상처가 썩어들어가거나 계속해서 피를 쏟게 된다. |
| **피를 부르는 창** | 전투를 시작하면 적의 피를 보기 전까지 무기를 거두지 못한다. 적을 죽이지 못하면 자신의 피라도 바쳐야 무기의 갈증이 해소된다. |
| **야행성 (Nocturnal)** | 낮에는 무기력하지만, 해가 지고 밤이 되면 신체 능력과 정신력이 상승한다. 어둠 속에서 더 잘 보이고 더 빠르게 움직인다. |
| **산의 노인** | 엄격한 규율을 가진 비밀 조직의 수장. 조직의 대의를 위해서라면 자신의 얼굴과 이름, 심지어 인간성까지 버릴 준비가 되어 있다. |
| **과묵한 반려** | 말보다는 행동으로 신뢰를 증명하며, 파트너가 위기에 처했을 때 절대 배신하거나 도망치지 않는다. |
| **마법 도구 장인** | 마력을 띤 도구나 아티팩트를 만드는 데 천부적인 재능을 가진다. 짧은 시간 안에 고품질의 마법 지팡이, 부적, 스크롤 등을 뚝딱 만들어낸다. |
| **시대착오적** | 현대 사회의 상식이나 기술에 익숙하지 않아 엉뚱한 실수를 한다. 스마트폰을 못 쓰거나, 현대 패션 감각을 이해하지 못하는 등 생활력이 부족하다. |
| **검투사 (Gladiator)** | 대중의 환호를 즐기며, 1:1 전투와 살육에 특화된 직업적 전사. |
| **장물아비** | 훔친 물건의 가치를 알아보고 세탁하여 판매하는 뒷골목 상인. |
| **이단 심문관** | 교리에 어긋나는 존재를 색출하고 고문하거나 정화하는 집행자. |
| **무덤 도굴꾼** | 고대 무덤이나 유적의 함정을 해체하고 부장품을 훔치는 전문가. |
| **결계사** | 거점이나 시설을 보호하는 마법 장벽을 설치하고 유지보수하는 기술자. |
| **이중 첩자** | 적대하는 두 세력 모두에게 정보를 팔며 줄타기를 하는 정보상. |
| **군사 귀족 (Junker)** | 대대로 장군을 배출하는 명문 무가. 명예와 규율을 중시하며 사병을 거느림. |
| **파르티잔 (Partisan)** | 정규군이 패배한 뒤 점령지에서 게릴라전을 수행하는 비정규 저항군. |
| **군수업자** | 전쟁 당사국 양쪽에 무기를 팔아 막대한 이득을 취하는 죽음의 상인. |
| **헌병 (MP)** | 군 내부의 기강을 잡고 탈영병이나 범죄자를 체포하는 군사 경찰. |
| **야전 취사** | 열악한 재료로도 빠르고 영양가 높은 식사를 만들어 사기를 높인다. |
| **부패 경찰** | 범죄자와 결탁하여 뒤를 봐주고 이득을 챙기는 타락한 치안 유지군. |
| **정보상 (Informant)** | 돈만 주면 도시의 모든 비밀을 캐내어 파는 정보의 허브. |
| **해결사 (Fixer)** | 의뢰를 받아 더러운 일을 처리해 주는 만능 심부름꾼. |
| **사냥꾼 (Hunter)** | 짐승이나 몬스터의 습성을 파악하고 추적하여 사냥하는 전문가. |
| **약초꾼 (Herbalist)** | 깊은 산속에서 희귀한 약초나 독초를 채집하여 약을 만드는 사람. |
| **지도 제작자** | 미지의 영역을 탐험하며 지형을 기록하고 길을 개척하는 모험가. |
| **마물 요리사** | 독이 있거나 기괴한 몬스터를 안전하고 맛있는 요리로 가공하는 전문가. |
| **나무꾼** | 거친 숲에서 나무를 베고 길을 만들며 곰 같은 힘을 씀. |
| **음유시인 (Bard)** | 전설과 소문을 노래로 퍼뜨리며 여론을 조작하거나 사기를 북돋음. |
| **궁정 요리사** | 최고급 재료로 버프 효과가 있는 요리를 만듦. |
| **정원사 (Gardener)** | 희귀한 식물을 가꾸고 약초를 재배함. |
| **건축가** | 튼튼한 요새나 아름다운 신전을 설계하고 감독함. |
| **사서 (Librarian)** | 고대 문서를 관리하고 필요한 정보를 찾아줌. |
| **교사 (Teacher)** | 지식을 전수하고 제자를 육성함. |
| **양조장인** | 최고의 술을 빚어 사람들을 즐겁게 하고 정보를 얻음. |
| **보석 세공사** | 마석을 가공하여 아이템에 장착하거나 장신구를 만듦. |
| **통역가** | 다양한 종족의 언어를 통역하여 교섭을 도움. |
| **지도 제작자 (Cartographer)** | 미지의 땅을 탐험하며 지도를 그림. |
| **의사 (Doctor)** | 마법 없이 의술과 약으로 병을 고침. |
| **상인 (Merchant)** | 물건의 가치를 알아보고 싸게 사서 비싸게 팖. |
| **농부 (Farmer)** | 척박한 땅에서도 작물을 키워내는 근면함. |
| **광부 (Miner)** | 어둠 속에서 광맥을 찾아내는 감각. |
| **선원 (Sailor)** | 날씨를 읽고 배를 다루는 기술. |
| **해상왕 (Pirate King)** | 바다 위에서 왕처럼 군림하며, 선원들을 공포와 카리스마로 통솔함 (해적 특화) |
| **산중호걸 (Mountain King)** | 험준한 산세를 내 집 안방처럼 드나들며 매복과 기습에 능통함 (산적/도적 특화) |
| **수적 (Water Bandit)** | 강이나 호수 주변에 숨어들어 물길을 이용한 약탈과 도주에 특화됨 |
| **밀수꾼 (Smuggler)** | 봉쇄망이나 검문을 뚫고 금지된 물품을 운반하는 은밀한 경로를 알고 있음 |
| **현상수배 (Wanted)** | 목에 걸린 현상금의 액수를 곧 자신의 힘이자 자부심 척도로 여김 |
