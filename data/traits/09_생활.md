# 09. 생활 (Daily Life)

> **설명:** 전투나 모험 외에 일상생활, 가사, 직업 활동, 혹은 무리 내에서의 역할과 관련된 특성입니다. NPC의 직업이나 몬스터의 생태적 지위를 나타내기도 합니다.

---

### 생활 기술 및 역할

| 키워드 | 설명 |
| :--- | :--- |
| **살림꾼** | 요리, 청소, 도구 수리 등 가사 전반에 뛰어난 재능을 보이며, 타인을 돌보는 것에서 만족을 느낌 |
| **장인** | 무기, 도구, 예술품 등을 만들거나 수리하는 손재주가 뛰어남 (대장장이, 세공사) |
| **추적자** | 사냥감의 흔적, 발자국, 냄새를 분석하여 끈질기게 뒤를 쫓음 |
| **수호자** | 특정 장소(성소, 둥지)나 대상(주인, 유생)을 지키는 것에 특화된 방어적 본능 |
| **기록자** | 역사, 지식, 마법 등을 기록하고 보존하려는 학구적인 본능 |
| **약탈자** | 남의 것을 효율적으로 훔치거나 빼앗는 기술과 생존 방식 |
| **중재자** | 무리 간의 분쟁을 조율하거나, 타 종족과의 거래/협상을 담당함 |
| **예술가** | 뼈, 돌, 나무 등으로 기이한 조형물을 만들거나 춤/노래로 감정을 표현함 |
| **채집가** | 약초, 광물, 식재료 등 유용한 자원을 식별하고 수집하는 능력 |
| **지도자** | 무리를 통솔하고 지휘하며, 구성원의 사기를 높이는 카리스마 |
| **교육자** | 어린 개체나 후임자에게 생존 기술과 지식을 전수함 |
| **수호자** | 특정 대상이나 지역을 목숨 걸고 지키는 역할을 수행함 |
| **신수 조련** | 일반적인 방법으로는 길들일 수 없는 환수나 마수급 생명체를 자유자재로 부릴 수 있다. |
| **대식가** | 신체 활동에 필요한 에너지를 보충하기 위해 일반적인 양을 훨씬 초과하는 식사를 함 |
| **위장 신분** | 성별, 신분, 직업 등을 철저히 숨기거나 가짜 신분을 내세워 사회 활동을 함 |
| **문지기** | 차원의 문이나 던전 입구를 지키며 자격을 시험하거나 통행료를 징수함 |
| **장의사** | 시체를 처리하고 영혼을 달래주거나, 시체에서 유용한 부위를 적출하는 전문가 |
| **암시장 상인** | 금지된 물건이나 정보를 은밀하게 거래하는 뒷세계의 상인 |
| **이중 간첩** | 적대적인 두 세력 사이를 오가며 정보를 팔고 이득을 취함 |
| **외교관** | 서로 말이 통하지 않는 이종족 간의 대화를 통역하고 조율함 |
| **마물 요리사** | 독이 있거나 기괴한 몬스터를 조리하여 안전하고 맛있는(혹은 효과 있는) 음식으로 만듦 |
| **고물상 (Scavenger)** | 전장이나 폐허를 뒤져 쓸만한 부품이나 유물을 수집하고 재활용함 |
| **지도 제작자** | 미지의 영역을 탐험하며 지형과 위험 요소를 기록하여 지도로 만듦 |
| **간수** | 탈출이 불가능한 감옥이나 봉인된 괴물을 감시하고 관리함 |
| **영혼 치유사** | 육체의 상처가 아닌, 트라우마나 저주받은 영혼을 치유하고 상담함 |
