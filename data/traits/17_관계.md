# 17. 관계 (Relationships)

> **설명:** 타인, 집단, 사회와의 상호작용(Interactions), 애정, 증오, 정치, 계급 등 **관계성(Relational/Social)**에 기반한 트레잇입니다.

## 트레잇 목록

| 키워드 | 분류 | 설명 |
| :--- | :---: | :--- |
| **가스라이팅** | 관계 | 상대의 기억이나 판단을 끊임없이 의심하게 만들어 심리적으로 지배함. |
| **그루밍 (Grooming)** | 관계 | 신뢰 관계를 쌓아 상대가 자신에게 의존하거나 성적/착취적 요구에 응하게 만듦. |
| **감정 쓰레기통** | 관계 | 자신의 부정적 감정이나 스트레스를 특정 대상에게 무차별적으로 쏟아붓고 해소함. |
| **죄책감 유발** | 관계 | "내가 널 위해 희생했다"는 말로 상대에게 죄책감을 심어 행동을 통제함. |
| **피해자 코스프레** | 관계 | 자신이 가해자임에도 불구하고 약자 흉내를 내며 동정심을 유발해 여론을 조작함. |
| **착취 관계** | 관계 | 한쪽이 일방적으로 노동력, 금전, 감정을 쏟아붓고 다른 쪽은 받기만 하는 불균형. |
| **공의존** | 관계 | 서로가 없으면 심리적으로 불안해하며, 파괴적 관계임에도 헤어지지 못함. |
| **가학적 통제** | 관계 | 상대를 감금하거나 일거수일투족을 감시하며 통제하는 것에서 쾌감을 느낌. |
| **인질극 (감정)** | 관계 | "네가 떠나면 죽어버리겠다"는 식의 자해 협박으로 상대를 옭아맴. |
| **애증 (Love-Hate)** | 관계 | 미칠 듯이 사랑하면서 동시에 죽이고 싶을 만큼 증오하는 복합적 감정. |
| **혐관 (Enemies to Lovers)** | 관계 | 서로 혐오하고 으르렁거리지만, 끊임없이 신경 쓰고 얽히는 관계. |
| **짝사랑의 저주** | 관계 | 이루어질 수 없는 상대를 맹목적으로 사랑하며, 그 사랑이 자신을 파갉아먹음. |
| **계약 연애/결혼** | 관계 | 사랑 없이 특정한 목적(유산, 신분 세탁 등)을 위해 맺어진 비즈니스적 관계. |
| **쇼윈도 부부** | 관계 | 대외적으로는 완벽한 잉꼬부부지만, 사적으로는 남보다 못한 냉랭한 사이. |
| **정략결혼** | 관계 | 가문의 이익이나 국가 간의 동맹을 위해 강제로 맺어진 결혼. |
| **환승 이별 (배신)** | 관계 | 더 나은 조건이나 매력을 가진 상대에게 갈아타며 기존 파트너를 비참하게 버림. |
| **첫사랑의 망령** | 관계 | 죽거나 떠난 첫사랑을 잊지 못해, 현재의 연인에게서 첫사랑의 그림자를 찾음. |
| **집착광** | 관계 | 상대의 모든 것을 소유하려 하며, 아주 사소한 거절조차 견디지 못하고 폭발함. |
| **얀데레** | 관계 | 사랑하는 대상을 위해서라면 살인도 서슴지 않으며, 방해되는 모든 것을 제거함. |
| **구원튀 (Hit & Run)** | 관계 | 절망에 빠진 상대를 구원해 놓고 책임은 지지 않은 채 홀연히 사라져버림. |
| **어장관리** | 관계 | 여러 이성에게 여지를 주며 희망 고문을 하고, 누구와도 진지한 관계를 맺지 않음. |
| **비즈니스 파트너** | 관계 | 철저하게 이익 공유를 목적으로 하며, 감정 개입 없이 사무적으로만 대함. |
| **공범** | 관계 | 중대한 범죄 비밀을 공유함으로써 운명 공동체로 묶인 관계. 배신은 곧 파멸. |
| **라이벌 (Rival)** | 관계 | 서로의 실력을 인정하고 경쟁하며 성장하는 선의의 경쟁자. |
| **앙숙 (Nemesis)** | 관계 | 마주칠 때마다 사사건건 시비를 걸고 싸우는 견원지간. |
| **악우 (Bad Friend)** | 관계 | 험한 말을 주고받고 서로를 한심하게 여기지만, 위기 때는 돕는 끈질긴 친구. |
| **소꿉친구** | 관계 | 어린 시절부터 볼꼴 못 볼 꼴 다 보고 자라 이성적 긴장감은 없으나 신뢰는 깊음. |
| **유사 가족** | 관계 | 피 한 방울 섞이지 않았지만, 서로를 진정한 가족으로 여기고 의지함. |
| **대리 부모** | 관계 | 부모의 부재를 대신하여 어린 상대를 헌신적으로 키우고 보호함. |
| **멘토-멘티** | 관계 | 스승과 제자로서 지식과 신념을 전수하고 정신적 지주가 되어줌. |
| **충성 경쟁** | 관계 | 주군의 총애를 독차지하기 위해 동료를 견제하고 공을 세우려 애씀. |
| **낙하산 (Nepotism)** | 관계 | 실력이 아닌 인맥이나 혈연으로 자리를 차지하여 주변의 무시를 받음. |
| **정치적 희생양** | 관계 | 조직이나 권력자의 안위를 위해 모든 잘못을 뒤집어쓰고 버려지는 말. |
| **운명적 파트너** | 관계 | 처음 만난 순간부터 영혼 깊은 곳이 연결되어 있음을 느끼는 불가항력적 관계. |
| **영혼의 쌍둥이** | 관계 | 가치관, 취향, 생각하는 방식이 놀라울 정도로 일치하여 말하지 않아도 통함. |
| **붉은 실 (악연)** | 관계 | 아무리 끊어내려 해도 질기게 이어져 서로에게 상처만 주는 지독한 악연. |
| **저주받은 인연** | 관계 | 사랑할수록 서로를 불행하게 만들거나 파멸로 이끄는 비극적 관계. |
| **윤회의 고리** | 관계 | 전생부터 이어져 온 인연으로, 현생에서도 다시 만나 사랑하거나 싸울 운명. |
| **대체품** | 관계 | 자신이 사랑받는 이유가 본인의 매력이 아니라, 누군가를 닮았기 때문임을 알고 있음. |
| **관측자와 피관측자** | 관계 | 한쪽은 일방적으로 지켜보고, 다른 쪽은 그 시선을 의식하지 못한 채 살아감. |
| **브로맨스/워맨스** | 관계 | 연인 관계는 아니지만, 그 이상의 깊은 유대감과 애정을 나누는 동성 관계. |
| **스승 살해 (살부계승)** | 관계 | 제자가 스승을 뛰어넘기 위해, 혹은 신념의 차이로 인해 스승을 죽여야 하는 비극. |
| **하극상** | 관계 | 부하나 아랫사람이 실력이나 야망으로 윗사람을 짓밟고 올라섬. |
| **짝패 (Partner)** | 관계 | 등 뒤를 맡길 수 있는 유일한 존재이자, 완벽한 호흡을 자랑하는 전투 파트너. |
| **팬심 (Fanaticism)** | 관계 | 특정 대상을 연예인이나 신처럼 숭배하며, 그와의 만남이나 인정을 갈구함. |
| **스토커** | 관계 | 상대의 의사와 상관없이 일거수일투족을 미행하고 감시하며 망상에 빠짐. |
| **감정적 갑을관계** | 관계 | 더 많이 사랑하는 쪽이 약자(을)가 되어 상대(갑)의 눈치를 보고 휘둘림. |
| **트로피 와이프/허즈번드** | 관계 | 자신의 성공이나 재력을 과시하기 위한 장식품으로서의 배우자. |
| **대리 만족** | 관계 | 자신이 이루지 못한 꿈을 자식이나 제자에게 투영하여 강요함. |
| **비밀 친구** | 관계 | 사회적 지위나 신분 차이 때문에 남들 몰래 우정을 나누는 관계. |
| **랜선 연애** | 관계 | 현실에서는 만난 적 없지만, 마법 통신이나 서신을 통해 깊은 감정을 나눔. |
| **원나잇 (One Night)** | 관계 | 하룻밤의 쾌락이나 위로를 위해 만나고 깨끗하게 헤어지는 관계. |
| **섹스 파트너** | 관계 | 감정적인 교류 없이 육체적인 관계만을 목적으로 만남. |
| **기둥서방/정부** | 관계 | 경제적 어빌리티가 있는 파트너에게 기생하여 생활을 유지함. |
| **마마보이/파파걸** | 관계 | 성인이 되어서도 부모에게 정신적, 경제적으로 과도하게 의존함. |
| **츤데레** | 관계 | 겉으로는 쌀쌀맞고 까칠하게 대하지만, 속 마음은 따뜻하고 상대를 챙김. |
| **메가데레** | 관계 | 호감을 숨기지 않고 상대에게 엄청난 애정 공세를 퍼부음. |
| **쿨데레** | 관계 | 감정 표현이 적고 무뚝뚝하지만, 은근히 상대를 신경 쓰고 배려함. |
| **하라구로 (속검음)** | 관계 | 겉으로는 천사처럼 착해 보이지만, 속은 시커멓고 계산적인 인물. |
| **여왕님/주인님** | 관계 | 상대를 지배하고 명령하는 위치에서 쾌락을 느낌. (SM 성향) |
| **노예/하인** | 관계 | 상대에게 복종하고 봉사하는 것에서 안도감이나 기쁨을 느낌. (M 성향) |
| **소울 메이트** | 관계 | 이성적 끌림을 넘어 영혼의 안식을 주는 관계. |
| **악마의 속삭임** | 관계 | 상대의 욕망을 부추겨 타락의 길로 유혹하는 관계. |
| **수호 천사** | 관계 | 그림자처럼 뒤에서 몰래 상대를 지키고 돕는 헌신적인 존재. |
| **오이디푸스 콤플렉스** | 관계 | 부모에 대한 애증과 경쟁심, 그리고 죄책감. |
| **유사가족 놀이** | 관계 | 진짜 가족은 아니지만 서로 역할을 정해 가족 흉내를 내며 결핍을 채움. |
| **배신자 (Traitor)** | 관계 | 믿음을 저버리고 적의 편에 붙어 아군에게 치명적인 타격을 입힘. |
| **내부 고발자** | 관계 | 조직의 비리를 폭로하여 정의를 실현하지만, 조직 내에서는 배신자로 낙인찍힘. |
| **희생양 (Scapegoat)** | 관계 | 집단의 결속이나 분노 해소를 위해 억울하게 비난받고 축출당하는 존재. |
| **따돌림 주도** | 관계 | 집단 내에서 약자를 골라 따돌림을 주도하며 권력을 확인함. |
| **방관자** | 관계 | 괴롭힘이나 불의를 목격하고도 자신에게 피해가 올까 봐 침묵함. |
| **호구** | 관계 | 너무 착하거나 어수룩해서 남에게 쉽게 이용당하고 손해만 봄. |
| **여왕벌** | 관계 | 집단 내에서 중심이 되어 남성들의 주목을 독차지하고 여론을 주도함. |
| **감시자** | 관계 | 상부의 명령으로 특정 인물을 감시하고 보고하는 역할을 맡음. |
| **정보원 (빨대)** | 관계 | 조직 내부의 정보를 경쟁자나 기자에게 은밀히 흘림. |
| **정치적 정략** | 관계 | 권력을 얻거나 유지하기 위해 정략적으로 손을 잡은 관계. |
| **임시 동맹** | 관계 | 공통의 적을 물리치기 위해 어제의 적과 일시적으로 손을 잡음. |
| **후견인 (Patron)** | 관계 | 재능 있는 예술가나 마법사를 경제적으로 후원하고 키워줌. |
| **뮤즈 (Muse)** | 관계 | 예술가에게 영감을 주는 존재이자 사랑의 대상. |
| **플라토닉 러브** | 관계 | 육체적 욕망을 배제한 정신적인 사랑. |
| **아가페** | 관계 | 조건 없는 신의 사랑이나 부모의 사랑과 같은 헌신적 사랑. |
| **불륜/바람** | 관계 | 배우자나 연인이 있으면서 다른 사람과 몰래 관계를 맺음. |
| **동거** | 관계 | 결혼하지 않고 한집에서 살며 부부처럼 생활함. |
| **별거** | 관계 | 부부 관계는 유지하되 따로 살며 거리를 둠. |
| **이혼/파혼** | 관계 | 법적, 사회적 관계를 끊고 남남으로 돌아감. |
| **재혼** | 관계 | 이혼이나 사별 후 새로운 사람과 다시 결혼함. |
| **입양** | 관계 | 피가 섞이지 않은 아이를 법적인 자녀로 받아들임. |
| **의남매/의형제** | 관계 | 형제자매처럼 지내기로 맹세한 사이. |
| **대리전** | 관계 | 자신이 직접 싸우지 않고 대리인을 내세워 싸우게 함. |
| **꼭두각시** | 관계 | 자신의 의지 없이 누군가가 조종하는 대로 움직이는 허수아비 군주. |
| **흑막의 장기말** | 관계 | 자신은 주체적으로 행동한다고 믿지만, 사실은 흑막의 계획 일부일 뿐임. |
| **구애** | 관계 | 끈질기게 사랑을 고백하고 상대의 마음을 얻으려 노력함. |
| **밀당 (밀고 당기기)** | 관계 | 상대의 마음을 애태우게 하며 심리적 주도권을 잡으려는 연애 기술. |
| **철벽** | 관계 | 타인의 접근이나 호의를 단호하게 거절하고 거리를 둠. |
| **금사빠** | 관계 | 금방 사랑에 빠지고 또 금방 식어버리는 가벼운 연애 성향. |
| **모태솔로** | 관계 | 태어나서 한 번도 연애를 해본 적이 없음. |
| **가문의 인맥 (Family Connections)** | 관계 | 가문의 명성과 네트워크를 활용해 외부의 정보나 도움을 끌어냄. |
