# 06. 이동 (Mobility)

> **설명:** 존재의 주된 이동 방식이나 특별한 기동 어빌리티를 나타내는 트레잇입니다. 이동 방식은 몬스터의 서식지, 사냥 방식, 전투 스타일을 결정짓는 중요한 요소입니다.

## 키워드 목록

| 키워드 | 분류 | 설명 |
| :--- | :---: | :--- |
| **이족 보행 (Bipedal)** | 지상 | 인간처럼 두 다리로 걷거나 달립니다. 도구를 사용하거나 급격한 방향 전환이 가능합니다. |
| **사족 보행 (Quadrupedal)** | 지상 | 네 다리로 달립니다. 순간적인 가속력과 안정적인 추격 어빌리티가 뛰어납니다. |
| **다족 이동 (Multi-legged)** | 지상 | 곤충이나 거미처럼 여러 개의 다리로 벽이나 천장, 험지를 자유롭게 이동합니다. |
| **포복/사행 (Slithering)** | 지상 | 뱀처럼 배를 땅에 대고 미끄러지듯 이동합니다. 소리 없이 접근하거나 좁은 틈을 통과합니다. |
| **도약/점프 (Leaping)** | 지상 | 벼룩이나 개구리처럼 강력한 각력으로 먼 거리를 한 번에 뛰어넘거나 고지대를 선점합니다. |
| **돌진 (Stampede)** | 수중 | 거대한 몸집이나 단단한 갑각을 앞세워 장애물을 부수며 일직선으로 질주합니다. |
| **그림자 질주 (Shadow Dash)** | 지상 | 지면을 달리는 것이 아니라 그림자 속을 미끄러지듯 고속으로 이동합니다. |
| **익룡형 비행 (Winged Flight)** | 비행 | 날개를 직접 펄럭여 비행합니다. 바람을 일으키거나 급강하 공격이 가능합니다. |
| **부유 (Levitation)** | 비행 | 날개 없이 마력이나 염동력으로 공중에 둥둥 떠다닙니다. 지형의 영향을 받지 않습니다. |
| **활공 (Gliding)** | 지상 | 비막 등을 이용해 높은 곳에서 낮은 곳으로 미끄러지듯 날아갑니다. 상승 기류를 타기도 합니다. |
| **가스 추진 (Gas Propulsion)** | 지상 | 체내 가스를 분출하거나 공기를 압축하여 제트 엔진처럼 고속으로 추진합니다. |
| **군집 비행 (Swarm Flight)** | 비행 | 수많은 개체가 모여 하나의 구름처럼 날아다니며, 형태를 자유자재로 바꿉니다. |
| **유영 (Swimming)** | 수중 | 지느러미나 물갈퀴를 이용해 물속을 자유롭게 헤엄칩니다. |
| **심해 적응 (Deep Dweller)** | 비행 | 엄청난 수압을 견디며 해저 바닥을 기어다니거나 부유합니다. |
| **굴착 (Burrowing)** | 지하 | 앞발이나 드릴 같은 기관으로 땅을 파고 들어가 지하로 이동합니다. 진동 감지로 위치를 파악합니다. |
| **지맥 타기 (Leyline Travel)** | 지하 | 지하에 흐르는 마력의 길(지맥)을 타고 순식간에 먼 거리를 이동합니다. |
| **순간이동 (Teleportation)** | 지상 | 시야에 닿는 곳이나 기억하는 장소로 즉시 공간을 건너뜁니다. (쿨타임/마력 소모 존재) |
| **차원 도약 (Phase Shift)** | 특수 | 잠시 현실 차원에서 사라져 에테르계나 그림자계로 진입해 벽을 통과합니다. |
| **액체화 (Liquefaction)** | 수중 | 몸을 물이나 슬라임처럼 녹여 물리적인 타격을 무시하고 하수구 등을 통해 이동합니다. |
| **천장 보행 (Wall Crawling)** | 지상 | 중력을 무시하고 벽이나 천장에 거꾸로 매달려 이동하거나 대기합니다. |
| **현현 (Manifestation)** | 지상 | 특정 조건(안개, 공포, 누군가의 꿈)이 만족되는 곳에서 스르륵 나타납니다. |
| **기생 이동 (Parasitic)** | 지상 | 숙주의 몸에 숨어들어 숙주가 이동하는 대로 함께 이동합니다. |
| **그림자 도약** | 지상 | 하나의 그림자에서 다른 그림자로 즉시 건너뛰는 이동 방식 (은신과 이동의 결합) |
| **공간 전이** | 지상 | 단거리 공간을 접어 순식간에 적의 뒤나 사각지대로 이동함 (Blink) |
| **중력 역전** | 지상 | 자신의 중력 방향을 바꾸어 벽을 바닥처럼, 천장을 바닥처럼 뛰어다님 |
| **차원 미끄럼** | 수중 | 현실과 이면 세계의 틈새를 미끄러지듯 이동하여 물리적 충돌을 무시함 |
| **거미줄 이동** | 수중 | 끈적이는 줄을 발사하여 타잔처럼 고층 건물이나 숲 사이를 입체적으로 이동함 |
| **음속 구르기** | 지상 | 몸을 공처럼 말아 고속으로 회전하며 지면을 질주함 (소닉과 유사) |
| **안개화** | 수중 | 몸을 안개나 연기로 바꾸어 좁은 틈을 통과하거나 물리 공격을 흘려보내며 이동함 |
| **지중 유영** | 수중 | 땅을 파는 것이 아니라, 마치 물속을 헤엄치듯 흙과 바위 속을 부드럽게 통과함 |
| **번개 탑승** | 지상 | 번개 줄기나 전선을 타고 빛의 속도에 가깝게 이동함 |
| **거울 이동** | 수중 | 거울이나 반사되는 표면(유리, 물)을 입구와 출구로 삼아 이동함 |
| **잔상 이동** | 지상 | 너무 빨라 시각 정보가 따라잡지 못해, 이동 경로에 수많은 잔상을 남기며 교란함 |
| **부유 유영** | 비행 | 중력이 없는 공간에서 지느러미나 가스를 이용해 헤엄치듯 이동함. |
| **뿌리 다리** | 지상 | 이동하지 않을 때는 땅에 박아 영양분을 섭취하고, 필요시 뽑아서 이동함. |
| **비행 회피 (Flight Evasion)** | 기술 | 공중에 떠 있거나 비행하여 지상 공격을 쉽게 회피한다. |
| **멈추지 않는 바퀴 (Unstoppable Wheel)** | 기술 | 최대 속도 이동 중 이동 방해 효과에 면역. |
| **운동 에너지 축적 (Kinetic Battery)** | 기술 | 이동 거리에 비례하여 다음 공격의 위력이 상승함. |
| **공중 부양 (Levitation)** | 기술 | 지면에 발을 대지 않고 항상 약간 떠 있어 험지나 함정의 영향을 받지 않는다. |
| **벽 타기 (Wall Run)** | 기술 | 도구 없이도 맨손으로 벽을 타며, 그 속도가 평지를 걷는 것만큼 빠르다. |
| **야간 비행 (Night Flight)** | 기술 | 밤이 되거나 어두운 곳에서는 비행 속도와 소음이 현저히 줄어든다. |
| **수중 고속 이동 (High-Speed Swim)** | 기술 | 물속에서 지상보다 더 빠르게 움직이며, 저항을 거의 받지 않는다. |
| **악천후 이동 (Storm Walker)** | 기술 | 눈보라나 폭우 속에서도 이동 속도가 느려지지 않음. |
| **무중력 유영 (Zero-G Swim)** | 기술 | 지면을 밟지 않고 미끄러지듯 이동하며, 낙하 피해를 입지 않는다. |
| **천공의 주행 (Sky Drive)** | 기술 | 지형 영향을 받지 않고 공중을 자유롭게 이동함. |
| **기승 숙련 (Riding Mastery)** | 기술 | 모든 탈것을 완벽히 다루며 전투력을 향상시킴. |
| **탈것 친화 (Mount Affinity)** | 기술 | 탈것과 정신적으로 연결되어 의사를 공유함. |
| **물 위 걷기 (Water Walk)** | 기술 | 마력이나 표면 장력을 이용해 물이나 늪지 위를 빠지지 않고 달린다. |
| **잠복 (Burrow)** | 이동 | 지면 아래로 파고들어가 모습을 숨길 수 있다. 잠복 상태에서는 외부로부터 발견되기 어렵고 회복력이 상승한다. |
