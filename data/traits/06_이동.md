# 06. 이동 (Mobility)

> **설명:** 존재의 주된 이동 방식이나 특별한 기동 능력을 나타내는 특성입니다.

## 키워드 목록

| 특성 이름 | 특성 설명 |
|:---:|---|
| **지상 이동** | 이 생물은 지상에서 걷거나 달려서 이동합니다 |
| **비행** | 이 생물은 날아서 이동합니다 |
| **수영** | 이 생물은 물속에서 이동합니다 |
| **굴착** | 이 생물은 땅을 파고 이동합니다 |
| **등반** | 이 생물은 벽이나 나무를 타고 이동합니다 |
| **텔레포트** | 이 생물은 순간이동으로 이동합니다 |
| **차원 이동** | 이 생물은 차원을 넘나들며 이동합니다 |
