# 04. 지식 & 지혜 (Knowledge & Wisdom)

> **설명:** **"무엇을 아는가(Knowledge)"**와 **"어떻게 생각하는가(Wisdom/Intellect)"**를 모두 포함하는 트레잇입니다.
> 방대한 데이터베이스(지식)와 이를 처리하는 고성능 연산 장치(지혜/지성)를 의미합니다.
> ※ 단, 무기 제작, 연금술 등 **'물리적 결과물을 만드는 생산적 지식'**은 `14_제작`으로 분류합니다.

---

## 키워드 목록

| 키워드 | 분류 | 설명 |
| :--- | :---: | :--- |
| **고지능 (High Intelligence)** | 지성 | 인간을 초월한 연산 능력과 이해력을 보유함 (마법 공식 해석, 고차원적 설계) |
| **직관적 천재 (Intuitive Genius)** | 지성 | 체계적으로 배우지 않아도 본능적으로 사물의 이치나 마법의 원리를 깨우침 |
| **살아있는 도서관 (Living Library)** | 지식 | 창의적인 응용력은 부족하나, 방대한 양의 지식과 역사를 토씨 하나 틀리지 않고 기억함 |
| **속독 학습 (Speed Learning)** | 지성 | 일반적인 서적이나 문서를 초고속으로 스캔하여 단시간에 방대한 정보를 습득하고 기억함 |
| **기억의 궁전 (Memory Palace)** | 지성 | 한 번 보거나 들은 정보는 절대 잊지 않으며, 머릿속의 라이브러리에서 언제든 꺼내볼 수 있음 |
| **병렬 사고 (Parallel Processing)** | 지성 | 동시에 여러 개의 마법을 연산하거나, 여러 개의 자아를 동시에 운용하여 다중 작업을 수행함 |
| **다중 연산 (Multi-tasking)** | 지성 | 뇌를 파티션 나누듯 구획하여 동시에 서로 다른 복잡한 사고(마법+검술)를 수행함 |
| **패턴 인식 (Pattern Recognition)** | 지성 | 사소한 단서들의 공통점을 찾아내어 사건의 재구성을 하거나 약점을 찾아냄 (탐정형) |
| **사건 재구성 (Crime Scene Reconstruction)** | 지성 | 현장에 남은 미세한 단서만으로 과거에 일어난 사건을 홀로그램처럼 머릿속에 시뮬레이션함 |
| **편집증적 설계 (Paranoid Planning)** | 지성 | 아군을 포함한 모든 존재의 배신이나 최악의 수를 가정하고, 그에 대한 대항 수단을 미리 준비함 |
| **감정의 논리화 (Logical Emotion)** | 지성 | 타인의 감정을 수치나 화학 반응식처럼 논리적으로 분석하여 예측하고 대응함 |
| **기계적 중립 (Mechanical Neutrality)** | 지성 | 선악이나 감정의 치우침 없이 입력된 규칙과 논리 알고리즘만 따름 |
| **무정한 저울 (Cold Calculus)** | 지성 | 생명의 가치를 수치로 환산하여 철저히 공리주의적이고 논리적인 판단을 내림 |
| **전술 컴퓨터 (Tactical Computer)** | 지성 | 감정을 배제하고 수천 가지의 전술 시나리오를 시뮬레이션하여 최적의 수를 도출함 |
| **전술적 사고 (Tactical Mind)** | 지혜 | 고정된 병법지식이 아니라, 시시각각 변하는 전장 상황에 맞춰 유동적으로 수를 창조하는 능력 |
| **교활한 책략 (Cunning Stratagem)** | 지혜 | 함정을 파거나 상대를 속이는 등 전술적이고 지능적인 심리전과 기만을 구사함 |
| **수수께끼 달인 (Riddle Master)** | 지혜 | 은유, 비유, 암호 해독에 천재적인 재능을 보이며 언어유희를 즐김 |
| **언어 해독 (Linguistic Decryption)** | 지식 | 처음 듣는 언어나 고대의 룬 문자라도 문법적 구조를 파악해 즉시 이해함 |
| **진리 통찰 (Insight into Truth)** | 지혜 | 사물의 본질, 가치, 진위를 단번에 파악하며 상대의 속임수나 환영을 무력화하는 지혜 |
| **늙은 현자 (Elder Sage)** | 지혜 | 오랜 세월 축적된 경험을 통해 삶의 지혜와 깊은 통찰력을 가짐 |
| **야수적 본능 (Feral Instinct)** | 본능 | 논리적인 이성은 낮으나, 생존과 사냥에 특화된 직관적인 판단력을 가짐 |
| **보물 탐지 (Treasure Sense)** | 본능 | 물건의 가치나 마력이 담긴 아티팩트를 감별해내는 전문적인 식견 |
| **미래 직관 (Future Intuition)** | 본능 | 논리적 계산이 아닌 본능으로 찰나의 미래나 적의 공격 궤적을 예지 수준으로 읽어냄 |
| **천리안 (Clairvoyance)** | 지성 | 단순한 시력을 넘어, 먼 곳에서 일어나는 일이나 평행 세계, 혹은 미래의 진실을 꿰뚫어 보는 눈 |
| **텔레파시 (Telepathy)** | 지성 | 언어 중추를 거치지 않고 정신파로 직접 의사를 소통하거나 이미지를 전송함 |
| **집단 기억 (Hive Mind)** | 지성 | 개체 간에 기억이 실시간으로 동기화되어, 한 명이 겪은 일을 모두가 기억함 |
| **몽상가 (Daydreamer)** | 지성 | 현실과 꿈의 경계를 넘나들며, 꿈속의 논리를 현실에 적용하거나 자각몽을 꿀 수 있음 |
| **혼돈의 계산 (Chaos Calculation)** | 지성 | 무질서하고 불규칙한 패턴(카오스) 속에서 숨겨진 질서를 찾아내는 비선형적 사고방식 |
| **확률 조작 (Probability Manipulation)** | 지성 | 단순한 운이 아니라, 가능성이 낮은 사건의 변수를 계산하고 조작하여 필연으로 만듦 |
| **수학 (Mathematics)** | 지식 | 수와 공간, 구조, 변화를 연구하는 학문. 복잡한 마법 공식 설계나 천체 운동 계산의 기초. |
| **역사학 (History)** | 지식 | 과거의 사건, 인물, 문명의 흥망성쇠를 연구하여 현재의 교훈을 얻는 학문. |
| **철학 (Philosophy)** | 지식 | 존재, 지식, 가치, 이성, 언어 논리 등을 탐구하여 사고의 깊이를 더하는 학문. |
| **신학 (Theology)** | 지식 | 신의 본질, 교리, 종교적 진리를 체계적으로 연구하는 학문. |
| **법학 (Law)** | 지식 | 사회의 규칙과 법률을 해석하고 적용하여 논리적 정당성을 확보하는 지식. |
| **경제학 (Economics)** | 지식 | 재화의 생산, 분배, 소비 흐름을 분석하여 시장의 변동을 예측하는 지식. |
| **천문학 (Astronomy)** | 지식 | 별과 우주의 운행을 관측하여 시간, 계절, 그리고 예언적 징조를 읽어내는 학문. |
| **지리학 (Geography)** | 지식 | 대지의 구조, 기후, 인문 환경을 연구하여 지정학적 이점을 분석하는 학문. |
| **심리학 (Psychology)** | 지식 | 인간과 생명체의 마음, 행동 원리를 연구하여 타인의 심리를 꿰뚫어 보는 지식. |
| **정치학 (Politics)** | 지식 | 권력의 획득과 유지, 통치 구조와 외교 관계를 연구하는 학문. |
| **마법적 지식 (Magical Knowledge)** | 지식 | 마법의 원리, 역사, 주문 체계에 대해 학자 수준의 지식을 보유함 |
| **동물 언어 (Animal Language)** | 지식 | 모든 종류의 동물과 울음소리나 몸짓으로 의사소통할 수 있음 |
| **독립된 영격 (Independent Spirit)** | 지성 | 소환된 개체 하나하나가 단순한 꼭두각시가 아니라, 자아와 고유한 판단 어빌리티를 지닌다. |
| **정신 연결 (Mind Link)** | 지성 | 특정 대상과 신경망이 연결된 것처럼 실시간으로 감각과 정보를 공유함 |
| **예언자 (Prophet)** | 지성 | 인과율을 계산하거나 미래의 가능성을 연산하여 현재가 아닌 미래를 위해 행동함 |
| **모방 학습 (Copycat)** | 지성 | 한 번 본 기술이나 무술, 행동을 즉석에서 완벽하게 따라 할 수 있음 (카피캣) |
| **단순 명쾌 (Simple & Clear)** | 지성 | 복잡한 계산이나 꼼수를 쓰지 않고, 문제의 본질을 단순하고 명확하게 꿰뚫어 봄 |
| **도구적 지성 (Instrumental Intellect)** | 지성 | 전투와 명령 수행에 필요한 전술적 판단력은 갖추었으나, 창의성이나 감정, 도덕적 판단 어빌리티는 거세되어 있음. |
| **무지성(짐승) (Mindless)** | 본능 | 고등 사고 어빌리티가 거의 없어 순수한 본능과 반사 신경에 의존함 |
| **대화불가 (Mute)** | 패널티 | 지능 문제나 신체 구조상 말을 할 수 없어 괴성이나 몸짓으로 소통함 |
| **결계 유지 (Barrier Maintenance)** | 마법 | 흡수한 마력으로 전개한 결계를 지속적으로 유지함. |
| **봉인 해제 저항 (Seal Resistance)** | 마법 | 자신이 건 봉인은 타인이 해제할 수 없게 만듦. |
| **원초의 룬 (Primal Rune)** | 마법 | 고대 룬 문자로 자연 현상을 조작하는 기적. |
| **고속 영창 (High-Speed Chanting)** | 마법 | 긴 주문을 단 한 마디로 압축하여 즉시 발동. |
| **무영창 마법 (Silent Magic)** | 마법 | 입을 열지 않고 생각만으로 하급 마법 발동. |
| **마력 효율 극대화 (Mana Efficiency)** | 마법 | 일반인보다 훨씬 적은 마력으로 마법 수행. |
| **식물 지식 (Plant Knowledge)** | 지성 | 어떤 풀이 먹을 수 있고 약이 되며 독이 되는지 꿰뚫음. |
| **오래된 지혜 (Ancient Wisdom)** | 지성 | 해독 불가능한 고대 문자를 직관적으로 읽고 이해함. |
| **마술사의 소양 (Magician's Talent)** | 지성 | 전사임에도 마법의 원리를 파악하고 파훼함. |
| **지능 흡수 (Intellect Absorb)** | 지혜 | 흡수한 대상 중 가장 지능이 높은 존재의 사고방식을 계승하여 전술적 식견을 획득한다. |
| **마법적 재능 (Magical Prodigy)** | 지성 | 한 번 본 기술을 즉시 따라하거나, 물리 법칙을 무시하는 마나 조작에 천부적인 재능을 가짐. |
