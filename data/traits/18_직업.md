# 19. 직업 (Class & Role)

> **설명:** 캐릭터의 **사회적 역할(Role)**이나 **직업적 정체성(Class)**을 정의하는 트레잇입니다.
> 전투 스타일, 기술 체계, 혹은 생활 방식에 큰 영향을 미치는 핵심적인 배경 요소를 다룹니다.

---

## 트레잇 목록

| 키워드 | 분류 | 설명 |
| :--- | :---: | :--- |
| **전사 (Warrior)** | 전투 | 근접 무기와 갑주를 다루는 전투의 전문가. |
| **기사 (Knight)** | 전투 | 명예와 규율을 중시하며, 기승 전투와 방어술에 능함. |
| **용병 (Mercenary)** | 전투 | 돈을 받고 싸우는 실전적인 전사. 생존과 효율을 중시함. |
| **궁수 (Archer)** | 전투 | 원거리에서 활이나 석궁으로 적을 제압하는 사수. |
| **저격수 (Sniper)** | 전투 | 숨어서 단 한 발의 치명적인 공격으로 목표를 제거함. |
| **무도가 (Martial Artist)** | 전투 | 육체를 극한으로 단련하여 맨손이나 권각술로 싸움. |
| **광전사 (Berserker)** | 전투 | 이성을 잃고 폭주하여 파괴적인 힘을 발휘하는 전사. |
| **검투사 (Gladiator)** | 전투 | 투기장에서 관중의 환호를 위해 목숨을 걸고 싸우는 전사. |
| **마법사 (Mage)** | 마법 | 마나를 탐구하고 조작하여 주문을 시전하는 학자적 시전자. |
| **흑마법사 (Warlock)** | 마법 | 금지된 지식이나 사악한 존재와 계약하여 힘을 얻음. |
| **소환사 (Summoner)** | 마법 | 정령, 마수, 악마 등을 불러내어 부리는 계약자. |
| **성직자 (Cleric)** | 마법 | 신을 섬기며 신성력을 빌려 치유와 정화를 행함. |
| **드루이드 (Druid)** | 마법 | 자연의 힘을 빌리거나 짐승으로 변신하여 싸우는 자연의 수호자. |
| **연금술사 (Alchemist)** | 마법 | 물질의 성질을 변화시켜 포션, 폭탄, 호문쿨루스를 제조함. |
| **주술사 (Shaman)** | 마법 | 영혼이나 토템의 힘을 빌려 저주나 축복을 내림. |
| **암살자 (Assassin)** | 특수 | 은밀하게 침투하여 중요 요인을 제거하는 살수. |
| **도적 (Rogue)** | 특수 | 잠입, 함정 해제, 훔치기 등 뒷세계 기술에 능통함. |
| **첩자 (Spy)** | 특수 | 적진에 잠입하여 정보를 빼내거나 혼란을 조장함. |
| **음유시인 (Bard)** | 특수 | 노래와 연주로 아군을 고무하거나 마법적 효과를 일으킴. |
| **무희 (Dancer)** | 특수 | 화려한 춤사위로 적을 매혹하거나 회피 동작으로 농락함. |
| **조련사 (Tamer)** | 특수 | 야생 동물이나 마물을 길들여 동료로 삼고 부림. |
| **대장장이 (Blacksmith)** | 생활 | 금속을 제련하여 무기와 갑옷을 제작하거나 수리함. |
| **상인 (Merchant)** | 생활 | 물품을 거래하고 유통하여 이익을 창출하는 경제 전문가. |
| **요리사 (Chef)** | 생활 | 식재료를 가공하여 버프 효과가 있는 요리를 만듦. |
| **의사 (Doctor)** | 생활 | 의학적 지식으로 질병과 부상을 치료함. |
| **학자 (Scholar)** | 생활 | 역사, 마법, 생물 등 특정 분야의 지식을 깊이 탐구함. |
| **지휘관 (Commander)** | 지휘 | 전장에서 군대를 통솔하고 전략을 지시하는 리더. |
| **책략가 (Strategist)** | 지휘 | 전투나 전쟁의 판을 읽고 승리를 위한 계책을 내놓음. |
| **군주 (Lord)** | 지휘 | 영토와 백성을 다스리는 통치자이자 권력자. |
