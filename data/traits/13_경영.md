# 13. 경영 및 내정 (Management & Administration)

> **설명:** 국가, 영지, 단체, 상단 등을 운영하고 관리할 때 나타나는 경제, 행정, 문화적 트레잇입니다.

## 트레잇 목록

| 트레잇명 | 하위 분류 | 설명 |
| :--- | :---: | :--- |
| **특산물 독점** | 경제 | 특정 자원(미스릴, 향신료 등)의 생산을 독점하여 막대한 부를 축적함. |
| **마도 공학 단지** | 산업 | 마법과 기계 공학이 결합된 첨단 제조 시설을 보유하여 고부가가치 상품을 생산함. |
| **중계 무역항** | 경제 | 대륙 간 무역로의 중심지에 위치하여 통행세와 관세로 번영함. |
| **곡창 지대** | 농업 | 비옥한 토지와 마법적 농법으로 식량 자급자족을 넘어 수출까지 가능함. |
| **관광 명소** | 문화 | 고대 유적이나 아름다운 경관으로 수많은 외부인이 방문하여 외화를 씀. |
| **지하 자원 부국** | 산업 | 땅속에 금, 보석, 마석 등이 매장되어 있어 채굴업이 국가 경제의 근간임. |
| **노예 경제** | 경제 | 전쟁 포로나 빚진 자들을 노동력으로 착취하여 생산 단가를 극도로 낮춤. |
| **길드 중심 경제** | 경제 | 상인 조합이나 장인 길드가 실물 경제를 장악하고 가격을 통제함. |
| **자급자족** | 경제 | 외부와의 교류 없이 내부에서 모든 의식주를 해결하는 폐쇄적 경제 구조. |
| **금융 허브** | 경제 | 대륙의 자금이 모이는 은행과 투자사가 밀집해 있어 신용과 대출이 활발함. |
| **효율적 관료제** | 행정 | 훈련된 행정관들이 세금 징수와 법 집행을 빈틈없이 수행하여 국정 운영이 매끄러움. |
| **엄격한 법치** | 행정 | 법 앞에서는 왕족도 예외가 없을 정도로 법률이 엄격하고 공정하게 집행됨. |
| **부패한 관리** | 행정 | 뇌물이 없으면 행정 처리가 불가능하고, 매관매직이 성행하여 국고가 샙니다. |
| **지방 분권** | 행정 | 각 지역 영주나 시장에게 막강한 자치권을 주어 지역 특색에 맞는 발전을 유도함. |
| **공포 정치** | 통치 | 비밀경찰과 감시망을 통해 반대파를 숙청하고 공포로 질서를 유지함. |
| **종교적 권위** | 통치 | 신탁이나 종교 지도자의 말이 곧 국법이며, 국민 통합의 구심점이 됨. |
| **어빌리티주의 등용** | 인사 | 신분이나 출신에 상관없이 오직 어빌리티만으로 인재를 발탁하는 개방적 인사 시스템. |
| **세습 귀족정** | 통치 | 소수의 명문 가문이 주요 관직을 독점하고 권력을 대물림함. |
| **직접 민주주의** | 통치 | 중요 안건을 시민들이 직접 투표로 결정하는 광장 정치. |
| **전시 동원령** | 행정 | 평시에도 행정 조직이 준군사조직처럼 운영되어 위기 시 즉각 대처함. |
| **마나 통신망** | 인프라 | 마법 수정을 이용한 원거리 통신망이 구축되어 있어 정보 전달이 즉각적임. |
| **상하수도 시설** | 인프라 | 깨끗한 물 공급과 오물 처리가 완벽하여 전염병 발생률이 매우 낮음. |
| **공공 도서관** | 복지 | 누구나 지식을 접할 수 있는 도서관이 많아 국민의 평균 지적 수준이 높음. |
| **무상 치유소** | 복지 | 국가나 교단이 운영하는 무료 병원이 있어 빈민들도 치료를 받을 수 있음. |
| **도로망 정비** | 인프라 | 수도와 지방을 잇는 도로가 잘 닦여 있어 물류 이동과 군사 이동이 빠름. |
| **마법 가로등** | 인프라 | 밤에도 거리를 밝히는 마법 조명이 설치되어 야간 활동과 치안이 보장됨. |
| **대중 목욕탕** | 시설 | 시민들의 사교장이자 위생을 책임지는 대규모 목욕 시설. |
| **고아원 운영** | 복지 | 전쟁 고아나 버려진 아이들을 국가가 거두어 교육하고 일자리를 알선함. |
| **방어 결계** | 안보 | 도시 전체를 감싸는 투명한 마법 장벽이 있어 외부 침입이나 재해를 막음. |
| **지하철도** | 교통 | 마법이나 증기로 움직이는 지하 운송 수단이 있어 도시 내 이동이 획기적임. |
| **장인 정신** | 문화 | 물건 하나를 만들어도 혼을 담는 문화가 있어 품질이 세계 최고 수준임. |
| **축제의 나라** | 문화 | 일 년 내내 다양한 축제가 열려 국민들의 행복도가 높고 외부인이 많이 찾음. |
| **학문 숭상** | 문화 | 무력보다 지식과 토론을 중시하며, 학자를 최고로 대우하는 사회 분위기. |
| **미식 문화** | 문화 | 다양한 식재료와 조리법이 발달하여 요리 수준이 높고 식도락가가 많음. |
| **무술 연마** | 문화 | 남녀노소 누구나 호신술이나 검술을 배우는 것이 당연한 상무적인 기풍. |
| **예술 후원** | 문화 | 귀족들이 화가나 음악가를 적극 후원하여 예술이 꽃피운 도시. |
| **사치와 향락** | 문화 | 겉모습과 유행에 민감하며, 화려한 파티와 연회를 즐기는 쾌락주의. |
| **금욕과 절제** | 문화 | 검소함을 미덕으로 여기며, 사치를 죄악시하는 청교도적인 분위기. |
| **자유로운 토론** | 문화 | 신분 고하를 막론하고 광장에서 정치나 철학을 논하는 개방적인 문화. |
| **엄격한 예법** | 문화 | 인사법부터 식사 예절까지 복잡한 규칙이 존재하며 이를 어기면 배척당함. |
| **비축 물자** | 안보 | 기근이나 전쟁을 대비해 수년간 버틸 수 있는 식량과 자원을 창고에 쌓아둠. |
| **지하 벙커** | 안보 | 공습이나 마법 폭격 시 시민들이 대피할 수 있는 거대 지하 시설. |
| **소방 시스템** | 안전 | 화재 발생 시 마법사나 소방대가 즉각 출동하여 진압하는 체계. |
| **비밀 경찰** | 안보 | 반체제 인사나 스파이를 색출하고 감시하는 정보 조직. |
| **용병 계약** | 안보 | 위기 시 즉시 투입될 수 있는 외부 용병단과 상시 계약을 맺고 있음. |
| **피난 매뉴얼** | 안전 | 재난 발생 시 시민들이 어떻게 행동해야 하는지 훈련이 잘 되어 있음. |
| **전염병 격리** | 보건 | 역병 발생 시 신속하게 구역을 봉쇄하고 환자를 격리하는 방역 시스템. |
| **마법 탐지망** | 안보 | 도시 곳곳에 설치된 센서가 고농도 마나 반응이나 적의를 감지함. |
| **자경단** | 치안 | 주민들이 스스로 무장하여 마을을 지키는 자발적인 치안 조직. |
| **식량 배급제** | 복지 | 위기 시 사재기를 막고 모두에게 공평하게 식량을 나누어주는 시스템. |
| **화폐 개혁** | 경제 | 기존 화폐를 폐기하고 새로운 화폐를 발행하여 인플레이션을 잡거나 검은 돈을 무력화함. |
| **조세 저항** | 경제 | 과도한 세금에 반발하여 국민들이 납세를 거부하거나 폭동을 일으킴. |
| **보전 마법** | 산업 | 식품이나 자재가 썩지 않도록 영구 보존 마법을 걸어 유통기한을 획기적으로 늘림. |
| **왕립 연구소** | 산업 | 국가가 주도하여 신기술이나 마법을 연구하는 기관. 막대한 예산이 들어가지만 성과는 확실함. |
| **무역 분쟁** | 외교 | 국가 간 관세나 무역 불균형 문제로 갈등이 빚어져 경제 제재나 봉쇄가 일어남. |
| **망명 정부** | 정치 | 본국이 점령당한 후 해외로 피신하여 저항 운동을 지휘하는 임시 정부. |
| **괴뢰국** | 정치 | 겉으로는 독립국이지만 실제로는 강대국의 조종을 받는 허수아비 국가. |
| **다문화 정책** | 사회 | 다양한 종족과 문화를 받아들이고 공존을 장려하는 개방적 정책. |
| **종족 격리** | 사회 | 특정 지역에 특정 종족만 거주하게 하거나 이동을 제한하는 차별적 정책. |
| **금주령** | 사회 | 술의 제조와 판매를 법으로 금지하여 범죄율을 낮추려 하지만 밀주가 성행함. |
| **통행 금지** | 치안 | 야간에 시민들의 통행을 금지하여 범죄를 예방하거나 반란을 방지함. |
| **언론 통제** | 정치 | 신문이나 소문을 검열하여 국가에 불리한 정보가 퍼지는 것을 막음. |
| **프로파간다** | 정치 | 예술이나 연설을 이용해 대중을 선동하고 특정 사상을 주입함. |
| **전략 물자** | 경제 | 전쟁 수행에 필수적인 자원(철, 석유, 마석)을 국가가 직접 관리하고 통제함. |
| **국채 발행** | 경제 | 국가의 신용을 담보로 빚을 내어 대규모 사업이나 전쟁 비용을 조달함. |
| **부동산 투기** | 경제 | 개발 정보를 미리 입수한 귀족들이 땅을 사재기하여 시세 차익을 노림. |
| **노조 결성** | 사회 | 노동자나 하급 장인들이 권리 향상을 위해 조직을 결성하고 파업을 벌임. |
| **복지 포퓰리즘** | 정치 | 표를 얻기 위해 실현 불가능하거나 재정에 부담이 되는 무리한 복지 공약을 남발함. |
| **인구 감소** | 사회 | 전쟁이나 역병, 저출산으로 인해 생산 가능 인구가 줄어 국력이 쇠퇴함. |
| **베이비 붐** | 사회 | 전쟁 후 평화가 찾아오거나 풍요로워지면서 인구가 폭발적으로 증가함. |
| **두뇌 유출** | 사회 | 유능한 학자나 기술자들이 더 나은 대우를 찾아 해외로 떠남. |
| **사면령** | 정치 | 국가적 경사나 화합을 명분으로 죄수들을 풀어주거나 죄를 면제해줌. |
| **친환경 마법** | 산업 | 자연을 훼손하지 않고 지속 가능한 마력을 사용하는 청정 에너지 기술. |
| **연금술 경제** | 경제 | 금을 만들어내거나 물자를 변환하는 연금술이 경제에 큰 비중을 차지함. |
| **용병 길드** | 군사 | 돈을 받고 싸워주는 용병들을 관리하고 알선하는 거대 조직. |
| **첩보국** | 군사 | 적국의 정보를 빼내거나 요인을 암살하고 역정보를 흘리는 비밀 조직. |
| **군수 공장** | 산업 | 대량의 무기와 군수품을 찍어내는 전시 체제 공장. |
| **해상 봉쇄** | 군사 | 적국의 항구를 군함으로 막아 물자 반입을 차단하고 고사시킴. |
| **초토화 작전** | 군사 | 후퇴하면서 적이 이용할 수 있는 모든 시설과 자원을 파괴함. |
| **군역 면제세** | 행정 | 돈을 내면 군대 징집을 면제해주는 제도로, 부유층만 혜택을 봄. |
| **매관매직** | 정치 | 관직을 돈으로 사고파는 행위가 만연하여 무능한 자들이 권력을 잡음. |
| **비선 실세** | 정치 | 공식 직함은 없으나 통치자의 총애를 등에 업고 국정을 좌지우지하는 인물. |
