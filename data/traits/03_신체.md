# 03. 신체 (Physical)

> **설명:** 존재의 육체적 특징, 외형, 구조 등 신체의 물리적 형태와 관련된 특성입니다.

---

### 신체 구조 및 외형

| 키워드 | 분류 | 설명 |
| :--- | :---: | :--- |
| **강철 피부** | 신체 | 일반적인 무기로는 뚫기 힘들 정도로 단단한 외피 |
| **썩은 살점** | 신체 | 썩어가는 살점으로 이루어져 있으며, 주변에 역병을 퍼뜨릴 수 있음 |
| **다수의 눈** | 신체 | 2개를 초과하는 눈을 가져 넓은 시야를 확보하거나 특수 시야를 가짐 |
| **가시 돋친 몸** | 신체 | 온몸이 가시로 덮여 있어 접촉 시 피해를 반사함 |
| **흑요석 갑각** | 신체 | 흑요석처럼 단단하고 예리한 갑각으로 덮여 있음 |
| **황금 가죽** | 신체 | 황금빛으로 빛나는 희귀하고 값비싼 가죽 |
| **불타는 갈기** | 신체 | 사자나 말의 갈기처럼 불꽃이 영원히 타오름 |
| **수정 뿔** | 신체 | 수정처럼 투명하거나 빛나는 뿔을 가짐 |
| **강철 깃털** | 신체 | 강철처럼 단단하여 무기로도 사용할 수 있는 깃털 |
| **뼈 날개** | 신체 | 뼈로만 이루어져 으스스한 분위기를 자아내는 날개 |
| **여러개의 머리** | 신체 | 머리가 여러 개 있어 동시에 여러 방향을 보거나 생각할 수 있음 |
| **붉은 비늘** | 신체 | 붉은색 비늘로 덮여 있으며, 화염 저항력을 암시할 수 있음 |
| **거대한 날개** | 신체 | 몸집에 비해 유난히 크고 강력한 날개 |
| **날카로운 발톱** | 신체 | 무기처럼 사용할 수 있는 예리한 발톱 |
| **긴 꼬리** | 신체 | 균형을 잡거나 추가 공격에 사용하는 긴 꼬리 |
| **뿔 달린 머리** | 신체 | 위협적인 뿔이 돋아난 머리 |
| **거대한 덩치** | 신체 | 일반적인 동종에 비해 압도적으로 큰 체격 |
| **맹독 혈액** | 신체 | 체액 자체가 맹독성이라 피를 흘리면 주변에 피해를 줌 |
| **여러개의 팔** | 신체 | 팔이 4개 이상으로 다수 공격이나 작업에 유리함 |
| **무형의 몸** | 신체 | 물리적인 실체가 없어 물리 공격을 무시함 (유령, 슬라임) |
| **완벽한 육체** | 신체 | 균형 잡힌 근육과 신체 능력을 타고났으며, 전염병이나 독에 대한 저항력이 일반인을 아득히 상회함 |
| **은밀한 기색** | 신체 | 호흡과 심박수를 조절하여 인기척을 극한으로 줄이는 신체적 특징 (탐지 확률 감소) |
| **파괴적 기원** | 신체 | 존재의 근원 자체가 파괴적이어서 통상적인 치유가 잘 듣지 않거나 부작용을 일으킴 |
| **붕괴된 신체** | 신체 | 가혹한 반동으로 전신의 근육과 뼈에 미세한 균열이 가득함 (통각 둔화, 내구도 감소) |
| **기원: 검** | 신체 | 존재의 근원이 '검'과 동질화되어 도검 제작/사용에 특화되나, 치유/타 속성 효율 저하 |
| **칼날의 몸** | 신체 | 신체 내부가 금속성을 띄어 외상 시 칼날이 돋아나거나 내구도가 비정상적으로 높음 |
| **투명화** | 신체 | 빛을 굴절시키거나 투과시켜 육안으로 식별하기 어렵게 만듦 |
| **룬 문신** | 신체 | 피부에 마법적인 룬 문자가 새겨져 있어 상시적인 마법 효과를 냄 |
| **수은 혈액** | 신체 | 혈액이 수은과 같은 액체 금속으로 이루어져 형태 변환이나 맹독성을 가짐 |
| **보석 심장** | 신체 | 심장이 마력을 머금은 보석으로 되어 있어 강력한 에너지원이자 급소가 됨 |
| **분리형 사지** | 신체 | 팔이나 다리, 머리 등을 자유롭게 떼어내어 원격으로 조종할 수 있음 |
| **과잉 성장** | 신체 | 뼈, 근육, 뿔 등이 비정상적으로 계속 자라나 기괴하지만 강력한 힘을 냄 |
| **마력 방출** | 신체 | 에너지를 신체 밖으로 분사하거나 폭발시켜 순간적인 기동력과 공격력을 얻음 |
| **생체 원자로** | 신체 | 고효율의 에너지를 끊임없이 공급하는 체내 순환 시스템을 보유함 |
| **성장 정지** | 신체 | 특정 시점(계약, 각성 등) 이후로 신체의 노화나 성장이 완전히 멈춤 |
| **마나 회로** | 신체 | 에너지를 전달하고 연산하는 생체 내부의 마법 신경망이 고도로 발달함 |
| **가호 받은 육체** | 신체 | 특정 속성(물, 숲 등)이나 환경으로부터 보호받는 축복이나 가호를 받은 신체 |
| **마법 저항성** | 신체 | 피부나 체질 자체가 마법에 대한 강한 저항력을 가져, 마법 공격을 튕겨내거나 무효화함 |
| **저주받은 신체** | 신체 | 신체 일부(점, 팔, 눈 등)에 씻을 수 없는 저주가 서려 있어 주변에 불행을 퍼뜨리거나 능력을 제한함 |
| **황금률(체질)** | 신체 | 평생 동안 재물이나 자원이 마르지 않고 제 발로 굴러들어오는 운명적이고 신비로운 체질 |
| **신성 보유** | 신체 | 몸속에 신의 피나 기운이 흐르고 있어 초자연적인 권능을 발휘할 수 있는 상태 |
| **액체 금속** | 신체 | 신체가 T-1000처럼 액체 금속으로 이루어져 물리 피해를 무시하고 형태를 자유롭게 바꿈 |
| **음파 기관** | 신체 | 목이나 신체 일부에 강력한 초음파나 충격파를 발산하는 생체 기관이 있음 |
| **포자 분출구** | 신체 | 몸에서 환각, 독, 마비 등의 효과를 가진 포자를 뿜어내는 구멍이 뚫려 있음 |
| **거울 피부** | 신체 | 피부가 거울처럼 매끄러워 빛이나 레이저, 마법 공격을 반사함 |
| **그림자 융합** | 신체 | 신체를 그림자와 동화시켜 2차원 평면으로 숨거나 이동할 수 있음 |
| **수정 뼈** | 신체 | 뼈가 마력을 증폭시키는 희귀한 수정으로 이루어져 있어 마법 효율이 높음 |
| **살아있는 문신** | 신체 | 피부의 문신이 스스로 움직이거나 튀어나와 공격/방어를 보조함 |
| **촉수 다발** | 신체 | 팔이나 등에서 자유롭게 움직이는 촉수 다발이 뻗어 나와 다각도 공격이 가능함 |
| **기생 갑주** | 신체 | 갑옷처럼 보이지만 사실은 숙주의 몸을 파고들어 양분을 빨아먹는 생체 기생물임 |
| **뇌 분산** | 신체 | 뇌가 머리에 있지 않고 전신에 분산되어 있어, 머리가 터져도 죽지 않음 |
| **저주받은 그릇** | 신체 | 내부에 막대한 에너지를 품고 있으나, 그 근원이 극도로 타락하여 닿는 모든 것을 변질시키거나 미쳐버리게 만드는 물건(혹은 신체) |
| **이형의 혈액** | 신체 | 혈액이 검고 끈적한 맹독성 물질로 변하여, 부상 시 튀는 피 자체가 무기가 됨 |
| **마나의 심장** | 신체 | 자연계의 마나를 스스로 흡수하여 축적하며, 고갈되더라도 시간이 지나면 다시 차오르는 무한한 마력 회로를 내장함 |
| **영혼 포식자** | 신체 | 영혼이나 생명력을 에너지원으로 삼아야만 생존할 수 있는 본능적인 신체 구조 및 대사 기능 |
| **죽음의 냄새** | 신체 | 신체에서 피와 죽음을 연상시키는 향기를 풍겨, 포식자나 언데드 몬스터들을 끊임없이 유인함 |
| **에너지의 갑주** | 신체 | 고속 이동 시 발생하는 마찰열과 공기 저항으로부터 신체를 보호하는 오라 |
| **에너지 뱀파이어** | 신체 | 스스로 에너지를 생성할 수 없어, 계속해서 움직이거나 타인의 속도를 훔쳐야만 생존할 수 있음 |
| **유령 보행** | 신체 | 항상 위상(Phase)이 틀어져 있어, 특별한 장비 없이는 누구도 만질 수 없는 저주받은 상태 |
| **태양의 축복** | 신체 | 항성 에너지를 체내에 축적하여 생명력과 마력의 원천으로 삼는 특수한 생체 기관 |
| **달의 저주** | 신체 | 태양 아래서는 약해지지만, 달빛이나 어둠 속에서만 진정한 힘을 발휘하는 야행성 체질 |
| **초밀도 근육** | 신체 | 근육 밀도가 강철보다 높아, 작은 체구로도 거대한 질량을 들어 올리거나 파괴함 |
| **적응형 내성** | 신체 | 한 번 맞은 속성이나 공격 방식에 대해 내성이 생겨, 두 번째부터는 피해가 급감함 |
| **인지 저해** | 신체 | 사소한 변장(안경 등)만으로도 타인이 자신의 정체를 알아보지 못하게 만드는 최면적 암시 |
| **얼굴 없는 자** | 신체 | 평소에는 평범한 이웃의 얼굴을 하고 있지만, 본모습은 인지할 수 없는 코스믹 호러적 존재 |
| **힘의 제어구** | 신체 | 착용 중인 장비가 방어구인 동시에 사용자의 넘치는 힘을 억제하는 봉인구 역할 |
| **필멸자의 껍질** | 신체 | 영혼은 신이지만 육체는 인간에 가까워, 신적인 힘을 과도하게 쓰면 육체가 붕괴됨 |
| **밤의 제왕** | 신체 | 태양 아래서는 평범하지만, 밤이나 어둠 속에서는 모든 능력치가 2배로 상승하는 야행성 |
| **노쇠한 육체** | 신체 | 지식과 기술은 정점에 달했으나, 늙고 병든 육체 때문에 파워 슈트나 마법 장비에 의존해야 함 |
| **과잉 무장** | 신체 | 너무 많은 장비를 챙겨 무게로 인해 이동 속도나 회피율이 감소함 |
| **마나 과잉** | 신체 | 체내에 보유할 수 있는 마력의 총량이 일반인보다 월등히 많아 장기전에 유리함 |
| **기생 숙주** | 신체 | 체내에 마력을 탐하는 기생 생물들이 살고 있어, 주기적으로 마력을 공급하지 않으면 고통을 겪음 |
| **용의 심장** | 신체 | 체내에서 호흡만으로도 막대한 마력을 생성하는 초월적인 기관(심장)을 가졌다. 마력 회복 속도와 총량이 규격을 벗어난다 |
| **용의 혈통** | 신체 | 일반인보다 월등한 생명력, 근력, 재생력을 가진다. 수명이 길고 노화가 늦다 |
| **마나 친화체** | 신체 | 마력을 단순히 에너지가 아니라 신체의 일부처럼 다룬다. 마력 효율이 좋지만, 그만큼 소비량도 막대하여 지속적인 공급이 필요하다 |
| **마력 포식자 (Mana Predator)** | 신체 | 생명체의 마력을 직접 흡수하여 자신의 것으로 만드는 특수한 신체 구조를 가진다. 접촉만으로도 마력을 빨아들일 수 있다. |
| **마안 보유자 (Mystic Eyes Holder)** | 신체 | 특수한 눈을 가져 시선만으로 초자연적인 효과를 발휘할 수 있다. 마안의 종류와 위계에 따라 효과가 달라진다. |
| **신체 성장 지연** | 신체 | 과도한 훈련이나 특정 생활 방식으로 인해 신체적 성장이 또래보다 느리게 진행된다. 체력·근력 면에서 한계가 드러날 수 있다. |
| **영혼의 그릇** | 신체 | 육체는 단지 껍데기일 뿐이며, 영혼이 깃든 아주 작은 핵심(벌레, 보석 등)만 무사하다면 언제든지 새로운 육체로 갈아타 부활할 수 있다. |
| **거짓된 생명** | 신체 | 겉모습은 평범한 생명체처럼 보이지만, 내부는 이질적인 물질(벌레, 기계 등)로 채워져 있어 급소를 찔려도 피를 흘리지 않거나 죽지 않는다. |
| **벌레 군집체** | 신체 | 하나의 단일 개체가 아니라 수천, 수만 마리의 미세한 벌레(또는 소형 개체)들이 모여 하나의 형상을 유지하고 있다. 타격 무기에 면역에 가까우며, 흩어졌다가 다시 뭉칠 수 있다. |
| **마력 회로 결핍** | 신체 | 선천적으로 마력을 생성하거나 순환시키는 기관이 존재하지 않거나 막혀있는 상태. |
| **묶여서도 싸우는 자** | 신체 | 몸을 가누기 힘들 정도로 지치면, 스스로를 기둥이나 벽에 묶어서라도 쓰러지지 않고 싸운다. 서 있는 상태로 죽음을 맞이할지언정 무릎 꿇지 않는다. |
| **악성 정령의 팔** | 신체 | 한쪽 팔이 인간의 것이 아닌, 고대 악령이나 마신의 신체로 대체되어 있다. 평소에는 봉인되어 있으나, 개방하면 기괴하게 변형되어 초자연적인 힘과 저주를 뿜어낸다. |
| **비대칭의 미학** | 신체 | 신체의 좌우 밸런스가 극단적으로 무너져 있다. 한쪽은 평범하지만, 변형된 다른 한쪽은 거대하거나 흉측하다. 이 기형적인 구조가 예측 불가능한 공격 패턴을 만들어낸다. |
| **인체 공학의 무시** | 신체 | 관절의 가동 범위나 뼈의 구조가 인간의 상식을 벗어나 있다. 팔이 뒤로 꺾이거나 목이 180도 돌아가는 등, 기괴한 움직임으로 적의 공격을 피하거나 사각에서 공격한다. |
| **키메라의 육체** | 신체 | 인간뿐만 아니라 짐승, 곤충, 마수 등 다양한 생물의 특징이 몸 하나에 섞여 있다. 맹수의 발톱, 곤충의 갑각, 물고기의 아가미 등을 상황에 따라 부분적으로 발현한다. |
| **양손잡이** | 신체 | 양손을 똑같이 자유롭게 사용한다. 양손으로 동시에 투척 무기를 던지거나, 한 손이 부상당해도 전투력 손실이 없다. |
| **거짓된 껍데기** | 신체 | 타인이 기대하는 모습이나 전설 속의 이미지를 연기한다. 본래의 자아와 연기하는 자아가 분리되어 있어, 정신 간섭이나 세뇌가 통하지 않는다. |
| **연체 신체** | 신체 | 뼈와 관절을 자유자재로 조작하거나 탈구시킬 수 있어, 불가능해 보이는 자세로 공격하거나 구속을 풀 수 있다. |
| **호화로운 장비** | 신체 | 항상 최고급, 최상의 장비만을 착용한다. 입고 있는 옷이나 장신구 하나하나가 국보급 가치를 지니며, 그 자체로 강력한 방어력과 마법 내성을 가진다. |
| **오염된 심장** | 신체 | 본래의 심장은 파괴되었고, 저주받은 덩어리나 마력이 그 기능을 대신하고 있다. 심장이 멈춰도 죽지 않으며, 저주에 대한 강한 내성을 가진다. |
| **인공 생명력** | 신체 | 음식 섭취나 수면이 필요 없으며, 외부에서 마력만 공급된다면 영구히 활동할 수 있다. 생존을 위한 생리 현상이 제거되었다. |
| **부활의 핵** | 신체 | 죽음에 이르면 육체는 소멸하지만, 남겨진 핵(알/코어)에서 시간이 지나면 육체를 재생하여 부활한다. |
| **속성 면역** | 신체 | 특정 원소(화염, 냉기, 번개, 산성)나 독에 대해 신체가 완벽하게 적응하여 피해를 입지 않는다. |
| **물리 내성** | 신체 | 피부와 근육이 비정상적으로 단단하거나 충격을 흡수하여, 일반적인 물리 공격(참격, 타격, 관통) 피해를 대폭 경감시킨다. |
| **수중 호흡** | 신체 | 아가미나 마법적인 폐 구조를 통해 물속에서도 호흡 곤란 없이 자유롭게 활동한다. |
| **마나 결정화 피부** | 신체 | 피부 표면이 단단한 마나석으로 덮여 있어 마법 방어력이 높지만, 마력 흡수 공격에 취약함. |
| **유선형 갑각** | 신체 | 거센 바람을 흘려보내기 위해 매끄럽게 진화한 갑각. 공기 저항을 덜 받음. |
| **퇴화한 시각** | 신체 | 빛이 없는 곳에서 진화하여 눈이 없거나 퇴화함. 대신 청각/후각이 극도로 발달. |
| **이중 심장** | 신체 | 예비용 심장이 하나 더 있어, 하나가 파괴되어도 즉사하지 않고 생존함. |
| **신축성 관절** | 신체 | 뼈와 관절이 고무처럼 늘어나거나 꺾여, 사거리가 변칙적이고 구속에서 쉽게 탈출함. |
| **강철 턱** | 신체 | 뼈를 씹어 부술 정도로 강력한 치악력을 가진 턱과 이빨. |
| **발광 기관** | 신체 | 몸에서 자체적으로 빛을 내어 어둠을 밝히거나, 순간적으로 섬광을 터뜨려 적을 실명시킴. |
| **분리형 기생체** | 신체 | 신체 일부(손, 눈 등)가 본체에서 분리되어 독립적으로 움직이는 기생 생물임. |
| **무성 생식핵** | 신체 | 짝짓기 없이 스스로 복제 개체를 생성할 수 있는 생체 기관. |
| **점액 코팅** | 신체 | 산성비나 독기로부터 피부를 보호하는 중화 점액을 항시 분비함. |
| **열 에너지 흡수** | 신체 | 고열을 피해가 아니라 에너지원으로 전환하여 체력을 회복함. |
| **광합성 피부** | 신체 | 어두운 곳에서 미세한 빛이라도 효율적으로 흡수하여 에너지를 만듦. |
| **결정화 발톱** | 신체 | 단단한 수정을 파괴하거나 채굴하기 위해 다이아몬드처럼 경도 높은 발톱을 가짐. |
| **염분 배출** | 신체 | 과다한 염분을 눈물이나 땀으로 즉시 배출하여 탈수를 막음. |
| **부정형 신체** | 신체 | 정해진 형태 없이 흐물거리거나 수시로 변형되어 물리 타격을 무시함. (쇼고스) |
| **촉수 다발** | 신체 | 입이나 손 대신 수많은 촉수가 돋아나 사물을 잡거나 감각 기관 역할을 함. |
| **비실체화** | 신체 | 물리적 육체를 버리고 에너지나 가스 형태로 존재하여 통과함. |
| **재생 불능의 피** | 신체 | 혈액이 강산성이나 저주를 띠어, 닿은 물체의 회복력을 영구히 제거함. |
| **무호흡 생존** | 신체 | 산소가 없는 진공 상태에서도 영구히 생존할 수 있는 대사 구조. |
| **다중 입** | 신체 | 신체 곳곳에 불규칙하게 입이 돋아나 헛소리를 하거나 물어뜯음. |
| **행군 지구력** | 신체 | 무거운 군장을 메고도 장시간 지치지 않고 걸을 수 있는 튼튼한 하체. |
| **전쟁의 흉터** | 신체 | 온몸에 남은 흉터들이 위압감을 주어, 초심자나 민간인을 위축시킨다. |
| **마녀의 낙인** | 신체 | 신체 일부에 지워지지 않는 문양이 있어 마법적 매개체 역할을 함. |
| **영적 그릇** | 신체 | 영혼이나 신령을 빙의시키기에 최적화된 비어있는 육체 체질. |
| **룬 각인 뼈** | 신체 | 뼈에 고대 마법 문자가 새겨져 있어 죽어도 육체가 썩지 않고 보존됨. |
| **성흔 (Stigmata)** | 신체 | 신의 축복 혹은 저주로 인해 손발에 피가 흐르는 상처가 주기적으로 나타남. |
| **동면 체질** | 신체 | 식량이 부족한 겨울이나 극한 상황에서 신진대사를 멈추고 잠들 수 있음. |
| **위장색 피부** | 신체 | 카멜레온처럼 주변 환경에 맞춰 피부색을 바꿔 천적으로부터 숨음. |
| **강철 위장** | 신체 | 썩은 고기, 독초, 뼈 등 무엇이든 소화시키고 탈이 나지 않음. |

| **강철 같은 골격** | 신체 | 뼈가 굵고 단단하여 무거운 갑옷과 대형 무기의 무게를 지탱하는 데 최적화됨. |
| **압도적인 악력** | 신체 | 손아귀 힘이 비정상적으로 강해, 적의 공격에 무기를 놓치지 않으며 한 손으로도 대검을 휘두름. |
| **신축성 근육** | 신체 | 근육이 고무처럼 유연하여 좁은 틈을 통과하거나 상상도 못한 각도로 몸을 비틀 수 있음. |
| **소리 없는 발소리** | 신체 | 발바닥 구조가 특이하여 어떤 지면을 걸어도 발소리가 거의 나지 않는 타고난 잠입 체질. |
| **맹수 같은 동공** | 신체 | 야간에도 사물의 움직임을 포착하며, 초장거리의 목표물을 뚜렷하게 식별함. |
| **날씨 적응성 피부** | 신체 | 혹한이나 폭염 속에서도 체온을 일정하게 유지하여 체력 소모를 최소화함. |
| **균형 잡힌 세고리관** | 신체 | 공중에서 몸을 회전시키거나 좁은 난간 위에서도 결코 균형을 잃지 않음. |
| **이중 심장** | 신체 | 심장이 두 개라 치명상을 입어도 즉사하지 않고 혈류를 조절해 생존함. |
| **초고속 신경계** | 신체 | 외부 자극에 반응하는 속도가 일반인의 몇 배나 빨라 화살도 보고 피함. |
| **폐활량 확장** | 신체 | 숨을 오랫동안 참거나 격렬한 운동 중에도 호흡이 흐트러지지 않음. |
| **강화된 동맥** | 신체 | 상처를 입어도 혈관이 수축하여 과다출혈을 막는 생리적 특징. |
| **거대한 어깨** | 신체 | 활시위를 당기거나 거대한 방패를 버티기에 적합한 넓고 단단한 어깨 골격. |
| **섬세한 손가락** | 신체 | 미세한 진동을 느끼는 손가락. 자물쇠의 내부 핀 움직임을 촉각으로 읽어냄. |
| **대지 공명 발바닥** | 신체 | 지면의 미세한 진동을 통해 보이지 않는 적의 위치를 파악하는 발바닥 감각. |
| **독 저항 체질** | 신체 | 소량의 독에 지속적으로 노출되어 웬만한 맹독에는 면역이 된 신체. |
| **크로노스 심장** | 신체 | 시공간과 분리되어 박동하는 심장으로, 시간 정지 중에도 피를 순환시킴. |
| **회색 눈** | 신체 | 색각을 상실하고 세상을 흑백으로 보게 된 눈. 정지된 세계를 오래 관측한 부작용. |
| **그림자화** | 신체 | 실체가 흐릿해지고 빛을 받으면 피부가 타들어가는, 그림자와 동화된 육체. |
| **황금의 손** | 신체 | 확률이나 운명에 개입할 때마다 금빛으로 빛나는 손. |
