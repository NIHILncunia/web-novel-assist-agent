# 03. 신체 (Physical)

> **설명:** 존재의 육체적 특징, 외형, 구조 등 신체의 물리적 형태와 관련된 특성입니다.

---

### 신체 구조 및 외형

| 키워드 | 설명 |
| :--- | :--- |
| **강철 피부** | 일반적인 무기로는 뚫기 힘들 정도로 단단한 외피 |
| **썩은 살점** | 썩어가는 살점으로 이루어져 있으며, 주변에 역병을 퍼뜨릴 수 있음 |
| **다수의 눈** | 2개를 초과하는 눈을 가져 넓은 시야를 확보하거나 특수 시야를 가짐 |
| **가시 돋친 몸** | 온몸이 가시로 덮여 있어 접촉 시 피해를 반사함 |
| **흑요석 갑각** | 흑요석처럼 단단하고 예리한 갑각으로 덮여 있음 |
| **황금 가죽** | 황금빛으로 빛나는 희귀하고 값비싼 가죽 |
| **불타는 갈기** | 사자나 말의 갈기처럼 불꽃이 영원히 타오름 |
| **수정 뿔** | 수정처럼 투명하거나 빛나는 뿔을 가짐 |
| **강철 깃털** | 강철처럼 단단하여 무기로도 사용할 수 있는 깃털 |
| **뼈 날개** | 뼈로만 이루어져 으스스한 분위기를 자아내는 날개 |
| **여러개의 머리** | 머리가 여러 개 있어 동시에 여러 방향을 보거나 생각할 수 있음 |
| **붉은 비늘** | 붉은색 비늘로 덮여 있으며, 화염 저항력을 암시할 수 있음 |
| **거대한 날개** | 몸집에 비해 유난히 크고 강력한 날개 |
| **날카로운 발톱** | 무기처럼 사용할 수 있는 예리한 발톱 |
| **긴 꼬리** | 균형을 잡거나 추가 공격에 사용하는 긴 꼬리 |
| **뿔 달린 머리** | 위협적인 뿔이 돋아난 머리 |
| **거대한 덩치** | 일반적인 동종에 비해 압도적으로 큰 체격 |
| **맹독 혈액** | 체액 자체가 맹독성이라 피를 흘리면 주변에 피해를 줌 |
| **여러개의 팔** | 팔이 4개 이상으로 다수 공격이나 작업에 유리함 |
| **무형의 몸** | 물리적인 실체가 없어 물리 공격을 무시함 (유령, 슬라임) |
| **완벽한 육체** | 균형 잡힌 근육과 신체 능력을 타고났으며, 전염병이나 독에 대한 저항력이 일반인을 아득히 상회함 |
| **은밀한 기색** | 호흡과 심박수를 조절하여 인기척을 극한으로 줄이는 신체적 특징 (탐지 확률 감소) |
| **파괴적 기원** | 존재의 근원 자체가 파괴적이어서 통상적인 치유가 잘 듣지 않거나 부작용을 일으킴 |
| **붕괴된 신체** | 가혹한 반동으로 전신의 근육과 뼈에 미세한 균열이 가득함 (통각 둔화, 내구도 감소) |
| **기원: 검** | 존재의 근원이 '검'과 동질화되어 도검 제작/사용에 특화되나, 치유/타 속성 효율 저하 |
| **칼날의 몸** | 신체 내부가 금속성을 띄어 외상 시 칼날이 돋아나거나 내구도가 비정상적으로 높음 |
| **투명화** | 빛을 굴절시키거나 투과시켜 육안으로 식별하기 어렵게 만듦 |
| **룬 문신** | 피부에 마법적인 룬 문자가 새겨져 있어 상시적인 마법 효과를 냄 |
| **수은 혈액** | 혈액이 수은과 같은 액체 금속으로 이루어져 형태 변환이나 맹독성을 가짐 |
| **보석 심장** | 심장이 마력을 머금은 보석으로 되어 있어 강력한 에너지원이자 급소가 됨 |
| **분리형 사지** | 팔이나 다리, 머리 등을 자유롭게 떼어내어 원격으로 조종할 수 있음 |
| **과잉 성장** | 뼈, 근육, 뿔 등이 비정상적으로 계속 자라나 기괴하지만 강력한 힘을 냄 |
| **마력 방출** | 에너지를 신체 밖으로 분사하거나 폭발시켜 순간적인 기동력과 공격력을 얻음 |
| **생체 원자로** | 고효율의 에너지를 끊임없이 공급하는 체내 순환 시스템을 보유함 |
| **성장 정지** | 특정 시점(계약, 각성 등) 이후로 신체의 노화나 성장이 완전히 멈춤 |
| **마나 회로** | 에너지를 전달하고 연산하는 생체 내부의 마법 신경망이 고도로 발달함 |
| **가호 받은 육체** | 특정 속성(물, 숲 등)이나 환경으로부터 보호받는 축복이나 가호를 받은 신체 |
| **마법 저항성** | 피부나 체질 자체가 마법에 대한 강한 저항력을 가져, 마법 공격을 튕겨내거나 무효화함 |
| **저주받은 신체** | 신체 일부(점, 팔, 눈 등)에 씻을 수 없는 저주가 서려 있어 주변에 불행을 퍼뜨리거나 능력을 제한함 |
| **황금률(체질)** | 평생 동안 재물이나 자원이 마르지 않고 제 발로 굴러들어오는 운명적이고 신비로운 체질 |
| **신성 보유** | 몸속에 신의 피나 기운이 흐르고 있어 초자연적인 권능을 발휘할 수 있는 상태 |
| **액체 금속** | 신체가 T-1000처럼 액체 금속으로 이루어져 물리 피해를 무시하고 형태를 자유롭게 바꿈 |
| **음파 기관** | 목이나 신체 일부에 강력한 초음파나 충격파를 발산하는 생체 기관이 있음 |
| **포자 분출구** | 몸에서 환각, 독, 마비 등의 효과를 가진 포자를 뿜어내는 구멍이 뚫려 있음 |
| **거울 피부** | 피부가 거울처럼 매끄러워 빛이나 레이저, 마법 공격을 반사함 |
| **그림자 융합** | 신체를 그림자와 동화시켜 2차원 평면으로 숨거나 이동할 수 있음 |
| **수정 뼈** | 뼈가 마력을 증폭시키는 희귀한 수정으로 이루어져 있어 마법 효율이 높음 |
| **살아있는 문신** | 피부의 문신이 스스로 움직이거나 튀어나와 공격/방어를 보조함 |
| **촉수 다발** | 팔이나 등에서 자유롭게 움직이는 촉수 다발이 뻗어 나와 다각도 공격이 가능함 |
| **기생 갑주** | 갑옷처럼 보이지만 사실은 숙주의 몸을 파고들어 양분을 빨아먹는 생체 기생물임 |
| **뇌 분산** | 뇌가 머리에 있지 않고 전신에 분산되어 있어, 머리가 터져도 죽지 않음 |
| **저주받은 그릇** | 내부에 막대한 에너지를 품고 있으나, 그 근원이 극도로 타락하여 닿는 모든 것을 변질시키거나 미쳐버리게 만드는 물건(혹은 신체) |
| **이형의 혈액** | 혈액이 검고 끈적한 맹독성 물질로 변하여, 부상 시 튀는 피 자체가 무기가 됨 |
| **마나의 심장** | 자연계의 마나를 스스로 흡수하여 축적하며, 고갈되더라도 시간이 지나면 다시 차오르는 무한한 마력 회로를 내장함 |
| **영혼 포식자** | 영혼이나 생명력을 에너지원으로 삼아야만 생존할 수 있는 본능적인 신체 구조 및 대사 기능 |
| **죽음의 냄새** | 신체에서 피와 죽음을 연상시키는 향기를 풍겨, 포식자나 언데드 몬스터들을 끊임없이 유인함 |
| **에너지의 갑주** | 고속 이동 시 발생하는 마찰열과 공기 저항으로부터 신체를 보호하는 오라 |
| **에너지 뱀파이어** | 스스로 에너지를 생성할 수 없어, 계속해서 움직이거나 타인의 속도를 훔쳐야만 생존할 수 있음 |
| **유령 보행** | 항상 위상(Phase)이 틀어져 있어, 특별한 장비 없이는 누구도 만질 수 없는 저주받은 상태 |
| **태양의 축복** | 항성 에너지를 체내에 축적하여 생명력과 마력의 원천으로 삼는 특수한 생체 기관 |
| **달의 저주** | 태양 아래서는 약해지지만, 달빛이나 어둠 속에서만 진정한 힘을 발휘하는 야행성 체질 |
| **초밀도 근육** | 근육 밀도가 강철보다 높아, 작은 체구로도 거대한 질량을 들어 올리거나 파괴함 |
| **적응형 내성** | 한 번 맞은 속성이나 공격 방식에 대해 내성이 생겨, 두 번째부터는 피해가 급감함 |
| **인지 저해** | 사소한 변장(안경 등)만으로도 타인이 자신의 정체를 알아보지 못하게 만드는 최면적 암시 |
| **얼굴 없는 자** | 평소에는 평범한 이웃의 얼굴을 하고 있지만, 본모습은 인지할 수 없는 코스믹 호러적 존재 |
| **힘의 제어구** | 착용 중인 장비가 방어구인 동시에 사용자의 넘치는 힘을 억제하는 봉인구 역할 |
| **필멸자의 껍질** | 영혼은 신이지만 육체는 인간에 가까워, 신적인 힘을 과도하게 쓰면 육체가 붕괴됨 |
| **밤의 제왕** | 태양 아래서는 평범하지만, 밤이나 어둠 속에서는 모든 능력치가 2배로 상승하는 야행성 |
| **노쇠한 육체** | 지식과 기술은 정점에 달했으나, 늙고 병든 육체 때문에 파워 슈트나 마법 장비에 의존해야 함 |
| **과잉 무장** | 너무 많은 장비를 챙겨 무게로 인해 이동 속도나 회피율이 감소함 |
| **마나 과잉** | 체내에 보유할 수 있는 마력의 총량이 일반인보다 월등히 많아 장기전에 유리함 |
| **기생 숙주** | 체내에 마력을 탐하는 기생 생물들이 살고 있어, 주기적으로 마력을 공급하지 않으면 고통을 겪음 |
| **용의 심장** | 체내에서 호흡만으로도 막대한 마력을 생성하는 초월적인 기관(심장)을 가졌다. 마력 회복 속도와 총량이 규격을 벗어난다 |
| **용의 혈통** | 일반인보다 월등한 생명력, 근력, 재생력을 가진다. 수명이 길고 노화가 늦다 |
| **마나 친화체** | 마력을 단순히 에너지가 아니라 신체의 일부처럼 다룬다. 마력 효율이 좋지만, 그만큼 소비량도 막대하여 지속적인 공급이 필요하다 |
| **마력 포식자 (Mana Predator)** | 생명체의 마력을 직접 흡수하여 자신의 것으로 만드는 특수한 신체 구조를 가진다. 접촉만으로도 마력을 빨아들일 수 있다. |
| **마안 보유자 (Mystic Eyes Holder)** | 특수한 눈을 가져 시선만으로 초자연적인 효과를 발휘할 수 있다. 마안의 종류와 위계에 따라 효과가 달라진다. |
| **신체 성장 지연** | 과도한 훈련이나 특정 생활 방식으로 인해 신체적 성장이 또래보다 느리게 진행된다. 체력·근력 면에서 한계가 드러날 수 있다. |
