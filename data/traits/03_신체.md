# 03. 신체 (Physical)

> **설명:** 존재의 육체적 특징, 외형, 구조 등 신체의 물리적 형태와 관련된 특성입니다.

---

### 신체 구조 및 외형

| 키워드 | 설명 |
| :--- | :--- |
| **강철 피부** | 일반적인 무기로는 뚫기 힘들 정도로 단단한 외피 |
| **썩은 살점** | 썩어가는 살점으로 이루어져 있으며, 주변에 역병을 퍼뜨릴 수 있음 |
| **다수의 눈** | 2개를 초과하는 눈을 가져 넓은 시야를 확보하거나 특수 시야를 가짐 |
| **가시 돋친 몸** | 온몸이 가시로 덮여 있어 접촉 시 피해를 반사함 |
| **흑요석 갑각** | 흑요석처럼 단단하고 예리한 갑각으로 덮여 있음 |
| **황금 가죽** | 황금빛으로 빛나는 희귀하고 값비싼 가죽 |
| **불타는 갈기** | 사자나 말의 갈기처럼 불꽃이 영원히 타오름 |
| **수정 뿔** | 수정처럼 투명하거나 빛나는 뿔을 가짐 |
| **강철 깃털** | 강철처럼 단단하여 무기로도 사용할 수 있는 깃털 |
| **뼈 날개** | 뼈로만 이루어져 으스스한 분위기를 자아내는 날개 |
| **다두(Multi-headed)** | 머리가 여러 개 있어 동시에 여러 방향을 보거나 생각할 수 있음 |
| **붉은 비늘** | 붉은색 비늘로 덮여 있으며, 화염 저항력을 암시할 수 있음 |
| **거대한 날개** | 몸집에 비해 유난히 크고 강력한 날개 |
| **날카로운 발톱** | 무기처럼 사용할 수 있는 예리한 발톱 |
| **긴 꼬리** | 균형을 잡거나 추가 공격에 사용하는 긴 꼬리 |
| **뿔 달린 머리** | 위협적인 뿔이 돋아난 머리 |
| **거대한 덩치** | 일반적인 동종에 비해 압도적으로 큰 체격 |
| **맹독 혈액** | 체액 자체가 맹독성이라 피를 흘리면 주변에 피해를 줌 |
| **다중 팔** | 팔이 4개 이상으로 다수 공격이나 작업에 유리함 |
| **무형의 몸** | 물리적인 실체가 없어 물리 공격을 무시함 (유령, 슬라임) |
| **마나 친화체** | 마나를 몸으로 직접 흡수하거나 효율적으로 다루는 체질 |
| **완벽한 육체** | 균형 잡힌 근육과 신체 능력을 타고났으며, 전염병이나 독에 대한 저항력이 일반인을 아득히 상회함 |
