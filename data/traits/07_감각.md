# 07. 감각 (Senses)

> **설명:** 존재가 주변 환경을 인지하는 방식이나 특별한 감각 어빌리티를 나타내는 트레잇입니다.

## 키워드 목록

| 트레잇 이름 | 분류 | 설명 |
| :--- | :---: | :--- |
| **어둠 시야** | 육감 | 빛이 전혀 없는 어둠 속에서도 대낮처럼 사물을 식별합니다. |
| **초감각** | 육감 | 오감을 초월한 제6감으로 위험이나 초자연적인 현상을 감지합니다. |
| **진동 감지** | 시각 | 시각 대신 지면이나 공기의 미세한 진동을 느껴 보이지 않는 대상의 위치를 파악합니다. |
| **진실 시야** | 육감 | 환영, 은신, 변신 등을 꿰뚫어 보고 사물의 본질을 직관합니다. |
| **예리한 후각** | 후각 | 수 킬로미터 밖의 냄새를 맡거나, 냄새만으로 대상의 상태(공포, 질병 등)를 파악합니다. |
| **예리한 청각** | 청각 | 아주 작은 속삭임이나 심장 박동 소리까지 듣습니다. |
| **예리한 시야** | 육감 | 독수리처럼 먼 거리를 확대해 보거나, 아주 빠르게 움직이는 물체를 포착합니다. |
| **마법 감지** | 육감 | 주변의 마나 흐름이나 마법적인 물건, 함정을 본능적으로 느낍니다. |
| **살의 감지** | 육감 | 자신을 향한 적대적인 의도나 살기를 미리 느껴 기습에 대비합니다. |
| **열 감지** | 시각 | 적외선 카메라처럼 생체나 물체의 열을 시각화하여 은신한 적을 찾아냅니다. |
| **공포 취기** | 후각 | 공포에 질린 대상이 내뿜는 페로몬이나 냄새를 맡고 끈질기게 추적합니다. |
| **마나 흐름 시야** | 육감 | 세상 만물을 마나의 흐름으로 보며, 마법 회로의 약점이나 급소를 파악합니다. |
| **거짓말 탐지** | 청각 | 상대방의 심박수, 동공 확장, 목소리 떨림 등을 감지하여 진위를 판별합니다. |
| **제3의 눈** | 시각 | 이마에 보이지 않는 눈이 있어 영적인 흐름과 사물의 진실을 꿰뚫어 봄. |
| **예민한 후각** | 후각 | 바람에 실려 오는 희미한 피 냄새나 물 냄새를 맡아 방향을 잡음. |
| **기상 감지** | 시각 | 관절의 쑤심이나 공기의 습도로 폭풍우나 눈보라를 미리 예측함. |
| **트래킹 (Tracking)** | 육감 | 꺾인 나뭇가지나 발자국 깊이를 보고 대상의 종류, 크기, 부상 여부를 파악함. |
| **전기장 감지** | 육감 | 상어처럼 생물이 내뿜는 미세한 생체 전기 신호를 감지합니다. |
| **죄악 감지** | 육감 | 대상이 저지른 죄나 업보(Karma)를 검은 아우라 형태로 감지함 |
| **죽음의 시야** | 육감 | 대상의 수명이나 '죽음의 선'을 보아, 어디를 찌르면 죽는지 직관함 |
| **시간 감각** | 시각 | 시계 없이도 현재 시각이나 경과 시간을 1초 단위로 정확하게 인지함 |
| **약점 간파** | 육감 | 구조적, 심리적, 마법적 약점이 붉게 빛나는 표식처럼 보임 |
| **신분 감별** | 육감 | 대상의 위장이나 변장을 꿰뚫고 진짜 이름이나 종족을 알아냄 |
| **공감각 (소리의 색채화)** | 청각 | 소리가 색깔로 보이거나, 냄새가 소리로 들리는 등 감각이 혼재되어 예민함 |
| **피 냄새 추적** | 후각 | 한 번 맛보거나 맡은 피 냄새는 대륙 끝까지라도 쫓아갈 수 있음 |
| **공포 시야** | 육감 | 대상이 가장 두려워하는 것이 무엇인지 형상화되어 보임 |
| **인과율 보기** | 시각 | 어떤 행동이 가져올 결과나 인과 관계의 실타래를 시각적으로 인지함 |
| **시간선 감지** | 육감 | 시간의 흐름이 뒤틀리거나 개변된 흔적(타임 패러독스)을 본능적으로 감지함 |
| **거짓 탐지** | 청각 | 상대방의 목소리 톤이나 심박수 변화가 아니라, 영혼의 파동을 읽어 거짓말을 본능적으로 감지함 |
| **투기 감지** | 육감 | 적의 미세한 근육 움직임이나 살기를 미리 읽어, 보이지 않는 사각지대의 공격도 막아냄 |
| **전쟁 감지** | 후각 | 어디서 분쟁이나 전쟁이 일어나고 있는지 피 냄새나 불길한 기운으로 원격에서 감지함 |
| **곤충 조종** | 육감 | 벌레나 하등 생물과 감각을 공유하거나 정찰 및 암살 명령을 내림 |
| **저격수의 시선** | 육감 | 원거리 목표물을 조준할 때, 시야가 확대되고 손떨림이 보정되어 명중률이 비약적으로 상승함 |
| **야생의 감각** | 육감 | 오감이 맹수처럼 발달하여, 논리적 사고를 거치지 않고도 위험, 살기, 거짓말 등을 피부로 느낀다 |
| **행운 감지** | 육감 | 지금 이 선택이 좋은 결과를 가져올지 나쁜 결과를 가져올지 막연하게나마 느낌(Feeling)으로 알 수 있다 |
| **전투 본능 (Combat Instinct)** | 육감 | 강인한 정신력이 직감과 결합되어, 전투 중 최적의 타이밍과 공격 경로를 본능적으로 파악한다. |
| **전투 직감 (Combat Intuition)** | 육감 | 수많은 전투 경험을 통해 쌓인 본능적인 감각. 논리적 사고 없이도 위험을 감지하고 최적의 행동을 선택한다. |
| **생존 본능 (Survival Instinct)** | 육감 | 죽음의 위험을 느끼면 본능적으로 생존 경로를 찾아낸다. 이성보다 본능이 먼저 반응하여 위기를 모면한다. |
| **반향 정위** | 청각 | 시야가 차단된 곳에서 소리의 반사를 통해 지형과 적을 완벽히 파악함. (초음파) |
| **다차원 시각** | 시각 | 3차원을 넘어 4차원 이상의 축을 보거나, 과거와 미래를 동시에 인지함. |
| **독도법** | 육감 | 지도와 나침반만 있으면 낯선 지형에서도 길을 잃지 않고 최단 경로를 찾는다. |
| **은신처 감각** | 육감 | 도심이나 야생에서 추적을 피하기 좋은 은신처나 비밀 통로를 본능적으로 찾아냄. |
| **기 감지** | 육감 | 시각이나 청각이 아닌, 생명체가 발산하는 고유의 에너지를 느껴 위치와 강함을 파악함. |
| **공기 읽기 (Reading the Atmosphere)** | 육감 | 말하지 않아도 집단 내의 미묘한 기류나 상사의 의중을 본능적으로 감지하고 그에 맞춰 행동하는 고도로 발달된 눈치. |
| **광기의 눈 (Madness Eye)** | 마법 | 눈을 마주친 자의 심연을 들여다보아 정신을 갉아먹는다. |
| **석화의 마안 (Petrification Eye)** | 마법 | 눈을 마주친 대상을 돌로 만들거나 약화시킴. |
| **사냥꾼의 표식 (Hunter's Mark)** | 마법 | 한 번 지정한 사냥감은 시야에서 사라져도 그 기척을 마법적으로 느낄 수 있다. |
| **감지: 생명 (Detect Life)** | 감각 | 주변에 살아있는 생명체의 기척을 느낀다. |
| **꿰뚫어 보는 눈 (Insight)** | 감각 | 상대의 본질, 숨겨진 어빌리티, 혹은 거짓말을 직관적으로 간파한다. |
| **미래 직관 (Future Intuition)** | 감각 | 본능으로 찰나의 미래를 읽어 적의 공격을 피함. |
| **사각 감지 (Blindspot Detect)** | 감각 | 시야가 닿지 않는 곳의 공격을 공기 흐름으로 감지. |
| **복제품 감지 (Clone Detect)** | 감각 | 마력 흔적을 읽어 복제품과 원본을 식별함. |
| **마안 감지 (Eye Detect)** | 감각 | 주변에 마안 보유자가 있으면 그 위치를 감지함. |
| **소환물 감지 (Summon Detect)** | 감각 | 주변의 소환된 존재를 감지하고 강도를 추정함. |
| **벌레의 감각 (Bug Senses)** | 감각 | 부리는 벌레들과 시각 및 청각을 공유함. |
| **야성의 감 (Wild Instinct)** | 감각 | 짐승의 직감으로 함정이나 기습을 미리 예지함. |
| **필중의 예감 (Sure Hit Instinct)** | 감각 | 반드시 맞는다는 확신과 함께 회피 불가 공격. |
| **기척 감지 (Presence Detect)** | 감각 | 숨어 있는 자들의 미세한 기척을 찾아냄. |
| **심안: 위 (Mind's Eye)** | 감각 | 시각 없이 제6감으로 위험을 느껴 회피함. |
| **야생의 직감 (Survival Instinct)** | 감각 | 논리적 사고 이전에 근육이 먼저 반응하여, 시야 밖에서의 기습이나 함정을 회피한다. |
| **마력 감지안 (Mana Sight)** | 감각 | 시야에 들어온 대상의 마나량과 속성을 색깔로 구분하여 본다. |
| **함정 간파 (Trap Detect)** | 감각 | 인위적으로 설치된 함정이나 마법진의 위화감을 본능적으로 감지한다. |
| **약점 간파 (Weakness Detect)** | 감각 | 적의 방어 자세에서 빈틈이나 구조적 약점이 붉게 빛나는 것처럼 보인다. |
| **생명 감지 (Life Radar)** | 감각 | 장애물 너머에 있는 생명체의 위치와 상태를 레이더처럼 감지한다. |
| **불침번 (Vigilance)** | 감각 | 잠을 자면서도 주변의 소리나 살기에 민감하게 반응하여 깬다. |
| **위기 감지 (Crisis Detect)** | 감각 | 누군가 자신을 노리거나 미행하는 것을 등 뒤의 오한으로 느낌. |
| **야간 시야 (Night Vision)** | 감각 | 가로등이 없는 어두운 골목에서도 사물을 명확히 식별한다. |
| **청각 필터링 (Auditory Filter)** | 감각 | 도시의 소음 속에서 필요한 정보(발소리, 대화)만 골라 듣는다. |
| **거짓말 탐지 (Lie Detect)** | 감각 | 상대의 미세한 표정 변화나 목소리 떨림으로 거짓말을 간파함. |
| **제6감 (Sixth Sense)** | 감각 | 보이지 않는 위험이나 살기를 피부로 느끼며 회피율 상승. |
| **영적 감수성 (Spiritual Sensitivity)** | 감각 | 주변의 영적 에너지를 시각적으로 구분하여 파악함. |
| **기습 감지 (Ambush Detect)** | 감각 | 살기가 느껴지면 본능적으로 몸을 피하거나 잠에서 깸. |
| **급소 포착 (Vital Spot Detect)** | 감각 | 적의 갑옷 틈새나 해부학적 약점을 본능적으로 찾음. |
| **블라인드 파이트 (Blind Fight)** | 감각 | 눈이 멀어도 청각과 공기 흐름으로 적의 위치 파악. |
| **암살자의 눈 (Assassin's Eye)** | 감각 | 아직 자신을 눈치채지 못한 적의 급소를 100% 확률로 포착한다. |
| **급소 감지 (Vital Detect)** | 감각 | 해부학적 지식으로 적의 동맥이나 신경 위치를 정확히 파악하여 찌른다. |
| **눈먼 싸움 (Blind Fighting)** | 감각 | 보이지 않는 적(투명화)을 공격할 때도 빗나가지 않으며, 기습에 당해도 방어 자세를 취한다. |
| **전투 반사 (Combat Reflexes)** | 감각 | 적이 아주 작은 빈틈만 보여도 놓치지 않고 짐승 같은 반응 속도로 반격한다. |
| **배신의 냄새 (Scent of Betrayal)** | 감각 | 동료나 부하의 배신 징후를 본능적으로 감지. |
| **암흑 시야** | 감각 | 빛이 없는 완전한 어둠 속에서도 대낮처럼 사물을 흑백으로 식별할 수 있다. |
| **기척 차단 (Presence Concealment)** | 감각 | 자신의 존재감을 극한으로 지워 유령과 같은 상태가 된다. |
| **구조 통찰 (Structural Insight)** | 감각 | 사물의 재질, 내부 구조, 역사까지 시각적으로 분석함. (구조 파악) |
| **살기 감지 (Killing Intent Detect)** | 감각 | 보이지 않는 곳에서의 살기나 적의를 본능적으로 감지함. |
| **청각 탐지 (Auditory Detection)** | 감각 | 미세한 호흡 소리나 공기 흐름으로 은신한 적을 찾아냄. (호흡 감지) |
| **진명 간파 (True Name Insight)** | 감각 | 대상을 보는 순간 진명과 정보를 꿰뚫어 봄. |
