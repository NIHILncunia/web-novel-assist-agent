# 07. 감각 (Senses)

> **설명:** 존재가 주변 환경을 인지하는 방식이나 특별한 감각 능력을 나타내는 특성입니다.

## 키워드 목록

| 특성 이름 | 특성 설명 |
|:---:|---|
| **어둠 시야** | 빛이 전혀 없는 어둠 속에서도 대낮처럼 사물을 식별합니다. |
| **초감각** | 오감을 초월한 제6감으로 위험이나 초자연적인 현상을 감지합니다. |
| **진동 감지** | 시각 대신 지면이나 공기의 미세한 진동을 느껴 보이지 않는 대상의 위치를 파악합니다. |
| **진실 시야** | 환영, 은신, 변신 등을 꿰뚫어 보고 사물의 본질을 직관합니다. |
| **예리한 후각** | 수 킬로미터 밖의 냄새를 맡거나, 냄새만으로 대상의 상태(공포, 질병 등)를 파악합니다. |
| **예리한 청각** | 아주 작은 속삭임이나 심장 박동 소리까지 듣습니다. |
| **예리한 시야** | 독수리처럼 먼 거리를 확대해 보거나, 아주 빠르게 움직이는 물체를 포착합니다. |
| **마법 감지** | 주변의 마나 흐름이나 마법적인 물건, 함정을 본능적으로 느낍니다. |
| **살의 감지** | 자신을 향한 적대적인 의도나 살기를 미리 느껴 기습에 대비합니다. |
| **열 감지** | 적외선 카메라처럼 생체나 물체의 열을 시각화하여 은신한 적을 찾아냅니다. |
| **공포 취기** | 공포에 질린 대상이 내뿜는 페로몬이나 냄새를 맡고 끈질기게 추적합니다. |
| **마나 흐름 시야** | 세상 만물을 마나의 흐름으로 보며, 마법 회로의 약점이나 급소를 파악합니다. |
| **거짓말 탐지** | 상대방의 심박수, 동공 확장, 목소리 떨림 등을 감지하여 진위를 판별합니다. |
| **영혼 시야** | 육체 껍데기가 아닌 내면의 영혼이나 아우라를 직접 봅니다. |
| **전기장 감지** | 상어처럼 생물이 내뿜는 미세한 생체 전기 신호를 감지합니다. |
| **죄악 감지** | 대상이 저지른 죄나 업보(Karma)를 검은 아우라 형태로 감지함 |
| **죽음의 시야** | 대상의 수명이나 '죽음의 선'을 보아, 어디를 찌르면 죽는지 직관함 |
| **행운 감지** | 지금 이 순간 운이 좋은 곳이나 나쁜 곳을 본능적으로 느낌 (도박사, 탐험가) |
| **시간 감각** | 시계 없이도 현재 시각이나 경과 시간을 1초 단위로 정확하게 인지함 |
| **약점 간파** | 구조적, 심리적, 마법적 약점이 붉게 빛나는 표식처럼 보임 |
| **신분 감별** | 대상의 위장이나 변장을 꿰뚫고 진짜 이름이나 종족을 알아냄 |
| **공감각 (소리의 색채화)** | 소리가 색깔로 보이거나, 냄새가 소리로 들리는 등 감각이 혼재되어 예민함 |
| **피 냄새 추적** | 한 번 맛보거나 맡은 피 냄새는 대륙 끝까지라도 쫓아갈 수 있음 |
| **공포 시야** | 대상이 가장 두려워하는 것이 무엇인지 형상화되어 보임 |
| **인과율 보기** | 어떤 행동이 가져올 결과나 인과 관계의 실타래를 시각적으로 인지함 |
