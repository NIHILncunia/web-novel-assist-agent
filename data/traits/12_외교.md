# 12. 외교 (Diplomacy)

> **설명:** 국가, 단체, 혹은 종족이 외부 세력을 대하는 태도나 외교적 기조를 나타내는 특성입니다.

## 키워드 목록

| 키워드 | 설명 |
| :--- | :--- |
| **패권주의 (Hegemony)** | 무력이나 경제력으로 타 세력을 지배하고 영향력을 확대하려는 성향 |
| **고립주의 (Isolationism)** | 외부와의 교류를 최소화하고 내부 문제에 집중하며 폐쇄적인 태도를 취함 |
| **사대주의 (Sadae)** | 강대국이나 상위 세력을 섬기며 그들의 보호 아래 생존을 도모함 |
| **중립주의 (Neutrality)** | 분쟁에 개입하지 않고 어느 편에도 서지 않으며 실리를 추구함 |
| **확장주의 (Expansionism)** | 영토, 교세, 시장 등을 끊임없이 넓히려는 공격적인 기조 |
| **평화주의 (Pacifism)** | 무력 사용을 극도로 꺼리며 대화와 협상을 통한 해결을 최우선시함 |
| **기회주의 (Opportunism)** | 신의나 원칙보다 상황에 따라 이득이 되는 쪽으로 빠르게 태세를 전환함 |
| **배타주의 (Exclusivism)** | 타 종족이나 외부 문화를 배척하고 순수성을 고집함 |
| **동화주의 (Assimilation)** | 타 세력을 정복하거나 흡수하여 자신의 문화로 동화시키려 함 |
| **균형자 (Balancer)** | 강대국 사이에서 세력 균형을 맞추며 중재자 역할을 자처함 |
| **실리주의 (Pragmatism)** | 명분보다는 실제적인 이익과 효율을 최우선으로 고려함 |
| **신비주의 (Mysticism)** | 정보를 통제하고 내부 사정을 감추어 외부가 경외심을 갖게 함 |
| **호혜평등 (Reciprocity)** | 모든 세력을 동등하게 대우하며 주고받는 관계를 중시함 |
| **제국주의 (Imperialism)** | 타국을 식민지화하거나 정치/경제적으로 종속시키려 함 |
| **개입주의 (Interventionism)** | 타 세력의 내분이나 분쟁에 적극적으로 개입하여 영향력을 행사함 |
| **비동맹 (Non-Alignment)** | 거대 세력의 블록에 속하지 않고 독자 노선을 걸음 |
| **전투적 외교 (Aggressive)** | 협상 테이블에서도 무력 시위나 위협을 서슴지 않음 |
| **문화적 우월감** | 자신들의 문화가 우월하다고 믿으며 타 문화를 계몽 대상으로 여김 |
| **상업적 외교** | 정치적 명분보다 무역 이익과 경제적 파트너십을 최우선시함 |
| **종교적 전파** | 외교의 주된 목적이 교세 확장과 포교에 있음 |
| **생존 우선** | 자존심이나 명예를 버리고 생존을 위해서라면 무엇이든 양보함 |
| **비밀 외교** | 공식적인 채널보다 물밑 접촉과 밀약을 선호함 |
| **대리전 (Proxy)** | 직접 나서지 않고 하위 세력이나 용병을 내세워 분쟁을 조율함 |
| **다자간 협력** | 여러 세력과 동시에 동맹을 맺어 안전보장 체계를 구축함 |
| **기만 전술** | 거짓 정보나 위장 평화 조약을 통해 상대를 방심시킴 |
| **원리원칙** | 한 번 정한 외교 원칙이나 조약을 손해를 감수하고서라도 지킴 |
| **기술 쇄국** | 자원이나 인력은 교류하되, 핵심 기술이나 마법 지식 유출은 엄격히 통제함 |
| **가문의 적대자** | 가문의 오래된 적대 관계를 상속받아, 특정 세력과의 협상이나 공존이 구조적으로 어려워진다. |
