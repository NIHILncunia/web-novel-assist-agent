# 02. 기원 (Origin)

> **설명:** 존재의 태생적 배경, 출처, 혹은 서사적 근원을 나타내는 특성입니다.

## 키워드 목록

| 키워드 | 설명 |
| :--- | :--- |
| **자연 발생** | 마나나 자연의 기운이 뭉쳐 저절로 태어남 (자연 환경에서 스스로 탄생) |
| **마법 실험체** | 인위적인 마법 실험이나 연금술로 창조됨 (마법 실험의 결과물) |
| **이계의 존재** | 다른 차원이나 행성에서 건너옴 (외계/이세계/차원 포식자) |
| **고대신의 파편** | 잊혀진 신의 육체나 권능 일부가 떨어져 나와 형성됨 (고대 신의 힘이나 파편에서 탄생) |
| **저주받은 영혼** | 죽지 못하고 현세에 묶인 원혼이나 저주로 변이된 존재 |
| **신의 창조물** | 신이 직접적인 의도를 가지고 빚어낸 피조물 |
| **기계 생명체** | 과학이나 마도 공학 기술로 제작된 인공지능 로봇 |
| **돌연변이** | 정상적인 생태계에서 벗어나 기형적으로 진화함 |
| **용의 혈통** | 드래곤의 피를 이어받아 강력한 잠재력을 지님 |
| **정령의 현신** | 순수한 원소 에너지가 실체화된 존재 |
| **악마의 계약자** | 악마에게 영혼을 팔아 힘을 얻은 변절자 |
| **타락한 수호자** | 본래 성소나 보물을 지키던 존재였으나 타락함 |
| **그림자 피조물** | 어둠과 그림자 속에서 태어난 실체 없는 존재 |
| **운석 포자** | 우주에서 떨어진 운석에 묻어온 미지의 생명체 |
| **심연의 산물** | 바다 깊은 곳이나 지하 깊숙한 심연에서 기어 나옴 |
| **황금률** | 일생 동안 금전적인 문제가 따르지 않으며, 원하는 물건이 제 발로 굴러들어오는 듯한 운명적 특성 |
| **마력의 결정체** | 마력이 응집되어 형성된 존재 |
| **인공 생명체** | 인위적으로 만들어진 생명체 (기계 생명체와 유사하나 마법적/생물학적일 수 있음) |
| **태양의 파편** | 태양의 힘이나 파편에서 탄생한 존재 |
| **고대 종족** | 오래전부터 존재해온 고유한 종족 |
| **화산의 화신** | 화산의 힘에서 태어난 존재 |
| **알에서 부화** | 알을 통해 태어나는 생물학적 방식 |
