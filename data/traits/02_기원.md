# 02. 기원 (Origin)

> **설명:** 존재의 태생적 배경, 출처, 혹은 서사적 근원을 나타내는 특성입니다.

## 키워드 목록

| 키워드 | 설명 |
| :--- | :--- |
| **자연 발생** | 마나나 자연의 기운이 뭉쳐 저절로 태어남 (자연 환경에서 스스로 탄생) |
| **마법 실험체** | 인위적인 마법 실험이나 연금술로 창조됨 (마법 실험의 결과물) |
| **이계의 존재** | 다른 차원이나 행성에서 건너옴 (외계/이세계/차원 포식자) |
| **고대신의 파편** | 잊혀진 신의 육체나 권능 일부가 떨어져 나와 형성됨 (고대 신의 힘이나 파편에서 탄생) |
| **저주받은 영혼** | 죽지 못하고 현세에 묶인 원혼이나 저주로 변이된 존재 |
| **신의 창조물** | 신이 직접적인 의도를 가지고 빚어낸 피조물 |
| **기계 생명체** | 과학이나 마도 공학 기술로 제작된 인공지능 로봇 |
| **돌연변이** | 정상적인 생태계에서 벗어나 기형적으로 진화함 |
| **용의 혈통** | 드래곤의 피를 이어받아 강력한 잠재력을 지님 |
| **정령의 현신** | 순수한 원소 에너지가 실체화된 존재 |
| **악마의 계약자** | 악마에게 영혼을 팔아 힘을 얻은 변절자 |
| **타락한 수호자** | 본래 성소나 보물을 지키던 존재였으나 타락함 |
| **그림자 피조물** | 어둠과 그림자 속에서 태어난 실체 없는 존재 |
| **운석 포자** | 우주에서 떨어진 운석에 묻어온 미지의 생명체 |
| **심연의 산물** | 바다 깊은 곳이나 지하 깊숙한 심연에서 기어 나옴 |
| **황금률** | 일생 동안 금전적인 문제가 따르지 않으며, 원하는 물건이 제 발로 굴러들어오는 듯한 운명적 특성 |
| **마력의 결정체** | 마력이 응집되어 형성된 존재 |
| **인공 생명체** | 인위적으로 만들어진 생명체 (기계 생명체와 유사하나 마법적/생물학적일 수 있음) |
| **태양의 파편** | 태양의 힘이나 파편에서 탄생한 존재 |
| **고대 종족** | 오래전부터 존재해온 고유한 종족 |
| **화산의 화신** | 화산의 힘에서 태어난 존재 |
| **알에서 부화** | 알을 통해 태어나는 생물학적 방식 |
| **꿈의 구현** | 누군가의 강렬한 소망이나 악몽이 현실로 실체화되어 태어남 |
| **잊혀진 노래** | 고대의 전설이나 노래 가사가 마력을 얻어 생명체로 거듭남 |
| **데이터 오류** | (SF/현대) 시스템의 버그나 글리치로 인해 발생한 변칙적인 존재 |
| **그림자 잔재** | 죽은 자의 그림자가 본체와 분리되어 독자적인 자아를 가짐 |
| **인공 신화** | 누군가의 의도나 계획에 의해 '이상적인 영웅'이나 '신의 대행자'로서 설계되어 태어남 |
| **매혹의 저주** | 본인의 의지와 상관없이 이성을 강제로 매료시켜 갈등과 파멸을 부르는 운명적 특성 |
| **비극적 운명** | 뛰어난 능력과 선한 의도를 가졌음에도, 결말이 비극으로 끝나도록 예정된 가혹한 운명 |
| **반신반인** | 신과 인간의 혈통이 섞여 태어난 존재로, 초월적인 권능과 인간적인 고뇌를 동시에 지님 |
| **신의 대행자** | 신들이 인간 세상을 통제하거나 특정 목적을 달성하기 위해 지상에 보낸 간섭자 |
| **시간 여행자** | 미래나 과거에서 시간을 넘어 현재로 온 존재로, 역사를 바꾸려는 목적을 가짐 |
| **차원 유랑자** | 여러 차원을 떠돌아다니며 정착하지 못하는 방랑자 |
| **각성한 사물** | 오래된 물건에 영혼이 깃들어 자아를 가지게 된 존재 (츠쿠모가미) |
| **집단 무의식** | 대중의 믿음이나 공포가 모여 형체를 이루고 태어난 개념적 존재 |
| **개념의 의인화** | '죽음', '전쟁', '기아' 등 추상적인 개념이 인격을 입고 현현함 |
| **공허의 태생** | 존재하지 않아야 할 '무(Null)'의 공간에서 태어난 역설적인 생명체 |
| **전생자** | 전생의 기억을 온전히 가지고 새로운 육체로 다시 태어난 존재 |
| **신화 포식자** | 신이나 신화적 존재를 잡아먹고 그 권능을 찬탈하여 기원을 덮어쓴 존재 |
| **실험 실패작** | 완벽한 실험체를 만들기 위한 과정에서 버려졌으나 끈질기게 살아남은 폐기물 |
| **멸망의 잔재** | 이미 멸망해버린 세계나 문명에서 유일하게 살아남아 건너온 생존자 |
| **자연 에너지 전도체** | 특수한 차원의 에너지를 몸으로 받아들이고 방출하는 살아있는 통로(Conduit) |
| **살아있는 역설** | 인과율에서 벗어난 존재. 과거의 자신이 죽어도 현재의 자신이 사라지지 않는 특이점 |
| **별의 아이** | 태양계 밖에서 온 존재로, 우주 공간에서도 호흡 없이 생존하며 비행할 수 있음 |
| **인공 구세주** | 자연적으로 태어난 것이 아니라, 누군가 세상을 구원(혹은 통제)하기 위해 의도적으로 설계한 생체 병기 |
| **제우스의 혈통** | 신들의 왕의 피를 이어받아, 태생적으로 번개와 마법에 높은 친화력을 가짐 |
| **대지의 딸** | 부모 없이 흙으로 빚어져 신의 숨결로 생명을 얻은 존재 |
| **검의 기원** | 존재의 근원이 '검'이라는 개념으로 이루어져 있어, 도검류 관련 기술 습득이 비정상적으로 빠름 |
| **허수 친화** | 물리 세계에 존재하지 않는 차원이나 에너지(허수)를 다루는 데 선천적인 재능을 가짐 |
| **원소 친화** | 자연계에 존재하는 모든 원소와 높은 친화력을 가져, 어떤 속성의 마법이든 페널티 없이 습득함 |
| **마물화 진행 (Monster Transformation Progress)** | 원래는 신이나 영웅이었으나 저주나 타락으로 인해 마물로 변해가는 과정에 있다. 인간성을 잃어가지만 그만큼 힘은 증가한다. |
| **반영웅 (Anti-Hero)** | 영웅으로 인정받지 못하고 오히려 마물로 취급받는 존재. 영웅의 힘은 가지지만 그 정체성은 부정된다. |
| **가문의 유산** | 명문 가문의 후계자로서 선조로부터 전해 내려온 마술, 지식, 비밀, 유물 등을 계승한 상태. |
| **불사의 시련** | 수많은 시련을 겪으며 불사의 경지에 도달한 존재. 죽음의 경험이 축적되어 일반적인 죽음의 개념을 초월한다. |
| **쇠락한 명문** | 과거에는 위대했으나 현재는 힘과 영광을 잃고 이름만 남은 혈통이나 조직 출신. |
| **반신의 혈통** | 신과 인간의 혼혈로 태어나, 인간의 한계를 아득히 초월한 잠재력을 가진다. 성장 속도가 빠르며, 특정 신성 영역(태양, 빛 등)에 대한 친화력을 가진다. |
| **지역 결속** | 특정한 장소나 지역에 영혼이 묶여 있어 벗어날 수 없다. 해당 지역 내에서는 강력한 힘을 발휘하지만, 경계를 넘는 순간 소멸하거나 힘을 잃는다. |
| **이름 없는 영웅** | 역사에 이름을 남기지 못한 무명의 실력자. 명성이나 유물의 위광은 없지만, 순수한 실력만으로 영웅의 반열에 오른다. 진짜 이름을 간파당해도 약점이 드러나지 않는다. |
| **살인 훈련** | 인격을 배제하고 오직 효율적인 살상만을 목적으로 하는 가혹한 훈련을 받아, 감정 동요 없이 살인을 수행한다. |
| **부패한 나뭇잎** | 사회의 어두운 곳에서 소모품으로 쓰이다 버려질 운명을 받아들이고, 삶에 대한 집착이 희박하다. |
| **신대의 마술사** | 마법이 쇠퇴하기 전, 신들이 지상에 머물던 시대의 마법 체계를 사용한다. 현대의 마법사들이 평생을 바쳐도 도달할 수 없는 경지를 호흡하듯이 자연스럽게 구사한다. |
| **최초의 영웅** | 모든 신화와 영웅 전설의 원형(Archetype)이 되는 존재. 모든 영웅의 기원이므로, 후대의 영웅들이 가진 유물이나 일화의 원전을 소유하거나 파훼법을 알고 있다. '영웅 살해자' 속성을 가진다. |
| **마력 중독자** | 고농도 마나 환경에서 태어나 마나 없이는 숨을 쉬지 못하는 체질. |
| **규소 생명체** | 탄소가 아닌 규소(돌/수정) 기반으로 이루어진 외계 생명체. 고열에 강함. |
| **군집 의식체** | 개별 자아 없이 하나의 거대한 초월적 의식을 공유하는 군집. |
| **차원 포식자** | 차원의 벽을 갉아먹으며 세계를 이동하고 에너지를 섭취하는 존재. |
| **전쟁 고아** | 끊임없는 전쟁 속에서 부모를 잃고 전장에서 자라 생존 기술을 익힌 아이들. |
| **강화 병사 (Super Soldier)** | 약물이나 마법 시술로 감정을 억제하고 신체 능력을 극대화한 생체 병기. |
| **영매의 핏줄** | 대대로 영혼을 보고 대화할 수 있는 능력을 타고난 가문 출신. |
| **금기된 서약자** | 고대 신이나 악마와 영혼을 담보로 계약하여 태어난 대가성 존재. |
| **성유물 수호자** | 신성한 유물을 지키는 임무를 띤 가문에서 자라 그 기운에 동화됨. |
| **별의 파편** | 하늘에서 떨어진 운석에서 발견된, 우주의 마력이 깃든 개체. |
| **야생아** | 문명사회와 단절된 채 짐승의 손에 길러져 언어보다 울음소리에 익숙함. |
| **기사 가문의 서자** | 정당한 대우는 못 받았으나 기초 무술만큼은 완벽하게 교육받은 출신. |
| **뒷골목의 쥐** | 빈민가에서 쓰레기를 뒤지며 살아남기 위해 도둑질과 암습을 본능으로 익힘. |
| **숲의 파수꾼** | 대대로 성소나 숲을 지키는 부족에서 태어나 자연 마법과 궁술이 생활인 존재. |
| **버려진 병기** | 전쟁 도구로 키워졌으나 평화가 찾아오자 버려진, 싸움 외에는 아무것도 모르는 존재. |
| **해적의 핏줄** | 바다 위에서 태어나 균형 감각과 수영, 거친 육탄전에 최적화된 배경. |
| **검투사의 후예** | 자유를 얻기 위해 목숨을 걸고 싸웠던 부모의 전투 감각을 물려받음. |
| **몰락한 귀족** | 한때 화려했으나 모든 것을 잃고, 가문의 검술과 자존심만 남은 자. |
| **야만족의 생존자** | 혹독한 북부나 남부의 야생에서 부족 전쟁을 겪으며 살아남은 강인한 전사. |
| **도망친 노예** | 족쇄를 끊고 탈출하는 과정에서 은신과 도주, 생존 기술을 처절하게 익힘. |
| **은퇴한 노장** | 수많은 전장을 누비고 살아남아, 늙었지만 노련한 전투 지혜를 가진 자. |
