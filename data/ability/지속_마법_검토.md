## 1. 재분류 제안 (지속 -> 액티브)
다음 어빌리티들은 '상시 적용되는 상태'보다는 **'사용자의 의지에 따른 행동(Action)'**이나 **'발동(Activation)'**을 묘사하고 있어, **액티브(Active)** 권역으로 이동하는 것을 제안합니다.

| 이름 | 분류 | 설명 | 재분류 사유 |
| :--- | :--- | :--- | :--- |
| **환영 분신** | 정신 | 진짜와 구분하기 힘든 환영을 만들어내어 적을 교란한다. | '환영을 만들어낸다'는 능동적인 시전 행위가 포함됩니다. |
| **꼭두각시의 실** | 정신 | 종속된 대상과 연결되어 감각 공유 및 조종. | 대상을 능동적으로 '조종'하는 행위입니다. |
| **원초의 룬** | 원소 | 고대 룬 문자로 자연 현상을 조작하는 기적. | 자연 현상을 '조작'하는 것은 시전자의 의지가 개입된 행동입니다. |
| **중력 제어** | 특수 | 자신 주변의 중력을 자유자재로 조절하여 날아다니거나 적을 짓누른다. | 비행이나 공격(짓누르기)을 위해 중력을 '조절'하는 액티브 스킬입니다. |
| **차원 간섭** | 특수 | 물리적으로 접촉하지 않고도 벽 너머나 원거리의 물체에 간섭한다. | 염동력과 유사한 형태로, 특정 대상에게 물리력을 행사하는 '행동'입니다. |

## 2. 설명 수정 제안 (지속성 강화)
다음 어빌리티들은 지속 능력으로 유지하되, **자동 발동**이나 **상시 상태**임이 더 명확하게 드러나도록 설명 수정을 제안합니다.

| 이름 | 현재 설명 |수정 제안 |
| :--- | :--- | :--- |
| **마법 반사** | 자신을 향해 날아오는 마법을 그대로 적에게 되돌려 보낸다. | → 자신을 향해 날아오는 마법이 닿는 즉시 **자동으로** 적에게 반사된다. |
| **검의 묘지** | 황량한 심상 풍경을 보여주어 적의 전의를 감소시킴. | → 사용자 주변에 황량한 심상 풍경이 **상시 투영되어**, 범위 내 적의 전의를 감소시킴. (오라 형태임을 명시) |
| **마력 갑주** | 고밀도 마력을 갑옷 형태로 둘러 공방 일체 방어. | → 고밀도 마력이 **항상 전신을 감싸고 있어** 공방 일체의 방어 능력을 제공한다. |
