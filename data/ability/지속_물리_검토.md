## 1. 재분류 제안 (지속 -> 액티브)
물리 권역에는 '자세(Stance)'나 '기술(Technique)'로 분류되어야 할 액티브 성격의 어빌리티들이 다수 포함되어 있습니다. 특히 **켜고 끄는(Toggle)** 형태의 은신이나 태세 변환은 액티브로 이동해야 합니다.

| 이름 | 분류 | 설명 | 재분류 사유 |
| :--- | :--- | :--- | :--- |
| **구속 면역** | 신체 | 신체를 진동시켜 모든 물리적/마법적 구속을 탈출함. | '진동시켜 탈출한다'는 구체적인 탈출 **행동**입니다. |
| **기척 차단** | 기술 | 자신의 기척을 지워 유령 같은 상태가 됨. | 전형적인 은신(Stealth) 액티브 스킬입니다. |
| **반격의 자세** | 기술 | 적의 공격을 기다렸다가 카운터 시 위력 배가. | 특정 타이밍을 노리거나 자세를 잡는 액티브 기술입니다. |
| **부동의 자세** | 기술 | 땅에 뿌리를 내린 듯 고정되어 충격에도 버팀. | 이동을 포기하고 방어력을 높이는 '태세(Stance)' 액티브입니다. |
| **금속 융합** | 기술 | 금속제 무기나 도구를 접촉하면 자신의 신체 일부처럼 흡수하거나 변형시켜 다룰 수 있다. | 물체를 '흡수'하고 '변형'하는 것은 능동적인 조작 행위입니다. |
| **환경 은신** | 기술 | 주변 지형에 맞춰 피부색이나 질감을 바꿔 완벽하게 위장한다. | 카멜레온처럼 변색하는 것은 능동적인 위장술입니다. |
| **위장술** | 기술 | 지형지물을 이용해 몸을 숨기는 어빌리티가 뛰어나 정체를 숨김. | 몸을 숨기는 '행위'를 묘사합니다. |
| **강타 태세** | 기술 | 명중을 희생하는 대신 체중을 실어 파괴력 극대화. | 명중과 파괴력을 교환하는 태세 변환(액티브)입니다. |
| **정밀 타격** | 기술 | 파괴력보다 정확도에 집중하여 작은 목표도 맞춤. | 태세 변환(액티브)입니다. |
| **앉아 쏴** | 기술 | 자리에 고정하여 이동을 포기하고 사거리 2배 증폭. | 시즈 모드와 같은 태세 변환(액티브)입니다. |
| **그립 전환** | 기술 | 검날을 잡고 찌르는 등 변칙적 사용으로 중갑 관통. | 특정 상황에서 사용하는 액티브 기술(하프 소딩)입니다. |

## 2. 설명 수정 제안 (지속성 강화)
아래 항목들은 지속 능력으로 유지하되, 설명의 뉘앙스를 '상시 적용'으로 수정할 필요가 있습니다.

| 이름 | 현재 설명 | 수정 제안 |
| :--- | :--- | :--- |
| **비행 회피** | 공중에 떠 있거나 비행하여 지상 공격을 쉽게 회피한다. | → **상시 공중 부양 상태**를 유지하여 지상 공격을 무시하거나 쉽게 회피한다. |
| **소리 없는 살인** | 무기를 휘두를 때 바람 소리가 나지 않음. | → 무기를 휘두르는 속도와 관계없이 **바람 소리가 자체가 발생하지 않는다.** |
| **자동 반격** | 근접 공격을 회피하면 무의식적으로 즉시 반격을 가한다. | → (유지) '무의식적으로'라는 표현이 있어 리액션(Reaction)형 패시브로 적절함. |
