# 정신 권역 - 강화계 (고양)

> **권역:** 정신
> **계통:** 강화계
> **형태:** 고양

---

| 이름 | 원천 (Source) | 대상 | 피해 유형 | 상태 이상 | 설명 |
| :--- | :---: | :---: | :---: | :---: | :--- |
| **호기로운 선언** | 언어 | 범위 | 해당 없음 | 해당 없음 | 자신의 목표나 승리를 큰 소리로 선언하여 자신의 어빌리티치를 일시적으로 대폭 상승시킨다. |
| **왕의 자격** | 왕도 | 자신 | 해당 없음 | 회복/강화 | 왕이 될 자격을 증명하듯, 잃어버린 체력과 마력을 대량 회복하고 일시적으로 모든 어빌리티치를 상승시킨다 |
| **자존심 각성** | 자존심 | 자신 | 해당 없음 | 해당 없음 | 자신의 자존심을 자극해 일시적으로 전반 어빌리티치를 끌어올린다. 자존심이 상처받은 상황에서 더 강하게 발동한다. |
| **용맹 각성** | 용맹 | 자신 | 해당 없음 | 강화/정신 보호 | 용맹의 힘을 일시적으로 극대화하여 정신 방어력과 격투 위력을 폭발적으로 상승시킨다. 위기 상황에서 발동된다. |
| **소원 대행** | 신앙 | 자신 | 해당 없음 | 강화 | 자신이 섬기는 대상의 소원을 이루기 위한 행동을 할 때, 일시적으로 모든 어빌리티치와 행운이 상승한다. |
| **신념의 충돌** | 신념 | 자신 | 해당 없음 | 강화 | 적과의 대화나 전투를 통해 서로의 신념이 정면으로 충돌할 때, 자신의 신념을 관철하기 위해 정신력과 마력 회복 속도가 대폭 상승한다. |
| **전투 함성 (Battle Cry)** | 소리 | 범위 | 해당 없음 | 사기 | 우렁찬 함성으로 아군의 사기를 북돋아 공포 상태를 해제하고 공격력을 일시적으로 상승시킨다. |
| **숭고한 희생** | 희생 | 단일 | 해당 없음 | 대신 맞기 | 아군에게 향하는 치명적인 공격을 몸을 던져 대신 받아낸다 |
| **최후의 발악** | 생존본능 | 자신 | 해당 없음 | 해당 없음 | 체력이 바닥나거나 죽음이 임박했을 때, 생존을 위해 보유한 자원이나 명예를 모두 소모하여 탈출 기회를 만든다. |
| **광신도의 돌격** | 신앙 | 자신 | 해당 없음 | 방어 무시 | 방어를 포기하고 적에게 돌진한다. "신께서 보살피시리라"는 믿음으로 화살비를 뚫고 지나가며, 적의 공격에 맞아도 멈추지 않는다. |
| **희생 각성** | 희생 | 자신 | 해당 없음 | 광폭화/강화 | 자신을 희생할 각오를 하면 일시적으로 모든 어빌리티치가 극한까지 상승한다. 하지만 사용 후에는 심각한 후유증이 따르며, 정신적 피로가 극도로 누적된다 |
| **마물 본능 해방 (Monster Instinct Release)** | 본능 | 자신 | 해당 없음 | 광폭화/강화 | 억눌려 있던 마물의 본능을 해방시켜 이성을 잃고 본능에 따라 행동한다. 전투력은 극대화되지만 통제가 어려워진다. |
| **광화 가속** | 광기 | 자신 | 해당 없음 | 광폭화/극대 강화 | 광화 상태를 더욱 심화시켜 이성을 완전히 잃는 대신 어빌리티치를 극한까지 상승시킨다. 사용 후에는 회복이 어려워진다. |
| **집념의 일격** | 집념 | 단일 | 물리 | 필중 | 육체적 한계를 무시하고, 상대를 맞추겠다는 일념만으로 날리는 공격. 회피가 불가능한 궤적으로 날아가거나, 막혀도 방어를 뚫고 충격을 전달한다. |
