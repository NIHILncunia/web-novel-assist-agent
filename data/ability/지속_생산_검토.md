## 1. 재분류 제안 (지속 -> 액티브)
생산/경영 권역 어빌리티 중, 구체적인 '제작', '수리', '건축', '요청' 행위를 포함하는 항목들은 액티브로 분류하는 것이 적합합니다.

| 이름 | 분류 | 설명 | 재분류 사유 |
| :--- | :--- | :--- | :--- |
| **가문의 인맥** | 경영 | 가문의 명성을 활용해 정보나 도움을 요청함. | 능동적으로 인맥을 통해 도움을 '요청'하는 것은 사회적 액티브 스킬입니다. |
| **신전 구축** | 경영 | 거점을 마술적 요새(신전)로 개조함. | 거점을 '개조'하고 '구축'하는 것은 건설 액티브입니다. |
| **도구 수리** | 생활 | 전투 중이나 휴식 시 장비의 내구도를 간단하게 응급 처치하여 유지한다. | '수리한다'는 명확한 생산 활동(Action)입니다. 패시브라면 '내구도 감소율 저하'가 적합합니다. |
| **약초학** | 생활 | 자연에서 채집한 풀과 열매로 해독제나 회복약을 즉석에서 제조한다. | 약초를 찾아내는 것은 패시브일 수 있으나, 약을 '제조'하는 것은 크래프팅 액티브입니다. |

## 2. 설명 수정 제안 (지속성 강화)
행동보다는 '지식'이나 '상태'임을 강조하여 지속성 여부를 명확히 합니다.

| 이름 | 현재 설명 | 수정 제안 |
| :--- | :--- | :--- |
| **신분 세탁** | 수배령이 내려져도 가짜 신분으로 검문을 통과하는 어빌리티. | → (유지/보류) 위조 신분을 '만드는' 것이면 액티브, 검문 시 자동으로 통과되는 운/현혹이면 패시브이나 전자일 가능성이 높음. (재분류 고려 대상) |
| **어둠의 경로** | 일반인은 모르는 비밀 통로(개구멍, 지하 통로)를 꿰뚫음. | → **상시적으로** 주변의 비밀 통로를 감지하고 파악한다. (탐지 패시브화) |
