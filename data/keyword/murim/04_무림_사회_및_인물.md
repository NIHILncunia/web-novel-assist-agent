# 무협 용어 - 04. 무림 사회 및 인물

| 분류 | 키워드 | 설명 | 예문 |
|:---:|:---:|---|---|
| 조직 | **개방 (丐幇)** | 거지들의 집단이자 정보 단체. 구파일방의 일방(一幇)에 해당한다. | "개방의 정보망은 천하 제일이다." |
| 조직 | **하오문 (下汚門)** | 점소이, 기녀, 소매치기 등 뒷골목 하층민들의 정보 조직. 흑도에 속한다. | "하오문의 정보력은 개방 못지않다." |
| 조직 | **소림사 (少林寺)** | 불교의 본산이자 천하무공의 발원지. 권법과 봉술이 유명하다. (구파) | "소림의 백팔나한진을 뚫을 자는 없다." |
| 조직 | **무당파 (武當派)** | 도교의 본산. 태극권과 검법으로 유명하며, 부드러움으로 강함을 제압한다. (구파) | "무당의 태극검은 물 흐르듯 유려하다." |
| 조직 | **화산파 (華山派)** | 매화검법으로 대표되는 검술 명문. 빠르고 변화무쌍한 검을 구사한다. (구파) | "화산의 매화가 만개하니 검기가 흩날린다." |
| 조직 | **종남파 (終南派)** | 천하제일검가를 다투는 문파. 묵직하고 심오한 검법을 자랑한다. (구파) | "종남의 유검은 화산의 매화검과 쌍벽을 이룬다." |
| 조직 | **아미파 (峨嵋派)** | 여승들로 이루어진 문파. 검법과 불교 무공을 조화롭게 사용한다. (구파) | "아미파 장문인이 의천검을 뽑아 들었다." |
| 조직 | **청성파 (靑城派)** | 도교 문파. 빠르고 날카로운 검법인 청사검법이 유명하다. (구파) | "청성의 검은 뱀처럼 파고든다." |
| 조직 | **점창파 (點蒼派)** | 사일검법 등 찌르기 위주의 날카로운 검법을 구사하는 문파. (구파) | "점창의 쾌검은 눈으로 쫓을 수 없다." |
| 조직 | **공동파 (崆峒派)** | 권법과 복마검법 등 다양한 무공을 보유한 문파. (구파) | "공동의 칠상권은 내장을 파괴하는 위력이 있다." |
| 조직 | **곤륜파 (崑崙派)** | 서역과 중원의 경계에 위치한 도교 문파. 운룡대팔식 등 경공과 검법이 유명하다. (구파) | "곤륜의 검은 신선이 춤추는 듯하다." |
| 조직 | **남궁세가 (南宮世家)** | 창궁무애검법으로 대표되는 검술 명가. 제왕검이라 불리며 높은 위상을 가진다. (오대세가) | "남궁의 검에는 왕도의 기상이 서려 있다." |
| 조직 | **모용세가 (慕容世家)** | 연환검법과 가전 무공으로 유명한 명문가. 귀족적인 기풍을 지녔다. (오대세가) | "모용의 검은 우아하면서도 치명적이다." |
| 조직 | **사천당가 (四川唐家)** | 암기와 독을 다루는 가문. 당문이라고도 불리며, 독보적인 기술을 보유했다. (오대세가) | "당가의 암기는 그림자 속에서 날아든다." |
| 조직 | **제갈세가 (諸葛世家)** | 지략과 진법에 능한 가문. 무림의 머리 역할을 하며, 선기(부채)를 주로 쓴다. (오대세가) | "제갈세가의 진법에 걸리면 빠져나갈 수 없다." |
| 조직 | **하북팽가 (河北彭家)** | 오호단문도 등 도법으로 유명한 가문. 호방하고 패도적인 기풍을 가졌다. (오대세가) | "팽가의 도는 산도 쪼갤 만큼 강력하다." |
| 조직 | **북해빙궁 (北海氷宮)** | 북쪽의 극한지에 위치한 세력. 냉기를 다루는 빙공을 사용한다. (새외오궁) | "빙궁의 한기에 주위가 얼어붙었다." |
| 조직 | **남만야수궁 (南蠻野獸宮)** | 남쪽 밀림에 위치한 세력. 맹수를 부리거나 야성적인 무공을 사용한다. (새외오궁) | "야수궁주가 거대한 호랑이를 타고 나타났다." |
| 조직 | **포달랍궁 (布達拉宮)** | 서장(티베트)에 위치한 라마교의 본산. 강력한 밀교 무공을 사용한다. (새외오궁) | "포달랍궁의 승려들이 금강저를 휘둘렀다." |
| 조직 | **마라혈궁 (魔羅血宮)** | 서역 혹은 서북에 위치한 마도의 세력. 피를 매개로 한 사악한 무공을 쓴다. (새외오궁) | "혈궁의 사자들이 산채를 피바다로 만들었다." |
| 조직 | **남해태양궁 (南海太陽宮)** | 남쪽 바다 혹은 섬에 위치한 세력. 뜨거운 양기의 무공을 사용한다. (새외오궁) | "태양궁의 무공은 불과 같이 뜨겁다." |
