# 무협 용어 - 01. 세계관 및 개념

| 분류 | 키워드 | 설명 | 예문 |
|:---:|:---:|---|---|
| 개념/세계관 | **협 (俠)** | 힘없는 이를 돕고 불의에 맞서는 기개와 희생정신. 무협의 핵심 사상. | "협을 잃은 힘은 폭력일 뿐이다." |
| 개념/세계관 | **협객행 (俠客行)** | 협의를 실천하기 위해 강호를 유람하며 불의를 심판하는 행동. | "그는 십 년간의 협객행을 마치고 고향으로 돌아왔다." |
| 개념/세계관 | **의 (義)** | 사람으로서 마땅히 지켜야 할 도리. 신의, 의리 등을 포함한다. | "목에 칼이 들어와도 의를 저버릴 순 없다." |
| 개념/세계관 | **강호 (江湖)** | 강과 호수라는 뜻으로, 무인들이 활동하는 세상 그 자체를 비유적으로 이르는 말. | "강호의 도가 땅에 떨어졌구나." |
| 개념/세계관 | **중원 (中原)** | 무협의 주 무대가 되는 중국 대륙(황하 중류 남부)을 이르는 말. | "중원 무림의 역사는 피로 쓰여졌다." |
| 개념/세계관 | **새외 (塞外)** | 중원의 바깥 지역. 만리장성 이북이나 서역 등 중원 무림의 영향력이 닿지 않는 곳. | "새외의 고수들이 중원을 넘보고 있다." |
| 개념/세계관 | **무림 (武林)** | 무인들의 사회. 강호와 거의 동일한 의미로 쓰이나, 좀 더 조직적인 사회를 뜻하기도 한다. | "무림맹주를 선출하기 위한 비무대회가 열렸다." |
| 개념/세계관 | **정파 (正派)** | 올바른 도리를 따르는 문파들의 총칭. 협의와 도덕을 중시한다. | "정파의 명숙들이 한자리에 모여 마교의 침공을 논의했다." |
| 개념/세계관 | **백도 (白道)** | 정파 무림을 일컫는 별칭. 밝고 올바른 길이라는 의미. | "백도의 무인들이 힘을 합쳐 마교를 막아냈다." |
| 개념/세계관 | **사파 (邪派)** | 정통적인 도리에서 벗어나 변칙적이거나 잔혹한 무공을 익히는 문파들의 총칭. 실리와 힘을 중시한다. | "사파의 무인들은 승리를 위해서라면 수단과 방법을 가리지 않는다." |
| 개념/세계관 | **흑도 (黑道)** | 사파 무림을 일컫는 별칭. 어둠의 길, 뒷골목 세계를 의미하기도 한다. | "흑도채의 산적들이 상단을 습격했다." |
| 개념/세계관 | **녹림 (綠林)** | 산적이나 도적 떼를 일컫는 말. 주로 험한 산세에 자리 잡는다. | "녹림 십팔채가 연합하여 관군에 대항했다." |
| 개념/세계관 | **마도 (魔道)** | 마교나 마공을 익힌 이들이 걷는 길. 일반적인 윤리를 벗어난 잔혹하고 파괴적인 성향. | "마도에 빠진 자는 되돌아올 수 없다." |
| 개념/세계관 | **천하 (天下)** | 하늘 아래의 온 세상. 무림을 넘어선 더 넓은 세상, 혹은 패권의 대상을 의미한다. | "천하를 제패할 영웅이 나타났다." |
| 개념/사건 | **기연 (奇緣)** | 우연한 계기로 절세 무공이나 영약을 얻는 등, 주인공의 성장을 돕는 운명적인 만남 또는 사건. | "동굴 속에서 백 년 묵은 고수를 만난 것은 그에게 일생일대의 기연이었다." |
| 행위 | **멸문 (滅門)** | 문파 전체를 몰살시켜 없애버림. | "그 사건으로 인해 한 가문이 멸문을 당했다." |
| 체질 | **극양지체 (極陽之體)** | 세상의 모든 양기를 받아들일 수 있는 특이 체질. 화공(火功) 계열 무공에 천재적 재능을 보인다. | "그는 백 년에 한 번 나올까 말까 한 극양지체라, 양강(陽剛)한 무공을 익히는 속도가 남달랐다." |
| 체질 | **극음지체 (極陰之體)** | 세상의 모든 음기를 받아들일 수 있는 특이 체질. 빙공(氷功) 계열 무공에 천재적 재능을 보인다. | "그녀의 극음지체는 모든 냉기를 지배하여, 혹한 속에서도 추위를 느끼지 못했다." |
| 체질 | **구음절맥 (九陰絕脈)** | 온몸의 아홉 음맥이 막혀 20세를 넘기기 힘든 저주받은 체질. 그러나 반대로 음공을 익히기엔 최적의 조건이 되기도 한다. | "의원은 아이가 구음절맥을 타고나 오래 살지 못할 것이라 진단했다." |
| 체질 | **독인 (毒人)** | 온몸이 독으로 절여져 피와 살 자체가 맹독인 인간. 닿기만 해도 중독된다. | "독인이 지나간 자리는 풀 한 포기 자라지 않았다." |
| 체질 | **만독불침 (萬毒不侵)** | 세상의 어떤 독에도 중독되지 않는 신이한 육체. 영약을 과다 복용하거나 특수한 수련을 통해 얻는다. | "그는 만독불침의 몸이라 당문의 독도 통하지 않는다." |
| 상태이상 | **주화입마 (走火入魔)** | 내공을 잘못 운용하여 기가 폭주하고 심신이 망가지는 위험한 상태. | "무리한 운기조식은 역으로 주화입마에 빠질 위험이 있다." |
| 상태이상 | **심마 (心魔)** | 수련 과정에서 생기는 내면의 번뇌나 트라우마가 형상화된 것. 정신을 좀먹고 심하면 무공을 잃거나 미치게 된다. | "그는 스승의 죽음이라는 심마에서 벗어나지 못하고 폐인이 되었다." |
| 상태 | **내상 (內傷)** | 내공의 충돌이나 타격으로 장기나 기혈이 손상된 상태. | "심각한 내상을 입어 피를 토했다." |
| 상태 | **외상 (外傷)** | 칼에 베이거나 타박상 등 신체 외부의 부상. | "자잘한 외상은 금방 회복될 것이다." |
| 상태 | **공능 (功能)** | 무공이나 약효가 발휘하는 특수한 어빌리티가나 효력. | "이 영약의 공능은 실로 놀라웠다." |
| 신체 | **단전 (丹田)** | 기가 모이는 신체의 중심. 보통 배꼽 아래의 하단전을 의미한다. | "단전에 기를 모아라." |
| 신체 | **상단전 (上丹田)** | 양미간 안쪽에 위치한 단전. 정신력, 신(神)과 관련된다. (인당혈) | "상단전이 개발되면 제6감이 예민해진다." |
| 신체 | **중단전 (중丹田)** | 가슴 정중앙에 위치한 단전. 마음, 기(氣)와 관련된다. (전중혈) | "분노로 인해 중단전이 꽉 막힌 듯 답답했다." |
| 신체 | **하단전 (下丹田)** | 배꼽 아래 세 치(약 9cm) 지점에 위치한 단전. 정(精)과 내공의 저장소. (기해혈/관원혈) | "하단전의 내공을 끌어올렸다." |
| 신체 | **경락 (經絡)** | 기혈이 흐르는 통로. 경맥과 낙맥을 합친 말. | "전신의 경락이 뚫리며 기운이 용솟음쳤다." |
| 신체 | **기경팔맥 (奇經八脈)** | 12정경 외에 기가 흐르는 8개의 특수한 맥. 독맥, 임맥, 충맥, 대맥, 양교맥, 음교맥, 양유맥, 음유맥. | "기경팔맥을 타통하여 절정의 고수가 되었다." |
| 신체 | **임독양맥 (任督二脈)** | 기경팔맥 중 몸의 앞면(임맥)과 뒷면(독맥)을 흐르는 가장 중요한 두 맥. | "임독양맥이 타통되자 천지의 기운이 몸으로 쏟아져 들어왔다." |
| 아이템 | **신병이기 (神兵利器)** | 전설적인 장인에 의해 만들어지거나 특별한 기연으로 얻게 되는 영험한 무기. | "그가 손에 쥔 것은 전설로만 전해지던 신병이기, 의천검이었다." |
| 아이템 | **영약 (靈藥)** | 내공을 크게 증진시키거나 만병을 통치하는 신비한 약초나 단약. | "절벽에서 떨어진 그는 우연히 천년설삼을 발견하는 기연을 얻었다." |
| 에너지 | **내공 (內功)** | 체내에 축적된 기의 총량이나 힘. 무공 사용의 원동력이 된다. | "60년 갑자 내공을 주입했다." |
| 에너지 | **외공 (外功)** | 육체 자체를 단련하여 힘을 얻는 수련법. 근육과 뼈를 강철처럼 만든다. | "그는 외공을 극성으로 익혀 칼이 들어가지 않는다." |
| 에너지 | **무공 (武功)** | 무술을 통해 발휘하는 모든 기술과 어빌리티의 총칭. 내공과 외공을 포함한다. | "전설적인 무공 비급을 얻었다." |
| 에너지 | **진기 (眞氣)** | 내공이 정제되어 실질적인 힘을 발휘하는 기운. 보편적인 에너지원. | "진기를 끌어올려 검에 불어넣었다." |
| 에너지 | **선천진기 (先天眞氣)** | 태어날 때부터 가지고 있는 순수한 기운. 진기와 같은 의미로 사용된다. | "선천진기가 손상되면 수명에 지장이 간다." |
| 에너지 | **진원진기 (眞元眞氣)** | 생명의 근원이 되는 기운. 진기와 같은 의미로 사용된다. | "진원진기를 소모하여 금지된 술법을 펼쳤다." |
| 개념/세계관 | **우화등선 (羽化登仙)** | 인간의 경지를 벗어나 신선이 되어 하늘로 오른다는 의미. 무협 세계관의 최종 목표 중 하나로 꼽힌다. | "모든 속세를 초월한 그는 마침내 우화등선하여 신선이 되었다." |
| 개념/무공 | **심검 (心劍)** | 검이 없어도 마음만으로 검기를 발현하거나 베는 경지. | "손에 검은 없었으나 심검이 공간을 베었다." |
| 개념/무공 | **무형검 (無形劍)** | 형체가 없는 검기. 보이지 않아 막기 힘들다. | "보이지 않는 무형검에 옷자락이 잘려 나갔다." |
| 수련 | **주천 (周天)** | 기를 경락을 따라 한 바퀴 돌리는 것. | "운기조식하여 기를 서른여섯 번 주천시켰다." |
| 수련 | **소주천 (小周天)** | 기를 임맥과 독맥을 따라 순환시키는 수련법. | "소주천을 완성하여 내공의 기초를 다졌다." |
| 수련 | **대주천 (大주天)** | 기를 전신의 12정경과 기경팔맥을 모두 돌게 하는 수련법. | "대주천을 행하자 막혔던 혈도가 뚫렸다." |
| 수련 | **폐관수련 (閉關修練)** | 외부와의 출입을 끊고 밀실에 갇려 수련에만 전념하는 것. | "그는 생사관을 건 폐관수련에 들어갔다." |
| 수련 | **면벽수련 (面壁修練)** | 벽을 마주하고 앉아 잡념을 없애고 참선하는 수련. | "9년의 면벽수련 끝에 깨달음을 얻었다." |
| 수련 | **환골탈태 (換骨奪胎)** | 뼈를 바꾸고 태를 벗는다는 뜻. 신체가 근본적으로 개벽하여 초인적인 자질을 갖게 됨. | "환골탈태하여 피부가 옥처럼 희어지고 눈빛이 맑아졌다." |
| 수련 | **반로환동 (返老還童)** | 늙은 몸이 다시 아이처럼 젊어짐. 무공이 극상의 경지에 올랐을 때 나타나는 현상. | "백발의 노인이 반로환동하여 청년의 모습을 되찾았다." |
| 개념/무공 | **등봉조극 (登峰造極)** | 무예의 경지가 최정상에 이름. 한 분야의 끝을 보았다는 의미. | "그의 창술은 이미 등봉조극의 경지에 이르러, 천하에 적수가 없었다." |
| 개념/무공 | **검강 (劍罡)** | 검기가 극도로 응축되어 형체를 갖춘 단단한 기운. 검을 떠나서도 위력을 발휘한다. | "마침내 그의 검 끝에서 푸른 검강이 십 장이나 뻗어 나갔다." |
| 개념/무공 | **이기어검 (以氣御劍)** | 내공만으로 검을 허공에서 자유자재로 부리는 경지. 검술의 최상위 경지 중 하나. | "노인은 손가락을 까딱하는 것만으로 이기어검을 시전하여 날아가는 파리를 세 조각냈다." |
| 묘리 | **강(强)** | 힘이 크게 실리는 원리. 무공에 강력한 파괴력을 부여한다. | |
| 묘리 | **강(剛)** | 강함(剛猛)과 단단함(堅固)을 나타내는 묘리. 정면 대결에서 밀리지 않는 강력한 힘과 방어력을 바탕으로 상대를 제압한다. (외공, 금강불괴 등) | |
| 묘리 | **쾌(快)** | 빠른 속도를 활용하는 원리. 신속한 움직임과 공격으로 상대를 제압한다. | |
| 묘리 | **환(幻)** | 환상이나 허초(페인트)를 사용하는 원리. 상대를 현혹하여 빈틈을 만든다. | |
| 묘리 | **중(重)** | 무게중심을 이용하여 힘을 운용하는 원리. 상대에게 압도적인 중압감을 주거나 방어에 활용된다. | |
| 묘리 | **유(柔)** | 부드러움(柔軟)으로 강함을 제압하는 묘리. 상대의 힘을 흘려보내거나 역이용하고, 유연한 움직임으로 공격을 피하며 빈틈을 노린다. (태극권 등) | |
| 묘리 | **변(變)** | 변화를 주는 원리. 예측 불가능한 움직임과 공격으로 상대를 혼란시킨다. | |
