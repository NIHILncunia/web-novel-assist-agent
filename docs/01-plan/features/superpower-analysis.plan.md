# Plan: 초능력 데이터 분석 및 어빌리티 체계 확장 (superpower-analysis)

## 1. 배경 및 목적
- **배경**: `data/word_list/character/초능력.md`는 수백 가지의 이능력을 키워드화하여 보유하고 있으나, 현재의 [권역-계통-형태] 어빌리티 시스템에 완전히 통합되지 않은 상태임.
- **목적**: `초능력.md`의 모든 항목을 현재 시스템과 대조하여, 기존 체계에 수용 가능한 항목을 분류하고, 기존 체계로 설명 불가능한 영역을 식별하여 **어빌리티 권역/계통을 확장**함.

## 2. 주요 과업 (Key Tasks)

### 2.1. 초능력 키워드 전수 조사 및 대조
- **대상**: `data/word_list/character/초능력.md` (약 200개 이상의 키워드)
- **내용**: 
    - 각 키워드를 `manuals/99-1_ability_syntax.md`의 기존 권역(마법, 물리, 정신, 특수 등)과 매핑.
    - 매핑되지 않는 '미분류' 항목들을 추출하여 공통된 특성 파악.

### 2.2. 어빌리티 권역/계통 확장안 도출
- **신규 권역 후보**: 인과(Causality), 매체(Media), 법칙(Rule) 등 초능력 특유의 개념적 능력군 정의.
- **신규 계통/형태 후보**: '합성', '분해', '신체 대체' 등 초능력 문서에서 반복적으로 나타나는 작동 방식을 표준화.

### 2.3. 데이터 이행 및 문법화
- 분석 완료된 초능력 키워드들을 `data/ability/detailed_lists/` 하위의 정규 파일로 변환하여 저장.
- `manuals/99-1_ability_syntax.md` 가이드 업데이트.

## 3. 성공 기준 (Success Criteria)
- `초능력.md` 내 모든 키워드에 대한 [권역-계통-형태] 정의 완료.
- 새로운 권역 정의를 통해 어빌리티 시스템의 수용 능력이 1.5배 이상 확장됨.
- 에이전트가 '초능력' 스타일의 능력을 생성할 때 표준 문법을 100% 활용 가능함.

## 4. 일정 및 우선순위
1. **우선순위 High**: 미분류 초능력 추출 및 신규 권역 정의.
2. **우선순위 Medium**: 기존 권역 내 초능력 데이터 병합.
3. **우선순위 Low**: 가이드 문서 업데이트 및 샘플 데이터 생성.
