## 1. 목적

이 문서는 세계관 장르와 표현 방식에 상관없이, 세상에 존재할 수 있는 거의 모든 **능력 / 기술 / 스킬 / 권능 / 이능 / 주문 / 기예**를 하나의 공통 규격으로 기술하기 위한 어빌리티 문법의 개편 초안이다.

목표는 다음과 같다.

1. 마법, 무공, 초능력, 성법, 저주, 기계 기술, 패시브, 필살기까지 하나의 문법으로 설명할 수 있어야 한다.
2. 문법은 창작 자유도를 해치지 않되, 데이터 분류와 검색에는 충분히 엄격해야 한다.
3. 표현용 이름과 내부 분류용 구조를 분리하여, 독자 친화성과 데이터 정합성을 동시에 확보해야 한다.

## 2. 현재 문법의 강점

현행 `99-1`의 핵심 구조인 아래 문법은 유지 가치가 높다.

`[권역:원천] - [계통] - [형태]`

강점:

1. 짧고 기억하기 쉽다.
2. 창작 단계에서 아이디어 조합이 빠르다.
3. 파일 분류 규칙과 연결하기 쉽다.
4. "무엇을, 어떻게, 어떤 모양으로"라는 감각을 준다.

---

## 3. 현재 문법의 한계

### 3-1. `권역`이 본질 분류와 표현 분류를 동시에 맡고 있다

현재의 `마법/물리/정신/특수...`는 어떤 경우에는 힘의 본질처럼 보이고, 어떤 경우에는 작품 내 표현 방식처럼 보인다.

예:

- 순간이동은 마법일 수도 있고 초능력일 수도 있고 기술일 수도 있다.
- 예지는 정신 능력일 수도 있고 신탁일 수도 있고 데이터 예측일 수도 있다.

즉, `권역` 하나에 너무 많은 의미가 몰려 있다.

### 3-2. `형태`가 일관된 축이 아니다

일부 형태는 시각적 발현이다.

- 구체
- 광선
- 장벽
- 오라

일부 형태는 작동 메커니즘에 가깝다.

- 가호
- 대여
- 회복
- 정화

일부는 효과 목적에 가깝다.

- 설득
- 위압
- 확정

즉, 현재 `형태`는 서로 다른 종류의 분류가 섞여 있다.

### 3-3. `원천`은 중요하지만 문법상 제약이 거의 없다

`원천`은 창작 자유도의 핵심이지만, 완전 자유 입력이면 데이터가 쉽게 흩어진다.

따라서 세부 원천은 자유롭게 두더라도, 상위 카테고리는 규격화할 필요가 있다.

## 4. v2 설계 원칙

### 원칙 1. 본질 축과 표현 축을 분리한다

- 본질 축: 이 능력이 세상의 어느 층위를 건드리는가
- 표현 축: 이 능력이 작품 안에서 어떤 문화/방식으로 보이는가

### 원칙 2. `형태`는 진짜 발현 형태만 담당한다

`형태`는 가능한 한 "눈에 보이거나 운용 가능한 발현 모양"만 맡는다.

### 원칙 3. `효과`는 별도 축으로 분리한다

능력이 어떤 모습으로 나오느냐와, 실제로 무엇을 일으키느냐는 다른 문제다.

### 원칙 4. 패시브와 액티브를 다른 종으로 보지 않는다

둘은 별개의 문법이 아니라, 동일한 문법 위에서 `발동 방식`이 다른 것으로 처리한다.

## 5. 제안하는 보편 문법 구조

### 5-1. 내부 정규 문법

권장 내부 구조:

`[층위/표현권역:세부원천] - [계통] - [형태] -> [효과]`

예:

- `[물질/마도:화염] - [방출] - [투사체] -> [폭발/화상]`
- `[정신/초상:공포] - [간섭] - [시선] -> [위압/행동제한]`
- `[개념/신성:운명] - [강제] - [표식] -> [확정/박탈]`

### 5-2. 사용자 표시용 축약 문법

표시용 문법은 더 단순하게 유지한다.

`[표현권역:원천] - [계통] - [형태]`

즉, 기존 표기를 완전히 버리지 않고 **표시용 포맷으로 강등**한다.

## 6. 새로 도입할 핵심 축

### 6-1. 층위 (Layer)

능력이 개입하는 세계의 층위.

1. **물질층**
   - 원소, 에너지, 무기, 구조물, 물리 현상
2. **생명층**
   - 세포, 조직, 유전자, 재생, 감염, 진화
3. **정신층**
   - 기억, 감정, 인식, 환각, 의지, 자아
4. **정보층**
   - 데이터, 언어, 상징, 기록, 코드, 전파
5. **관계층**
   - 계약, 명령, 종속, 인연, 소속, 군세
6. **개념층**
   - 시간, 공간, 확률, 진실, 정의, 운명
7. **초월층**
   - 신성, 저주, 권능, 영혼, 카르마, 존재 격
8. **혼성층**
   - 둘 이상의 층위를 동시에 묶어 작동하는 복합 능력
9. **메타층**
   - 시스템, 규칙 외부 개입, 서사 보정, 존재 판정 자체의 수정

의미:

- `권역`보다 더 근본적인 분류
- 능력의 본질을 규정하는 1차 축

### 6-2. 표현 권역 (Expression Domain)

작품 내에서 능력이 어떤 방식으로 인식되는가.

1. 마도형
2. 육체형
3. 기예형
4. 정신형
5. 초상형
6. 기술형
7. 신성형
8. 혼성형
9. 주술형
10. 계약형
11. 상징형
12. 이계형
13. 생체형
14. 병장형
15. 의례형

의미:

- "이게 마법처럼 보이는가, 초능력처럼 보이는가, 기술처럼 보이는가"를 담당
- 본질 분류가 아니라 서사적 표현 분류

### 6-3. 원천 대분류 (Source Class)

세부 원천의 상위 카테고리.

1. **원소형**
   - 화염, 냉기, 번개, 대지, 바람, 물
2. **물질형**
   - 피, 뼈, 금속, 안개, 소리, 그림자, 유리
3. **생체형**
   - 근육, 신경, 세포, 호흡, 장기, 분비물
4. **정신형**
   - 기억, 공포, 분노, 욕망, 자아, 꿈
5. **정보형**
   - 언어, 문서, 전파, 코드, 데이터, 상징
6. **관계형**
   - 계약, 혈통, 군세, 명령, 신앙, 인연
7. **개념형**
   - 시간, 공간, 확률, 진실, 질서, 혼돈
8. **초월형**
   - 신성, 저주, 영혼, 업보, 권능, 존재 격
9. **기술형**
   - 전력, 연산, 회로, 엔진, 나노머신, 센서
10. **상징형**
   - 이름, 문양, 언어, 서명, 계보, 서사적 역할
11. **환경형**
   - 날씨, 지맥, 지형, 밤, 바다, 도시, 전장
12. **사회형**
   - 권위, 법, 군세, 신분, 조직, 집단 감정

의미:

- `원천`을 자유 입력으로 두되, 완전 무제한 문자열이 되지 않게 함

## 10. 설계 철학상 중요한 판단

### 판단 1. "마법"은 본질이 아니라 표현일 가능성이 높다

따라서 `마법권역`은 최상위 존재론 분류보다는 표현 분류로 재배치하는 편이 좋다.

### 판단 2. "형태"는 좁게, "효과"는 넓게

형태에 의미를 많이 넣으면 분류가 흔들린다.  
효과는 넓어도 된다.

### 판단 3. 원천은 자유롭되, 대분류 아래에서만 자유롭게

이렇게 해야 데이터 오염 없이 창작 자유도를 보존할 수 있다.

## 11. v2 예시 브레인스토밍

### 예시 A. 고전 파이어볼

- 층위: 물질층
- 표현 권역: 마도형
- 원천 대분류: 원소형
- 세부 원천: 화염
- 계통: 방출
- 형태: 투사체

## 15. 축별 귀속 원칙

이 섹션은 확장된 선택지들 사이의 경계가 흐려지는 문제를 막기 위한 규칙이다.

핵심 원칙은 다음 한 줄로 요약된다.

- **계통은 동사**
- **형태는 외형 또는 발현 매체**
- **효과는 결과**

즉, 하나의 항목이 여러 축에 걸쳐 보일 때는 아래 기준으로 귀속한다.

### 15-1. 계통 귀속 원칙

계통은 능력이 **무슨 방식으로 작동하는가**를 설명한다.

다음 질문에 답한다.

- 이 능력은 대상을 밀어내는가, 흡수하는가, 조작하는가, 고정하는가?
- 이 능력은 환경을 바꾸는가, 내부 상태를 바꾸는가, 외부로 투사하는가?

계통으로 귀속되는 항목의 특징:

1. 문장을 만들면 자연스럽게 동사처럼 읽힌다.
2. 동일한 계통 안에서 서로 다른 형태가 파생될 수 있다.
3. 결과가 무엇이든 작동 원리는 비교적 유지된다.

예:

- 방출
- 간섭
- 제어
- 강제
- 봉인
- 흡수
- 전이
- 복제
- 재구성
- 정화

### 15-2. 형태 귀속 원칙

형태는 능력이 **어떤 모양으로 발현되는가**, 혹은 **어떤 매체를 통해 행사되는가**를 설명한다.

다음 질문에 답한다.

- 독자가 이 능력을 볼 때 무엇처럼 보이는가?
- 사용자는 이 능력을 어떤 인터페이스로 다루는가?

형태로 귀속되는 항목의 특징:

1. 시각화가 가능하다.
2. 발동 방식과는 별개로 "나타나는 양상"을 설명한다.
3. 같은 계통이라도 형태가 다르면 전투 감각이 달라진다.

예:

- 투사체
- 광선
- 파동
- 장벽
- 영역
- 표식
- 사슬
- 오라
- 분신
- 장치
- 노래
- 진형
- 시선
- 의식

### 15-3. 효과 귀속 원칙

효과는 능력 사용 후 **실제로 무엇이 바뀌는가**를 설명한다.

다음 질문에 답한다.

- 그래서 대상은 어떤 상태가 되는가?
- 전장, 신체, 정신, 관계, 규칙이 어떻게 변하는가?

효과로 귀속되는 항목의 특징:

1. 결과를 묘사한다.
2. 같은 계통과 형태라도 효과 조합에 따라 완전히 다른 능력이 될 수 있다.
3. 종종 상태이상, 피해, 부여, 박탈과 연결된다.

예:

- 피해
- 회복
- 강화
- 약화
- 구속
- 탐지
- 차단
- 무효화
- 봉인
- 관통
- 절단
- 감염
- 지배
- 설득
- 안정화

## 17. 애매할 때의 판정 순서

새 항목이 들어왔을 때 아래 순서로 판정한다.

1. 이것이 **무슨 방식으로 작동하는가**를 먼저 본다.
   - 답이 명확하면 계통
2. 그것이 **어떤 모습이나 매체로 나타나는가**를 본다.
   - 답이 명확하면 형태
3. 사용 후 **무엇이 변하는가**를 본다.
   - 답이 명확하면 효과

부가 원칙:

- 하나의 개념이 세 축 모두에 등장하면 안 된다.
- 우선 귀속된 축 외의 의미는 태그 또는 설명으로 내린다.
- 이름이 같아도 문법상 역할이 다르면 다른 어휘로 재명명한다.

예:

- `반사`가 계통이면 효과는 `피해 반환`, `되튕김` 등으로 푼다.
- `낙인`이 형태면 효과는 `추적`, `약화`, `폭주 유발` 등으로 푼다.
- `진형`이 형태면 계통은 `지휘`, 효과는 `강화`, `차단`, `기동 향상` 등으로 푼다.

## 20. 표준 어휘 정제 원칙

이 섹션은 `계통`, `형태`, `효과` 어휘 목록을 실제 규격으로 다듬기 위한 기준이다.

### 20-1. 정제 기준

표준 어휘는 아래 조건을 우선 충족해야 한다.

1. **서로 겹치지 않아야 한다**
   - 같은 층위의 다른 단어와 의미가 크게 중복되면 안 된다.
2. **동일 축 내에서 문법 품사가 일관되어야 한다**
   - 계통은 동사적 명사
   - 형태는 외형/매체 명사
   - 효과는 결과 상태 명사
3. **장르를 초월해 재사용 가능해야 한다**
   - 특정 작품 감성에만 유효한 용어는 표준어휘로 올리지 않는다.
4. **세부 표현은 설명이나 태그로 내릴 수 있어야 한다**
   - 표준어휘는 넓고, 세부 연출은 하위 설명에서 담당한다.

### 20-2. 표준 어휘 등급

어휘는 3단계로 관리한다.

1. **핵심 표준어**
   - 기본 문법에서 직접 사용 가능
2. **확장 표준어**
   - 특정 축이나 장르에서 자주 필요할 때 사용 가능
3. **비권장 별칭**
   - 검색용 또는 과거 호환용으로만 남기고, 새 문법에는 직접 쓰지 않음

## 21. 계통 표준 어휘안

### 21-1. 핵심 표준어

아래는 보편 능력 문법의 핵심 계통 후보군이다.

| 계통 | 정의 |
| :--- | :--- |
| 방출 | 힘이나 대상을 외부로 쏘아 보냄 |
| 구현 | 실체, 구조, 개체를 만들어 냄 |
| 강화 | 대상의 성능이나 상태를 끌어올림 |
| 제어 | 환경, 사물, 흐름, 힘을 조작함 |
| 간섭 | 내부 상태나 정보에 개입함 |
| 감지 | 정보나 존재를 읽어냄 |
| 이동 | 위치, 거리, 좌표를 바꿈 |
| 전이 | 상태, 속성, 힘을 옮김 |
| 소환 | 외부의 존재나 자원을 불러옴 |
| 흡수 | 외부의 힘이나 자원을 거둬들임 |
| 봉인 | 대상을 가두거나 기능을 묶음 |
| 변환 | 성질, 속성, 구조를 바꿈 |
| 복제 | 구조나 기능을 베껴 재현함 |
| 강제 | 규칙, 행동, 판정을 억지로 고정함 |
| 조성 | 공간, 환경, 체계를 구성함 |
| 회복 | 손상되거나 잃은 것을 복원함 |
| 박탈 | 기능, 자격, 상태를 제거함 |

아래는 필요성이 높지만 핵심 표준어와의 관계를 주석으로 관리해야 하는 확장군이다.

## 24. 실무 적용용 축소안

실제 문법 문서에 처음부터 모든 확장 표준어를 다 넣을 필요는 없다.

권장 단계:

1. **핵심 표준어**만 본문에 싣는다.
2. **확장 표준어**는 부록으로 분리한다.
3. **비권장 별칭**은 호환표로 관리한다.

이렇게 하면 문법 본문은 간결하게 유지하면서도 확장성은 잃지 않는다.
