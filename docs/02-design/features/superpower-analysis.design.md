# Design: 초능력 데이터 분석 및 어빌리티 체계 확장 (superpower-analysis)

## 1. 초능력 데이터 정밀 분석 결과

`data/word_list/character/초능력.md`의 키워드들을 분석한 결과, 기존 어빌리티 시스템(`manuals/99-1_ability_syntax.md`)과 비교했을 때 다음과 같은 특징적 패턴과 공백이 발견됨.

### 1.1. 5대 기본 작동 패턴 (The 5 Core Operations)
초능력 문서 전반에서 거의 모든 원천(Source)에 대해 공통적으로 나타나는 5가지 작동 방식임. 이를 '계통(Lineage)'의 표준으로 정립할 필요가 있음.
1.  **조종 (Manipulation)**: 기존 환경에 존재하는 물질을 제어.
2.  **생성 (Creation)**: 무(無)에서 유(有)를 창조.
3.  **대체 (Substitution/Sync)**: 자신의 신체 일부 혹은 전부를 해당 물질로 변환.
4.  **합성 (Synthesis)**: 동일 혹은 이질적 원천을 결합하여 고차원적 힘을 생성.
5.  **분해 (Decomposition)**: 물질을 해체하거나 속성을 소멸시킴.

### 1.2. 기존 권역으로 설명하기 힘든 초능력군
| 초능력 유형 | 기존 분류상 한계 | 제안하는 신규 권역/계통 |
| :--- | :--- | :--- |
| 사망 회귀, 운명 조작 | '특수-인과계'에 포함되나 비중이 큼 | **인과 권역 (Causality)** 강화 |
| 언령, 물리법칙 무시 | '특수-규칙계'에 포함되나 작동 방식이 이질적 | **개념 권역 (Conceptual/Meta)** 신설 |
| 미디어 침투, 거울 세계 | 공간계와 정신계의 경계에 있음 | **매체 권역 (Media/Boundary)** 신설 |
| 소리/빛의 고체화 | 구현계와 상태 변화의 결합 | **변환계 (Transformation)** 확장 |

## 2. 어빌리티 권역 체계 확장 설계안

### 2.1. 권역(Domain) 구조 개편 제안
기존 6개 권역 체계를 유지하되, **[D. 특수 권역]**을 보다 명확한 상위 개념으로 분리하거나 확장함.

- **[G. 개념 권역 (Conceptual)] (신설)**: 세계의 법칙, 시스템, 메타 데이터를 조작하는 권역.
    - **인과계 (Causality)**: 시간, 확률, 운명, 회귀.
    - **법칙계 (Law/Rule)**: 영역 내 물리법칙 재정의, 언령, 금기 설정.
    - **경계계 (Boundary)**: 가상-현실, 거울-실재, 그림자-본체 간의 통로 조작.

### 2.2. 계통(Lineage) 및 형태(Form) 보완
- **마법/개념 권역 공통**: 상기 언급한 '5대 기본 작동 패턴'을 계통으로 명문화.
- **물리 권역**: '신체 분열', '타인과의 합체' 등 고차원적 육체 조작 형태 추가.

## 3. 구현 과업 및 이행 계획 (Action Items)

### 3.1. [DO-REFINE] 초능력 키워드 전수 매핑 리포트 작성
- `초능력.md`의 모든 항목(약 300개 추정)을 `[권역:원천]-[계통]-[형태]` 구조로 치환하는 엑셀/테이블 작업 수행.
- 이 과정에서 매핑되지 않는 항목들을 통해 신규 권역의 상세 형태(Form)를 도출함.

### 3.2. [DO-UPDATE] 어빌리티 표준 문법 가이드 갱신
- `manuals/99-1_ability_syntax.md`에 신규 권역 및 계통 정의 추가.
- '초능력' 스타일의 능력 생성을 위한 별도의 섹션 또는 태그(`[이능]`) 추가.

### 3.3. [DO-MIGRATE] 데이터베이스화
- 분석된 데이터를 `data/ability/detailed_lists/`에 권역별로 분산 저장.
- 기존 `초능력.md`는 분석 완료 후 아카이빙 처리.

## 4. 성공 기준 (Success Criteria)
- 초능력 데이터의 100%가 신규/기존 어빌리티 문법으로 설명 가능함.
- `manuals/99-1_ability_syntax.md` 개정판 배포 완료.
- 개편된 체계를 사용하여 '사망 회귀'와 '거울 세계 창조'를 표준 문법으로 정의할 수 있음.
