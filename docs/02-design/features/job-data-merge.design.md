# Design: 직업 데이터 통합 및 정규화 (job-data-merge)

## 1. 데이터 병합 설계 (Data Merging)

### 1.1. 소스 데이터 분석
- **현실 직업 (`data/word_list/common/직업.md`)**:
    - 포맷: `| 분류 | 키워드 | 설명 | 예문 |`
    - 액션: 키워드와 설명을 추출. 예문은 "설명 (예: '예문')" 형태로 통합하거나 삭제.
- **판타지 직업 (`data/word_list/fantasy/직업.md`)**:
    - 포맷: `| 분류 | 키워드 | 설명 | 예문 |`
    - 액션: 키워드와 설명을 추출.
- **기존 트레잇 (`data/traits/18_직업.md`)**:
    - 포맷: `| 키워드 | 분류 | 설명 |`
    - 액션: 기존 데이터를 기반으로 새로운 데이터를 병합.

### 1.2. 병합 로직 (Python Script)
- **스크립트 명**: `scripts/merge_job_data.py`
- **로직**:
    1.  `18_직업.md`에서 기존 직업 로드 (중복 제거 기준점).
    2.  판타지 직업 병합: '가상' 카테고리로 1차 분류 후, 키워드에 따라 '전투', '마법', '특수' 등으로 세분화.
    3.  현실 직업 병합: '현대' 카테고리로 분류.
    4.  결과 저장: `data/traits/18_직업.md`에 `Coding Rules` 포맷(`| :--- | :---: | :--- |`)으로 기록.

## 2. 카테고리 체계 설계 (Classification Schema)

통합될 `18_직업.md`의 '분류' 컬럼에 사용할 표준 카테고리:
- **전투**: 무력 및 직접 전투 (전사, 용기사 등)
- **마법**: 마법 및 신비 기술 (마법사, 연금술사 등)
- **특수**: 은밀 기술, 암살, 도적질 등 (암살자, 닌자 등)
- **지휘**: 통치, 전략, 군사 지휘 (국왕, 장군 등)
- **전문**: 현대 지식 및 전문 면허 (변호사, 프로그래머 등)
- **예술**: 창작, 공연, 미적 활동 (소설작가, 무희 등)
- **의료**: 치유 및 의학 연구 (의사, 간호사 등)
- **학술**: 학문 연구 및 교육 (학자, 교사 등)
- **생활**: 일상 서비스 및 생산 (상인, 농부, 대장장이 등)

## 3. 구현 과업 (Implementation Tasks)

1.  **[DO-SCRIPT]** `scripts/merge_job_data.py` 작성 및 실행.
2.  **[DO-CLEANUP]** `data/word_list/` 하위의 직업 관련 파일들을 `archive/` 폴더로 이동 또는 삭제.
3.  **[DO-VERIFY]** `uv run python scripts/check_traits.py`를 실행하여 최종 무결성 검증.

## 4. 성공 기준 (Success Criteria)
- `18_직업.md` 파일 내 키워드가 200개 이상으로 확장됨.
- 모든 행이 `| 키워드 | 분류 | 설명 |` 포맷을 정확히 지킴.
- 중복된 키워드가 존재하지 않음.
