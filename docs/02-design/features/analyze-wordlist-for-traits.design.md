# Design: word_list 데이터의 트레잇 승격 및 어빌리티 권역 체계 확장 설계

## 1. 개요
본 설계는 `data/word_list/`에 산재한 데이터를 정규 시스템(`traits`, `ability`)으로 편입시키고, 특히 `초능력.md` 분석을 통해 기존 어빌리티 권역(Domain) 체계를 보완/확장하는 것을 목표로 함.

## 2. 어빌리티 권역 체계 확장안 (Based on 초능력.md)

### 2.1. 기존 권역 내 수용 및 고도화
- **마법 권역 (Magic)**: 원소 조작계 초능력(불, 물, 바람 등)은 기존 '마법 권역'의 원천(Source)으로 통합하되, '영창' 유무에 따른 태그 분류 강화.
- **물리 권역 (Physical)**: 신체 변형, 강화, 재생 등은 '육체계(Physiology)' 하위의 형태(Form)로 세분화.
- **정신 권역 (Mental)**: 텔레파시, 기억 주입, 감정 조작 등은 기존 '간섭계(Influence)'에 완벽히 매칭됨.

### 2.2. 권역 확장 및 신설 제안 (Conceptual/Meta Domain)
`초능력.md`의 고차원적 능력들을 위해 기존 **특수 권역(Special)**을 세분화하거나 **개념 권역(Conceptual)** 신설을 검토함.

| 신설/확장 후보 | 정의 | 초능력 예시 |
| :--- | :--- | :--- |
| **인과 권역 (Causality)** | 확률, 운명, 시간의 흐름 자체를 조작 | 사망 회귀, 운명의 실 조작, 인과 뒤틀기 |
| **매체 권역 (Meta/Media)** | 현실과 가상, 거울, 그림자 등 경계를 조작 | 미디어 침투, 거울 세계 창조, 소리의 고체화 |
| **법칙 권역 (Rule/Law)** | 특정 영역 내 물리/시스템 법칙을 재정의 | 언령(말하는 대로), 물리법칙 무시, 거짓말 금지 |

## 3. word_list 데이터 재배치 매핑 (Destiny Map)

### 3.1. 트레잇(Traits) 승격군
| 원본 파일 | 이동 경로 (Candidate) | 정규화 방향 |
| :--- | :--- | :--- |
| `character/성격.md` | `traits/10_정신.md` 병합 | 중복 제거 및 포맷 통일 |
| `character/특징.md` | `traits/19_특이체질.md` (신설) | 신체/정신의 경계에 있는 고유 특징 |
| `character/신분.md` | `traits/20_사회배경.md` (신설) | 캐릭터의 출신 및 사회적 지위 |
| `character/상태이상.md` | `traits/21_상태이상.md` (신설) | 상시 적용되는 고질적 상태 (장애 등) |
| `common/질병.md` | `traits/08_약점.md` 병합 | 패널티 성격의 트레잇으로 전환 |

### 3.2. 어빌리티(Ability) 전환군
| 원본 파일 | 이동 경로 | 변환 규칙 |
| :--- | :--- | :--- |
| `character/초능력.md` | `ability/detailed_lists/` | `[권역:원천]-[계통]-[형태]` 문법 적용 |
| `character/초능력.md` | `traits/` (일부) | '하늘을 날 수 있는' 등은 `06_이동` 트레잇으로도 병합 가능 |

### 3.3. 키워드(Keyword) 유지군
- **대상**: `common/` 하위의 날씨, 보석, 암석, 음식, 의류, 천체 등.
- **조치**: `data/word_list/`에서 `data/keyword/`로 이동하여 단순 참조용 데이터로 보존.

## 4. 구현 과업 (Implementation Tasks)

1.  **[DO-EXPAND]** `manuals/99-1_ability_syntax.md`에 '인과/법칙' 관련 신규 권역/계통 정의 추가.
2.  **[DO-MIGRATE-ABILITY]** `초능력.md`를 분석하여 `data/ability/` 하위의 각 권역별 파일로 분산 저장 및 문법화.
3.  **[DO-MIGRATE-TRAIT]** 성격, 특징, 신분 등 핵심 파일을 `data/traits/`로 이동 및 번호 할당.
4.  **[DO-CLEANUP]** `word_list` 폴더 구조를 `data/keyword/` 중심으로 슬림화.

## 5. 성공 기준 (Success Criteria)
- `초능력.md` 내 100%의 항목이 어빌리티 혹은 트레잇으로 분류 완료.
- 신규 권역(인과, 법칙 등)이 기존 문법 체계와 충돌 없이 병합됨.
- `word_list`의 무분별한 확장을 막고 정규 시스템 중심의 데이터 관리 체계 확립.
