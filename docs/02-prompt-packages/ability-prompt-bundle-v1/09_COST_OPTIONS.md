# 비용 선택지 프롬프트

비용은 능력을 사용하기 위해 선지불하거나 소모하는 자원이다.

## 표준 선택지

- 마력
- 체력
- 정신력
- 수명
- 재료
- 매개체
- 없음
- 탄약
- 정보
- 기억
- 감정
- 관계
- 신앙
- 영혼 파편
- 환경 자원
- 확률 소모

## 판정 규칙

1. 비용은 사용 시점에 지불하는가
2. 사용자가 의도적으로 감수하는가
3. 반복 사용을 제한하는 자원인가

## 빠른 예시

- 자기장 조작: 정신력, 체력, 전력 중 설정에 따라 선택
- 초재생: 체력 없음이 아니라 보통 생명력 소모, 대사 자원, 세포 소모 같은 비용을 둘 수 있음
- 함성 버프: 정신력, 체력, 음성 소모, 지휘권 소모, 신앙 등 가능
