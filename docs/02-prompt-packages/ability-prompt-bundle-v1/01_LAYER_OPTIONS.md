# 층위 선택지 프롬프트

어빌리티의 첫 판단은 "무엇을 건드리는가"다. 아래에서 가장 가까운 층위를 고른다.

## 층위 목록

- 물질층: 원소, 에너지, 무기, 구조물, 물리 현상
- 생명층: 세포, 조직, 대사, 재생, 감염, 진화
- 정신층: 기억, 감정, 인식, 환각, 의지, 자아
- 정보층: 데이터, 언어, 기록, 코드, 전파, 상징
- 관계층: 계약, 명령, 종속, 인연, 소속, 군세
- 개념층: 시간, 공간, 확률, 진실, 정의, 운명
- 초월층: 신성, 저주, 영혼, 권능, 업보, 존재 격
- 혼성층: 둘 이상의 층위를 동시에 묶는 복합 능력
- 메타층: 시스템, 판정, 서사 보정, 존재 판정 수정

## 판정 질문

1. 이 능력은 무엇의 상태를 바꾸는가
2. 육체인가, 정신인가, 관계인가, 개념인가
3. 설명을 가장 짧게 줄였을 때 어떤 세계 층위를 건드린다고 말할 수 있는가

## 빠른 예시

- 울버린식 초재생: 생명층
- 매그니토식 자기장 조작: 물질층
- 함성으로 사기 진작: 관계층 또는 정신층
- 시간 정지: 개념층
- 부활 판정 무시: 메타층 또는 초월층
