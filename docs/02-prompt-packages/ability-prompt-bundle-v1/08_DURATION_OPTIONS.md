# 지속 방식 선택지 프롬프트

지속 방식은 능력의 결과가 얼마나, 어떤 조건으로 유지되는지를 뜻한다.

## 표준 선택지

- 순간
- 시간제
- 조건부 지속
- 영구
- 충전 유지
- 소멸까지 유지
- 중첩형
- 점감형
- 파급형

## 판정 질문

1. 효과가 즉시 끝나는가
2. 일정 시간 유지되는가
3. 어떤 조건이 깨지면 끝나는가
4. 시간이 지날수록 약해지는가
5. 주변으로 퍼져나가는가

## 빠른 예시

- 상처 봉합: 순간
- 사기 진작 버프: 시간제 또는 유지 중 지속
- 계약 낙인: 조건부 지속 또는 영구
- 전염 저주: 파급형
