# 형태 선택지 프롬프트

형태는 능력이 어떤 모양으로 드러나는지, 혹은 어떤 매체를 통해 행사되는지를 뜻한다.

## 핵심 표준어

- 투사체
- 광선
- 파동
- 장벽
- 장판
- 영역
- 오라
- 표식
- 사슬
- 무기화
- 신체변형
- 접촉
- 시선
- 음성
- 동작
- 의식
- 매개체
- 소환체
- 무형

- 기둥
- 덫

- 사상체
- 낙인

## 판정 질문

1. 독자가 볼 때 무엇처럼 보이는가
2. 사용자는 어떤 인터페이스로 이 능력을 다루는가
3. 작동 방식이 아니라 발현 양상을 설명하고 있는가

## 빠른 예시

- 함성 버프: 음성, 파동, 오라, 진형 중 하나
- 초재생: 무형 또는 신체변형
- 자기장 갑옷: 오라
- 금속 폭풍: 탄막, 파편, 영역
