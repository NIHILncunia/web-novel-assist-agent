# 계통 선택지 프롬프트

계통은 능력이 어떤 방식으로 작동하는지를 뜻한다. 계통은 동사처럼 읽혀야 한다.

## 핵심 표준어

- 방출: 힘이나 대상을 외부로 쏘아 보냄
- 구현: 실체, 구조, 개체를 만들어 냄
- 강화: 대상의 성능이나 상태를 끌어올림
- 제어: 환경, 사물, 흐름, 힘을 조작함
- 간섭: 내부 상태나 정보에 개입함
- 감지: 정보나 존재를 읽어냄
- 이동: 위치, 거리, 좌표를 바꿈
- 전이: 상태, 속성, 힘을 옮김
- 소환: 외부 존재나 자원을 불러옴
- 흡수: 외부 힘이나 자원을 거둬들임
- 봉인: 대상을 가두거나 기능을 묶음
- 변환: 성질, 속성, 구조를 바꿈
- 복제: 구조나 기능을 베껴 재현함
- 강제: 규칙, 행동, 판정을 억지로 고정함
- 조성: 공간, 환경, 체계를 구성함
- 회복: 손상되거나 잃은 것을 복원함
- 박탈: 기능, 자격, 상태를 제거함

## 판정 질문

1. 이 능력은 어떤 방식으로 대상에 개입하는가
2. 같은 작동 논리로 다른 형태를 만들 수 있는가
3. 결과가 달라도 작동 원리 설명이 유지되는가

## 빠른 예시

- 상처를 낫게 한다: 회복
- 금속을 마음대로 휘게 한다: 제어
- 아군 전열을 정돈하고 버프를 묶는다: 지휘 또는 강화
- 적의 의지를 꺾는다: 간섭 또는 강제
