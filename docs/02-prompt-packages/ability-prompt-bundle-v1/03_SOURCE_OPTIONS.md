# 원천 선택지 프롬프트

원천은 능력의 재료이자 매개다. 세부 원천은 자유롭게 만들 수 있지만 반드시 아래 대분류 아래에 둔다.

## 원천 대분류

- 원소형: 화염, 냉기, 번개, 대지, 바람, 물
- 물질형: 피, 뼈, 금속, 안개, 소리, 그림자
- 생체형: 근육, 신경, 세포, 호흡, 장기
- 정신형: 기억, 공포, 분노, 욕망, 꿈
- 정보형: 언어, 코드, 문서, 전파, 기록
- 관계형: 계약, 혈통, 군세, 명령, 신앙
- 개념형: 시간, 공간, 확률, 진실, 질서
- 초월형: 신성, 저주, 영혼, 업보, 권능
- 기술형: 전력, 연산, 회로, 엔진, 센서
- 상징형: 이름, 문양, 서명, 계보, 역할
- 환경형: 날씨, 지맥, 지형, 밤, 바다, 도시
- 사회형: 권위, 법, 신분, 조직, 군중 감정

## 원천 설계 규칙

1. 원천은 분류축이 아니라 보조축이다.
2. 동일한 원천도 표현 권역에 따라 전혀 다른 연출을 가질 수 있다.
3. 너무 추상적이면 대분류를 먼저 정하고, 그 아래 세부 원천을 좁힌다.

## 확장 후보 예시

- 생명 회복 계열: 재생, 세포, 혈액, 생명력, 대사
- 금속 조작 계열: 철, 자성, 강철, 합금, 전자기장
- 함성/응원 계열: 음성, 명령, 군세, 사기, 권위, 신념
- 시간 조작 계열: 시계열, 인과, 지연, 가속, 가능성
- 계약/빙의 계열: 맹세, 서약, 혼, 권속, 대가

## 판정 질문

1. 이 능력은 무엇을 매개로 움직이는가
2. 원천을 바꾸면 같은 구조가 다른 연출로 재생산되는가
3. 설명문에서 가장 상징적인 재료는 무엇인가
