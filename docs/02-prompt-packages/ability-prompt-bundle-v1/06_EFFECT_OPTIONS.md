# 효과 선택지 프롬프트

효과는 사용 후 실제로 무엇이 바뀌는가를 뜻한다.

- 피해
- 회복
- 강화
- 약화
- 구속
- 이동
- 탐지
- 은신
- 생성
- 소멸
- 변형
- 복제
- 차단
- 부여
- 박탈
- 교란
- 확정
- 왜곡

## 판정 질문

1. 사용 후 그래서 대상은 어떻게 되는가
2. 작동 원리가 아니라 결과 상태를 설명하는가
3. 다른 계통, 형태와 조합되어도 동일 개념으로 남는가

## 빠른 예시

- 울버린식 치유: 회복, 안정화
- 자기장으로 총알을 비틀어 막음: 차단, 왜곡
- 함성으로 아군 사기 상승: 강화, 안정화
- 함성으로 적을 주춤하게 만듦: 약화, 공포 부여, 교란
