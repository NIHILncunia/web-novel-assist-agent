# 태그 선택지 프롬프트

태그는 구조 필드를 대체하지 않는다. 태그의 역할은 검색 보조, 연출 보조, 세계관 특화 메모다.

## 태그 작성 규칙

1. 구조 필드 중복 태그를 넣지 않는다.
2. 태그는 명사형 또는 개념형을 우선한다.
3. 3개에서 8개 사이를 권장한다.
4. 표준 태그로 치환 가능하면 표준 태그를 우선한다.

## 비권장 예시

- `#방출`
- `#투사체`
- `#피해`
- `#마법`
- `#기술`
- `#상대를 불태운다`

## 태그 판정 질문

1. 이것이 구조 필드가 아니라 검색어로 남아야 하는가
2. 이 태그가 연출 감각이나 세계관 특성을 더 잘 드러내는가
3. 구조와 설명을 읽지 않고도 분류 보조 가치가 있는가
