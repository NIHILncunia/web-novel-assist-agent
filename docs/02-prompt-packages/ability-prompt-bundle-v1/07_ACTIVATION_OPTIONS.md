# 발동 방식 선택지 프롬프트

발동 방식은 능력이 어떤 타이밍과 절차로 켜지는지를 뜻한다.

## 표준 선택지

- 상시
- 즉발
- 차징
- 유지
- 조건반응
- 누적해방
- 의식 시전
- 자동 발동
- 토글
- 연계 발동
- 피격 반응
- 환경 반응
- 소모 교환
- 제물 기반

## 판정 질문

1. 사용자가 의식적으로 켜는가
2. 조건 충족 시 자동으로 작동하는가
3. 준비 시간이 필요한가
4. 켠 뒤 유지해야 하는가

## 빠른 예시

- 초재생: 상시 또는 자동 발동
- 전장의 함성 버프: 즉발 또는 유지
- 대규모 소환진: 의식 시전
- 분노 누적 후 폭주: 누적해방
