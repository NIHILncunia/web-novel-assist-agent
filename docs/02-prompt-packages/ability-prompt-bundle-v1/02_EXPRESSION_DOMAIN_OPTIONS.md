# 표현 권역 선택지 프롬프트

표현 권역은 이 능력이 작품 안에서 어떤 방식으로 보이는가를 정한다.

## 표현 권역 목록

- 마도형: 주문, 마력, 원소술, 마법진 기반
- 육체형: 신체 강화, 호흡, 재생, 격투 기반
- 기예형: 무공, 검술, 사격술, 손기술 기반
- 정신형: 의지, 염동, 지각, 심상 기반
- 초상형: 현실의 틈을 비트는 초능력 기반
- 기술형: 기계, 회로, 장비, 데이터 기반
- 신성형: 신탁, 축복, 권능, 성역 기반
- 혼성형: 둘 이상의 표현 문법이 동시에 적용
- 주술형: 저주, 금기, 매개 의식 기반
- 계약형: 계약, 대가, 서약, 귀속 기반
- 상징형: 이름, 문양, 언어, 의미 기반
- 이계형: 외부 차원, 소환계, 이질 공간 기반
- 생체형: 유전자, 조직, 생체 변이 기반
- 병장형: 병기, 탄약, 병장기술 기반
- 의례형: 제단, 제물, 합창, 의식 절차 기반

## 판정 질문

1. 독자가 이 능력을 봤을 때 무엇처럼 이해할까
2. 사용자는 이 능력을 어떤 인터페이스로 다루는가
3. 동일한 효과라도 연출이 다르면 표현 권역이 달라지는가

## 빠른 예시

- 자기장 조작을 돌연변이 초능력으로 쓰면: 초상형
- 자기장 조작을 마법진으로 쓰면: 마도형
- 자기장 조작을 슈트/장비로 쓰면: 기술형
- 외침으로 아군을 강화하는 전장 지휘라면: 기예형, 정신형, 관계 중심이면 신성형/상징형도 가능
