# 출력 템플릿 프롬프트

최종 응답은 아래 템플릿을 따른다.

```markdown
## [어빌리티명]

- 구조: `[층위/표현권역:세부원천] - [계통] - [형태] -> [효과]`
- 축약 표기: `[표현권역:원천] - [계통] - [형태]`
- 대상:
- 발동 방식:
- 지속 방식:
- 비용:
- 리스크:
- 태그:
- 설명:

### 설계 근거

- 층위 판단:
- 표현 권역 판단:
- 원천 판단:
- 계통 판단:
- 형태 판단:
- 효과 판단:

### 변주안

1. 저비용형:
2. 고출력형:
3. 광역형:
4. 패시브형 또는 조건반응형:
```

## 여러 개를 제안할 때

1. 기본형 먼저 제시한다.
2. 그 다음 변주형을 제시한다.
3. 변주형은 무엇이 달라졌는지 한 줄로 명시한다.

## 금지

1. 구조를 숨기고 이름과 설명만 출력하지 않는다.
2. 비용과 리스크를 합쳐 적지 않는다.
3. 태그를 구조 필드 대용으로 쓰지 않는다.
