# [Common] 어빌리티 태그 프로토콜 (Ability Tag Protocol)

> **파일명:** `manuals/99-2_ability_tags.md`
> **목적:** 어빌리티의 특성을 분류하고 데이터베이스화하기 위한 표준 태그 키워드 관리.
> **적용:** 어빌리티 생성 시 **'태그(Tag)' 필드 필수 입력**.

---

## 1. 핵심 규칙 (Core Rules)

### ① 태그 필드 필수 (Mandatory Tag Field)
모든 어빌리티 생성 시, 데이터 스키마에 **[태그 (Tags)]** 컬럼을 반드시 포함해야 합니다.
태그는 해당 어빌리티를 검색하거나 분류할 때 사용되는 핵심 메타데이터입니다.

### ② 오픈 태깅 (Open Tagging)
아래 제공된 태그 목록은 **기초 가이드라인(Baseline)**입니다.
*   **사용 권장:** 가급적 아래 목록에 있는 표준 태그를 사용하여 데이터 일관성을 유지하십시오.
*   **자유 확장:** 표현하고자 하는 개념이 목록에 없다면, **창작자가 자유롭게 새로운 태그를 생성하여 기입**할 수 있습니다.
*   **형식:** 태그는 가급적 '명사형'으로 작성합니다. (예: `가르기`(X) -> `절단`(O))
