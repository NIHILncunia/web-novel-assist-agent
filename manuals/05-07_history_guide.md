# 05-07. 사건 설정 가이드 (History Guide)

> **작성일:** 2026-01-04
> **수정일:** 2026-01-04

## 1. 개요
세계관의 **역사적 사건, 대전쟁, 쿠데타** 등 과거에 일어난 중요한 사건에 대한 템플릿입니다.

---

## 2. 에이전트 작업 지침

### 2-1. 작성 원칙
1. **원인-전개-결과의 인과관계**
   - 사건은 **우연이 아닌 필연**으로 발생해야 합니다.
   - 원인이 명확하고, 결과가 논리적이어야 합니다.

2. **현재와의 연결**
   - 과거 사건은 **현재 서사에 영향**을 미쳐야 합니다.
   - 그냥 옛날 이야기로 끝나면 의미 없습니다.
   - 예: 100년 전 전쟁의 후유증이 현재까지 이어짐

3. **다면적 해석**
   - 역사는 승자의 기록입니다. **다른 시각**도 존재합니다.
   - 공식 기록과 실제 진실이 다를 수 있습니다.

4. **규모와 파급력**
   - 사건의 **규모에 맞는 결과**가 있어야 합니다.
   - 대전쟁 → 국경선 변경, 인구 감소, 경제 파탄 등

### 2-2. 주의사항

#### ⚠️ 피해야 할 것
- **우연의 연속:** "마침 ~해서 ~했다"는 비논리적
- **영향 없는 사건:** 역사에 기록될 정도면 파급력이 있어야 함
- **일방적 악:** "악의 제국이 침략했다"는 단순화
- **현재 복사:** 2차 세계대전을 그대로 옮기는 식은 식상

#### ✅ 해야 할 것
- **명확한 원인:** 왜 전쟁이 일어났는가? (자원, 종교, 복수 등)
- **양측의 시각:** 각자의 명분과 정당성
- **구체적 피해:** 사망자 수, 파괴된 도시, 경제적 손실
- **장기적 영향:** 100년 후에도 이어지는 여파

### 2-3. 사건 유형별 체크리스트

#### 전쟁
- [ ] **개전 이유**가 설득력 있는가?
- [ ] **주요 전투**가 3개 이상 설정되었는가?
- [ ] **전환점**이 있는가?
- [ ] **피해 규모**가 구체적인가?
- [ ] **전후 조약/협정**이 있는가?
- [ ] **패전국 처우**가 설정되었는가?

#### 쿠데타/혁명
- [ ] **불만의 축적 과정**이 있는가?
- [ ] **주동자**와 **참여 세력**이 명확한가?
- [ ] **실패 가능성**도 있었는가?
- [ ] **숙청**이 있었는가?
- [ ] **체제 변화**가 구체적인가?

#### 재난/재해
- [ ] **원인**이 자연재해인가, 인재인가?
- [ ] **피해 범위**가 명확한가?
- [ ] **대응 과정**이 있는가?
- [ ] **복구 여부**가 설정되었는가?
- [ ] **책임 소재**가 있는가?

### 2-4. 공통 체크리스트
- [ ] **시기**가 명확한가? (몇 년 전, 어느 왕 통치 시기 등)
- [ ] **원인**이 논리적인가?
- [ ] **전개 과정**이 구체적인가?
- [ ] **결과/영향**이 설득력 있는가?
- [ ] **현재 서사**와 어떻게 연결되는가?
- [ ] **공식 기록**과 **실제 진실**이 다른가?
- [ ] **생존자/후손**이 현재 어떻게 살고 있는가?
- [ ] **기념일/추모 행사**가 있는가?
- [ ] **이 사건을 모르면** 현재 상황을 이해할 수 없는가?
