# 특성 및 능력 작명/생성 표준 (Trait & Ability Naming/Creation Standards)

> **작성일:** 2026-01-17
> **설명:** 데이터베이스(`data/traits`, `data/ability`)의 일관성과 재사용성을 보장하기 위한 작명 및 생성 규칙입니다.

---

## 1. 기본 원칙: 모듈화 (Modularity)

**"하나의 특성은 하나의 기능만 수행해야 한다."**

특성과 능력은 레고 블록과 같아야 합니다. 너무 구체적이거나 복합적인 기능이 결합된 블록은 다른 곳에 재사용하기 어렵습니다.

*   **Bad (복합 기능):** `독을 품은 날개` (독 + 비행) → 날개가 없는 몬스터에게 줄 수 없음.
*   **Good (분리):** `독샘` (독) + `거대한 날개` (비행) → 각각 따로 떼어내어 다른 엔티티에 조립 가능.

---

## 2. 작명 문법 (Naming Syntax)

### 2.1. 허용 구조 (Allowed)

1.  **[명사]**: 가장 간결하고 명확한 형태.
    *   예: `강철 피부`, `야간 시야`, `재생`
2.  **[수식어] + [명사]**: 구체적인 속성을 부여.
    *   예: `단단한 비늘`, `놀라운 민첩성`, `부식성 혈액`
3.  **[수식어] + [복합 명사]**: **[복합 명사]**가 하나의 고유한 개념(Compound Noun)으로 통용되는 경우 허용.
    *   예: `타오르는 [화염 검]` ('화염 검'은 하나의 아이템 명칭으로 볼 수 있음)
    *   예: `고귀한 [하이 엘프]` ('하이 엘프'는 하나의 종족명)

### 2.2. 금지 구조 (Prohibited)

**[수식어 1] + [수식어 2] + [명사] (이중 수식 금지)**

서로 다른 두 개의 수식어가 붙는 것은 해당 특성이 **두 가지 속성**을 동시에 가지고 있거나 **불필요하게 복잡함**을 의미합니다. 이는 모듈성을 해칩니다.

*   **Bad:** `붉게 타오르는 화염 검`
    *   이유: '붉게'(색상) + '타오르는'(상태) + '화염'(속성) + '검'(본체). 너무 긺.
    *   수정: `화염 검` (색상은 묘사에서 처리하거나, 중요한 속성이면 별도 특성으로 분리)
*   **Bad:** `빠르고 강력한 근력`
    *   이유: '빠른'(민첩) + '강력한'(힘)이 섞임.
    *   수정: `초인적 근력` + `신속` (분리)
*   **Bad:** `치명적인 맹독 이빨`
    *   이유: '치명적인'(수식) + '맹독'(속성) + '이빨'(부위). 문장이 되려 함.
    *   수정: `맹독 이빨` (직관적 명사형)

---

## 3. 분류 기준: 특성 vs 능력

몬스터나 캐릭터의 데이터를 추출할 때, **원인(Cause)**과 **결과(Effect)**를 구분하여 저장합니다.

| 분류 | 정의 | 예시 |
| :--- | :--- | :--- |
| **특성 (Trait)** | **[원인/재질/생태]** 엔티티가 '무엇으로 이루어져 있는가', '어떤 성질을 타고났는가'. | `거대한 날개`, `독샘`, `강철 비늘`, `탐욕스러운 성격` |
| **지속 능력 (Passive)** | **[상광/효과]** 특성으로 인해 얻게 되는 상시적인 이점이나 페널티. | `비행`, `독 면역`, `물리 저항`, `공포 오라` |
| **발동 능력 (Active)** | **[행동/기술]** 특성이나 자원을 사용하여 능동적으로 행하는 기술. | `날개 치기`, `맹독 뿜기`, `방어 태세`, `위협` |

*   **예시:** 드래곤 데이터 추출
    *   (O) `거대한 날개`는 **특성**에 저장.
    *   (O) 날개가 있어서 날 수 있다는 사실(`비행`)은 **지속 능력**에 저장.
    *   (O) 날개를 휘둘러 적을 공격하는 기술(`날개 공격`)은 **발동 능력**에 저장.

---

## 4. 요약 가이드

1.  이름은 **짧고 직관적인 명사형**으로 짓는다. (서술형 문장 금지)
2.  수식어가 덕지덕지 붙으면 **기능을 분리**할 수 있는지 의심한다.
3.  **[수식어]+[명사]** 형태를 지향하되, [명사]가 **복합 명사**인 경우 수식어를 하나 더 허용한다.
4.  특성은 **'재료'**, 능력은 **'기능'**이다.
