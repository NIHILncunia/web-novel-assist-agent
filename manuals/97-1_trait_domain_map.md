# [Common] 트레잇-권역 매핑 가이드 (Trait-Domain Mapping)

> **파일명:** `manuals/97-1_trait_domain_map.md`
> **목적:** 트레잇(Passive)과 어빌리티(Active)의 시스템적 일관성을 유지하기 위해, 각 트레잇 카테고리가 어빌리티의 어느 **[권역(Domain)]**에 해당하는지 정의합니다.
> **활용:** 캐릭터나 종족 생성 시, 트레잇을 부여할 때 해당 트레잇이 어떤 어빌리티와 시너지를 내는지 판단하는 기준으로 사용합니다.

---

## 1. 트레잇 카테고리별 권역 매핑표

**범례:**
*   ✅ **적용 (Applied):** 어빌리티 권역과 직접 연결되어, 해당 힘의 '근원'이나 '매개체'가 되는 트레잇.
*   ➖ **제외 (Excluded):** 단순한 수치, 환경, 배경 설정 등이라 권역 문법을 적용하기 애매한 트레잇.

| 번호 | 카테고리명 | 적용 여부 | 매핑 권역 (Domain) | 비고 (Mapping Logic) |
| :--- | :--- | :---: | :--- | :--- |
| **00** | **유형 (Type)** | ➖ | - | 단순 분류 태그 (메타 정보) |
| **01** | **크기 (Size)** | ➖ | - | 단순 물리적 제원 (Stat) |
| **02** | **기원 (Origin)** | ✅ | **[특수]** / **[마법]** | 존재 자체가 마법적이거나 이질적인 경우 (예: 언데드, 정령, 악마) |
| **03** | **신체 (Body)** | ✅ | **[물리]** | 육체계/신법계 어빌리티의 기반 (예: 강철 피부, 다관절) |
| **04** | **지식 (Intellect)** | ✅ | **[정신]** | 감지계/분석계 어빌리티의 기반 (예: 연산 보조, 도서관 기억) |
| **05** | **군집 (Swarm)** | ✅ | **[특수]** | 소환계/연결 능력의 기반 (예: 하이브 마인드, 군체 의식) |
| **06** | **이동 (Move)** | ✅ | **[물리]** / **[특수]** | 신법계(비행)나 공간계(워프)의 패시브화 (예: 날개, 공간 도약) |
| **07** | **감각 (Sense)** | ✅ | **[정신]** / **[물리]** | 감지계 어빌리티의 상시 발동형 (예: 열감지, 마력 감지) |
| **08** | **약점 (Weakness)** | ➖ | - | 권역의 반대 개념(패널티)이라 분류 제외 (단, '화염 취약'처럼 속성은 참조함) |
| **09** | **생활 (Life)** | ➖ | - | 식성, 수면 등 RP적 요소 (단, '흡혈' 등은 특수 권역 가능) |
| **10** | **정신 (Mind)** | ✅ | **[정신]** | 정신 강화계/방어계의 기반 (예: 광란, 부동심) |
| **11** | **지역 (Region)** | ➖ | - | 거주지/서식지 정보 (배경 설정) |
| **12** | **외교 (Diplomacy)** | ✅ | **[전술]** / **[정신]** | 교섭계/간섭계 능력의 기반 (예: 매혹, 카리스마, 위압감) |
| **13** | **경영 (Manage)** | ✅ | **[생산]** | 자원 관리 능력 (예: 행정 특화, 수전노) |
| **14** | **제작 (Craft)** | ✅ | **[생산]** | 가공계/연금계 어빌리티의 기반 (예: 마이스터, 신의 손) |
| **15** | **속성 (Element)** | ✅ | **[마법]** | 방출계/제어계 마법의 근원 (예: 화염 친화, 빙결 체질) |
| **16** | **전투 (Combat)** | ✅ | **[물리]** | 타격계/기교계 어빌리티의 패시브화 (예: 무기의 달인, 야수성) |
| **17** | **관계 (Relation)** | ➖ | - | 인물 간 서사 정보 (스토리) |
| **18** | **직업 (Job)** | ➖ | - | 사회적 지위/역할 (메타 정보) |

## 2. 매핑 활용 가이드

트레잇을 설계하거나 캐릭터 시트를 작성할 때, 위 매핑표를 참고하여 다음과 같이 시너지를 구성할 수 있습니다.

### **A. 시너지 (Synergy)**
해당 권역의 어빌리티 효율을 높여주는 트레잇 조합.

*   **[물리 권역] 시너지:**
    *   **트레잇:** `03_신체` (강철 근육) + `16_전투` (야수성)
    *   **어빌리티:** [물리:타격계] (파괴력 증가), [물리:육체계] (지속시간 증가)
*   **[마법 권역] 시너지:**
    *   **트레잇:** `15_속성` (화염 친화) + `04_지식` (마력 연산)
    *   **어빌리티:** [마법:방출계] (화염구 위력 증가), [마법:제어계] (마나 소모 감소)

### **B. 역설계 (Reverse Engineering)**
캐릭터가 가져야 할 어빌리티(Active)를 먼저 정하고, 이를 뒷받침할 트레잇(Passive)을 역으로 도출.

*   **목표:** "군대를 지휘하며 적을 공포에 떨게 하는 장군" (어빌리티: [전술:지휘계], [전술:교섭계])
*   **필요 트레잇 도출:**
    *   `12_외교` → [위압감], [왕의 자질]
    *   `10_정신` → [부동심] (흔들리지 않는 지휘를 위해)
