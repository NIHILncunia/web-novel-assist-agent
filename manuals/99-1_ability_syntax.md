# [Common] 보편 어빌리티 문법 v2 (Universal Ability Syntax v2)

> **파일명:** `manuals/99-1_ability_syntax.md`  
> **목적:** 장르와 표현 방식에 상관없이, 세상에 존재할 수 있는 거의 모든 능력 / 기술 / 스킬 / 권능 / 이능 / 주문 / 기예를 하나의 공통 문법으로 정의하기 위한 표준 구조 가이드.  
> **적용:** 어빌리티 생성, 분석, 데이터베이스 기입, 검증 시 이 규칙을 따른다.  
> **상태:** 초안 v2

---

## 1. 설계 목표

이 문법의 목표는 다음과 같다.

1. 마법, 무공, 초능력, 성법, 저주, 기계 기술, 패시브, 필살기까지 하나의 규격으로 설명할 수 있어야 한다.
2. 창작 자유도를 유지하되, 분류와 검색에는 충분히 엄격해야 한다.
3. 표현용 이름과 내부 구조를 분리하여, 독자 친화성과 데이터 정합성을 동시에 확보해야 한다.

---

## 2. 핵심 원칙

### 2-1. 능력은 결과물이 아니라 구조로 분해한다

어빌리티는 이름으로 분류하지 않는다.  
어떤 층위에서, 어떤 원천을 사용해, 어떤 방식으로, 어떤 형태로 발현되며, 무슨 결과를 일으키는지로 분해한다.

### 2-2. 패시브와 액티브는 별도 종이 아니다

패시브와 액티브는 서로 다른 문법이 아니라, 같은 구조 위에서 **발동 방식**이 다른 경우로 처리한다.

### 2-3. 본질 축과 표현 축을 분리한다

- **본질 축:** 이 능력이 세상의 어느 층위를 건드리는가
- **표현 축:** 이 능력이 작품 안에서 어떤 방식으로 보이는가

### 2-4. 축 간 역할을 엄격히 구분한다

- **계통은 동사**
- **형태는 발현 모양 또는 매체**
- **효과는 결과**

---

## 3. 내부 정규 문법

### 3-1. 기본 표기

보편 어빌리티의 내부 정규 문법은 아래를 따른다.

`[층위/표현권역:세부원천] - [계통] - [형태] -> [효과]`

예:

- `[물질/마도:화염] - [방출] - [투사체] -> [피해/폭발/화상]`
- `[정신/초상:공포] - [간섭] - [시선] -> [공포 부여/행동제한]`
- `[개념/신성:운명] - [강제] - [표식] -> [확정/박탈]`

### 3-2. 표시용 축약 문법

사용자에게 보여줄 때는 아래 축약 문법을 사용할 수 있다.

`[표현권역:원천] - [계통] - [형태]`

예:

- `[마도:화염] - [방출] - [투사체]`
- `[초상:공포] - [간섭] - [시선]`

## 4. 문법 축 정의

## 4-1. 층위 (Layer)

능력이 개입하는 세계의 층위.

| 층위 | 설명 |
| :--- | :--- |
| 물질층 | 원소, 에너지, 무기, 구조물, 물리 현상 |
| 생명층 | 세포, 조직, 대사, 재생, 감염, 진화 |
| 정신층 | 기억, 감정, 인식, 환각, 의지, 자아 |
| 정보층 | 데이터, 언어, 기록, 코드, 전파, 상징 |
| 관계층 | 계약, 명령, 종속, 인연, 소속, 군세 |
| 개념층 | 시간, 공간, 확률, 진실, 정의, 운명 |
| 초월층 | 신성, 저주, 권능, 영혼, 카르마, 존재 격 |
| 혼성층 | 둘 이상의 층위를 동시에 묶어 작동하는 복합 능력 |
| 메타층 | 시스템, 판정, 서사 보정, 존재 판정 수정 |

## 4-2. 표현 권역 (Expression Domain)

작품 안에서 능력이 어떤 방식으로 인식되는가.

| 표현 권역 | 설명 |
| :--- | :--- |
| 마도형 | 주문, 마력, 원소술, 마법진 기반 |
| 육체형 | 신체 강화, 호흡, 재생, 격투 기반 |
| 기예형 | 무공, 검술, 사격술, 손기술 기반 |
| 정신형 | 의지, 염동, 지각, 심상 기반 |
| 초상형 | 현실의 틈을 비트는 초능력 기반 |
| 기술형 | 기계, 회로, 장비, 데이터 기반 |
| 신성형 | 신탁, 축복, 권능, 성역 기반 |
| 혼성형 | 둘 이상의 표현 문법이 동시에 적용 |
| 주술형 | 저주, 매개 의식, 금기 기반 |
| 계약형 | 계약, 대가, 서약, 귀속 기반 |
| 상징형 | 이름, 문양, 언어, 의미 기반 |
| 이계형 | 외부 차원, 소환계, 이질 공간 기반 |
| 생체형 | 유전자, 조직, 생체 변이 기반 |
| 병장형 | 병기, 탄약, 병장기술 기반 |
| 의례형 | 제단, 제물, 합창, 의식 절차 기반 |

## 4-3. 원천 (Source)

원천은 능력의 근원 재료이자 매개이다.  
세부 원천은 자유 입력 가능하지만, 반드시 아래의 **원천 대분류** 아래에 속해야 한다.

| 원천 대분류 | 예시 |
| :--- | :--- |
| 원소형 | 화염, 냉기, 번개, 대지, 바람, 물 |
| 물질형 | 피, 뼈, 금속, 안개, 소리, 그림자 |
| 생체형 | 근육, 신경, 세포, 호흡, 장기 |
| 정신형 | 기억, 공포, 분노, 욕망, 꿈 |
| 정보형 | 언어, 코드, 문서, 전파, 기록 |
| 관계형 | 계약, 혈통, 군세, 명령, 신앙 |
| 개념형 | 시간, 공간, 확률, 진실, 질서 |
| 초월형 | 신성, 저주, 영혼, 업보, 권능 |
| 기술형 | 전력, 연산, 회로, 엔진, 센서 |
| 상징형 | 이름, 문양, 서명, 계보, 역할 |
| 환경형 | 날씨, 지맥, 지형, 밤, 바다, 도시 |
| 사회형 | 권위, 법, 신분, 조직, 군중 감정 |

규칙:

1. 원천은 **분류축이 아니라 보조축**이다.
2. 원천은 자유롭게 발명할 수 있지만, 대분류 밖으로 벗어나면 안 된다.
3. 동일한 원천이라도 표현 권역이 다르면 다른 연출을 가질 수 있다.

## 5. 계통 표준어

계통은 능력이 **무슨 방식으로 작동하는가**를 설명한다.

### 5-1. 핵심 표준어

| 계통 | 정의 |
| :--- | :--- |
| 방출 | 힘이나 대상을 외부로 쏘아 보냄 |
| 구현 | 실체, 구조, 개체를 만들어 냄 |
| 강화 | 대상의 성능이나 상태를 끌어올림 |
| 제어 | 환경, 사물, 흐름, 힘을 조작함 |
| 간섭 | 내부 상태나 정보에 개입함 |
| 감지 | 정보나 존재를 읽어냄 |
| 이동 | 위치, 거리, 좌표를 바꿈 |
| 전이 | 상태, 속성, 힘을 옮김 |
| 소환 | 외부의 존재나 자원을 불러옴 |
| 흡수 | 외부의 힘이나 자원을 거둬들임 |
| 봉인 | 대상을 가두거나 기능을 묶음 |
| 변환 | 성질, 속성, 구조를 바꿈 |
| 복제 | 구조나 기능을 베껴 재현함 |
| 강제 | 규칙, 행동, 판정을 억지로 고정함 |
| 조성 | 공간, 환경, 체계를 구성함 |
| 회복 | 손상되거나 잃은 것을 복원함 |
| 박탈 | 기능, 자격, 상태를 제거함 |

### 5-2. 확장 표준어

| 계통 | 설명 |
| :--- | :--- |
| 증폭 | 출력 증대 특화 |
| 분열 | 하나를 다수로 나눔 |
| 융합 | 둘 이상을 결합 |
| 고정 | 상태나 판정을 묶음 |
| 전개 | 구조나 효과를 펼침 |
| 반전 | 속성, 관계, 방향을 뒤집음 |
| 반사 | 외부 작용을 되돌림 |
| 기록 | 정보를 새기거나 저장 |
| 해석 | 정보나 구조를 읽고 의미를 복원 |
| 귀속 | 대상과 속성, 자격, 소유권을 묶음 |
| 오염 | 구조나 상태를 침식 |
| 정화 | 오염이나 이상 상태를 씻어냄 |
| 배양 | 생명, 자원, 개체를 길러냄 |
| 진화 | 구조의 상향 변이를 누적 |
| 재구성 | 부서진 구조를 다시 짜맞춤 |
| 교환 | 하나를 대가로 다른 결과를 얻음 |
| 동조 | 둘 이상의 상태를 연결·공명 |
| 지휘 | 집단 단위 행동을 통제 |
| 협상 | 관계층에서 의사결정을 유도 |
| 채집 | 자원 확보 특화 |
| 제작 | 완제품 조립 특화 |
| 해체 | 구조 분해 특화 |

### 5-3. 판정 기준

계통 여부는 아래 질문으로 판정한다.

1. 이 능력은 **어떤 방식으로 대상에 개입하는가**
2. 같은 작동 논리로 다른 형태를 만들 수 있는가
3. 결과가 달라도 작동 원리 설명이 유지되는가

---

## 6. 형태 표준어

형태는 능력이 **어떤 모양으로 발현되는가**, 혹은 **어떤 매체를 통해 행사되는가**를 설명한다.

### 6-1. 핵심 표준어

| 형태 | 정의 |
| :--- | :--- |
| 투사체 | 발사되어 날아가는 단일 실체 |
| 광선 | 선형으로 즉시 도달하는 흐름 |
| 파동 | 퍼져나가는 면적형 충격 |
| 장벽 | 차단, 방호를 위한 벽 형태 |
| 장판 | 지면 또는 평면에 펼쳐진 지속 영역 |
| 영역 | 공간 전체를 덮는 입체 규칙장 |
| 오라 | 사용자 주변에 감도는 상시 발현 |
| 표식 | 대상이나 지점에 새겨지는 표기 |
| 사슬 | 연결, 구속, 연쇄 작용 매체 |
| 무기화 | 검, 창, 총열 등 무장 형식 |
| 신체변형 | 신체 일부나 전체가 변형된 발현 |
| 접촉 | 맞닿는 순간 작동하는 형식 |
| 시선 | 바라봄 자체가 발동 매체 |
| 음성 | 말, 외침, 노래 등 청각 매체 |
| 동작 | 자세, 검식, 춤, 수인 등 행위 매체 |
| 의식 | 준비와 절차를 거쳐 성립하는 형식 |
| 매개체 | 물건, 부적, 문서, 장비 등을 통해 발현 |
| 소환체 | 불려온 개체를 통해 작동 |
| 무형 | 눈에 보이는 발현체 없이 직접 적용 |

### 6-2. 확장 표준어

| 형태 | 설명 |
| :--- | :--- |
| 탄막 | 다수 투사체 집합 |
| 돌진 | 이동 자체가 타격 인터페이스 |
| 참격 | 궤적이 보이는 베기형 발현 |
| 폭발 | 점발현 후 즉시 터짐 |
| 파편 | 분산 조각 확산형 |
| 장치 | 설치된 기계/구조물 인터페이스 |
| 기둥 | 수직 분출형 |
| 덫 | 조건 발동형 설치 매체 |
| 사역체 | 지배 중인 개체를 통한 행사 |
| 분신 | 복수 개체 동시 운용 |
| 의태 | 다른 것처럼 변장한 발현 |
| 투영 | 이미지, 개념, 존재의 비춤 |
| 접속 | 링크, 네트워크, 정신 결선 |
| 노래 | 음성 특화형 |
| 주문문 | 문자, 룬, 문양 기반 형식 |
| 진형 | 집단 배치로 성립하는 형식 |
| 시나리오 | 규칙이 단계적으로 전개되는 형식 |
| 좌표 | 위치 지정 기반 형식 |
| 사상체 | 정신·개념이 준개체로 드러남 |
| 낙인 | 상태를 새기는 표식 특수형 |

### 6-3. 판정 기준

형태 여부는 아래 질문으로 판정한다.

1. 독자가 볼 때 **무엇처럼 보이는가**
2. 사용자는 이 능력을 **어떤 인터페이스로 다루는가**
3. 작동 방식이 아니라 **발현 양상**을 설명하는가

---

## 7. 효과 표준어

효과는 능력 사용 후 **실제로 무엇이 바뀌는가**를 설명한다.

### 7-1. 핵심 표준어

| 효과 | 정의 |
| :--- | :--- |
| 피해 | 체력, 구조, 안정성을 깎음 |
| 회복 | 손실된 상태를 복구 |
| 강화 | 성능을 높임 |
| 약화 | 성능을 낮춤 |
| 구속 | 행동, 이동, 발동을 제한 |
| 이동 | 위치를 바꾸게 함 |
| 탐지 | 정보를 드러냄 |
| 은신 | 감지나 노출을 피함 |
| 생성 | 없던 대상이나 구조를 만듦 |
| 소멸 | 존재, 구조, 상태를 지움 |
| 변형 | 상태, 구조, 성질을 바꿈 |
| 복제 | 구조나 기능을 재현 |
| 차단 | 흐름, 통로, 연결을 끊음 |
| 부여 | 자격, 속성, 상태를 새로 줌 |
| 박탈 | 자격, 속성, 상태를 제거 |
| 교란 | 판단, 구조, 흐름을 흐트러뜨림 |
| 확정 | 결과나 상태를 고정 |
| 왜곡 | 거리, 판정, 구조를 비틂 |

### 7-2. 확장 표준어

| 효과 | 설명 |
| :--- | :--- |
| 무효화 | 기능이 발휘되지 않게 만듦 |
| 반사 | 외부 작용을 되돌린 결과 |
| 전이 | 상태나 속성이 다른 대상으로 이동 |
| 감염 | 대상 내부로 번지는 변화 |
| 증식 | 수, 범위, 밀도가 늘어남 |
| 소환 | 새 개체가 배치됨 |
| 봉인 | 기능이 잠김 |
| 동기화 | 둘 이상의 상태가 맞춰짐 |
| 지배 | 통제권 획득 |
| 설득 | 자발적 협조 유도 |
| 공포 부여 | 심리 위축 유발 |
| 명령 강제 | 행동 수행 강요 |
| 정찰 | 정제된 탐지 결과 확보 |
| 가시화 | 보이지 않던 것을 드러냄 |
| 비가시화 | 보이던 것을 숨김 |
| 추적 | 특정 대상 위치를 계속 파악 |
| 절단 | 잘려나간 결과 |
| 파쇄 | 깨지거나 부서진 결과 |
| 관통 | 방어를 뚫고 닿는 결과 |
| 폭주 유발 | 통제 상실 상태 유발 |
| 안정화 | 불안정 상태를 정리 |
| 정립 | 미정 상태를 굳힘 |

### 7-3. 판정 기준

효과 여부는 아래 질문으로 판정한다.

1. 사용 후 **그래서 대상은 어떻게 되는가**
2. 작동 원리가 아니라 **결과 상태**를 설명하는가
3. 다른 계통·형태와 조합되어도 동일 결과 개념이 유지되는가

## 10. 문법 기록 예시

### 예시 A. 화염구

- 층위: 물질층
- 표현 권역: 마도형

`[물질/마도:화염] - [방출] - [투사체] -> [피해/폭발/화상]`

- 효과: 회복
- 발동 방식: 상시

`[생명/육체:재생] - [회복] - [무형] -> [회복]`

## 12. 운용 지침

1. 새 어빌리티를 만들 때는 먼저 **층위**를 정한다.
2. 그다음 작품 내 연출에 맞는 **표현 권역**을 정한다.
3. 세부 **원천**을 고른다.
4. 능력의 작동 방식을 **계통**으로 고른다.
5. 발현 양상을 **형태**로 고른다.
6. 실제 결과를 **효과**로 적는다.
7. 마지막으로 발동 방식, 비용, 리스크를 붙인다.

이 순서를 따르면 대부분의 능력은 장르에 상관없이 같은 틀 안에 수렴된다.
