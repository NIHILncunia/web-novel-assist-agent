# [Step 2] 세계관 분기 및 컨셉 제안 (World Initiation)

> **작성일:** 2026-01-04
> **수정일:** 2026-01-04

## 1. 개요
이 단계는 창작의 **첫 번째 분기점**입니다. 에이전트는 사용자가 기존에 보유한 자산(공용 세계관)을 활용할지, 아니면 새로운 아이디어에 맞춰 신규 세계관을 설계할지 판단하고 가이드합니다.

**[목표 결과물]**
1.  **세계관 확정:** [공용 세계관 선택] OR [신규 세계관 컨셉 확정]
2.  **임시 작업 공간 생성:** `incubator` 내에 폴더 생성.

---

## 2. 작업 프로세스

### Phase 1. 분기 확인 (Branch Check)
사용자에게 가장 먼저 아래 질문을 던져 경로를 설정하십시오.
> "사용자님, 이번 이야기는 **[A] 기존의 공용 세계관**을 기반으로 하시겠습니까, 아니면 **[B] 완전히 새로운 세계**를 창조하시겠습니까?"

### Phase 2-A. 기존 세계관 선택 (Existing)
사용자가 **[A]**를 선택한 경우:
1.  `library/shared_world/` 폴더 내의 파일 목록을 요약하여 제시합니다.
2.  선택된 세계관의 핵심 제약 사항(절대 어기면 안 되는 룰)을 리마인드합니다.
3.  **즉시 종료:** [Step 3. 로그라인] 단계로 넘어갈 준비를 합니다.

### Phase 2-B. 신규 세계관 제안 (New Creation)
사용자가 **[B]**를 선택한 경우:
1.  **원본 요청 기록:** 사용자가 제공한 요청 프롬프트를 그대로 기록합니다. (나중에 컨셉 노트 파일에 저장)
2.  **키워드 분석:** 사용자의 요청에서 소재, 장르, 분위기, 세계관 유형 등을 추출하여 구조화합니다.
    * **장르 추출:** 판타지, 무협, 현대 등
    * **세계관 요소:** 이세계, 현대 판타지, 아포칼립스 등
    * **톤/분위기:** 밝음, 어두움, 피폐함, 희망적 등
    * **기타 키워드:** 특정 소재, 직업, 능력 체계 등
3.  **장르별 키워드 리스트 참조:** 분석된 장르에 맞는 키워드 리스트를 참조합니다.
    * **판타지:** `data/word_list/fantasy/판타지_용어.md` 참조 (종족, 직업, 마법, 아이템, 지역 등)
    * **무협:** `data/word_list/murim/무협_용어.md` 참조 (예정 - 문파, 무공, 무기, 지역 등)
    * **기타:** 해당 장르의 키워드 리스트가 있다면 우선 참조
4.  **3가지 맛 제안 (Concept Menu):** 수집된 키워드와 리스트를 조합하여, 서로 다른 매력을 가진 3가지 컨셉을 제안합니다. **(절대 세부 설정은 하지 않습니다.)**

## 3. 신규 세계관 제안 양식 (Concept Template)
신규 제안 시에는 독자가 느낄 **'재미의 포인트'**와 **'분위기'**에 집중하여 아래 양식으로 출력하십시오.

### 📋 [세계관 컨셉 제안서]

#### 1. 사용자 원본 요청
> (사용자가 제공한 요청 프롬프트를 그대로 기록)

#### 2. 키워드 분석
**추출된 키워드:**
- **장르:** (예: 판타지, 로맨스, 모험, 일상)
- **세계관:** (예: 신규 생성, 이세계 배경, 검과 마법 판타지)
- **톤/분위기:** (예: 밝고 희망차, 피폐함, 어둡고 무거움)
- **작품 길이:** (예: 25화 단편, 200화 장편)
- **기타 소재:** (사용자가 언급한 특정 요소들)

**키워드 리스트 참조:**
- `data/word_list/[장르].md`에서 관련 용어 및 소재 확인

#### 3. 세계관 컨셉 제안

**[Option A] 정석/왕도형 (Classic)**
* **장르:** (예: 정통 헌터물)
* **핵심 룰(Rule):** 독자가 익숙하게 받아들일 수 있는 표준 설정.
    * *예: 게이트 발생 10년 후, 헌터 등급에 따른 철저한 계급 사회.*
* **분위기:** 안정적, 성장 중심, 쾌감.

**[Option B] 비틀기/반전형 (Twist)**
* **장르:** (예: 헌터물 + 코즈믹 호러)
* **핵심 룰(Rule):** 클리셰를 비트는 독특한 제약.
    * *예: 헌터들이 사용하는 마력은 사실 '자신의 수명'이다.*
* **분위기:** 긴장감, 미스터리, 절박함.

**[Option C] 퓨전/특수형 (Fusion)**
* **장르:** (예: 헌터물 + 사이버펑크)
* **핵심 룰(Rule):** 서로 다른 장르의 결합.
    * *예: 마법 대신 기계 의수와 약물로 강화된 신인류가 몬스터를 사냥.*
* **분위기:** 느와르, 화려함, 퇴폐적.

## 4. 데이터 저장 및 관리

### 4-1. 통합 대화 로그 (Conversation Log)
**모든 Step에서 공통으로 적용되는 규칙입니다.**

1.  **로그 파일 생성:** 작업 폴더 생성 즉시 `manuals/99_common_logger.md` 지침에 따라 `00_conversation_log.md`를 생성하고 기록합니다.
2.  **로그 기록 규칙:** 모든 "사용자 요청 => 노블 솔루션" 과정을 시간순으로 기록합니다.
    * **기록 원칙:**
        - **사용자 요청:** 자연어로 전부 기록 (원문 그대로)
        - **노블 솔루션:** "어떤 제공해줬다" 형식으로 요약 기록
    * **형식:**
        ```markdown
        ## [Step 2] 세계관 분기 및 컨셉 제안
        
        ### 요청 (YYYY-MM-DD HH:MM)
        판타지 장르로 밝고 희망찬 분위기의 단편을 쓰고 싶어. 검과 마법이 있는 이세계 배경이고, 로맨스 요소는 약간만 들어가면 좋겠어.
        
        ### 응답 (YYYY-MM-DD HH:MM)
        세계관 분기 질문 제공 (기존 세계관 vs 신규 세계관), 키워드 분석 수행 (장르: 판타지, 톤: 밝고 희망차, 작품 길이: 단편), 3가지 컨셉 제안 (정석형/비틀기형/퓨전형)
        
        ### 요청 (YYYY-MM-DD HH:MM)
        Option A 정석형으로 가고 싶어.
        
        ### 응답 (YYYY-MM-DD HH:MM)
        Option A 컨셉 확정, 02_world_concept_sheet.md 파일 저장 완료
        
        ---
        ```
3.  **로그의 목적:** 
    * 전체 창작 과정의 추적 및 복원
    * 결정 과정의 기록 보존
    * 나중에 "왜 이렇게 결정했는지" 확인 가능
