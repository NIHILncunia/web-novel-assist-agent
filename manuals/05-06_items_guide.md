# 05-06. 아이템 설정 가이드 (Items Guide)

> **작성일:** 2026-01-04
> **수정일:** 2026-01-04

## 1. 개요
세계관의 **무기, 아티팩트, 도구, 화폐** 등 사물에 대한 템플릿입니다.

---

## 2. 에이전트 작업 지침

### 2-0. 아이템 분류 규칙 (필수)
**⚠️ 중요:** 아이템을 생성할 때는 반드시 **skills create_item**을 사용하여 구조화된 데이터로 변환합니다.

1. **스킬 참조:** **skills create_item**의 분류 규칙 인터뷰에 따라 다음 4가지 축을 판단합니다:
   - **Axis 1. 대분류 & 소분류:** 무기/방어구/장신구/도구/소모품/재료·기타
   - **Axis 2. 등급:** 일반/고급/희귀/고유/영웅/전설/신화 (영웅 이상은 아티팩트)
   - **Axis 3. 자아 여부:** 없음/잠재/각성
   - **Axis 4 & 5. 속성 & 피해 유형:** 물리/원소/신성·암흑/정신/기타, 참격/관통/타격/에너지 계열/기타

2. **분류 결과 저장:** 
   - 분류된 아이템의 요약 정보(테이블 형식)는 `data/아이템.md`에 저장합니다.
   - 아이템의 상세한 서사적 설명은 개별 파일(`00_bible/06_items/[Item_Name].md`)에 기록합니다.
   - **⚠️ 중요:** 템플릿(`.agent/skills/create_item/templates/06_items_template.md`)의 **"1. 정의 및 외형"** 섹션에 분류 정보(대분류, 소분류, 등급)를 포함하고, **"2. 기능"** 섹션에 속성, 피해 유형, 자아 정보를 포함하세요.
   - 자세한 내용은 아래 "2-0-1. 아이템 목록과 개별 파일의 관계" 섹션을 참조하세요.

3. **아이템 검색:** 아이템이 필요할 때는 먼저 `data/아이템.md` 파일에서 기존 아이템을 검색하여 재사용 가능한지 확인합니다.

### 2-0-1. 아이템 목록과 개별 파일의 관계

아이템은 **두 가지 형태**로 관리됩니다:

1. **중앙 저장소: `data/아이템.md`**
   - 프로젝트 전체에서 공유되는 중앙 아이템 저장소
   - 아이템의 분류 정보(대분류, 소분류, 등급, 자아, 속성, 피해 유형)를 테이블 형식으로 저장
   - 아이템을 생성할 때는 반드시 `data/아이템.md`에도 테이블 형식으로 추가
   - 아이템이 필요할 때는 먼저 `data/아이템.md`에서 기존 아이템을 검색하여 재사용 가능한지 확인

2. **개별 파일: `00_bible/06_items/[Item_Name].md`**
   - 아이템의 상세한 서사적 설명을 기록하는 개별 파일
   - 템플릿(`.agent/skills/create_item/templates/06_items_template.md`)을 사용하여 생성
   - **"1. 정의 및 외형"** 섹션에 분류 정보(대분류, 소분류, 등급)를 포함
   - **"2. 기능"** 섹션에 속성, 피해 유형, 자아 정보를 포함
   - 분류 정보는 `data/아이템.md`에도 테이블 형식으로 저장
   - 나머지 섹션(3~6)에는 아이템의 조건/사용법, 제약/대가, 역사적 사건, 비고 등 상세 내용을 서술

**작업 흐름:**
1. 아이템이 필요할 때 → `data/아이템.md`에서 검색
2. 기존 아이템이 적합하면 → 재사용 (개별 파일이 있으면 참조)
3. 새 아이템이 필요하면 → 분류 규칙 적용 → `data/아이템.md`에 테이블 추가 → 개별 파일 생성

### 2-1. 작성 원칙
1. **장르별 키워드 리스트 참조**
   - `data/word_list/` 폴더의 키워드 리스트를 참조하여 아이템 이름과 트레잇을 선택하세요.
   - 판타지: `fantasy.md`의 "3. 아이템 및 물품 (Items & Objects)", "4. 마법 및 어빌리티 (Magic & Abilities)" 섹션 참조
   - 무협: `martial_arts.md` (예정)

2. **능력에는 반드시 대가**
   - 강력한 아이템일수록 **사용 조건**과 **대가**가 커야 합니다.
   - 예: 전설의 검 → 사용 시 수명 감소, 사악한 자가 만지면 화상

3. **역사와 전설**
   - 중요한 아이템에는 **과거 이야기**가 있어야 합니다.
   - 누가 만들었나? 누가 사용했나? 어떤 사건에 연루되었나?

4. **외형 묘사의 중요성**
   - 독자는 아이템을 볼 수 없으므로 **구체적 묘사**가 필수입니다.
   - 크기, 색깔, 재질, 무게, 장식 등

5. **게임 아이템이 아님**
   - "+10 공격력" 같은 수치는 지양하세요.
   - 능력은 **서술적**으로 표현하세요.
   - 나쁜 예: "공격력 +50"
   - 좋은 예: "성인 남성의 머리를 일격에 절단할 수 있는 위력"

### 2-2. 주의사항

#### ⚠️ 피해야 할 것
- **만능 아이템:** 모든 걸 해결하는 아이템은 서사 파괴
- **대가 없는 파워:** 공짜 점심은 없습니다
- **의미 없는 아이템:** 서사에 기여하지 않는 아이템은 불필요
- **RPG 인벤토리:** 아이템을 무한정 가지고 다니면 비현실적

#### ✅ 해야 할 것
- **사용 조건:** 누구나 쓸 수 있나? 특정 조건이 필요한가?
- **소지 방법:** 어떻게 가지고 다니는가? (크기, 무게 고려)
- **파손 가능성:** 부서지거나 소모되는가?
- **희소성:** 세상에 몇 개나 있는가?

### 2-3. 아이템 등급별 체크리스트

#### 일반 아이템 (소모품, 도구)
- [ ] **가격**이 설정되었는가?
- [ ] **구입처**가 명확한가?
- [ ] **소모성**인가, 영구적인가?
- [ ] **무게/부피**가 현실적인가?

#### 마법 아이템 (마법 검, 포션 등)
- [ ] **마나 소모**가 있는가?
- [ ] **사용 횟수** 제한이 있는가?
- [ ] **부작용**이 있는가?
- [ ] **제작 방법**이 설정되었는가?

#### 아티팩트 (전설급, 유니크 아이템)
- [ ] **유일무이**한 이유가 있는가?
- [ ] **과거 소유자**들의 이야기가 있는가?
- [ ] **사용 조건**이 까다로운가?
- [ ] **강력한 대가**가 있는가?
- [ ] **파괴 방법**이 있는가?
- [ ] **서사의 중요 기점**에 등장하는가?

### 2-4. 공통 체크리스트
- [ ] **외형 묘사**가 구체적인가?
- [ ] **기능**이 명확한가?
- [ ] **사용 조건/방법**이 설명되었는가?
- [ ] **제약/대가**가 설정되었는가?
- [ ] **희소성**이 명시되었는가?
- [ ] **역사/전설**이 있는가? (중요 아이템의 경우)
- [ ] 게임 시스템처럼 느껴지지 않는가?
- [ ] 이 아이템이 **서사에 어떤 역할**을 하는가?
  - 플롯 도구? 캐릭터 성장 수단? 갈등 유발 요소?
