# 05-04. 단체 설정 가이드 (Organizations Guide)

> **작성일:** 2026-01-04
> **수정일:** 2026-01-04

## 1. 개요
세계관을 구성하는 **단체, 길드, 학회, 비밀결사** 등 조직에 대한 템플릿입니다.

---

## 2. 에이전트 작업 지침

### 2-1. 작성 원칙
1. **목적이 명확해야 함**
   - 조직의 **존재 이유**가 분명해야 합니다.
   - 나쁜 예: "그냥 모험가 길드"
   - 좋은 예: "전쟁 고아들을 모아 정보원으로 훈련시키는 조직"

2. **계층과 권력 구조**
   - 누가 명령하고, 누가 따르는가?
   - 의사 결정은 어떻게 이루어지는가?

3. **내부 갈등**
   - 건강한 조직도 내부 갈등이 있습니다.
   - 파벌, 권력 다툼, 이념 차이 등을 설정하세요.

4. **외부와의 관계**
   - 이 조직은 다른 조직/국가와 어떤 관계인가?
   - 동맹, 적대, 경쟁, 중립 등을 명확히 하세요.

### 2-2. 주의사항

#### ⚠️ 피해야 할 것
- **일사불란한 조직:** 모두가 하나 같이 움직이는 조직은 비현실적
- **무적의 조직:** 약점 없는 조직은 긴장감 파괴
- **목적 없는 존재:** "그냥 있는" 조직은 의미 없음
- **이름만 다른 복사본:** 모든 길드가 비슷하면 구별 안 됨

#### ✅ 해야 할 것
- **구체적 활동:** 이 조직은 일상적으로 무엇을 하는가?
- **가입 조건:** 누구나 들어올 수 있는가? 조건이 있는가?
- **배신자/탈퇴자:** 조직을 떠나면 어떻게 되는가?
- **자금원:** 돈은 어디서 나오는가?

### 2-3. 조직 유형별 체크리스트

#### 공개 조직 (길드, 학회 등)
- [ ] **가입 절차**가 명확한가?
- [ ] **회비/기부금** 시스템이 있는가?
- [ ] **공개된 목적**이 설정되었는가?
- [ ] **본부 위치**가 명시되었는가?

#### 비밀 조직 (암살단, 비밀결사 등)
- [ ] **비밀 유지 수단**이 있는가?
- [ ] **모집 방법**이 설정되었는가?
- [ ] **배신자 처리 방법**이 있는가?
- [ ] **진짜 목적**이 숨겨져 있는가?

#### 종교 조직
- [ ] **신앙 대상**이 명확한가?
- [ ] **교리/율법**이 있는가?
- [ ] **성직자 계급**이 있는가?
- [ ] **이단/배교자** 처리 방식은?

### 2-4. 공통 체크리스트
- [ ] 이 조직의 **설립 이유**가 설득력 있는가?
- [ ] **권력 구조**가 명확한가?
- [ ] **내부 갈등**이 설정되었는가?
- [ ] **자금원/수입원**이 논리적인가?
- [ ] **약점**이 존재하는가?
- [ ] 다른 세력과의 **관계**가 명확한가?
- [ ] 이 조직이 **서사에 어떤 역할**을 하는가?
  - 주인공의 아군? 적? 중립?

# {{Organization_Name}}

## 1. 개요 (Overview)
* **조직 유형:** 길드 / 결사 / 종교 / 정부 / 상단 / 용병단 / 기타
* **핵심 테마:** 한 단어로 표현하는 이미지
* **한 줄 정의:** 조직을 한 줄로 요약
* **인원 규모:** 대략적인 구성원 수

## 2. 목적 (Purpose)
* **명시적 목적:** 대외적으로 내세우는 명분 (강령)
* **숨겨진 목적:** 실제 추구하는 이익이나 비밀 목표
* **설립 배경:** 창설자, 설립 시기, 역사적 유래

## 3. 구조 및 규율 (Structure & Rules)
* **조직 구조:** 지휘 체계, 부서, 파벌, 의사결정 방식
* **주요 인물:** 수장, 간부, 핵심 인물
* **가입 조건:** 자격 요건, 입단 시험, 가입비
* **탈퇴/배신 규율:** 이탈 시 페널티, 처벌 규정

## 4. 활동 (Activities)
* **주요 활동:** 비즈니스 모델, 주요 임무, 일상 업무
* **활동 지역:** 본거지, 영향권, 지부 위치
* **활동 방식:** 공개/비밀, 합법/불법, 활동 수단
* **자금원:** 운영 자금 조달 방식

## 5. 조직 트레잇 (Organization Traits)
> **💡 가이드:** `data/traits/` 폴더 참조 (조직의 성향, 특기 등)

| 트레잇명 | 분류 | 설명/비고 |
|:---|:---|:---|
|      |           |      |

## 6. 관계 (Relations)
> **참고:** `09_relationships_template.md` (관계도) 문서와 연동됩니다.
* **동맹 (Allies):** 협력 관계, 우호 세력
* **적대 (Enemies):** 경쟁, 전쟁 중인 세력
* **중립/거래 (Neutral):** 비즈니스 파트너, 이해관계자

## 7. 상태 및 역사 (Status & History)
* **현재 상태:** 전성기 / 쇠퇴기 / 위기 / 확장 중
* **주요 역사:** 조직과 관련된 사건 연대기

## 8. 기타
* **비고:** 설정 메모, 비밀 정보
