# 05-05. 국가 설정 가이드 (Nations Guide)

> **작성일:** 2026-01-04
> **수정일:** 2026-01-04

## 1. 개요
세계관을 구성하는 **국가, 제국, 왕국, 공국** 등 정치적 단위에 대한 템플릿입니다.

---

## 2. 에이전트 작업 지침

### 2-1. 작성 원칙
1. **국가는 생명체처럼**
   - 국가도 탄생, 성장, 쇠퇴, 멸망의 과정을 겪습니다.
   - 현재 어느 단계인지 명시하세요.

2. **정치 체제와 실권자**
   - 명목상 통치자와 실질적 권력자가 다를 수 있습니다.
   - 예: 왕은 꼭두각시, 재상이 실권

3. **내부 모순**
   - 완벽한 국가는 없습니다. 모든 국가에는 내부 갈등이 있습니다.
   - 계급 갈등, 종교 갈등, 지역 갈등 등

4. **지리적 특성이 국가를 만듦**
   - 섬나라는 해양 강국, 산악 지역은 방어 유리
   - 지리가 정치, 경제, 군사에 미치는 영향을 고려하세요

### 2-2. 주의사항

#### ⚠️ 피해야 할 것
- **일차원적 국가:** "악의 제국", "정의의 왕국" 같은 단순화 금지
- **현대 국가 복사:** 민주주의, 자본주의 같은 현대 개념 남발 주의
- **경제 무시:** 전쟁만 하고 경제는 신경 안 쓰는 국가는 비현실적
- **국민 무시:** 통치자만 있고 백성이 없는 국가는 텅 빈 껍데기

#### ✅ 해야 할 것
- **주요 산업:** 이 국가는 무엇으로 먹고사는가?
- **군사력 수준:** 병력 규모, 주력 병종
- **외교 관계:** 동맹국, 적대국, 무역 파트너
- **문화적 특색:** 음식, 의상, 축제 등

### 2-3. 정치 체제별 체크리스트

#### 군주제 (왕국, 제국)
- [ ] **왕위 계승 방식**이 정해졌는가? (장자, 선출, 실력)
- [ ] **귀족 계급**이 있는가?
- [ ] **왕권의 강도**는? (절대 왕정, 입헌 군주제)
- [ ] **반란/쿠데타** 가능성은?

#### 공화제/의회제
- [ ] **선출 방식**이 있는가?
- [ ] **투표권**은 누구에게 있는가?
- [ ] **임기**가 정해졌는가?
- [ ] **부패** 수준은?

#### 신정 정치
- [ ] **신/종교**가 무엇인가?
- [ ] **성직자** 권력은?
- [ ] **이교도** 처우는?
- [ ] **종교 재판**이 있는가?

### 2-4. 공통 체크리스트
- [ ] **건국 이유/역사**가 있는가?
- [ ] **영토 범위**가 명확한가?
- [ ] **인구 규모**가 설정되었는가?
- [ ] **주요 도시**가 3개 이상 있는가?
- [ ] **경제 구조**가 논리적인가?
- [ ] **군사력**이 국력에 비례하는가?
- [ ] **내부 갈등**이 설정되었는가?
- [ ] **대외 관계**가 명확한가?
- [ ] **쇠퇴 조짐**이나 **성장 동력**이 보이는가?
- [ ] 이 국가가 **서사에 어떤 역할**을 하는가?
