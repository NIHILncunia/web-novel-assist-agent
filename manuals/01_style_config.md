# [Step 1] 집필 스타일 및 선호도 설정 (Configuration)

> **작성일:** 2026-01-04
> **수정일:** 2026-01-08

## 1. 개요
이 문서는 **'노블(Novel)'**이 텍스트를 생성할 때 반드시 준수해야 할 **화자(Speaker)의 목소리와 서술 방식**을 정의합니다. 모든 창작 단계(특히 Step 9, 10)에서 이 설정값은 최우선적으로 적용됩니다.

이 매뉴얼은 두 부분으로 구성됩니다.
- **Part 1: 사용자 워크플로우:** 사용자와 AI가 상호작용하며 스타일을 설정하는 절차입니다.
- **Part 2: AI 내부 작업 지침:** AI가 '문체 분석' 등 내부 작업을 수행할 때 따르는 상세 지침입니다.

---

## Part 1. 사용자 워크플로우 (User Workflow)
에이전트는 Step 1을 시작할 때, 다음의 절차에 따라 사용자의 문체를 확정하고 `style_profile.md` 파일을 생성합니다.

### Phase 1. 문체 설정 방식 제안 (AI's First Question)
에이전트는 사용자에게 가장 먼저 아래의 선택지를 제시하여 문체 설정 방식을 결정합니다.

> **[AI 초기 질문 예시]**
> "마스터, 작품의 전체적인 문체를 설정하겠습니다. 어떤 방식으로 진행할까요?"
>
> 1.  **프리셋에서 선택:** 미리 정의된 서술 방식(외면 묘사 중심, 내면 심리 중심, 균형 잡힌 표준 웹소설) 중에서 선택합니다. (가장 빠르고 쉬운 방법)
> 2.  **기존 작품 스타일 참조:** 분석된 특정 작품(예: 나 혼자만 레벨업)의 스타일을 가져옵니다.
> 3.  **직접 상세 설정:** 18가지 문체 설문지를 통해 세부적으로 직접 설정합니다.

### Phase 2. 선택에 따른 `style_profile.md` 생성

#### **1. '프리셋에서 선택' 시:**
1.  에이전트는 `manuals/01-2_style_presets.md`를 참조하여 각 프리셋의 특징을 사용자에게 간단히 설명합니다.
2.  사용자가 "외면 묘사 중심"을 선택하면, 해당 프리셋의 18축 답변을 `style_profile.md` 파일에 즉시 생성하고 저장합니다.
3.  사용자에게 생성된 프로필을 보여주고, 추가 수정이 필요한지 확인합니다.

#### **2. '기존 작품 스타일 참조' 시:**
1.  에이전트는 `library/style_examples/` 폴더에 분석된 작품 목록을 제시합니다.
2.  사용자가 특정 작품(예: 전지적 독자 시점)을 선택하면, 해당 작품의 `_style_analysis.md` 파일의 분석 결과를 바탕으로 `style_profile.md` 파일을 생성합니다.

#### **3. '직접 상세 설정' 시:**
1.  에이전트는 `manuals/01-1_style_survey.md`의 18가지 설문을 사용자에게 순차적으로 질문합니다.
2.  사용자의 답변을 모두 취합하여 `style_profile.md` 파일을 생성합니다.

### Phase 3. 스타일 프로필 확정 및 저장
모든 과정의 최종 결과물은 **`style_profile.md`** 파일입니다. 이 파일은 `_templates/Sheets/01_style_profile_template.md` 템플릿 양식을 기반으로 생성되며, `00_bible/` 폴더에 저장됩니다. 이후 모든 집필 단계(Step 9, 10)에서 저의 서술 방식을 결정하는 최우선 지침이 됩니다.

## Part 2. AI 내부 작업 지침 (AI Internal Guidelines)

### 2-1. 문체 분석 작업 지침 (Style Analysis Workflow)
이 섹션은 `library/style_examples/`의 문체 분석 파일을 생성하거나, 사용자가 제공한 샘플 텍스트의 스타일을 분석할 때 사용하는 AI의 내부 작업 지침입니다.

#### 1단계: 원문 수집
**목적:** 분석할 작품의 원문을 수집하여 저장합니다.
**수집 대상:** 사용자가 제공한 텍스트 샘플 또는 유명 웹소설. (최소 3~5화 분량 권장)
**저장 위치:** `library/novel_sample_texts/[작품명]/`

#### 2단계: 문체 특징 분석
**목적:** 수집한 원문을 바탕으로 작품의 문체 특징을 체계적으로 분석합니다.
**분석 항목:**
1.  **문장 호흡:** 문장 길이, 단문/장문 비율, 문장 구조.
2.  **어조:** 건조/감성, 냉소/열정, 유머/진지 등.
3.  **묘사 밀도:** 대사 vs 지문 비율, 장면 vs 행동 묘사 비율.
4.  **특수 습관:** 자주 쓰는 접속사/어미, 반복 패턴.
5.  **시점 및 서술 방식:** 1인칭/3인칭, 서술자 태도 등.

#### 3단계: 분석 결과 저장
**목적:** 분석한 문체 특징을 `_style_analysis.md` 형식으로 구조화하여 저장합니다.
**저장 위치:** `library/style_examples/[작품명]_style_analysis.md`
**핵심 내용:**
- 각 분석 항목에 대한 상세 설명 및 예시 문장.
- AI가 해당 문체를 모방하기 위한 구체적인 행동 규칙(Actionable Rules).
- **Before & After:** 일반적인 문장을 분석 대상 스타일로 재작성한 비교 예시.

### 2-2. 기타 적용 규칙
1.  **파일 우선 참조:** 집필(Step 9)을 시작하기 전, 반드시 해당 프로젝트의 `style_profile.md` 파일을 읽어 문체를 로드합니다.
2.  **영구 지속:** 한 번 생성된 프로필은 사용자가 "스타일 변경"을 명령하기 전까지 프로젝트 내내 유지됩니다.
3.  **오염 방지:** 에이전트 본연의 말투(AI스러운 딱딱함)가 섞이지 않도록 자가 검열을 거칩니다.

## 3. 데이터 저장 및 관리
(이 섹션은 폴더 생성, 파일 저장 위치, 대화 로그, 작품명 확정 등 프로젝트 공통 규칙을 다룹니다.)

### 3-1. 프로젝트 초기 설정 자동화 (필수 규칙)
- **트리거:** 만약 현재 진행 중인 프로젝트 폴더가 없는 상태에서 마스터가 Step 1 시작을 요청하면, 이는 새 프로젝트 시작으로 간주합니다.
- **자동 생성:** 에이전트는 **즉시, 자동으로** `manuals/00_idea_generation.md`에 명시된 것과 동일한 초기 폴더 및 파일 구조를 생성해야 합니다.
    1. 마스터에게 **가제(임시 제목)**를 질문하여 폴더명을 얻습니다.
    2. `incubator/[가제_컨셉명]/` 폴더를 생성합니다.
    3. 그 안에 `00_bible/`, `01_planning/`, `02_drafts/` 폴더와 `00_conversation_log.md` 파일을 생성합니다.
- **스타일 프로필 저장:** 이어서 생성되는 `style_profile.md` 파일은 `incubator/[가제_컨셉명]/00_bible/style_profile.md` 위치에 저장됩니다.

### 3-2. 통합 대화 로그
- 모든 상호작용은 `manuals/99_common_logger.md` 지침에 따라 `[작업폴더]/00_conversation_log.md`에 기록됩니다.
