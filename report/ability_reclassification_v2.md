# [Report] 어빌리티 권역 재분류 보고서 (Ability Reclassification)

> **목적:** 2026-02-02 업데이트된 `Ability Syntax v2` (사격계, 약화계, 전술 권역 추가)에 따라 기존 어빌리티를 재분류한 현황입니다.
> **비고:** 이 문서는 기존 데이터를 토대로 자동으로 분류한 **가상 시뮬레이션 결과**입니다.

---

## 📊 요약 (Summary)

*   **물리 권역:** [타격계]에 섞여 있던 활/총/포격 기술을 **[사격계]**로 독립시켰습니다.
*   **전술 권역:** 정신/물리 권역에 흩어져 있던 지휘, 함성, 교섭 스킬을 **[전술 권역]**으로 통합했습니다.
*   **특수 권역:** 저주와 상태이상을 거는 스킬들을 **[약화계]**로 분류했습니다.

---

## A. 물리 권역 (Physical Domain)
> **변경점:** `[사격계]` 신설. 투사체를 발사하는 기술이 타격계에서 분리됨.

### **① 타격계 (Striking)**
*   **돌진** ([신법]에서 이동 성향이 강하나, 충돌 공격이므로 타격 요소 포함)
*   **암살** ([무기] - [일점])
*   **음속 펀치** ([신체] - [연격])
*   **철권** ([주먹] - [파쇄])
*   **뼈 부수기** ([신체] - [파쇄])
*   **팔극권** ([무술] - [파쇄])
*   **비검** ([검술] - [일점])
*   **무명검** ([검술] - [활용])
*   **뱀의 연격** ([신체] - [연격])

### **② 사격계 (Shooting) [NEW]**
> *기존 [타격-투척]이나 [타격-일점]에서 이동된 항목*
*   **연발 사격** (기존: [물리:활]-[타격]-[연격]) → **[물리:활]-[사격]-[연사]**
*   **원거리 포격** (기존: [물리:무기]-[타격]-[투척]) → **[물리:무기]-[사격]-[곡사]**
*   **침묵의 저격** (기존: [물리:무기]-[타격]-[일점]) → **[물리:무기]-[사격]-[조준]**
*   **초장거리 저격** → **[물리:무기]-[사격]-[조준]**
*   **부동 사격** → **[물리:무기]-[사격]-[태세]**
*   **발로 창 쏘기** → **[물리:창]-[사격]-[투척]** (발사체 개념)
*   **투척 (단검)** → **[물리:무기]-[사격]-[연사]**

### **③ 신법계 (Maneuver)**
*   **긴급 회피/이탈** ([신체] - [회피])
*   **입체 기동** ([장비] - [도약])
*   **공중 기동** ([신체] - [도약])
*   **음주 가무** ([알코올] - [회피])

### **④ 육체계 (Physiology)**
*   **과부하** ([신체] - [과부하])
*   **아드레날린 부스트** ([호르몬] - [과부하])
*   **부동의 자세** ([신체] - [강화])

### **① 지휘계 (Command)**
*   **전투 함성** (기존: [정신:소리]-[강화]-[고양]) → **[전술:소리]-[지휘]-[호령]**
*   **왕의 호령** (기존: [정신:패기]-[방출]-[파동]) → **[전술:패기]-[지휘]-[호령]**
*   **최후의 돌격** (기존: [물리:군단]-[신법]-[돌진]) → **[전술:군단]-[지휘]-[호령]** (군단 전체 돌격 명령)
*   **현상금 선포** (기존: [정신:재물]-[규칙]-[지정]) → **[전술:재물]-[지휘]-[지정]**
*   **왕의 깃발** (기존: [마법:오라]-[제어]-[영역]) → **[전술:깃발]-[지휘]-[진형]**
*   **해적의 노래** (기존: [정신]) → **[전술:노래]-[지휘]-[호령]**

### **② 교섭계 (Negotiation)**
*   **도발의 외침** (기존: [정신:소리]-[간섭]-[조작]) → **[전술:소리]-[교섭]-[도발]**
*   **권주 (술 권하기)** (기존: [정신:대화]-[간섭]-[평정]) → **[전술:대화]-[교섭]-[회유]**
*   **매수** (기존: [정신:재물]-[간섭]-[주입]) → **[전술:재물]-[교섭]-[회유]**
*   **인질극** (기존: [특수]) → **[전술:행동]-[교섭]-[협박]**
*   **위협적인 과시** (기존: [정신:행동]-[간섭]-[조작]) → **[전술:행동]-[교섭]-[위압]**
*   **결투 신청** (기존: [정신:명예]-[규칙]-[강제]) → **[전술:명예]-[교섭]-[강제]**
