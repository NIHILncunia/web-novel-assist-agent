---
description: 외부 국가, 문명, 단체 컨셉 추출
---

1. 사용자에게 분석할 대상(국가, 도시, 길드, 가문 등)의 이름과 출처 작품/역사(예: "반지의 제왕의 곤도르", "조선 왕조")를 요청합니다.
2. 웹 검색을 통해 대상의 상세 정보를 수집합니다. 정치 체제, 사회 구조, 지리적 환경, 외교 정책, 주요 사건에 집중하십시오.
   - 쿼리: `[대상 이름] [출처] 분석 특징 제도`
3. 다음의 지침 파일을 읽고 각 규칙을 숙지합니다:
   - `prompt/02_refinement/extract_concepts_from_group.md` (집단 분석 및 특성 추출 규칙)
4. 검색 결과와 지침을 바탕으로 다음 내용을 포함하는 분석 리포트를 생성합니다:
   - **4대 핵심 카테고리:** 군집(Social), 외교(Diplomacy), 경영(Management), 지역환경(Region) 관점에서 분석.
   - **핵심 컨셉 키워드:** 3~5개 식별.
   - **데이터 생성:** 각 키워드 별로 아래 수량을 엄격히 준수하십시오.
     - **[직접 추출 (Extraction)]**: 원작 반영, **반드시 3개**.
     - **[브레인스토밍 (Expansion)]**: 파생 아이디어, **반드시 5개**.
     - **총합**: 키워드당 **8개**의 아이디어(특성 또는 능력)를 생성해야 합니다.
   - **주의사항:** 특성(Trait)과 능력(Skill)을 모두 생성할 수 있습니다. 상태/성질은 특성으로, 기술/행동은 능력으로 분류하십시오.
5. 최종 응답 생성 전, 스스로 다음 사항을 검증합니다 (Self-Correction):
   - **[메타데이터]**: 리포트 상단에 `분석 대상`, `출처`, `작성일`, `상태`가 포함된 메타데이터 블록이 있는가?
   - 각 키워드마다 '직접 추출' 3개 + '브레인스토밍' 5개가 채워졌는지 확인하십시오.
   - 성격에 따라 특성과 능력이 적절히 배분되었는지 확인하십시오.

6. **[자가 점검 (Self-Verification)]**: 리포트 작성 완료 후, 반드시 다음 절차를 수행합니다:
   - `data/traits/` 및 `data/ability/` 폴더의 파일을 읽어 기존 데이터를 확인합니다.
   - 리포트에서 생성한 모든 특성과 능력의 **이름**과 **설명(효과)**을 기존 데이터와 대조합니다.
   - **중복 판단 기준:**
     * 이름이 정확히 일치하는 경우 → 중복으로 판단
     * 이름은 다르지만 설명의 핵심 내용이 거의 동일한 경우 → 중복으로 판단
   - 중복이 발견된 항목은 해당 항목 옆에 **`(이미 존재)`** 괄호 표기를 추가합니다.
   - 중복 항목은 사용자에게 전달하되, 데이터 적용 시에는 추가하지 않습니다.

7. 최종 응답 출력:
   - **[파일명]**: 저장할 파일명을 `[출처(영문)]_[대상명(영문)].md` 형식으로 제안합니다. (예: `history_joseon.md`)
   - 중복 표기가 포함된 리포트를 사용자에게 전달합니다.
   - 모든 출력은 반드시 한글로 작성하십시오.
