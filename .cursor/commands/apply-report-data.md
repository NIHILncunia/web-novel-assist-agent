# 분석 리포트 데이터 적용 및 아카이빙 워크플로우

리포트에서 추출된 특성/능력을 `data/traits/`와 `data/skill/`에 적용하고, 완료 후 자동으로 아카이브로 이동합니다. 중복 검사를 포함합니다.

## 작업 순서

### Step 1: 리포트 확인
1. 사용자로부터 적용할 리포트 파일의 경로를 확보합니다.
   - 예: `report/concept_analyze/character/fate_stay_night_saber.md`
   - 또는: `archive/report/concept_analyze/character/fate_stay_night_saber.md`
2. 리포트 파일이 존재하는지 확인합니다.

### Step 2: 중복 검사 실행
1. `tools/check_duplicates.py` 스크립트를 실행합니다.
   - 명령어: `uv run python tools/check_duplicates.py [리포트_경로]`
2. 스크립트 결과를 확인합니다:
   - **중복 발견 시:** 사용자에게 중복 항목 목록을 보여주고, 계속 진행할지 확인합니다.
   - **중복 없음:** Step 3으로 진행합니다.

### Step 3: 데이터 추출 및 분류
1. 리포트에서 특성/능력을 추출합니다:
   - `**[특성] 이름**` 형식의 항목들
   - `**[발동] 이름**` 형식의 항목들
   - `**[지속] 이름**` 형식의 항목들
2. **중복 표기 확인:**
   - 각 항목에 `(이미 존재)` 표기가 있는지 확인합니다.
   - **중복 표기가 있는 항목은 제외하고** 신규 항목만 추출합니다.
3. 각 항목의 `**분류:**` 필드를 확인하여 대상 파일을 결정합니다.
   - 예: `data/traits/10_정신.md` → `data/traits/10_정신.md`
   - 예: `data/skill/발동.md` → `data/skill/발동.md`

### Step 4: 데이터 적용
1. 각 분류 파일에 대해:
   - 해당 파일을 읽습니다.
   - 파일 끝에 새로운 항목을 추가합니다.
   - 마크다운 테이블 형식을 유지합니다.
2. **특성 (Traits):**
   - 형식: `| **이름** | 설명 |`
   - 파일: `data/traits/[분류파일].md`
3. **발동 능력:**
   - 형식: `| **이름** | 계통 | 대상 | 피해 유형 | 상태 이상 유형 | 설명 |`
   - 파일: `data/skill/발동.md`
4. **지속 능력:**
   - 형식: `| **이름** | 계통 | 대상 | 피해 유형 | 상태 이상 유형 | 설명 |`
   - 파일: `data/skill/지속.md`

### Step 5: 완료 확인
1. 적용된 항목 수를 확인합니다.
2. 사용자에게 결과를 알립니다:
   - 적용된 특성 개수
   - 적용된 발동 능력 개수
   - 적용된 지속 능력 개수

### Step 6: 리포트 아카이빙 (자동)
데이터 적용이 완료되면 리포트를 자동으로 아카이브로 이동합니다.

1. **리포트 메타데이터 수정:**
   - 리포트 내용 상단의 메타데이터 블록을 수정합니다.
   - `> **상태:** [작성 중/작성 완료 등]` 부분을 `> **상태:** 완료 (Archived)` 로 변경합니다.
   - `> **수정일:**` 필드에 아카이브 날짜를 추가합니다. (예: `> **수정일:** 2026-01-20 (데이터 적용 및 아카이브)`)

2. **아카이브 경로 생성:**
   - 원본 경로의 루트 앞에 `archive/`를 추가하여 구조를 유지합니다.
   - 예: `report/concept_analyze/character/fate_stay_night_saber.md` → `archive/report/concept_analyze/character/fate_stay_night_saber.md`
   - 필요한 디렉토리가 없으면 생성합니다.

3. **아카이브 파일 생성:**
   - 수정된 리포트 내용을 아카이브 경로에 저장합니다.
   - 파일이 안전하게 생성되었는지 확인합니다.

4. **원본 파일 삭제:**
   - 아카이브 파일이 정상적으로 생성되었음을 확인한 후, 원본 파일을 삭제합니다.
   - 명령어: `rm "[원본 파일 경로]"` 또는 파일 삭제 도구 사용

5. **완료 알림:**
   - 사용자에게 다음을 알립니다:
     - 데이터 적용 완료 (적용된 항목 수)
     - 리포트가 아카이브로 이동되었음
     - 아카이브 경로

## 주의사항

- **중복 처리:** 리포트에 `(이미 존재)` 표기가 있는 항목은 자동으로 제외됩니다. 중복 검사 스크립트(`check_duplicates.py`)도 실행하되, 리포트의 자가 점검 결과를 우선합니다.
- **파일 형식:** 마크다운 테이블 형식을 정확히 유지해야 합니다.
- **설명 정제:** 리포트의 설명에서 원작 고유명사나 저작권 관련 용어를 제거하고 범용적으로 작성합니다.
- **아카이브 자동화:** 데이터 적용이 성공적으로 완료되면 반드시 아카이브 처리를 수행합니다. 사용자 확인 없이 자동으로 진행됩니다.
