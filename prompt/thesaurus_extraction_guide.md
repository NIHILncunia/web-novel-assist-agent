# 시소러스(Thesaurus) 키워드 추출 가이드

이 가이드는 `library/references/Thesaurus` 폴더에 있는 PDF 파일들로부터 데이터를 추출하여 `data/word_list/Thesaurus` 폴더의 마크다운 파일에 정리하는 기준을 제공합니다.

## 공통 지침
- **목표**: 각 도서의 구조화된 정보를 "키워드 리스트" 형태로 추출하여, AI가 글을 쓸 때 쉽게 참조할 수 있도록 합니다.
- **언어**: 원문(영어)의 의미를 살려 한국어로 번역하여 기록하는 것을 권장합니다.
- **도구**: `tools/extract_pdf_text.py`를 사용하여 텍스트를 추출한 후 정리합니다.
