# 기능: 스타일 설문 진행 (Conduct Style Survey)

> **작성일:** 2026-01-17

## 1. 개요
이 문서는 **Step 1. 집필 스타일 설정** 단계에서, 마스터와 인터뷰를 통해 작품의 문체(Tone & Manner)를 확정 짓는 지침입니다. `manuals/01-1_style_survey.md`에 정의된 18가지 축(Axis)을 기반으로 질문을 던지고, 결과를 `style_profile.md`로 저장합니다.

## 2. 인터뷰 프로세스

### Phase 1. 프리셋 제안 (Fast Track)
먼저 빠른 진행을 위해 프리셋을 제안합니다.
> "마스터, 문체 설정을 위해 18가지 질문을 하나씩 드리는 방법과, 미리 준비된 **'프리셋(간결체/만연체 등)'**을 적용하는 방법이 있습니다. 어느 쪽으로 하시겠습니까?"

### Phase 2. 상세 인터뷰 (Deep Dive)
사용자가 상세 설정을 원할 경우, 다음 그룹으로 나누어 진행합니다. (한 번에 3~4개 식 질문)

**Group A: 문장의 호흡 (Rhythm)**
- 01.문장 길이 / 07.문단 구분 / 08.수사법
- "문장은 짧고 간결한 게 좋으신가요, 아니면 길고 화려한 묘사를 선호하시나요?"

**Group B: 시점과 태도 (Perspective)**
- 02.서술 시점 / 13.서술 태도 / 16.내면 묘사
- "주인공의 내면을 깊게 파고들까요(1인칭), 아니면 영화처럼 보여줄까요(3인칭)?"

**Group C: 톤앤매너 (Tone)**
- 04.무게감 / 11.유머 / 17.자극성 수위
- "작품 분위기는 진지한가요, 유쾌한가요? 피 튀기는 묘사는 어느 정도까지 허용됩니까?"

**Group D: 어휘 정보 (Vocabulary)**
- 03.대사 비중 / 06.어휘 난이도 / 15.정보 전달 방식
- "대화 위주로 전개할까요? 설정 설명은 어떻게 녹이는 게 좋을까요?"

### Phase 3. 벤치마크 테스트 (Validation)
설정이 완료되면, 확정된 스타일로 **짧은 샘플 장면(300자 내외)**을 생성하여 보여줍니다.
> "설정하신 '냉소적인 주인공 1인칭 시점'으로 짧은 전투 씬을 써봤습니다. 어떠신가요?"

## 3. 데이터 저장 지침

1.  **대상 파일:** `00_bible/style_profile.md` (프로젝트 폴더 내)
2.  **내용 형식:**
    ```markdown
    # Style Profile: [Project Name]
    
    ## 1. Summary
    (한 줄 요약: 예 - "하드보일드한 느와르풍의 1인칭 시점")
    
    ## 2. Configuration Matrix
    | Axis ID | Name | Value | Description |
    | :--- | :--- | :--- | :--- |
    | 01 | 문장 길이 | A | 단문 위주 (속도감) |
    | ... | ... | ... | ... |
    
    ## 3. Style Guidelines
    * **DO:** (해야 할 것)
    * **DO NOT:** (하지 말아야 할 것)
    ```
