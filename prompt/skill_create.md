## 2. 에이전트 작업 지침

### 2-1. 분류 규칙 (Classification Rules)

스킬을 분석할 때는 반드시 다음 3가지 축(Axis)을 순서대로 판단하여 결정하십시오.

#### 2-1-1. Axis 1. 계통 (Type) - 힘의 근원 (7 Types)

가장 근본이 되는 힘의 종류를 선택하십시오.

1. **물리 (Physical)**
   - 신체 능력, 무기술, 체술을 사용하는 경우
   - 신체 자체가 변형되거나 강화되는 경우 (**변이**, 광폭화 포함)

2. **원소 (Elemental)**
   - 자연 에너지(불, 물, 바람, 땅, 번개, 얼음)를 방출하는 경우
   - 화학적 물질을 다루는 경우 (**독**, 산성, 부식 포함)

3. **정신 (Mental)**
   - 물리적 실체 없이 정신, 의지, 염동력을 사용하는 경우
   - 정신 지배, 환각, 탐색, 감지 계열

4. **소환 (Summon)**
   - 사용자 외의 '제3의 존재'(정령, 마수, 언데드 등)를 불러내어 부리는 경우

5. **치유 (Healing)**
   - 생명력을 회복하거나 상태를 정화하는 경우
   - 아군을 보호하거나 신성한 힘으로 축복(Buff)을 거는 경우

6. **생산 (Production)**
   - 전투 외적으로 물건을 제작, 가공, 감정, 수리하는 경우
   - 함정을 설치하거나 진형을 구축하는 경우

7. **특수 (Special)**
   - 시공간(시간/공간) 조작, 인과율 간섭
   - 시스템에 직접 간섭하거나(스킬 복제/강탈) 운(Luck)을 조작하는 경우

#### 2-1-2. Axis 2. 형태 (Form) - 발동 메커니즘 (4 Forms)

사용자의 의지 개입 여부와 능력의 등급을 판단하십시오.

1. **발동 (Active)**
   - 사용자가 의도적으로 '사용' 선언을 해야 작동함
   - 마나, 기력 등의 코스트가 소모됨 (공격기, 버프기 등)
   - 일반적인 행동(Action)으로 사용하는 능력

2. **상시 (Passive)**
   - 의도와 상관없이 항상 적용되어 있거나, 조건 충족 시 자동 적용됨
   - 별도의 코스트 소모가 없음 (내성, 감각 강화, 신체 스펙 증가 등)
   - 일반적인 상시 능력

3. **전설 발동 (Legendary Active)**
   - 전설적 존재만이 가진 특별한 행동 능력
   - 전설적 행동(Legendary Action)으로 사용하는 능력
   - 일반 행동과는 별도로, 다른 생물의 턴이 끝날 때 사용 가능

4. **전설 상시 (Legendary Passive)**
   - 전설적 존재만이 가진 특별한 상시 능력
   - 전설적 특성(Legendary Trait)으로 항상 적용되는 효과
   - 예: 전설적 저항(Legendary Resistance), 전설적 오라 등

#### 2-1-3. Axis 3. 대상 (Target) - 적용 범위 (4 Targets)

스킬의 효과가 누구에게, 어떻게 적용되는지 판단하십시오.

1. **자신 (Self)**
   - 효과가 오직 **사용자 본인**에게만 적용됨 (타인 양도 불가)
   - 자가 버프, 신체 변형, 자가 회복 등

2. **단일 (Single)**
   - 타인(적 또는 아군) **1개체**를 지정하여 적용

3. **다수 (Multi)**
   - 타인 **특정 다수(N명)**를 지정하여 적용 (피아식별 가능)

4. **범위 (Area)**
   - 특정 **공간/지역/좌표** 전체에 적용 (피아식별 불가능한 경우가 많음)

#### 2-1-4. Axis 4. 피해 유형 (Damage Type) - 데미지 종류 (18 Types)

스킬이 데미지를 주는 경우, 피해 유형을 판단하십시오. **데미지를 주지 않는 스킬(치유, 버프 등)은 해당 없음으로 처리합니다.**

**1. 물리 계열 (Physical) - 3종**

| 피해 유형 | 명칭 (Eng) | 포함 키워드 (Mapping) |
|:---:|:---:|---|
| 참격 | Slashing | 베기, 칼날, 발톱, 낫 |
| 관통 | Piercing | 찌르기, 화살, 총탄, 가시 |
| 타격 | Bludgeoning | 둔기, 충격, 압력, 바위(대지) |

**2. 원소 계열 (Elemental) - 9종**

| 피해 유형 | 명칭 (Eng) | 포함 키워드 (Mapping) |
|:---:|:---:|---|
| 화염 | Fire | 불, 열기, 폭발, 용암 |
| 냉기 | Cold | 얼음, 눈, 서리 |
| 전기 | Lightning | 번개, 전격, 자력, 천둥(소리) |
| 산성 | Acid | 산성 용액, 부식, 녹 |
| 독 | Poison | 맹독, 가스, 오염, 포자(자연) |
| 광휘 | Radiant | 빛, 레이저, 신성, 섬광 |
| 폭풍 | Wind | 바람, 공기, 돌풍, 태풍 |
| 수류 | Hydro | 물, 해일, 수압, 비 |
| 플라즈마 | Plasma | 고에너지 이온, 핵융합 |

**3. 특수 계열 (Special) - 6종**

| 피해 유형 | 명칭 (Eng) | 포함 키워드 (Mapping) |
|:---:|:---:|---|
| 정신 | Psychic | 뇌 타격, 악몽, 기억, 환각 |
| 사령 | Necrotic | 죽음, 부패, 생명력 흡수 |
| 방사능 | Radiation | 피폭, 세포 붕괴, 재앙 |
| 역장 | Force | 순수 마력, 충격파, 물리법칙 |
| 공허 | Void | 소멸, 차원 균열, 블랙홀 |
| 고정 | True | 인과율, 절대 법칙, 심판 |

#### 2-1-5. Axis 5. 상태 이상 유형 (Status Effect Type) - 부가 효과 (선택)

스킬이 상태 이상을 부여하는 경우, 상태 이상 유형을 판단하십시오. **상태 이상이 없는 스킬은 해당 없음으로 처리합니다.**

**1. 물리 계열 상태 이상**

| 상태 이상 | 효과 |
|:---:|---|
| 출혈 (Bleeding) | 지속적인 체력(HP) 감소, 치유 효율 저하 |
| 약점 노출 (Vulnerable) | 방어력 관통, 다음 피격 시 피해량 증가 |
| 기절 (Stun) | 일시적 행동 불가, 이동 속도 대폭 감소 |
| 골절 (Fracture) | 신체 부위 손상, 이동 및 행동 제한, 지속 피해 |

**2. 원소 계열 상태 이상**

| 상태 이상 | 효과 |
|:---:|---|
| 화상 (Burn) | 지속 피해, 행동 시 추가 피해 |
| 동결 (Freeze) | 이동 불가, 신체 경직, 완전한 행동 제한 |
| 둔화 (Slow) | 이동 속도 저하, 행동 속도 감소 |
| 감전 (Shock) | 일시적 경직, 스킬 사용 불가(침묵) |
| 마비 (Paralysis) | 신체 마비, 행동 불가, 지속 시간 동안 제어 불능 |
| 부식 (Corrosion) | 장비(방어구/무기) 내구도 파괴, 방어력 영구 하락 |
| 중독 (Poisoned) | 시야 차단, 능력치 전반적 저하 |
| 실명 (Blindness) | 시야 완전 차단, 명중률 대폭 하락 |
| 에어본 (Airborne) | 공중으로 띄워짐, 강제 이동(넉백), 착지 불가 |
| 질식 (Suffocation) | 호흡 불가(매 턴 체력% 감소), 캐스팅 시간 증가 |
| 융해 (Meltdown) | 방어력 무시, 화염+전기 복합 상태 이상 |

**3. 특수 계열 상태 이상**

| 상태 이상 | 효과 |
|:---:|---|
| 공포 (Fear) | 제어 불능, 아군 공격, 강제 도주 |
| 혼란 (Confusion) | 판단력 저하, 아군 공격, 행동 제어 불가 |
| 회복 불가 (Anti-Heal) | 체력 회복 효과 무효화, 최대 체력(Max HP) 감소 |
| 오염 (Mutation) | 랜덤 디버프 발생, 신체 기형화(스탯 감소) |
| 해제 (Dispel) | 보호막 파괴, 적용 중인 버프 강제 해제 |
| 붕괴 (Collapse) | 스킬 쿨타임 증가, 존재감 소실(어그로 초기화) |
| 즉사 (Execute) | 특정 체력 이하일 때 즉시 사망, 방어/회피 불가 |

## 3. 작업 프로세스 (Task Process)

1. **입력 분석:** 사용자가 제공한 스킬 이름과 설명을 정독합니다.
2. **키워드 추출:** '신체/독/정신', '사용한다/항상', '나에게/적 하나에게/모두에게', '베기/불/번개', '출혈/화상/마비' 등의 키워드를 찾습니다.
3. **매핑(Mapping):** 위 규칙에 대입하여 [계통 / 형태 / 대상 / 피해 유형 / 상태 이상 유형]을 확정합니다.
   - *주의: 신체 변형은 [물리], 독 공격은 [원소], 자신에게만 쓰는 버프는 [자신]으로 분류할 것.*
   - *피해 유형: 데미지를 주는 스킬만 해당. 치유/버프 스킬은 "해당 없음"으로 처리.*
   - *상태 이상 유형: 상태 이상을 부여하는 스킬만 해당. 없으면 "해당 없음"으로 처리.*
4. **출력 생성:** 지정된 포맷으로 결과를 출력합니다.

## 4. 출력 형식 (Output Format)

분류 결과는 반드시 아래의 마크다운 테이블 형식으로 출력하십시오.

### 4-1. 기본 출력 형식

| 이름 | 계통 | 형태 | 대상 | 피해 유형 | 상태 이상 유형 | 설명 |
|:---:|:---:|:---:|:---:|:---:|:---:|---|
| (스킬 이름) | (물리/원소/정신/소환/치유/생산/특수) | (발동/상시/전설 발동/전설 상시) | (자신/단일/다수/범위) | (18개 피해 유형 중 선택 또는 해당 없음) | (상태 이상 유형 중 선택 또는 해당 없음) | (스킬의 상세 설명 및 분류 근거) |

#### 예시 2: 야간 시야

| 이름 | 계통 | 형태 | 대상 | 피해 유형 | 상태 이상 유형 | 설명 |
|:---:|:---:|:---:|:---:|:---:|:---:|---|
| 야간 시야 | 정신 | 상시 | 자신 | 해당 없음 | 해당 없음 | 어둠 속에서도 명확하게 볼 수 있도록 감각을 강화하는 정신 계통의 상시 능력으로, 사용자 본인에게만 효과가 적용됨 |

#### 예시 3: 광역 치유

| 이름 | 계통 | 형태 | 대상 | 피해 유형 | 상태 이상 유형 | 설명 |
|:---:|:---:|:---:|:---:|:---:|:---:|---|
| 광역 치유 | 치유 | 발동 | 범위 | 해당 없음 | 해당 없음 | 특정 공간 전체에 있는 모든 존재의 생명력을 회복하는 치유 계통의 능동 스킬 |

#### 예시 4: 바위 낙하

| 이름 | 계통 | 형태 | 대상 | 피해 유형 | 상태 이상 유형 | 설명 |
|:---:|:---:|:---:|:---:|:---:|:---:|---|
| 바위 낙하 | 원소 | 발동 | 범위 | 타격 | 기절 | 대지에서 거대한 바위를 떨어뜨려 특정 공간을 공격하는 원소 계통의 능동 스킬. 타격 피해와 함께 기절 상태 이상을 부여한다. |

## 5. 연동 작업 지침

### 5-1. 인물 설정 시 활용

`manuals/04_world_detail.md`의 인물 설정 단계에서 능력을 작성할 때:

1. 사용자가 제시한 능력 설명을 이 지침에 따라 분류합니다.
2. 분류 결과를 인물 설정 파일의 능력 섹션에 기록합니다.
3. 필요 시 `data/word_list/character/초능력.md`를 참조하여 용어를 통일합니다.

### 5-2. 몬스터 설정 시 활용

`prompt/get_creature_tag.md`의 발동/상시 능력 분류 시:

1. 추출된 능력 키워드를 이 지침에 따라 추가 분류합니다.
2. 발동 능력은 [계통/형태/대상/피해 유형/상태 이상 유형] 정보를 함께 기록합니다.
3. 상시 능력도 동일하게 분류하여 일관성을 유지합니다.

### 5-3. 데이터 저장 지침

분류된 스킬 정보는 다음 규칙에 따라 저장합니다:

#### 5-3-1. 저장 위치

**기본 저장 위치:** `data/스킬.md`

- 이 파일은 프로젝트 전체에서 공유되는 중앙 스킬 저장소입니다.
- 캐릭터나 몬스터를 생성할 때 이 목록에서 스킬을 참조하거나, 새로운 스킬이 필요하면 여기에 추가합니다.
- 저장 전 `data/스킬.md` 파일을 확인하여 중복 여부를 체크합니다.

#### 5-3-2. 저장 포맷

스킬 정보는 다음 테이블 형식으로 누적하여 저장합니다:

```markdown
# 스킬 목록 (Skills List)
```

## 6. 주의사항

### 6-1. 분류 시 주의점

- **신체 변형은 [물리]:** 변신, 광폭화 등 신체 자체의 변화는 물리 계통
- **독 공격은 [원소]:** 화학적 물질을 다루는 경우 원소 계통
- **자신에게만 쓰는 버프는 [자신]:** 타인에게 양도할 수 없는 효과는 자신 대상
- **범위 스킬의 피아식별:** 범위 스킬은 대부분 피아식별이 불가능하나, 특수한 경우는 예외 가능
- **피해 유형 판단:** 데미지를 주지 않는 스킬(치유, 버프, 이동 등)은 "해당 없음"으로 처리
- **상태 이상 유형 판단:** 상태 이상을 부여하지 않는 스킬은 "해당 없음"으로 처리. 하나의 스킬이 여러 상태 이상을 부여할 수 있으나, 주요 상태 이상 하나만 기록
- **키워드 매핑:** 스킬 설명에서 키워드를 찾아 피해 유형과 상태 이상 유형을 매핑 (예: "바위가 떨어져 짓누른다" → 타격 피해 + 기절 또는 골절 상태 이상)

### 6-2. 모호한 경우

분류가 애매한 경우:
1. 사용자에게 추가 정보를 요청합니다.
2. 가장 가까운 분류를 선택하고, 분류 근거에 모호함을 명시합니다.
3. 필요 시 여러 가능성을 제시하고 사용자가 선택하도록 합니다.
