# 기능: 전설 및 신화 생성 (Lore Creation)

> **작성일:** 2026-01-17

## 1. 개요
이 문서는 세계관 내에 구전되는 **전설, 신화, 민담, 야사** 등을 설계하는 지침입니다. 단순한 옛날 이야기가 아니라, 현재의 서사에 영향(믿음, 복선, 떡밥)을 주는 요소를 생성합니다.

**주의:** 이 프롬프트는 '역사적 사실(History)'이 아닌, **'이야기(Story/Lore)'**를 생성합니다. (사실 여부와 무관한 믿음의 영역)

## 2. 인터뷰 프로세스 (5 Axes)

### Axis 1. 유형 (Type)
> "이 이야기는 어떤 형태입니까?"
- **옵션:** 창세 신화 / 영웅 전설 / 비극적 민담 / 저주 및 금기 / 예언 / 괴담

### Axis 2. 핵심 내용 (Core Story)
> "이야기의 줄거리는 무엇입니까?"
- **주인공:** (신, 영웅, 괴물 등)
- **주요 사건:** (세상을 만들거나, 용을 잡거나, 금기를 어김)
- **교훈/결말:** (권선징악, 비극적 결말, 열린 결말)

### Axis 3. 전승 방식 및 왜곡 (Transmission)
> "이 이야기는 어떻게 전해지며, 얼마나 믿을만 합니까?"
- **전승 수단:** 구전(노래), 경전, 벽화, 금서
- **신뢰도:** 절대적 진실로 여겨짐 / 헛소문 취급 / 반신반의
- **왜곡:** 원래 내용에서 어떻게 변질되었는가?

### Axis 4. 진실 (The Truth)
> "실제 진실은 무엇입니까? (마스터와 에이전트만 아는 비밀)"
- **Pack:** 전설은 과장되었거나, 사실은 정반대일 수 있습니다.
- **예:** 용이 공주를 납치한 게 아니라, 공주가 용을 타고 가출한 것이다.

### Axis 5. 현재 영향 (Current Impact)
> "이 이야기가 현재 시점의 주인공이나 세상에 어떤 영향을 줍니까?"
- **문화:** 축제, 관습, 욕설, 속담
- **플롯:** 주인공이 풀어야 할 수수께끼, 찾아야 할 유물, 피해야 할 장소

---

## 3. 데이터 저장 지침

1.  **대상 파일:** `00_bible/08_stories/[Lore_Name].md`
2.  **템플릿:** `_templates/world_detail/08_stories_template.md` (없을 경우 표준 양식 사용)
3.  **저장 규칙:**
    - 파일명은 `전설_[이름].md`, `신화_[이름].md` 형식을 권장합니다.

---

## 4. 출력 예시

```markdown
# 붉은 달의 저주 (Curse of the Red Moon)

## 1. 개요
붉은 달이 뜨는 밤에 숲에 들어가면 늑대인간이 된다는 민담.

## 2. 전승 내용
아이들에게 숲에 가지 말라고 경고하는 자장가로 전해짐.

## 3. 진실
실제로는 늑대인간이 아니라, 고대 뱀파이어 일족이 깨어나는 주기임. 늑대 소리는 그들을 피하기 위한 경보기였음.

## 4. 현재 영향
마을 사람들은 붉은 달이 뜨면 집 문을 걸어 잠그고 소금을 뿌림. 주인공은 이를 무시하고 나갔다가 뱀파이어와 조우함.
```
