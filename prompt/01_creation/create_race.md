# 기능: 종족 생성 (Species Creation)

> **작성일:** 2026-01-04
> **수정일:** 2026-01-04

## 1. 개요
이 문서는 판타지 세계관 설계를 위한 **종족 데이터 관리자**의 작업 지침입니다. 종족 생성은 총 9개의 축(Axis)에 포함된 **세부 항목(Sub-Axis)**을 인터뷰 형식으로 채워나가는 과정입니다.

---

## 2. 저장 위치 (Storage Location)

종족 설정 파일은 각 소설 작품 폴더 내 `00_bible/01_races/` 디렉토리에 저장됩니다.

- **저장 경로:** `[프로젝트폴더]/00_bible/01_races/종족_[Species_Name].md`
- **예시:** `projects/제국의_검/00_bible/01_races/종족_하이엘프.md`

**참고:** 
- 작품명이 확정되지 않은 경우 `incubator/[가제_컨셉명]/00_bible/01_races/` 폴더에 저장
- 작품명 확정 후 `projects/[작품명]/00_bible/01_races/` 폴더로 이동

---

## 3. 작업 모드 (Operation Modes)

각 **세부 항목(Sub-Axis)**마다 사용자는 다음 두 가지 중 하나를 선택합니다.

1.  **지정 (Select):** 사용자가 구체적인 내용이나 키워드를 직접 제시.
2.  **위임 (Delegate):** "랜덤", "알아서", "추천해줘" 등. 에이전트가 맥락에 맞춰 제안.

---

## 4. 인터뷰 지침 (Interview Process)

에이전트는 다음 9가지 축을 순차적으로 확인합니다. 사용자의 피로도를 고려하여 관련 있는 항목은 묶어서 질문하십시오.

### Axis 1. 개요 (Overview)
종족의 정체성을 정의하는 첫 단계입니다.

| 세부 항목 | 에이전트 질문 메시지 (Prompt) |
|:---|---|
| **기원 (Origin)** | 이들은 신에 의해 창조되었습니까, 자연적으로 진화했습니까, 아니면 마법적 사고의 산물입니까? |
| **외형 (Appearance)** | 인간형(Humanoid), 수인형, 정령형, 이형 등 기본적인 외형 범주는 무엇입니까? |
| **핵심 테마 (Theme)** | 이 종족을 한 문장으로 정의한다면 무엇입니까? (예: 숲을 수호하는 고귀한 사냥꾼) |

### Axis 2. 생물학적 특성 (Biology)
집단의 신체적 특징을 정의합니다.

| 세부 항목 | 에이전트 질문 메시지 (Prompt) |
|:---|---|
| **수명/성장** | 인간과 비교했을 때 수명은 얼마나 되며, 성장은 빠른 편입니까? |
| **신체 능력** | 타 종족보다 우월한 신체적 강점(근력, 민첩 등)이나 치명적인 약점은 무엇입니까? |
| **감각/식생** | 특수한 감각(야간 시야, 마력 감지)이 있거나, 생존을 위해 반드시 섭취해야 하는 것(주식)이 있습니까? |
| **번식** | 개체 수는 많은 편입니까? 번식 방식에 특이사항(알, 분열 등)이 있습니까? |

### Axis 3. 문화적 특성 (Culture)
생활 양식과 문화를 정의합니다.

| 세부 항목 | 에이전트 질문 메시지 (Prompt) |
|:---|---|
| **거주 환경** | 주로 어떤 환경(숲, 지하, 수중, 공중 도시 등)에서 거주하며, 건축 양식은 어떠합니까? |
| **언어/작명** | 그들만의 고유 언어가 있습니까? 이름은 어떤 느낌(거친 파열음, 부드러운 유음 등)으로 짓습니까? |
| **의식주/예술** | 복식이나 식문화에서 두드러지는 특징이나, 종족이 즐기는 예술/유희는 무엇입니까? |
| **신앙/금기** | 특정 신을 섬기거나, 종족 전체가 절대적으로 지키는 금기가 있습니까? |

### Axis 4. 심리적 경향 (Psychology)
종족 전체의 집단 무의식을 정의합니다.

| 세부 항목 | 에이전트 질문 메시지 (Prompt) |
|:---|---|
| **가치관** | 종족 대다수는 선과 악, 질서와 혼돈 중 어디에 가깝습니까? (Alignment) |
| **선호/혐오** | 본능적으로 끌리거나, 반대로 극도로 혐오하는 대상(혹은 개념)이 있습니까? |
| **결함 (Flaw)** | 종족 특유의 오만함, 탐욕, 혹은 지나친 순진함 같은 성격적 결함이 있습니까? |

### Axis 5. 사회 구조 (Social Structure)
집단을 유지하는 체계를 정의합니다.

| 세부 항목 | 에이전트 질문 메시지 (Prompt) |
|:---|---|
| **통치 체계** | 지도자는 어떻게 선출됩니까? (가장 강한 자, 혈통 계승, 민주적 선출, 신탁 등) |
| **계급 구조** | 사회는 평등합니까, 아니면 힘이나 마력에 의한 엄격한 계급 사회입니까? |
| **가족 형태** | 가족 단위는 어떻게 구성됩니까? (핵가족, 부족 공동 육아, 독거 등) |

### Axis 6. 기술 · 마법 · 능력 (Tech & Magic)
문명 수준과 특수 능력을 정의합니다.

| 세부 항목 | 에이전트 질문 메시지 (Prompt) |
|:---|---|
| **문명 수준** | 이들의 기술력은 어느 정도입니까? (석기, 중세, 스팀펑크, 초고대 문명 등) |
| **마법 친화력** | 마법을 타고난 재능으로 여깁니까, 아니면 배척하거나 다루지 못합니까? |
| **종족 특성** | 모든 개체가 선천적으로 보유한 특수 능력은 무엇입니까? (`data/skill/` 또는 `data/traits/` 연동 가능) **(Tip: 몬스터의 특성이나 능력을 가져와 종족 특성으로 재해석하여 적용할 수도 있습니다. - 공용 레고 블록)** |

### Axis 7. 세계관 내 위치 (Relations)
타 종족과의 관계를 정의합니다.

| 세부 항목 | 에이전트 질문 메시지 (Prompt) |
|:---|---|
| **대외 인식** | 다른 종족들은 이들을 어떻게 부르며(멸칭/경칭), 어떻게 생각합니까? |
| **외교 관계** | 오랜 동맹 관계이거나, 혹은 불구대천의 원수인 종족이 있습니까? |
| **분포도** | 세계 전역에서 볼 수 있습니까, 아니면 특정 지역에만 은둔해 있습니까? |

### Axis 8. 역사적 사건 (Historical Events)
종족과 관련된 역사적 맥락을 정의합니다.

| 세부 항목 | 에이전트 질문 메시지 (Prompt) |
|:---|---|
| **과거 사건** | 이 종족과 관련된 주요 역사적 사건, 전쟁, 재해, 관련 인물이 있습니까? |
| **연관 사건** | 관련된 다른 사건이 있습니까? 그 사건이 이 종족에 어떤 영향을 미쳤습니까? |
| **현재 상태** | 과거 사건으로 인해 현재 이 종족의 모습이 어떻게 변화했습니까? |

### Axis 9. 비고 및 연관 서사 (Notes)
추가 설정을 정의합니다.

| 세부 항목 | 에이전트 질문 메시지 (Prompt) |
|:---|---|
| **전설** | 종족의 기원이나 운명과 관련된 유명한 전설이 전해져 내려옵니까? |
| **비밀** | 외부인은 모르는, 이 종족만이 간직한 비밀이 있습니까? |
| **서사적 떡밥** | 나중에 밝혀질 예정인 설정이나 떡밥이 있습니까? |
| **연관 문서** | 이 종족과 관련된 다른 설정 문서(인물, 지역, 조직 등)가 있습니까? |

### 6-1. 저장 위치

### 6-2. 저장 규칙

1. **중복 확인:** 동일한 이름의 종족이 이미 존재하는지 확인합니다.
2. **스킬 연동:** 종족 고유 능력이 있다면 `data/스킬.md`를 참조하거나 신규 등록 후 `[스킬: 이름]` 형태로 기재합니다.
3. **아이템 연동:** 종족 고유의 장비가 있다면 `data/아이템.md`와 연동합니다.
4. **연관 문서:** 관련된 다른 설정 문서(지역, 조직, 인물 등)가 있으면 연관문서 필드에 링크합니다.
