# 기능: 특성 생성 및 분류 기준 (Trait Creation & Criteria)

> **작성일:** 2026-01-21
> **설명:** 13가지 특성 카테고리의 정의와, 특성(Trait)과 능력(Skill)을 구분하는 명확한 기준을 제시합니다.

## 1. 특성 vs 능력 구분 기준

세계관 데이터를 생성할 때, 해당 요소가 **'특성(Trait)'**인지 **'능력(Skill)'**인지 헷갈린다면 다음 기준을 따르십시오.

| 구분 | **특성 (Trait)** | **지속 능력 (Passive Skill)** | **발동 능력 (Active Skill)** |
| :--- | :--- | :--- | :--- |
| **정의** | **"타고난 것 / 그냥 그런 것"** | **"수련이나 마법으로 얻은 상시 효과"** | **"의지를 가지고 사용하는 기술"** |
| **예시 (비행)** | **날개 (Wings)**<br>신체 기관이 있어서 그냥 날 수 있음. | **비행 숙련 (Flight Mastery)**<br>비행 중 회피율이 증가하는 기술적 보정. | **비행 마법 (Fly)**<br>마나를 소모하여 일시적으로 날아오름. |
| **예시 (신체)** | **강철 피부 (Steel Skin)**<br>피부 자체가 단단함. | **고통 내성 (Pain Resistance)**<br>고통을 참아내는 정신적/육체적 훈련 상태. | **철갑화 (Iron Body)**<br>일시적으로 피부를 강철로 바꿈. |
| **속성** | 선천적, 생리적, 불변(대체로), 배경 설정 | 후천적, 기술적, 가변, 성장 가능 | 소모적(마나/체력), 순간적, 조작 가능 |
| **불이익** | **가능 (약점, 페널티)**<br>예: 태양광 취약, 이동 불가 | **드묾**<br>주로 이로운 보정 효과. | **대가 (Cost)**<br>사용 시 자원 소모나 반동. |

## 2. 13대 특성 카테고리 (Trait Categories)

새로운 특성을 생성할 때는 다음 13가지 카테고리 중 가장 적합한 곳에 분류해야 합니다.

### **00. 유형 (Type)**
*   **정의:** 존재의 생물학적 종족, 본질적 분류.
*   **예시:** 인간형, 언데드, 정령, 기계, 야수, 슬라임
*   **질문:** "이 존재는 생물학적으로 무엇입니까?"

### **01. 크기 (Size)**
*   **정의:** 물리적인 체급과 공간 점유.
*   **예시:** 소형(고블린), 중형(인간), 거대(드래곤), 초소형(요정)
*   **질문:** "얼마나 큽니까?"

### **02. 기원 (Origin)**
*   **정의:** 태생적 배경, 출처, 서사적 근원.
*   **예시:** 이계의 존재, 인공 생명체, 자연 발생, 신의 창조물, 용의 혈통
*   **질문:** "어디서, 어떻게 태어났습니까?"

### **03. 신체 (Physical)**
*   **정의:** 육체적 특징, 구조, 외형. (가장 많은 특성이 포함됨)
*   **예시:** 강철 피부, 맹독 혈액, 날카로운 발톱, 다수의 눈, 재생 불가 부위
*   **질문:** "몸이 어떻게 생겼거나 구성되어 있습니까?"

### **04. 지성 (Intellect)**
*   **정의:** 지능 수준, 연산 능력, 지식 습득 방식, 통신 수단. (**하드웨어적 지능**)
*   **예시:** 고지능, 텔레파시, 군집 의식, 마법적 지식, 언어 해독
*   **질문:** "얼마나 똑똑하며, 어떻게 생각하고 소통합니까?"

### **05. 군집 (Social)**
*   **정의:** 사회적 구조, 무리 생활 방식, 계급.
*   **예시:** 절대적 상명하복, 독자 행동, 여왕 중심 사회, 용병단
*   **질문:** "혼자 다닙니까, 무리를 짓습니까? 사회 구조는 어떻습니까?"

### **06. 이동 (Mobility)**
*   **정의:** 주된 이동 방식이나 기동 특성. (**'이동 기술'이 아닌 '이동 방식'**)
*   **예시:** 비행, 부유, 굴착, 순간이동(종족 특성), 벽 타기
*   **질문:** "어떻게 움직입니까?"

### **07. 감각 (Senses)**
*   **정의:** 주변 환경을 인지하는 감각 기관의 능력.
*   **예시:** 야간 시야, 열 감지, 마력 감지, 진동 감지, 천리안
*   **질문:** "무엇을 볼 수 있고 느낄 수 있습니까?"

### **08. 약점 (Weakness)**
*   **정의:** 치명적인 결함, 취약점, 공포 대상.
*   **예시:** 태양광 취약, 은 취약, 불 공포증, 핵(Core) 노출
*   **질문:** "무엇에 닿으면 죽거나 무력화됩니까?"

### **09. 생활 (Life)**
*   **정의:** 직업, 역할, 생태적 지위, 식습관을 제외한 일상 활동.
*   **예시:** 대장장이, 수호자, 약탈자, 수집가, 기록자
*   **질문:** "싸우지 않을 때는 무엇을 하며 지냅니까?"

### **10. 정신 (Mind)**
*   **정의:** 성격, 의지, 신념, 광기, 트라우마. (**소프트웨어적 정신**)
*   **예시:** 불굴의 의지, 복수심, 공포 면역, 광기, 헌신
*   **질문:** "어떤 마음가짐이나 정신 상태를 가지고 있습니까?"

### **11. 지역환경 (Environment)**
*   **정의:** (주로 장소에 부여됨) 자연, 문명, 던전, 재해 등 장소의 모든 환경적 특징.
*   **예시:** 마나 과잉 지대, 슬럼가, 마탑, 산성비 지대, 고대 결계
*   **질문:** "그곳은 어떤 지형, 기후, 시설, 위험 요소를 가지고 있습니까?"

### **12. 외교 (Diplomacy)**
*   **정의:** 대외적 태도, 외교 성향, 정치적 입장.
*   **예시:** 중립주의, 패권주의, 배타주의, 사대주의, 인질 외교
*   **질문:** "다른 세력을 어떻게 대합니까?"

### **13. 경영 (Management)**
*   **정의:** 국가, 영지, 단체의 내정, 경제, 행정, 인프라 운영 능력.
*   **예시:** 특산물 독점, 효율적 관료제, 마나 통신망, 장인 정신, 공포 정치
*   **질문:** "이 조직은 무엇으로 돈을 벌고, 어떻게 내부를 통치합니까?"

## 3. 적용 지침

1.  **우선 순위:** '타고난 것' > '지속 능력' > '발동 능력'.
2.  **중복 방지:** 이미 `특성`에 있는 내용을 `지속 능력`으로 또 만들지 마십시오. (예: '비행' 특성이 있으면 '비행' 지속 능력은 불필요. 단, '고속 비행' 같은 강화 기술은 가능)
3.  **레고 블록:** 몬스터의 특성이라도 인물에게 적용할 수 있습니다. (예: 인물에게 '야수' 유형의 '광폭화' 특성 부여 가능)
