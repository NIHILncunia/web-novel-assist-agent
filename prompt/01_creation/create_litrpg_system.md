# 기능: 상태창 및 시스템 설계 (LitRPG System Design)

> **작성일:** 2026-01-17

## 1. 개요
이 문서는 **게임 판타지, 상태창(Status Window), 시스템(System)** 요소가 등장을 하는 작품을 위한 설계 지침입니다. 사용자 인터페이스(UI)부터 성장 메커니즘까지 구체화합니다.

## 2. 인터뷰 프로세스 (5 Axes)

### Axis 1. 인터페이스 (UI & Visual)
> "상태창은 어떻게 보입니까?"
- **시각:** 홀로그램, 망막 투사, 허공에 뜬 글자, 낡은 양피지
- **타인 노출:** 사용자만 보임 / 타인도 볼 수 있음 / 특정 스킬로 확인 가능

### Axis 2. 능력치 (Stats & Attributes)
> "강함을 어떤 수치로 표현합니까?"
- **기본 스탯:** 힘(STR), 민첩(AGI), 지능(INT) 등 고전적 방식
- **특수 스탯:** 운(LUK), 매력(CHR), 신성력, 광기 등 고유 스탯

### Axis 3. 성장 방식 (Progression)
> "어떻게 강해집니까?"
- **레벨업:** 경험치 축적 → 레벨 상승 → 스탯 포인트 분배
- **숙련도:** 행동 반복 → 해당 스킬 레벨 상승
- **업적:** 특정 조건 달성 → 칭호 및 보상 획득
- **아이템:** 장비 파밍 의존

### Axis 4. 스킬 및 클래스 (Skills & Classes)
> "직업과 기술 체계는 어떻습니까?"
- **클래스:** 전직 시스템, 히든 클래스 존재 여부
- **스킬:** 스킬북 습득 / 자력 깨달음 / 시스템 상점 구매

### Axis 5. 시스템의 기원 (Origin)
> "이 시스템은 누가, 왜 만들었습니까?"
- **정체:** 신의 유희 / 초고대 문명의 유산 / 우주의 법칙 / 게임 운영자
- **목적:** 인간 육성 / 엔터테인먼트 / 멸망 대비 / 알 수 없음

## 4. 출력 예시

```markdown
# 각성자 시스템 (Awakener System)

## 1. 인터페이스
푸른색 반투명 홀로그램 창. 생각만으로 열고 닫을 수 있음. 본인만 볼 수 있음.

## 2. 능력치
* 근력 / 체력 / 민첩 / 마력 / **감각(Sense)**
* '감각'이 높으면 위험 감지 및 몬스터 약점 포착 가능.

## 3. 성장
몬스터 사냥 시 '에테르' 흡수. 레벨업 시 모든 신체 능력 자동 상승 및 포인트 2 지급.

## 4. 스킬
* 10레벨마다 '특성'이 개방됨.
* 몬스터의 '정수(Essence)'를 흡수하여 스킬 습득 가능.

## 5. 기원
현재 불명. '튜토리얼'이 끝나면 진실을 알려주겠다는 메세지만 있음.
```
