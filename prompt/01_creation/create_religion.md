# 기능: 종교 및 신앙 생성 (Religion Creation)

> **작성일:** 2026-01-17

## 1. 개요
이 문서는 세계관 내의 **종교, 신앙, 교단, 이단**을 설계하는 지침입니다. 신의 존재 여부부터 교리와 의식, 그리고 사회적 권력 구조까지 구체화합니다.

## 2. 인터뷰 프로세스 (5 Axes)

### Axis 1. 신격 (Deity)
> "무엇을 믿습니까? 그리고 그 대상은 실존합니까?"
- **대상:** 유일신 / 다신 / 자연령 / 조상신 / 개념(빛, 어둠) / 무신론
- **실존 여부:** 실제 기적을 행함 / 침묵함 / 존재하지 않음(허구)

### Axis 2. 교리 (Doctrine)
> "무엇을 가르치고, 무엇을 금지합니까?"
- **핵심 가치:** 사랑, 정의, 희생, 순수, 파괴, 쾌락
- **금기:** 살인, 이교도와의 접촉, 특정 음식, 마법 사용

### Axis 3. 조직 (Organization)
> "교단은 어떻게 운영됩니까?"
- **구조:** 중앙 집권형(교황청) / 분권형(개별 사원) / 비밀 결사
- **성직자:** 사제, 팔라딘, 무녀, 샤먼

### Axis 4. 의식과 관습 (Ritual)
> "신앙을 어떻게 표현합니까?"
- **의식:** 예배, 기도, 제물(동물/인신), 명상, 축제
- **상징:** 성물, 성표, 복장, 건축 양식

### Axis 5. 영향력 (Influence)
> "이 종교는 세상에 얼마나 큰 힘을 가집니까?"
- **정치:** 국교(정교일치) / 탄압받는 종교 / 독립적 세력
- **사회:** 일상 생활을 지배함 / 개인적 신앙에 불과함

## 4. 출력 예시

```markdown
# 성광교 (Order of the Holy Light)

## 1. 신격
빛의 여신 '루미나'. 실존하며, 고위 사제들에게 신성력을 부여함.

## 2. 교리
"어둠을 몰아내고 약자를 보호하라." 언데드와 흑마법을 극도로 혐오하며, 정화하는 것이 의무임.

## 3. 조직
교황을 정점으로 한 중앙 집권적 구조. 이단심문관과 성기사단(Paladin)을 보유함.

## 4. 의식
매일 아침 해가 뜰 때 기도를 올림. 중요한 날에는 '정화의 불꽃' 축제를 염.

## 5. 영향력
제국의 국교. 황제 대관식을 주관할 정도로 강력한 정치적 권한을 가짐.
```
