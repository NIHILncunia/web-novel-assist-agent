# 기능: 발동 능력 생성 (Active Ability Creation)

> **작성일:** 2026-01-14
> **수정일:** 2026-01-23

## 1. 개요
이 문서는 소설 세계관 설계를 위한 **발동 능력(Active Ability)** 생성 지침입니다. 의식적인 의지, 특정 조건, 자원 소모 등을 통해 사용하는 '행동'에 해당하는 능력을 체계적으로 생성합니다.

**⚠️ 중요:** 작명 및 생성 시 반드시 `manuals/97_trait_and_naming_rules.md`의 규칙(모듈화, 이중 수식 금지 등)을 준수하십시오.
**⚠️ 기준 참고:** 이것이 '특성'인지 '발동 능력'인지 헷갈린다면 `prompt/01_creation/create_trait.md`의 기준표를 확인하십시오. '의지'와 '소모'가 동반되어야 발동 능력입니다.

## 2. 생성 지침
다음 기준에 따라 최소 5개 이상의 새로운 발동 능력을 브레인스토밍하여, `data/skill/발동.md` 파일의 테이블 형식에 맞춰 제안하십시오.

*   **기반:** 캐릭터/몬스터의 '특성'(`data/traits/` 참조)이나 기존 '지속 능력'(`data/skill/지속.md` 참조)에서 논리적으로 파생될 수 있어야 합니다.
*   **명확한 효과:** 능력이 발동했을 때 어떤 결과가 나타나는지 구체적으로 묘사합니다.
*   **사용 조건 및 제약:** 발동에 필요한 자원(마나, 기력, HP 등), 재사용 대기시간, 특정 조건 등을 명시합니다.

### 2-1. 발동 능력 속성
| 속성       | 설명                                                                                                                                                                                                                            |
| :--------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **이름**   | 능력의 이름입니다. (예: 화염구 투척, 그림자 은신)                                                                                                                                                                                           |
| **계통**   | 능력의 근본적인 유형입니다. 아래 **[2-2. 허용된 값 목록]**을 반드시 따르십시오.                                                                                                                                                           |
| **대상**   | 능력의 영향을 받는 대상입니다. 아래 **[2-2. 허용된 값 목록]**을 반드시 따르십시오.                                                                                                                                                                     |
| **피해 유형** | 능력이 피해를 준다면, 그 유형입니다. 아래 **[2-2. 허용된 값 목록]**을 반드시 따르십시오.                                                                                                                                                        |
| **상태 이상 유형** | 능력이 부여하는 상태 이상입니다. 아래 **[2-2. 허용된 값 목록]**을 반드시 따르십시오.                                                                                                                                                              |
| **설명**   | 능력의 효과를 서사적이고 자연스러운 문장으로 서술합니다. (예: "허공에서 화염구를 생성하여..." ) |

### 2-2. 허용된 값 목록 (Allowed Values)
다음 속성은 반드시 아래 목록에 있는 값 중 하나를 선택해야 합니다.

*   **계통:** 물리, 원소, 정신, 소환, 치유, 생산, 특수
*   **대상:** 자신, 단일, 다수, 범위, 탈것, 해당 없음
*   **피해 유형:** 해당 없음, 물리, 참격, 관통, 타격, 화염, 냉기, 전기, 산성, 독, 광휘, 폭풍, 수류, 플라즈마, 정신, 사령, 저주, 어둠, 폭발, 방사능, 역장, 공허, 고정
*   **상태 이상 유형:** 해당 없음, 강화, 도발, 넘어짐, 출혈, 심층 창상, 신체 훼손, 방어구 관통, 기절, 골절, 넉백, 침묵, 화상, 공포, 부식, 동상, 동결, 둔화, 마비, 감전, 중독, 실명, 혼란, 표적, 젖음, 질식, 수면, 광분, 부패, 허약, 오염, 변이, 속박, 속박됨, 소멸, 처형

---

## 3. 결과물 저장
생성된 발동 능력은 `data/skill/발동.md` 파일에 누적 저장됩니다. 새로운 능력 생성 시, 해당 파일에 이미 동일한 이름의 능력이 있는지 확인하고 중복되지 않도록 합니다.
