# 기능: 마법 체계 설계 (Magic System Design)

> **작성일:** 2026-01-17

## 1. 개요
이 문서는 세계관의 근간이 되는 **마법, 초어빌리티, 이어빌리티** 시스템을 설계하는 지침입니다. 단순히 "마법이 있다"를 넘어, 마법의 원리, 대가, 한계, 그리고 사회적 영향을 구체화하여 개연성 있는 시스템을 구축합니다.

## 2. 인터뷰 프로세스 (5 Axes)

### Axis 1. 원천 (Source)
> "마법의 힘은 어디서 옵니까?"
- **옵션:** 마나(대기 중), 내공(신체 내부), 신성력(신), 정령, 악마 계약, 혈통
- **질문:** 그 힘은 무한합니까, 고갈됩니까?

### Axis 2. 대가와 리스크 (Cost & Risk)
> "마법을 사용하면 무엇을 잃습니까?"
- **비용:** 마나 소모, 체력 고갈, 수명 단축, 정신력 소모, 재료(촉매)
- **리스크:** 폭주 위험, 광기, 육체 변이, 사회적 낙인

### Axis 3. 학습과 발현 (Acquisition)
> "마법은 어떻게 배웁니까?"
- **선천적:** 혈통, 재능, 돌연변이 (Sorcerer형)
- **후천적:** 학습, 연구, 수련 (Wizard형)
- **외부적:** 계약, 선물, 기생 (Warlock형)

### Axis 4. 범위와 한계 (Scope & Limit)
> "마법으로 할 수 없는 것은 무엇입니까?"
- **규칙:** 죽은 자 소생 불가, 시간 여행 불가, 무에서 유 창조 불가
- **강도:** 산을 부술 수 있는가? 촛불을 켤 정도인가?

### Axis 5. 사회적 영향 (Societal Impact)
> "마법은 세상에 어떤 영향을 주었습니까?"
- **인식:** 경외의 대상 vs 공포의 대상 vs 일상적인 도구
- **제도:** 마법사 면허제, 마법 학교, 마법 금지법
- **기술:** 마도 공학(Magitech)의 존재 여부

## 4. 출력 예시

```markdown
# 서클 마법 체계 (Circle Magic System)

## 1. 원천
대기 중에 존재하는 '마나'를 심장 근처의 마나 홀(Circle)에 축적하여 사용.

## 2. 대가
마나 고갈 시 극심한 두통과 탈진. 과도한 사용은 혈관 파열을 유발(마나 역류).

## 3. 학습
철저한 계산과 이해를 통한 학문적 접근. 서클을 형성하는 데 수십 년의 수련이 필요함.

## 4. 한계
죽은 자를 되살릴 수 없으며, 시전자의 연산 어빌리티를 초과하는 마법은 실패함.

## 5. 사회
마법사는 국가의 중요 전략 자원으로 대우받으며, 철저한 통제를 받음. 마탑 연합이 모든 마법사를 관리함.
```
