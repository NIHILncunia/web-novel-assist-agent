# 기능: 단체 생성 (Organization Creation)

> **작성일:** 2026-01-04
> **수정일:** 2026-01-04

## 1. 개요
이 문서는 판타지 세계관 설계를 위한 **단체 데이터 관리자**의 작업 지침입니다. 단체 생성은 총 7개의 축(Axis)에 포함된 **세부 항목(Sub-Axis)**을 인터뷰 형식으로 채워나가는 과정입니다.

---

## 2. 저장 위치 (Storage Location)

단체 설정 파일은 각 소설 작품 폴더 내 `00_bible/04_organizations/` 디렉토리에 저장됩니다.

- **저장 경로:** `[프로젝트폴더]/00_bible/04_organizations/[Organization_Name].md`
- **예시:** `projects/제국의_검/00_bible/04_organizations/단체_은연.md`

**참고:** 
- 작품명이 확정되지 않은 경우 `incubator/[가제_컨셉명]/00_bible/04_organizations/` 폴더에 저장
- 작품명 확정 후 `projects/[작품명]/00_bible/04_organizations/` 폴더로 이동

---

## 3. 작업 모드 (Operation Modes)

각 **세부 항목(Sub-Axis)**마다 사용자는 다음 두 가지 중 하나를 선택합니다.

1. **지정 (Select):** 사용자가 구체적인 내용이나 키워드를 직접 제시.
2. **위임 (Delegate):** "랜덤", "알아서", "추천해줘" 등. 에이전트가 맥락에 맞춰 제안.

---

## 4. 인터뷰 지침 (Interview Process)

에이전트는 다음 7가지 축을 순차적으로 확인합니다. 사용자의 피로도를 고려하여 관련 있는 항목은 묶어서 질문하십시오.

### Axis 1. 개요 (Overview)
단체의 정체성을 정의하는 첫 단계입니다.

| 세부 항목 | 에이전트 질문 메시지 (Prompt) |
|:---|---|
| **한 줄 정의** | 이 단체를 한 문장으로 요약한다면 무엇입니까? |
| **설립 시기** | 이 단체는 언제 설립되었습니까? |
| **설립자** | 누가 이 단체를 설립했습니까? |
| **핵심 테마** | 이 단체를 대표하는 핵심 가치나 이념은 무엇입니까? (`data/word_list/character/성향가치관.md`를 참조하여 '집단의 성격'을 부여할 수 있습니다.) |

### Axis 2. 목적 및 설립 이유 (Purpose & Foundation)
단체의 존재 이유를 정의합니다.

| 세부 항목 | 에이전트 질문 메시지 (Prompt) |
|:---|---|
| **명시적 목적** | 이 단체가 외부에 알려진 공식적인 목적은 무엇입니까? |
| **숨겨진 목적** | 실제로는 어떤 숨겨진 목적을 가지고 있습니까? (없을 수도 있음) |
| **설립 배경** | 어떤 사건이나 필요에 의해 설립되었습니까? 설립 당시 상황과 설립 동기는 무엇입니까? |

### Axis 3. 구성과 계층 (Structure & Hierarchy)
단체의 조직 구조를 정의합니다.

| 세부 항목 | 에이전트 질문 메시지 (Prompt) |
|:---|---|
| **조직 구조** | 조직의 형태는 무엇입니까? (수직적/수평적, 중앙집권/분권 등) 계급이나 직위 체계는 어떻게 구성되어 있습니까? |
| **인원 규모** | 대략적인 구성원 수는 얼마나 됩니까? 각 계급별 인원은 어떻게 분포되어 있습니까? |
| **가입 조건** | 누구나 가입할 수 있나요? 특정 조건이나 자격이 필요합니까? 가입 절차는 무엇입니까? |
| **탈퇴/배신 처리** | 조직을 떠나거나 배신하면 어떻게 됩니까? 처벌 방법이나 조치는 무엇입니까? |

### Axis 4. 활동영역 (Activities & Operations)
단체의 실제 활동을 정의합니다.

| 세부 항목 | 에이전트 질문 메시지 (Prompt) |
|:---|---|
| **주요 활동** | 이 단체가 주로 하는 일은 무엇입니까? 일상적 활동, 핵심 업무, 특수 임무는 무엇입니까? |
| **활동 지역** | 주로 어느 지역에서 활동합니까? 본부나 지부의 위치는 어디입니까? 영향력 범위는 어디까지입니까? |
| **활동 방식** | 합법적/비합법적, 공개적/비밀적 등 활동 스타일은 무엇입니까? 활동 수단과 자금원/수입원은 무엇입니까? |

### Axis 5. 관계망 (Relations)
다른 세력과의 관계를 정의합니다. `data/traits/12_외교.md`를 참조하여 단체의 대외적 성향(예: 중립주의, 기회주의)을 먼저 정의하십시오.

| 세부 항목 | 에이전트 질문 메시지 (Prompt) |
|:---|---|
| **동맹 단체** | 협력 관계에 있는 다른 단체나 국가가 있습니까? 공동 목표는 무엇입니까? |
| **적대 단체** | 대립하거나 적대하는 단체나 국가가 있습니까? 갈등 원인은 무엇입니까? |
| **중립 관계** | 특별한 관계 없이 중립을 유지하는 곳은 어디입니까? 거래나 협상 관계는 있습니까? |
| **주요 인물** | 이 단체와 깊이 연관된 핵심 인물이 있습니까? (조직 대표, 외부 연락책 등) |

### Axis 6. 역사적 사건 (Historical Events)
단체와 관련된 역사적 맥락을 정의합니다.

| 세부 항목 | 에이전트 질문 메시지 (Prompt) |
|:---|---|
| **과거 사건** | 이 조직과 관련된 주요 역사적 사건, 전쟁, 분쟁, 관련 인물이 있습니까? |
| **연관 사건** | 관련된 다른 사건이 있습니까? 그 사건이 이 조직에 어떤 영향을 미쳤습니까? |
| **현재 상태** | 과거 사건으로 인해 현재 이 조직의 모습이 어떻게 변화했습니까? |

### Axis 7. 비고 (Notes)
추가 설정을 정의합니다.

| 세부 항목 | 에이전트 질문 메시지 (Prompt) |
|:---|---|
| **비밀** | 외부에 알려지지 않은 단체의 비밀이 있습니까? |
| **전설/역사** | 단체와 관련된 유명한 전설이나 역사적 사건이 있습니까? |
| **서사적 떡밥** | 나중에 밝혀질 예정인 설정이나 떡밥이 있습니까? |
| **연관 문서** | 이 단체와 관련된 다른 설정 문서(인물, 지역, 국가 등)가 있습니까? |

## 6. 데이터 저장 지침

### 6-1. 저장 위치

단체 설정 파일은 각 소설 작품 폴더 내 `00_bible/04_organizations/` 디렉토리에 저장됩니다.

- **저장 경로:** `[프로젝트폴더]/00_bible/04_organizations/[Organization_Name].md`
- 작품명이 확정되지 않은 경우 `incubator/[가제_컨셉명]/00_bible/04_organizations/` 폴더에 저장
- 작품명 확정 후 `projects/[작품명]/00_bible/04_organizations/` 폴더로 이동

### 6-2. 저장 규칙

1. **중복 확인:** 동일한 이름의 단체가 이미 존재하는지 확인합니다.
2. **연관 문서:** 관련된 다른 설정 문서(국가, 지역, 인물 등)가 있으면 연관문서 필드에 링크합니다.
3. **내부 갈등:** 조직 내부의 파벌이나 갈등이 있다면 명확히 기록합니다.

## 7. 작업 프로세스 요약

1. **단체 타입 결정:** 새로운 단체 생성 또는 기존 단체 수정
2. **인터뷰 진행:** 7가지 축(Axis)별 세부 항목을 질문하여 채움
3. **템플릿 적용:** 완성된 내용을 템플릿 형식에 맞춰 작성
4. **저장:** 지정된 저장 경로에 파일 생성
5. **가이드 확인:** `manuals/05-04_organizations_guide.md`의 체크리스트로 최종 검토
