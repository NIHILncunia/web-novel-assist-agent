# 기능: 플롯 생성 (Plot Creation)

> **작성일:** 2026-01-16
> **수정일:** 2026-01-16

## 1. 개요
이 문서는 시놉시스(Step 4)를 바탕으로, 실제 집필 가능한 단위인 **'아크(Arc)'**와 **'에피소드(Episode)'**를 설계하는 **[Step 6] 플롯 아웃라인** 단계의 작업 지침입니다.

---

## 2. 작업 프로세스

### Phase 1. 총 분량 및 속도 설정
1.  **총 화수:** 작품의 목표 완결 화수(예: 200화, 300화)를 마스터와 협의하여 결정합니다.
2.  **전개 속도:** 초반/중반/후반의 호흡(Pacing) 전략을 수립합니다. (예: 초반 15화까지 빠른 전개로 독자 유입 유도)

### Phase 2. 아크 할당 (Arc Allocation)
1.  전체 화수를 덩어리(Arc)로 나눕니다.
2.  기존 시놉시스의 기-승-전-결 흐름을 각 아크에 매핑합니다.
3.  아직 구체적인 사건이 없는 후반부 아크라도, **'확보된 화수(Slot)'**와 **'예상되는 핵심 목표'**는 반드시 기재합니다.

### Phase 3. 에피소드 매핑 (Episode Mapping)
1.  각 아크를 채울 구체적인 에피소드 리스트를 작성합니다.
2.  각 에피소드는 **'핵심 사건 한 줄 요약'** 형태로 기술합니다.
3.  **클라이맥스:** 아크의 마지막에는 갈등이 해소되거나 폭발하는 클라이맥스 에피소드를 배치합니다.

### Phase 4. 페이스 점검 및 출력
1.  작성된 플롯의 강약 조절(고구마/사이다 배분)을 점검합니다.
2.  `_templates/Sheets/06_story_arc_sheet.md` 양식에 맞춰 최종 결과물을 작성합니다.

---

## 3. 인터뷰 지침

에이전트는 다음 순서로 마스터와 소통하며 플롯을 완성합니다.

| 순서 | 단계 | 질문 예시 |
|:---:|:---|:---|
| 1 | **분량 설정** | "이 작품의 완결 목표 화수는 몇 화로 생각하고 계십니까? (웹소설 표준: 200화 내외)" |
| 2 | **아크 설계** | "시놉시스의 흐름을 고려할 때, 이야기를 크게 몇 개의 챕터(아크)로 나누는 것이 좋을까요? (예: 튜토리얼 15화 -> 아카데미 35화...)" |
| 3 | **세부 매핑** | "[Arc 1]의 구체적인 에피소드를 채워보겠습니다. 주인공이 위기를 겪고 각성하는 과정을 5화 단위로 끊어서 구상해볼까요?" |
