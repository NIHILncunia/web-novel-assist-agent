# 캐릭터 분석 보고서: 셀 (Cell)

## 1. 분석 개요
**셀(Cell)**은 우주 최강의 전사들의 세포를 채취하여 융합해 만든 궁극의 인조인간입니다. 그의 목표는 완전체가 되어 자신의 힘을 시험하고 공포를 퍼뜨리는 것입니다.

## 2. 핵심 컨셉 키워드 (Key Concepts)
1.  **유전적 융합 (Genetic Synthesis):** 전투 종족, 재생 종족, 우주 폭군 등의 유전자를 모두 가진 하이브리드 생명체.
2.  **생체 흡수 (Bio-Absorption):** 생명 에너지를 빨아들이거나 상대를 통째로 삼켜 진화하는 포식자.
3.  **데이터의 집대성 (Data Compilation):** 수많은 무술가들의 기술과 패턴이 입력된 살아있는 무기고.
4.  **완전체 (Perfect Form):** 결함을 극복하고 신에 근접한 힘을 얻은 상태이자, 그에 따른 오만함.
5.  **교활한 지략 (Cunning Intellect):** 목적 달성을 위해 은신, 기만, 심리전을 구사하는 지능형 악당.

## 4. 자가 점검 (Self-Verification)
1. **키워드:** 유전적 융합, 생체 흡수, 데이터의 집대성, 완전체, 교활한 지략 (5개 충족)
2. **데이터 수량:** 키워드별 직접 추출 3개 + 브레인스토밍 5개 = 총 40개 아이템 생성 완료.
3. **형식 준수:** 제안 사유 필드 추가 및 설명 내 고유명사 제거 원칙 준수.
4. **표현 규칙:** 제안 사유에는 사이어인, 피콜로, 셀 게임 등 원작 표현을 사용하여 근거를 명확히 함.
